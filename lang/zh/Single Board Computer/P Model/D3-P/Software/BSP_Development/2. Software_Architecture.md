# 2. 软件架构

图 2.1 显示了 TCC8050 的软件架构。三个核心由以下功能组成，各核心之间通过 IPC 交换信息。

TCC8050 使用 CA72（主核心）提供多媒体功能，CA53（副核心）在运行期间提供主核心的即时处理（例如后视摄像头）。CR5 提供实时 OS，以提供与汽车通信所需的功能。
