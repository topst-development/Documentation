## 1.1 功能框图

TCC8050 提供 Car Audio Video Navigation (AVN)、数字仪表盘和 Around View Monitor (AVM) 等一系列解决方案。TCC8050 集成了 ARM® Cortex-A72 多核处理器以及 Cortex-A53 多核处理器、用于微处理器的 Cortex-R5、用于汽车安全的安全子系统中 Hardware Security Module (HSM) 的 SC000 内核、用于存储管理的 Cortex-M4、Cortex-M4 子系统中用于 TSDEMUX 的另一个 Cortex-M4，以及硬连线的 Video Processing Unit (VPU)/Graphics Processing Unit (GPU)，从而将多媒体体验提升至最高水平。硬连线 VPU 支持视频编码和解码，GPU 则通过 OpenGL ES1.1/2.0/3.2 和 OpenCL 1.0/1.1/2.0 提供 3D 图形。TCC8050 支持 Linux® 和 Android™ 等多种操作系统。

TCC8050 是针对需要便捷连接功能的网络设备而优化的处理器：USB 3.0、USB 2.0 Device/Host 和 USB 2.0 Host 控制器实现了多媒体设备与存储设备之间的数据传输。Ethernet MAC 控制器提供符合 IEEE802.3 标准的互联网连接。此外，PCI Express (PCIe) Gen 3 为外部 IP 互连提供了高带宽。

这一创新且丰富的功能集扩展了可与 TCC8050 配合使用的应用类别，以满足不断发展的技术与市场需求。
