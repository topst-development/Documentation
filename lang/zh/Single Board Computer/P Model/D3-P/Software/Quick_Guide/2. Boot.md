#  2. 启动指南

本章介绍如何启动 TOPST D3 并登录到各个核心。

<br><br>

## 2.1 启动顺序

***FWDN*** 的下载顺序如下：

1. 连接用于 DP 显示器的 DP 线缆。
2. 连接调试板与 TOPST D3。
3. 将各条 TOPST USB 线缆连接到调试板，以便登录控制台并对各个核心进行调试。
4. 连接 5V 电源。

<br><br>
