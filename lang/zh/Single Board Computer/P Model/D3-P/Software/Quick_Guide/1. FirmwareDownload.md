# 1. FWDN 指南

本章介绍如何将 Firmware Downloader（***FWDN***）下载到 TOPST D3 并登录 Linux 控制台。

<br><br>

## 1.1   固件下载顺序

***FWDN*** 的下载顺序如下：

1. 进入 FWDN 模式。
2. 将 USB A-to-A 线缆连接到 USB 2.0 FWDN 端口。
3. 下载 TOPST 映像。

<br><br>

## 1.2   进入 FWDN 模式

按住 **SW2**（FWDN Mode Convert）按钮并接通电源即可进入 ***FWDN*** 模式。或者，如果已接通电源，按住 **SW2** 按钮（FWDN Mode Convert）并按下 **SW1** 按钮（System Reset）即可进入 ***FWDN*** 模式。

## 1.3 使用 CLI 工具在 Windows 环境下运行 FWDN
  
要使用 FWDN，请从下面的链接下载固件工具：

- <[FWDN Tool](https://drive.google.com/file/d/1UzArkpt-Aw67YhAMtlSfkELEHYBMBqT7/view?usp=sharing)>

您可以按如下方式下载以下各个 TOPST 映像。

- 脚本位置: topst.d3.pre.20240425001\fwdn.bat


```
.\fwdn.bat
```
在下图中，使用 .\fwdn.bat 命令下载了完整的 TOPST 映像。
按下 SW1（Reset）按钮重启 TOPST D3 后，将会执行 Ubuntu 启动器。
