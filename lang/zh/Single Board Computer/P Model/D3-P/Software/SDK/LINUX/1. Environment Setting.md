#  1. 设置主机环境

<br><br>

## 1.1 Ubuntu 安装

由于 TOPST D3 Linux SDK 基于 Yocto Project，因此 TOPST D3 SDK 的 Linux 版本遵循 Yocto 项目。

您也可以安装其他版本的 Linux，但本文档以 Ubuntu 22.04 为基础介绍 TOPST D3 Linux SDK。

Linux 发行版版本：

- Ubuntu 22.04 (LTS)

<br/><br/>

## 1.2 安装 WSL2 Ubuntu 

1. 以“**以管理员权限运行**”方式启动 Windows PowerShell
2. 启用 WSL2 系统。
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. 启用虚拟机功能。
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. 将 WSL 2 设置为默认版本。
    ```
    wsl --set-default-version 2
    ```
5. 在 Microsoft Store 中搜索 Ubuntu 22.04.3 LTS 并下载。

    * 如果需要下载 Linux 内核更新包，请从[此处](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)下载最新的软件包。


<br/><br/>

## 1.3 设置 Linux 环境

<br>

### 1.3.1 安装 SSH 和 Samba

安装虚拟机后，您可以使用 SSH 和 Samba 等附加工具，以获得更便捷的开发环境。SSH 和 Samba 允许您在远程计算机上执行命令，并将文件复制到其他计算机。

如果 SSH 和 Samba 已安装，或者您不打算使用它们，可以跳过本章。

使用以下命令安装 net-tools、SSH 和 Samba。

```
$ sudo apt install -y net-tools openssh-server samba
```


下载 SSH 和 Samba 后，您应根据自己的环境对每个程序进行设置。

<br>

### 1.3.2 实用工具

一次性安装这些实用工具。要使用 Yocto Project，必须在主机 PC（个人计算机或开发服务器）上安装以下实用工具。

使用以下命令安装实用工具。

```
$ sudo apt-get install -y gawk wget git diffstat unzip texinfo gcc-multilib build-essential chrpath

$ sudo apt-get install -y socat cpio python3 python3-pip python3-pexpect xz-utils debianutils

$ sudo apt-get install -y iputils-ping python3-git python3-jinja2 libegl1-mesa libsdl1.2-dev pylint

$ sudo apt-get install -y xterm zstd ncftp curl git-lfs vim zip
```

<br>

### 1.3.3 安装 Repo

如果已安装 Repo，则无需重新安装即可使用。  
在安装 Repo 之前，应正确设置已安装的 Python 版本（3.6 或更高）。

使用以下命令安装 repo。
```
$ sudo apt-get install repo
```

如果看到错误消息 '/usr/bin/env 'python' no such file or directory'，请使用以下命令使文件 'python' 指向 'python3'。

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
```
如果出现 Repo 错误，请使用以下命令下载最新版本并直接放入 /usr/bin/ 文件夹。

```
$ mkdir -p ~/bin

$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo > ~/bin/repo

$ chmod a+x ~/bin/repo

$ sudo mv ~/bin/repo /usr/bin/repo
```

### 1.3.4 Telechips USB 设备的 Udev 规则
执行以下命令后，在 Linux 中下载 FWDN 时无需使用 'sudo' 命令。
```
$ echo "SUBSYSTEM==\"usb\", ATTR{idVendor}==\"140e\", MODE=\"0666\", OWNER=\"${USER}\"" | sudo tee /etc/udev/rules.d/99-topst.rules
$ sudo udevadm control --reload-rules && sudo udevadm trigger
```
