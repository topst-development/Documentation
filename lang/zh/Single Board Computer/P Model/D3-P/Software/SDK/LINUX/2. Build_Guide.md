# 2. 构建指南

<br/><br/>

## 2.1 TOPST D3 Linux SDK 构建准备

TOPST D3 Linux SDK 基于 Yocto Project 3.1 Dunfell。因此，要使用 TOPST D3 Linux SDK，必须在主机 PC 上设置 Yocto Project 环境。要下载 SDK、source-mirror 和 tools，必须安装相关实用工具。  

<br/><br/>

## 2.2 Yocto Project  

Yocto Project 是一个专注于嵌入式 Linux 开发的开源项目。  
它结合使用 Open Embedded 项目（即 Poky）和 ***bitbake*** 作为构建系统来制作 Linux 镜像。  
使用 Yocto Project，您可以同时构建引导加载程序、内核和 rootfs。  

<br/><br/>
