# 3. 固件下载

本章介绍如何将 ***FWDN*** 下载到 TOPST D3（开放平台开发板）并登录 Linux 控制台。  
***FWDN V8*** 是用于在 Windows 10 64 位和 Linux 环境中下载固件的 PC 工具。本章介绍在 Windows 和 Linux 环境中下载的情况。

<br/><br/>

## 3.1 固件下载顺序

***FWDN*** 的下载顺序如下：

1. 将启动模式开关设置为 USB 启动模式。
2. 打开 Windows 命令提示符或 Linux 控制台并测试 ***FWDN V8***。
3. 将 ***FWDN V8*** 连接到开发板。
4. 下载 fai 文件。

<br/><br/>

## 3.2 通过 USB 启动连接 TOPST D3 与主机 PC

按住 **SW2** 并接通电源时，将启动 USB 启动流程。若不按 **SW2** 直接接通电源，则启动正常启动流程。

按下 **SW1** 会使系统复位。如果要下载固件，请同时按下 **SW1** 和 **SW2** 以 USB 模式启动。

## 3.3 准备下载 FWDN

1. 解压 "output.fwdn.zip" 
    ```
    $ mkdir images
    $ mv ./output.fwdn.zip ./images
    $ cd images
    $ unzip output.fwdn.zip
    ```
2. 将 "images" 文件夹复制到 Windows C 盘。
    ```
    $ cd ..
    $ cp -r /images /mnt/c/
    ```

## 3.5 Linux 环境中的 FWDN

在 Linux 环境中，可以使用 "./fwdn.sh" 命令下载 TOPST 镜像。

```
$ ./fwdn.sh
```

<br/><br/>

## 3.6 通过 UART 连接 TOPST

1. 使用 UART 连接来验证固件下载是否成功完成。
2. 在 Windows 环境中安装串口驱动程序 (CP210x Windows Driver)。([下载链接](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads))
3. 将启动模式更改为正常 (eMMC) 并重新启动。请使用 USB Type-C 转 USB 2.0 或 3.0 线缆，而非 C 转 C 线缆。
