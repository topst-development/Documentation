UART/JTAG 子板是用于串口和 JTAG 的调试板。使用 USB Type-C 线缆将 UART/JTAG 子板连接到主机 PC，即可查看串行日志。

**表 3.1 UART/JTAG 子板说明：**  

| 项目 | 说明                                           |

| u20  | 用于连接调试器的 Male Pin Header               |

| u40  | 用于 A53 Core 调试的 Debug 端口 (USB Type-C)   |
| u50  | 用于 A72 Core 调试的 Debug 端口 (USB Type-C)   |

## 3.4 将 UART/JTAG 子板连接到 TOPST D3  

本章介绍如何连接 TOPST D3 与 UART/JTAG 子板。  

按照以下步骤，使用柔性扁平电缆 (FFC) 将 UART/JTAG 子板连接到 TOPST D3：
1. 准备一根 FFC 和一根 USB Type-C 线缆。
2. 将 FFC 连接到 UART/JTAG 子板上的 Debug I/F 连接器和 TOPST D3 上的 Debug I/F 连接器。 <br/>
    * 连接时务必使 FFC 的蓝色线朝上。
3. 使用 USB Type-C 线缆将 UART/JTAG 子板连接到主机 PC。 <br/>
    * 请参阅表 3.1，根据目标内核选择合适的 UART 端口。例如，A72 UART 可连接到主内核（Cortex-A72 Quad）的 UART 端口。
4. 通过主机 PC 上的终端应用程序查看串行日志消息。

## 3.5 将 JTAG 调试器连接到 TOPST D3  

本章介绍如何将 JTAG 调试器连接到 TOPST D3。  

按照以下步骤将 JTAG 调试器连接到 TOPST D3：
1. 准备一台 JTAG 调试器。
2. 参照上面的“将 UART/JTAG 子板连接到 TOPST D3”一章，将 UART/JTAG 子板连接到 TOPST D3。
3. 将 JTAG 调试器连接到 UART/JTAG 子板上的 JTAG Header。
