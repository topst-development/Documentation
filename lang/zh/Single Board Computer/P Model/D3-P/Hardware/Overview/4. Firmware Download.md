# 4. 为下载固件将 TOPST D3 连接到主机 PC



Firmware Downloader(**FWDN**) 在主机 PC 上通过 USB 通信将 ROM 镜像写入 TOPST D3。  

TOPST D3 具有一个 Boot Mode 按钮，并通过该 Boot Mode 按钮支持以下两种启动模式：
- USB Boot Mode 用于使用主机 PC 上的 **FWDN** 程序写入 ROM 镜像。
- eMMC Boot Mode 用于使用存储在 eMMC 设备中的 ROM 镜像启动 TOPST D3。

**注意**：USB 2.0 D/H 端口用于固件下载器 (**FWDN**)。  

要使用 **FWDN**，请按以下方式将 TOPST D3 连接到主机 PC：
1. 检查主机 PC 上是否已安装 VTC 驱动程序。如果未安装 VTC 驱动程序，请按照 topst.ai 上提供的 **FWDN** 指南进行安装。
2. 准备一根 USB Type-A 线缆。
3. 使用 USB Type-A 线缆将 TOPST D3 上的 USB 2.0 D/H 连接到主机 PC。
4. 使用以下两种方法之一来更改 TOPST D3 的启动模式。<br/>
   1. 方法 1
       * 如果 TOPST D3 尚未通电，请按住 FWDN 按钮，然后为 TOPST D3 接入 5V 电源。
       * 松开 FWDN Boot mode 按钮。<br/>
   2. 方法 2
       * 如果 TOPST D3 已经通电，请按下 Reset 按钮和 FWDN Boot mode 按钮。
       * 松开 FWDN Boot mode 按钮。
5. 请按照 **FWDN** 指南下载您的 ROM 镜像。
