# 1. 简介


TOPST D3 是一款超小型、低功耗的计算机，配备微处理器、内存和输入/输出（I/O）端子。TOPST D3 可与多种传感器组合使用，包括运动、超声波、红外、LiDAR、电机驱动、车载通信收发器、麦克风和通信模块。  

如需支持，请查看 TOPST 网站（topst.ai）的硬件文档部分，并在 TOPST Technical Q&A 中发帖提问。

## 1.5 温度范围与散热  
建议的环境工作温度范围为 -10°C 至 55°C。   
当 TOPST D3 处于空闲状态或负载较轻时，TOPST D3 会通过动态电压频率调节（DVFS）方案降低 CPU 时钟频率和电压，以减少发热量。TOPST D3 无需任何额外的散热装置即可完美运行。如果您希望在诸如车规要求等扩展工作温度范围内以全性能运行，请联系 TOPST;topst@topst.ai
