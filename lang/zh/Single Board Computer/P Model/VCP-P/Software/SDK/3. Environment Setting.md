# 3. 环境设置

要成功进行 TOPST-VCP 开发板的开发，需要一个结构良好的开发环境。本章将指导您完成必要的步骤，为 Ubuntu 22.04 系统配置所有必需的工具、实用程序和软件包。

<br/><br/>

## 3.1 安装必需的工具和实用程序

在深入了解 TOPST-VCP 开发板的具体内容之前，安装一些基本的实用程序和工具至关重要。这些工具是后续其他软件和配置得以构建的基础。

1. **终端** : Ubuntu 22.04 自带终端。由于后续许多步骤都需要使用终端命令，请熟悉其用法。
2. **文本编辑器**: 虽然 Ubuntu 自带一个基本的文本编辑器，但您可以根据个人偏好考虑安装功能更强大的编辑器，如 “nano”、“vim”，或图形界面编辑器，如 “gedit”、“VSCode”。
3. **SSH 工具** : 在开发过程中，远程访问其他系统或设备（尤其是 TOPST- VCP 开发板）可能必不可少。多种 SSH 工具可以实现这一点：
4. **Putty** : 一款广受欢迎的免费开源终端仿真程序，支持 SSH 等多种协议。它轻量且易于使用。
5. **Tera Term** : 一款功能更为丰富的开源终端仿真程序，为包括 SSH 在内的各种通信协议提供广泛支持。

您可以根据自己的具体需求和偏好，选择其中一种或多种工具进行 SSH 访问。  

**供您参考，本指南文档使用 putty。**

<br/><br/>

## 3.2 使用 apt 安装软件

“apt” 软件包管理器是 Ubuntu 中的一款强大工具，可让您轻松安装、更新和管理软件包。

<br/>

### 3.2.1 更新软件包列表

在安装任何新软件之前，更新可用软件包的列表是一个良好的习惯。这可确保您获取最新的版本和依赖项。

```
$ sudo apt update
$ sudo apt upgrade
```

此命令会从软件源获取可用软件包的最新列表。

### 3.2.2 安装常用开发工具

对于大多数开发任务，尤其是针对 TOPST-VCP 开发板的任务，一些常用工具必不可少。

使用以下命令安装这些工具 :

```
$ sudo apt install build-essential git
```

此命令会同时安装 buide-essential 软件包和 git。
