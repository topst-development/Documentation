# 1. 简介

<br/><br/>

## 1.1 本指南的目的  

本指南旨在全面介绍如何在 Linux 系统上为 TOPST-VCP 开发板搭建软件开发环境。按照本文档中概述的步骤操作，开发人员将掌握有效使用 TOPST-VCP 开发板及其相关工具链所需的工具、配置和知识。

<br/><br/>

## 1.2 TOPST VCP 开发板概述  

TOPST-VCP 开发板是一款功能强大且用途广泛的开发板，专为各类应用而设计。该开发板的核心是基于 ARM Cortex-R5 架构构建的 TCC7045 芯片。这一组合确保了效率与性能之间的平衡，使其成为希望充分利用 ARM 架构应用性能的开发人员的首选。

## 1.3 工具链概述  

要在 TOPST-VCP 开发板上进行有效开发，配备合适的工具链至关重要。本指南特别推荐使用 gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi 进行交叉编译。该工具链不仅与 ARM Cortex-R5 架构兼容，还提供了一套针对 TCC7045 芯片优化的工具。
