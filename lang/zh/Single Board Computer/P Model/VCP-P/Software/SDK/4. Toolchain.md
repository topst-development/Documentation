# 4. 工具链

工具链是开发过程中的关键组成部分，在使用 TOPST-VCP 开发板等专用硬件时尤为重要。它提供了一整套工具，使开发者能够针对目标平台编译、链接和调试代码。

<br/><br/>

## 4.1 工具链概述

工具链通常由编译器、链接器、汇编器和调试器等工具组成。这些组件协同工作，将源代码转换为可在目标硬件上运行的可执行程序。由于硬件架构和平台种类繁多，选择并配置适合目标开发板的工具链至关重要

<br/><br/>

## 4.2 为开发板选择工具链

TOPST-VCP 开发板基于 ARM Cortex-R5 架构，推荐使用的工具链为 gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi。

该工具链针对 ARM 架构进行了优化，可确保与开发板上的 TCC7045 芯片兼容。

<br/><br/>

## 4.3 安装并设置工具链

请按照以下步骤下载、解压并设置工具链：

1. **下载工具链** : 使用 wget 命令从 Linaro 网站下载工具链 :

    ```
    $ wget https://releases.linaro.org/components/toolchain/binaries/7.2-2017.11/arm-eabi/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```

2. **解压工具链** : 下载完成后，解压 .tar.xz 文件的内容。

    ```
    $ tar -xvf gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```

3. **将工具链移动到 /opt** : /opt 目录是 Linux 上可选软件的标准存放位置。将解压后的工具链移动到该目录。

    ```
    $ sudo mv gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi /opt/
    ```

## 4.4 验证工具链安装

为确保工具链已正确安装：

1. **进入工具链目录** :

    ```
    $ cd /opt/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi
    ```

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/466c6ed7-4105-4cbd-9652-401bb18c7e56">
</p>
<p align="center"><strong>图 4.4 进入工具链目录</strong></p>

2. **检查已安装的 GCC 编译器版本** :
    
    ```
    $ ./bin/arm-eabi-gcc --version
    ```
