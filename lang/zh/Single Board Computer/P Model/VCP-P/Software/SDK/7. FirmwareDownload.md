# 7. 下载到 TOPST VCP 硬件

将构建好的软件传输到 TOPST-VCP 开发板是开发过程中的关键步骤。本章全面介绍如何使用基于 Linux 的开发环境将软件下载到 VCP 硬件上。

<br/><br/>

## 7.1 准备硬件

在开始下载过程之前，请确保 TOPST-VCP 开发板处于稳定位置且不受任何潜在干扰。请确保所有开关和连接器都易于操作，并且 3.3v 电源线连接正确。

<br/><br/>

## 7.2 将硬件连接到开发主机 PC

1. **USB C 线缆连接:** 使用 USB C 线缆将 TOPST-VCP 开发板连接到开发主机 PC。
2. **验证连接**: 在 Linux 机器上执行以下命令

    ```
    $ sudo dmesg | grep tty
    ```

## 7.3 传输构建好的软件

1. **将开发板设置为下载模式 :** 在 TOPST-VCP 开发板上，将 FWDN 开关拨到 FWDN 位置。按下 PORN 按钮进行复位。此时开发板已进入 FWDN 下载模式。

<p align="center">

</p>
<p align="center"><strong>图 7.2 将开发板设置为下载模式</strong></p>

2. **执行下载命令** : 使用 FWDN 工具将 4MB 闪存的软件下载到开发板上

    ```
    $ sudo ../../../tools/fwdn_vcp/fwdn --fwdn ../../../tools/fwdn_vcp/vcp_fwdn.rom -w output\tcc70xx_pflash_boot_4M_ECC.rom
    ```

<p align="center"><strong>图 7.3 执行下载命令</strong></p>

3. **复位开发板:** 下载过程完成后，将 FWDN 开关拨回 NORMAL 位置。通过重新上电或按下 PORN 按钮复位开发板。

## 7.4 验证开发板上的软件

软件下载到开发板后，验证其是否正确运行至关重要:

1. **安装 minicom**  
    ```
    $ sudo apt install minicom
    ```
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/20a8f4ad-68da-472d-8b56-7a8fffad0643"></p>
<p align="center"><strong>图 7.5 安装 Minicom</strong></p>

2.  **打开串口连接** : 使用以下命令启动串口连接

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

3. **现在可以在终端上看到以下结果** : 如果连接成功，您应该能够与开发板进行交互并观察其响应。这表明软件已成功下载并在 TOPST-VCP 开发板上正常运行。

## 7.5 常见问题排查

即使做了周密的准备，在下载过程中偶尔也可能遇到问题。以下是一些常见问题的解决方法:

**问题:** fwdn 工具报告没有访问 ttyUSB0 设备的权限。

**解决方法** : 当您的用户账户没有访问串行设备所需的权限时，就会出现此问题。您可以通过将用户账户添加到 dialout 组来授予这些权限。

1. **修改用户组权限** : 执行以下命令

    ```
    $ sudo usermod -aG dialout $USER
    ```
<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/a7552057-86de-4c49-876d-d50435bd16e4">
</p>
<p align="center"><strong>图 7.8 修改用户组权限</strong></p>


2. **注销并重新登录** : 要使组更改生效，您需要注销当前会话，然后重新登录。完成后，请再次尝试访问 ttyUSB0 设备

请记住，您遇到的大多数问题都有解决方案或替代方法。理解错误信息，并在有疑问时查阅文档或咨询在线社区，这一点至关重要。

**问题** : 使用 minicom 时，与 TOPST-VCP 开发板之间无法正常通信或出现异常行为。

**解决方法** :该问题可能是由于 minicom 中默认的流控制设置为硬件流控制导致的。为了与 TOPST-VCP 开发板顺畅通信，您需要将流控制设置为 "none"。


1. **启动 minicom :**

    只需输入以下命令即可启动 minicom 工具 :

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/7f8fd60c-eb59-474e-99f2-a5ab9cc6abc8">
</p>
<p align="center"><strong>图 7.9 启动 minicom</strong></p>

2. **进入设置界面 :** 在 minicom 中，按 Ctrl-A 然后按 “o” 进入设置界面。

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/79fa7579-374f-4714-9490-3a1d3fe40a70">
</p>
<p align="center"><strong>图 7.10 进入设置界面</strong></p>

3. **导航到串口设置** : 从选项列表中，选择 "Serial port setup"
4. **修改流控制 :** 在串口设置中，按 “ F” 将硬件流控制切换为 "No"。

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/9c4ac77c-1e19-4bee-a0f3-f3ad6f3b3791">
</p>
<p align="center"><strong>图 7.11 修改流控制</strong></p>

5. **退出并保存** : 完成后，退出设置并保存配置。现在 minicom 应该可以与 TOPST-VCP 开发板正常通信了。
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/e9c61695-1637-470c-b91f-34ddeff4a923"></p>
<p align="center"><strong>图 7.12 退出并保存</strong></p>

**注意**: 如果您使用的是 minicom 以外的其他串行通信工具，请同样将其流控制设置为 "none" 以确保正常运行。
