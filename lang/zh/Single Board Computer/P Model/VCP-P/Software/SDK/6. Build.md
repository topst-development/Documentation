#  6. 构建源代码

成功获取源代码后，下一个关键步骤是对其进行构建，确保其能够在 TOPST-VCP 开发板上以最佳状态运行。

<br/><br/>

## 6.1 了解 Makefile 与构建系统

Makefile 是众多构建系统的基石。它包含用于告知 make 工具如何编译和链接程序的规则与指令。通过使用 Makefile，开发者可以将构建流程自动化，从而确保一致性和效率。

<br/><br/>

## 6.2 启动构建流程

要开始构建源代码，请按照以下步骤操作 :

1. **使用以下命令进入构建目录 :**

    ```
    $ cd build/tcc70xx/gcc/
    ```

2. **使用以下命令运行 make 命令 :**

    ```
    $ make
    ```

该命令会读取当前目录中的 Makefile 并执行构建流程。

3. **验证构建输出** : 构建流程完成后，您应能在终端上看到以下输出文件
    - output/tcc70xx_pflash_boot.rom
    - output/tcc70xx_pflash_boot_2M_ECC.rom
    - output/tcc70xx_pflash_boot_3M_ECC.rom
    - output/tcc70xx_pflash_boot_4M_ECC.rom

    请确保这些文件存在，因为它们对后续开发阶段至关重要。
