# 2. 前提条件

在深入了解 TOPST-VCP 开发板的设置和开发流程之前，需要考虑若干前提条件。本章将向您介绍推荐的 Linux 发行版、硬件要求以及为确保开发过程顺畅所需的基础知识。

<br/><br/>

## 2.1 Linux 发行版推荐

在本指南中，我们建议在 **Ubuntu 22.04** 上搭建开发环境。该版本的 Ubuntu 提供了稳定的平台和广泛的社区支持，可确保与 TOPST-VCP 开发板及相关工具链的兼容性和易用性。

下载与安装：

- 访问 Ubuntu 官方网站，下载 Ubuntu 22.04 LTS（长期支持）发行版。
- 按照提供的安装指南，在您的开发主机 PC 上安装 Ubuntu 22.04。

## 2.2 硬件要求

要与 TOPST-VCP 开发板进行连接并执行开发任务，以下硬件组件必不可少 :

- TOPST-VCP 开发板：请确保手边备有开发板，最好放置在便于硬件操作的工作空间中。
- USB-C 线缆：用于连接您的开发主机 PC 与 TOPST-VCP 开发板。请确保线缆质量良好，以便在整个开发过程中保持稳定的连接。

准备好所需硬件后，使用 USB-C 线缆将 TOPST-VCP 开发板连接到您的开发主机 PC。请确保连接牢固，以避免开发过程中出现任何潜在的中断。

<br/><br/>

## 2.3 知识前提条件

开始之前，您必须熟悉以下概念：

- Ubuntu 基础：对如何在 Ubuntu 22.04 环境中操作和使用的基本理解。
- TOPST-VCP 的启动模式：TOPST-VCP 开发板提供多种启动模式，使开发人员能够为其特定项目选择最合适的模式。

有关如何选择启动模式的详细说明随开发板一并提供。请查阅所提供的文档，并根据您的开发需求选择合适的模式
