#  5. 获取源代码

源代码是任何开发项目的基础。它包含为特定平台构建和运行软件所需的全部文件、配置和说明。对于 TOPST-VCP 开发板而言，获取正确的源代码对于确保兼容性和最佳性能至关重要。

本章将指导您使用广泛使用的版本控制系统 git 获取源代码的过程。

<br/><br/>

## 5.1 克隆 TOPST-VCP 源代码

要获取 TOPST-VCP 开发板的源代码，您将使用 git clone 命令。该命令会在您的本地计算机上创建远程仓库的副本，使您可以直接处理这些代码。

请按照以下步骤克隆 TOPST-VCP 源代码：

1. **打开终端** : 在您的 Ubuntu 22.04 系统上启动终端应用程序。
2. **进入目标目录** : 在系统上选择一个合适的位置来保存源代码。例如，如果您想将其保存在用户主目录中，请使用以下命令

    ```
    $ cd ~
    ```

3. **克隆仓库** : 使用以下命令从提供的 git 地址克隆 TOPST-VCP 源代码

    ```
    $ git clone https://gitlab.com/topst.ai/topst-vcp.git
    ```

4. **进入克隆的目录** : 克隆过程完成后，使用以下命令进入包含源代码的目录

    ```
    $ cd topst-vcp
    ```

现在，您的计算机上已拥有 TOPST-VCP 源代码的本地副本，可以进行构建和开发了。

<br/><br/>

## 5.2 熟悉源代码结构

克隆完成后，熟悉源代码的目录结构和内容会很有帮助。这将使您更好地了解特定文件的位置以及代码库的组织方式。

- 使用 ls 等命令列出目录的内容。
- 浏览关键目录和文件，了解它们的用途和功能。

```
$ ls -al
```
