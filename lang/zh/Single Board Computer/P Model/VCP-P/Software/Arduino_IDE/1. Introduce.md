# 1. TOPST VCP Arduino 简介 

欢迎来到 TOPST VCP Arduino 项目！本仓库致力于为基于 Telechips TCC7045（一款先进的车辆控制处理器 (VCP)）的 TOPST VCP 创建 Arduino 软件包。我们的目标是提供一个专为汽车半导体量身定制、同时又与 Arduino 一样简单灵活的开发环境。

<br/><br/>

## 1.1 关于 TOPST VCP 
TOPST VCP 是一款专为汽车应用设计的强大而高效的处理器。通过将其与 Arduino 环境集成，我们旨在简化并加快汽车领域的开发流程。

<br/><br/>

## 1.2 项目组成 
本项目由三个主要部分组成：
1. **用于 Arduino 的 TOPST VCP 引导加载程序**：一个允许 Arduino sketch 在 TOPST VCP 上运行的自定义引导加载程序。
2. **Arduino Core**：经过修改以支持 TOPST VCP 的 Arduino 核心软件。
3. **移植到 TOPST VCP 的库**：一组经过适配的库，可在各类应用中充分发挥 TOPST VCP 的性能。

<br/><br/>

## 1.3 开发环境 
TOPST VCP Arduino 项目使开发人员能够在熟悉的 Arduino 集成开发环境 (IDE) 中编写软件，并直接在 TOPST VCP 上运行。这种方式简化了开发流程，使更广泛的开发人员群体能够轻松上手。
