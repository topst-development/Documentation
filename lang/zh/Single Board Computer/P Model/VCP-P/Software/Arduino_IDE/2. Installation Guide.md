# 2. TOPST VCP Arduino Core 安装指南

本指南将帮助您下载并安装用于 Arduino 集成开发环境（IDE）的 TOPST VCP Arduino core。

<br/><br/>

## 2.1 安装指南

### Step 1: 下载 Arduino IDE

首先，您需要 Arduino IDE，它是用于对 Arduino 开发板进行编程的平台。

- 访问 Arduino 官方网站：[Arduino Software](https://www.arduino.cc/en/software)
- 选择适合您操作系统（Windows、macOS、Linux）的版本。
- 下载并运行安装程序。

<br/>

### Step 2: 安装 Arduino IDE

请根据您的操作系统按以下步骤安装 Arduino IDE：

#### Windows:
1. 执行下载的 `.exe` 文件。
2. 按照安装提示进行操作。请确保安装所有必需的驱动程序。

#### macOS:
1. 打开 `.dmg` 文件。
2. 将 Arduino 应用程序拖动到 Applications 文件夹。

#### Linux:
1. 解压 `.tar.xz` 文件。
2. 在解压后的目录中打开终端。
3. 运行 `./install.sh` 进行安装。

<br/>

### Step 3: 添加 TOPST VCP 开发板

要对 TOPST VCP 开发板进行编程，您需要通过 Board Manager 将其 core 添加到 Arduino IDE。

1. 打开 Arduino IDE。
2. 转到 **File > Preferences**。
3. 在“Additional Board Manager URLs”字段中，添加以下 TOPST VCP core 的 URL：

    ```
    https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
    ```

    （注意：请将上面的 URL 替换为 TOPST VCP core 实际提供的 URL。）
4. 单击“OK”保存更改。
5. 转到 **Tools > Board > Boards Manager**。
6. 在 Boards Manager 中搜索“TOPST VCP”。
7. 当出现 TOPST VCP 条目时，单击“Install”。

<br/>

### Step 4: 选择 TOPST VCP 开发板

安装完成后，您需要选择 TOPST VCP 开发板：

1. 转到 **Tools > Board**。
2. 向下滚动找到“TOPST VCP”并选择它。

<br/>

### Step 5: 验证安装

通过上传一个简单的示例程序来测试您的设置是否正常：

1. 通过 USB 将 TOPST VCP 开发板连接到您的 PC。
2. 在 **Tools > Port** 下选择相应的端口。
3. 打开 **File > Examples > 01.Basics > Blink**。
4. 按下 **Upload** 按钮，将示例程序传输到开发板。
5. 如果板载 LED 开始闪烁，说明开发板设置正确。

<br/><br/>

## 2.2 故障排除

如果在设置过程中遇到任何问题，您可以参考[Arduino 故障排除指南](https://www.arduino.cc/en/Guide/Troubleshooting)。


如需了解更多信息和高级功能，请查阅 TOPST VCP 文档或访问[Arduino 帮助中心](https://support.arduino.cc/hc/en-us)。
