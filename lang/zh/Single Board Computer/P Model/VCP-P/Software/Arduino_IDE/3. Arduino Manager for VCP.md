# 3. TOPST VCP Arduino 开发板管理器

本仓库托管了适用于 TOPST VCP 的 Arduino 开发板管理器。该开发板管理器使用户能够轻松地在 Arduino IDE 中添加对 TOPST VCP 开发板的支持，从而使用熟悉的工具编写和上传程序。

<br/><br/>

## 3.1 功能特性

- 轻松安装 TOPST VCP 的开发板定义。
- 与 Arduino IDE 兼容。
- 支持所有主要的 TOPST VCP 开发板型号。

<br/><br/>

## 3.2 安装

要在 Arduino IDE 中安装 TOPST VCP 开发板管理器，请按照以下步骤操作：

1. 以 **以管理员权限运行** 的方式打开 Arduino IDE。
2. 前往 `File > Preferences`。
3. 在 "Additional Board Manager URLs" 字段中添加以下 URL：
   ```
   https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
   ```
   如果该字段中已有其他 URL，请使用逗号分隔。

4. 单击 "OK" 保存设置。
5. 前往 `Tools > Board > Boards Manager...`。
6. 在 Boards Manager 中搜索 "TOPST VCP"。
7. 单击 TOPST VCP 条目旁边的 "Install"。

<br/><br/>

## 3.3 使用方法

安装完成后，您可以在 Arduino IDE 的 `Tools > Board` 菜单中选择 TOPST VCP 开发板。请选择与您的硬件相对应的开发板，然后照常编写和上传您的程序。
