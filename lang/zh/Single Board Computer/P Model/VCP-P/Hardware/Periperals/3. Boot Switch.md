# 3. 启动模式 (SW2)


TOPST VCP 具有一个使用启动模式 (BM) 进行启动配置的引脚，并支持 2 种模式：  
UART 启动模式和正常模式。

滑动开关 (SW2) 用于选择 TOPST VCP 的启动模式。

## 3.1 UART 启动模式
此模式主要用于固件下载 (**FWDN**) 模式。
在此模式下，您可以使用 UART 端口将程序下载到用户定义区域。


表 3.2 说明了 UART 启动模式的滑动开关设置。
