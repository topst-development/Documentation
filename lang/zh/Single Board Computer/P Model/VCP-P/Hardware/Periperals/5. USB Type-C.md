# 5. 用于调试和 FWDN 的连接器 (JC1)  


在 TOPST VCP 上，JC1 用于通过 UART 进行调试或 FWDN。  
这是标准的 USB Type-C 连接器。  

图 5.1 显示了 JC1 的位置。  
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/8b19656c-59d5-4389-87f3-4939bf501587"></p>  
<p align="center"><strong>图 5.1 USB Type-C 连接器</strong></p>  

您可以通过 JC1 执行 FWDN 或查看 TCC7045 的调试消息。  
在 TOPST VCP 上，JC1 配有 USB to UART 桥接控制器，您可以使用 USB Type-C 线缆将 JC1 直接连接到 PC。
