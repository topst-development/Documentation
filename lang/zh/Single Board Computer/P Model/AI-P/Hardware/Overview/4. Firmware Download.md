# 4. 固件下载

<br/>

## 4.1 为下载固件将 TOPST AI 连接到计算机

Firmware Downloader(**FWDN**)在计算机上通过 UART 通信将 ROM 镜像写入
TOPST AI。

TOPST AI 具有一个 Boot Mode 按钮，并通过该 Boot Mode 按钮支持以下
两种启动模式:

- UART Boot Mode 用于使用计算机上的 **FWDN** 程序写入 ROM
  镜像。

- eMMC Boot Mode 用于使用存储在 eMMC 设备中的 ROM 镜像启动
  TOPST AI。

**注意**: USB Type-C 端口用于固件下载器(**FWDN**)。

要使用 **FWDN**，请按如下方式将 TOPST AI 连接到计算机:

1.  准备一根 USB Type-C 线缆和一根 Ethernet 线缆
2.  使用 USB Type-C 线缆将 TOPST AI 上的 USB Type-C 插座连接到
    您的计算机。
3.  使用 Ethernet 线缆将 TOPST AI 上的 Ethernet 连接器(RJ45)连接到
    您的计算机。
4.  使用下面两种方法之一更改 TOPST AI 的
    启动模式。
     1. 方法 1
         * 如果 TOPST AI 尚未通电，请按住 FWDN 按钮，然后将 5V 电源连接到 TOPST AI。
         * 松开 FWDN Boot mode 按钮。

     2. 方法 2
         * 如果 TOPST AI 已经通电，请按下 System Reset 按钮和 FWDN Boot mode 按钮。
         * 松开 FWDN Boot mode 按钮。

5.  根据 **FWDN** 文档下载您的 ROM 镜像。
