# 4. 构建指南

<br/><br/>

## 4.1 转换器

转换器读取神经网络文件，并将其转换为 TOPST AI NPU SW Toolkit 中使用的
网络文件格式 ”bin” 文件。
此外，它还执行网络推理并收集激活数据的统计信息，
这些信息随后用于网络量化。

<br/>

<strong>1.  Darknet</strong>

```
$ python ./EnlightSDK/converter.py \
  ./input_networks/yolov4.cfg \
  --weight ./input_networks/yolov4.weights \
  --type obj \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/yolov4.enlight \
  --enable-track \
  --mean 0 0 0 \
  --std 1 1 1 \
  --num-class 90
```

## 4.2 量化器

量化器将基于浮点运算的原始网络模型转换为
基于整数的（量化）网络。

<br/>

**1.  Darknet**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/yolov4.enlight \
  --output ./output_networks/yolov4_quantized.enlight
```

<br/>

**2.  TensorFlow Lite**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1.enlight \
  --output ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight
```

<br/>

**3.  ONNX**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/mb2-ssd-lite.enlight \
  --output ./output_networks/mb2-ssd-lite_quantized.enlight
```

<br/><br/>

## 4.3 编译器

编译器将量化后的神经网络编译为 NPU 代码和网络参数，
用于在 TOPST NPU HW 上处理神经网络。

<br/>

**1.  Darknet**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/yolov4_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

**2.  TensorFlow Lite**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

**3.  ONNX**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/mb2-ssd-lite_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

生成的文件存储在 “output_code/\<network_name\>”
目录中。

编译器输出文件：

- npu_cmd.bin: TELECHIPS NPU 推理代码
- quantized_network.bin: 网络权重和偏置参数
- network.h: 用于后处理的缓冲区大小和网络参数
- post_process.c: 后处理代码
- 其他文件: 调试信息（仅限内部）

在神经网络应用程序中，“npu_cmd.bin” 和 “quantized_network.bin”
通过 TELECHIPS NPU API 和 Linux 设备驱动程序加载到 DMA
缓冲区中。“network.h” 和 “post_process.c” 将按照 Network Object Build 中所示
构建为网络对象文件 (.so)。
