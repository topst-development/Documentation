# 1. TOPST AI NPU Tool Kit

TOPST AI 的 NPU 是硬件神经网络加速器。它针对目标检测、图像分类和人脸
检测等视觉应用神经网络的推理进行了
优化。

“TOPST-AI-Common-SW-NPU-Toolkit Guide” 文档介绍了 NPU Toolkit 的
使用方法。
