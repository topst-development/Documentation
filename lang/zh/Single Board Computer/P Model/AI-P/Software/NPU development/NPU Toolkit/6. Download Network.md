# 6. 下载网络

<br/>

1.  启动 TOPST AI 开发板。
2.  使用 “scp” 命令传输 Network 文件夹。

    $ scp -r yolov4_quantized/ root@192.168.0.100:/home/root //192.168.0.100 : TOPST AI Board IP Address
