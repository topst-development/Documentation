# 1. 示例应用程序

本章是 NPU 示例应用程序的指导文档。

TOPST AI SDK 提供了一个用于验证 NPU 功能的示例应用程序，
名为 ‘tc-nn-app’。

该 NPU 示例应用程序使用摄像头、图像文件和 PC 流作为输入，
将 NPU 图像处理结果输出到 LCD、文件和 PC
流。

<br/><br/>

## 1.1 概述

NPU 示例应用程序只能执行 Neural Process Unit (NPU)
运算。

tc-nn-app 的架构如下所示。
