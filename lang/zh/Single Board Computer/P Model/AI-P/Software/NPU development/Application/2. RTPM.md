## 2.1 性能监控

Real-Time Performance Toolkit (RTPM) 是使用 Python 开发的基于 GUI 的工具，
它可以在 PC 环境中监控 TOPST AI 的输出，
并允许您查看 CPU、NPU 和 Memory 性能数据。

<br/>

**表 2.1 RTPM 的性能数据列表：**

|  序号  |      性能数据        |                  说明                  |
|--------|----------------------|----------------------------------------|
| 1      | 推理时间             | 各模型的推理时间 (ms)                  |
| 2      | NPU                  | 各模型的 NPU 利用率                    |
| 3      | FPS                  | 基于 NPU 运行的 FPS 信息               |
| 4      | CPU                  | CPU 利用率（500ms 周期）               |
| 5      | Memory               | Memory 利用率（500ms 周期）            |

## 2.2 Injection 模式

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image3.png?raw=true"></p>
<p align="center"><strong>图 2.3 Injection 模式</strong></p>

Injection 模式是这样一种场景：TOPST AI 开发板从 RTPM 接收图像，
然后在 TOPST AI Board 上进行 NPU 推理，
并将结果发送回 RTPM。

<br/><br/>

## 2.3 Projection 模式

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image4.png?raw=true"></p>
<p align="center"><strong>图 2.4 Projection 模式</strong></p>

Projection 模式是这样一种场景：开发板通过摄像头接收图像，并将最终结果（合成了检测框的图像）发送到 RTPM。

### 2.4.3 运行 Projection 模式

1.  为 input mode 选择 Camera (EVB)。

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image19.png?raw=true"></p>
<p align="center"><strong>图 2.19 为 input mode 选择 Camera(EVB)</strong></p>

2.  按下 start 按钮。

3.  在 TOPST AI 开发板上运行 tcnnapp projection 模式。

	```
	# tcnnapp -i camera -o rtpm
	```
 - **注意**：使用 "-i camera" 选项执行命令时，输入路径将设置为默认值 /dev/video0。请确认所连接的摄像头在 /dev/ 下被识别为哪个 video 设备，如果不是 /dev/video0，请使用 "-p /dev/video*" 选项继续。
