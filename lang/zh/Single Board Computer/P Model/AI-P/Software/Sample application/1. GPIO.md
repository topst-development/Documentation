# 1. GPIO 示例

GPIO(general-purpose input/output)是集成电路或电路板上的
数字信号引脚，允许用户在运行时控制
包括输入或输出在内的
各种操作。
GPIO 并未针对特定用途进行预定义，默认情况下也
不会被使用。
GPIO 由汇编级电路网络设计者(集成电路 GPIO 由电路板设计者负责，
基板级 GPIO 由系统集成商负责，S/I)实现，
其用途和行为在使用时
进行定义。

GPIO 所执行的功能可能因系统而异，通常提供的功能如下。

- 输入/输出功能 (high=1, low=0)
- IRQ 信号检测: 这也可用于在 Power management 模式下唤醒处于 suspend
  状态的系统。
  - 即使在 Spinlock 被占用时也可以访问

上述功能可用于实现写保护、控制 LED、启用收发器设置、
  硬件看门狗功能或
  开关检测。

以下是测试开发板输入和输出的示例。您可以参考 Raspberry Pi 引脚图，
  通过控制引脚编号来测试输入和
  输出。

<br/>

**示例**

```
$ echo "90" > /sys/class/gpio/export
$ echo "out" > /sys/class/gpio/gpio90/direction
$ echo 1 > /sys/class/gpio/gpio90/value
$ echo 0 > /sys/class/gpio/gpio90/value
```
