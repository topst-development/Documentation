# 3. SPI 示例

Serial Peripheral Interface(SPI)是与 I2C、CAN 和 UART 类似的串行通信
(serial communication)方式。它是一种用于在微控制器、移位寄存器和
SD 卡等小型外围设备之间传输数据的
功能。简单来说，它是在设备与设备之间，即芯片(IC)与
芯片之间交换数据的通信方式之一。SPI 通信是
支持一对多通信的同步通信方式，其缺点是进行多路通信时
需要多条信号线。并且可以同时进行发送和
接收。由于布线简单，因此常用于简单的
传感器和存储器等芯片之间的
通信。
