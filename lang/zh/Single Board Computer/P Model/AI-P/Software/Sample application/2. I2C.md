# 2. I2C 示例

inter-integrated circuit（I2C）通常读作 "i-to-c"，但其正式发音为 "i-square-c"。

I2C 通信由一条用于发送和接收数据的 SDA 线和一条用于同步收发
时序的时钟线 SCL 组成。它由一个主设备和一个或多个从设备构成，
最多可以连接 127 个
从设备。

- I2C 通信是一种使用两条线的通信方式
- 将多个从设备连接到单个主设备的优点和缺点
  - 由于是使用时钟信号的同步通信方式，因此具有不受时序限制的优点
  - 由于为了选择从设备而始终附带地址数据，因此不适合传输长数据的缺点

3.  运行 i2c_example_app 时，它会获取亮度值。

    ```
     root@telechips-tcc7500-main:~# ./i2c_example_app
     Target is 144.
    ```

4.  如果用手遮住模块并运行，该值会增大。

    ```
    root@telechips-tcc7500-main:~# ./i2c_example_app
    Target is 228.
    ```
