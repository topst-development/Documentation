# 1. FWDN 指南

本章介绍如何将固件下载器（FWDN）下载到
TOPST AI。

TOPST AI 通过以太网和 UART 提供 FWDN 功能。在 FWDN
模式下，BL0（Chipboot ROM）通过 UART 从主机加载下一级固件（BL1）。
（BL1 进行初始化。）初始化 DRAM，并再次通过 UART 将支持
FWDN 以太网的 FWDN F/W 加载到 DRAM 中。FWDN F/W 通过 TCP/IP 或 UDP 与主机
建立连接，并执行 FWDN 功能（例如向存储器写入数据、从存储器读取数据
等）。

## 1.1 固件下载顺序

FWDN 的下载顺序如下：

1.  进入 FWDN 模式（请参阅 TOPST-AI/Hardware/Overview/4.Firmware Download）。
2.  将 USB C-to-A 线缆连接到 USB C 型 FWDN 端口。
3.  将以太网线缆连接到以太网端口。
4.  下载 TOPST AI 镜像。

<br/><br/>

## 1.2 进入 FWDN 模式 

按下 FWDN KEY（FWDN Mode Convert）并接通电源即可进入 FWDN
模式。或者，在已接通电源的情况下，按下 FWDN KEY
（FWDN Mode Convert）并按下 RESET KEY（System Reset）以进入
FWDN 模式。
