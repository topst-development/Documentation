# 2. 启动指南

本章介绍如何启动 TOPST AI 以及如何登录到
各个核心。

<br/><br/>

## 2.1 启动顺序

启动顺序如下：

1.  连接 MIPI 接口面板。
2.  连接 MIPI 接口摄像头模块。
3.  将 USB C to A 线缆连接到调试端口。
4.  连接 5V 电源。

## 2.2 使用 UART 连接 TOPST AI

要执行 USB 调试并进行 Linux 环境开发，您可以使用下图所示开发板上的 TOPST AI 调试端口访问核心（CA53）。
请在主机 PC 上安装 UART Bridge VCP 驱动程序（可从
https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads
获取）。
随后，当您将 UART 连接到 TOPST 调试板时，CP210x USB to UART 驱动程序将按如下方式设置。

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20Boot.image2.png?raw=true"
style="width:4.11111in;height:4.02083in"</p>
<p align="center"><strong>图 2.2 Windows 环境下的 USB 连接</strong></p>

请使用主机 PC 上的终端仿真器连接 UART 端口。
下图为连接到核心后启动的日志画面。

<br/>

**示例**

- 终端仿真器: PuTTY 或 mobaXterm
- 速率: 115200 bps
- 数据位: 8
- 校验位: None
- 停止位: 1
- 流控制: None
