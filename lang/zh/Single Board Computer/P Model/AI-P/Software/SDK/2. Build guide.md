# 2. 构建指南

<br/><br/>

## 2.1 TOPST AI SDK

TOPST AI SDK 基于 Yocto Project 4.0 kirkstone。
因此，要使用 TOPST AI SDK，必须在主机 PC 上配置 Yocto Project 环境。
要下载 SDK、source-mirror 和 tools，必须先安装相关实用工具。

您可以根据元数据从 upstream 下载源代码并执行构建。
构建完成后，将提供软件包、镜像和 SDK 作为结果。
图 2.1 显示了 Yocto Project 的任务流程。
