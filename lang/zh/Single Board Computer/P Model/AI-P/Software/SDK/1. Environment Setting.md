# 1. 环境设置 

<br/><br/>


## 1.1 Ubuntu 安装

由于 TOPST AI Linux SDK 基于 Yocto Project，因此 TOPST AI SDK 的 Linux 版本遵循 Yocto 项目。

您也可以安装其他版本的 Linux，但本文档以 Ubuntu 22.04 为基础说明 TOPST AI Linux SDK。

Linux 发行版版本：

- Ubuntu 22.04 (LTS)

<br/><br/>

## 1.2 安装 WSL2 Ubuntu 

1. 以“以管理员权限运行”方式执行 Windows PowerShell
2. 启用 WSL2 系统。
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. 启用虚拟机功能。
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. 将 WSL 2 设置为默认版本
    ```
    wsl --set-default-version 2
    ```
5. 在 Microsoft Store 中搜索 Ubuntu 22.04.3 LTS 并下载。

    * 如果需要下载 Linux 内核更新包，请从[此处](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)下载最新的软件包。


<br/><br/>

## 1.3 设置 Linux 环境

<br/>

### 1.3.1 安装 SSH 和 Samba 

在 Linux 环境中工作速度较慢，但您可以使用 SSH 和 Samba 在更加
便捷的环境中工作。SSH 和

Samba 可让您在远程计算机上执行命令，并将文件复制到
其他计算机。

如果已经安装了 SSH 和 Samba，或者您不打算使用它们，则可以
跳过本章。

```
 $ sudo apt-get install -y net-tools openssh-server samba 
```

下载 SSH 和 Samba 后，您应根据自己的环境对每个程序进行
设置。

<br/>

### 1.3.2 安装 Yocto Project 所需的实用工具 

一次性安装这些实用工具。要使用 Yocto Project，必须在 Host PC（个人计算机或
开发服务器）上安装以下

实用工具。

```
$ sudo apt-get install -y gawk wget git-core diffstat unzip texinfo gcc-multilib
$ sudo apt-get install -y build-essential chrpath socat cpio python3 python3-pip python3-pexpect
$ sudo apt-get install -y xz-utils debianutils iputils-ping python3-git python3-jinja2 libegl1-mesa libsdl1.2-dev pylint xterm

```

<br/>

### 1.3.3 安装 Repo

您可以通过 Repo 下载 TOPST AI SDK。

要安装 repo，请参考以下网站：
<https://source.android.com/source/downloading.html>

如果已安装 repo，则无需重新安装即可使用。

在安装 repo 之前，应正确设置已安装的 Python 版本（3.6 或更高）。

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
$ sudo apt-get install repo
```

<br/>

如果出现 repo 错误，请下载最新版本并将其直接放入 /usr/bin/ 文件夹。

```
$ mkdir -p ~/bin
$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo &gt;~/bin/repo
$ chmod a+x ~/bin/repo
$ sudo mv ~/bin/repo /usr/bin/repo
```
