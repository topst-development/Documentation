# 3. 固件下载

本章介绍如何将 FWDN 下载到 TOPST AI（开放平台开发板）并登录 Linux
控制台。

<br/><br/>

## 3.1 固件下载顺序

FWDN 的下载顺序如下：

1.  将启动模式开关设置为 fwdn 启动模式。
2.  打开 Windows 命令提示符并测试 FWDN ND。
3.  将 FWDN ND 连接到开发板。
4.  下载 fai 文件。

<br/><br/>

## 3.2 通过 Fwdn 启动连接 TOPST AI 与主机 PC

您可以使用 FWDN 将构建好的镜像传输到 TCC750x。
TCC750x 通过以太网和 UART 提供 FWDN 功能。

### 3.3.3 更改启动模式

如果按下启动模式开关并接通电源，则会启动 FWDN 启动流程。如果不按下
启动模式开关而接通电源，则会启动正常的
启动流程。
按下复位开关会使系统复位。如果要下载固件，
请同时按下启动模式开关和复位开关，进入 FWDN
启动模式。

### 3.3.4 Windows 下的 FWDN

1.  镜像构建完成后，将生成的 fwdn 文件夹复制到桌面，并在该文件夹内
    保存以下文件。
    要使用 FWDN，可从以下链接下载固件工具：

    - <[FWDN Tool](https://topst-downloads.s3.ap-northeast-2.amazonaws.com/Yocto/pre/topst.ai.pre.20240425001.windows.zip)>
  
    将 SD_Data.fai 镜像复制到 topst.ai.pre.20240425001.windows 中。
    SD_Data.fai 位于 **"{build_dir}/build/tcc7500-main/tmp/deploy/fwdn/"**。


2.  运行 **fwdn_batch.bat** 并输入**端口号**。

    <p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/Firmware%20Download.image5.png?raw=true"
    style="width:4.22917in;height:3.62292in"</p>

    <p align="center"><strong> 图 3.4 输入 FWDN 端口号</strong></p>

3.  完成 FWDN

    <p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/Firmware%20Download.image6.png?raw=true"
    style="width:5.32292in;height:1.21597in"</p>
 

    <p align="center"><strong> 图 3.5 完成固件下载</strong></p>


### 3.3.5 Linux 下的 FWDN

1.  镜像构建完成后，将生成的 fwdn 文件夹复制到桌面，并在该文件夹内
    保存以下文件。
    要使用 FWDN，可从以下链接下载固件工具：

    - <[FWDN Tool](https://topst-downloads.s3.ap-northeast-2.amazonaws.com/Yocto/pre/topst.ai.pre.20240425001.linux.zip)>
  
    将 SD_Data.fai 镜像复制到 topst.ai.pre.20240425001.linux 中。
    SD_Data.fai 位于 **"{build_dir}/build/tcc7500-main/tmp/deploy/fwdn/"**。



2.  运行 **fwdn_nd.sh** 并输入**端口号**。

    style="width:4.22917in;height:3.92292in"</p>

    <p align="center"><strong> 图 3.4 输入 FWDN 端口号</strong></p>
