# 2. AI-G 中的启动模式
---
AI-G 支持以下启动模式: 
- USB Boot Mode (FWDN)  
- eMMC Boot Mode (GPIO_SD Group)

AI-G 开发板默认固定为 eMMC Boot Mode。如果 eMMC 设备中没有启动镜像，启动模式将自动切换为 FWDN Boot Mode。 

<br/><br/><br/>

## 2.1 USB Boot Mode (FWDN)
--- 
图 2.1 显示了 Boot Mode 开关和 RESET 开关。USB Boot Mode 用于固件更新。要进入 FWDN 模式，需要同时使用 Boot mode 开关和 RESET 开关。建议在上传镜像时使用此方法。

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Hardware/2.11%20AI-G%20Boot%20Mode.png" width="550"></p>
<p align="center"><strong>图 2.1 用于进入 FWDN Boot Mode 的 Boot Mode 开关和 RESET 开关 </strong></p><br/>

以下步骤说明了进入 USB Boot Mode 的开关操作。 
1. 通电后，RESET 开关上方的 LED 会点亮。 
2. 按住 Boot Mode 开关。按下 Boot Mode 开关时，可以看到开关上方的红色 LED 点亮。持续按住开关以保持 LED 点亮。 
3. RESET 开关的 LED 默认为绿色。按一次 RESET 开关后，绿色 LED 会熄灭然后再次点亮。 
4. 松开 Boot Mode 开关。
