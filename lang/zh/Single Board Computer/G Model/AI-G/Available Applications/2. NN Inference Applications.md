# 2. 示例应用程序
---
本章介绍 AI-G SDK 提供的三个示例/测试应用程序。每个应用程序都旨在帮助用户评估和利用 AI-G 的 AI 能力。这些应用程序涵盖 NPU 推理测试和实时摄像头输入等多种场景。
<br/><br/><br/>
 
## 2.1 tcnnapp
---
tcnnapp 是一个示例 AI 应用程序，演示如何使用 AI-G 平台上的 NPU 执行基于图像的推理。它支持多种输入/输出模式，并展示如何使用 YOLOv5s 和 MobileNetv2 等预训练模型进行目标检测。
<br/><br/>
 
### 用例 1. 文件到文件的基本推理
本用例演示如何对本地图像文件运行推理并将结果保存到输出文件，适用于在不使用摄像头或显示硬件的情况下进行基本功能测试和模型验证。  
要执行推理，请输入以下命令：
```
$ tcnnapp -i file -p test.png -o file -P result.png
```
 
该命令使用输入图像文件 (test.png) 运行 tcnnapp，并将推理结果保存到输出文件 (result.png)。如果未指定模型，应用程序将自动使用默认量化模型 YOLOv5s 和 MobileNetv2。

### 用例 2. 使用摄像头和显示屏的实时推理
本用例演示如何在连接 MIPI CSI 摄像头和 MIPI DSI 显示屏的情况下使用 tcnnapp 执行实时 AI 推理并可视化结果。该应用程序从摄像头传输实时视频输入，在 NPU 上使用默认量化模型 (YOLOv5s 和 MobileNetv2) 执行实时推理，并将结果显示在屏幕上。  
设备连接如下：
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Available%20Applications/Figure%202.%20Device%20Connection.png" width="600"></p>
<p align="center"><strong>图 2.2 AI-G 上的摄像头和显示屏连接 </strong></p><br/>
 
连接设备后，请输入以下命令：
```
$ tcnnapp -i camera -o display
```
该命令以 CSI 摄像头作为输入启动实时推理。采集到的视频帧被送入 NPU 进行目标检测和分类处理。
边界框、类别标签和置信度分数等推理结果会直接渲染到输出帧上。
这些带标注的帧会在 5 英寸 DSI 显示屏上实时显示，为您提供即时的视觉反馈。
 
除可视化输出外，系统还会记录 CPU 占用率、NPU 利用率和内存状态等关键性能指标，可通过串口控制台或远程接口进行监控。

### 用例 3. 使用摄像头和 RTPM 的实时推理
本用例演示如何将 MIPI CSI 摄像头作为输入、将 Real-time Performance Monitor (RTPM) 作为输出方式来使用 tcnnapp。该应用程序从摄像头传输实时视频输入，在 NPU 上使用默认量化模型 (YOLOv5s 和 MobileNetv2) 执行实时推理，并通过 RTPM 将结果发送到 PC 以进行可视化和性能监控。  
RTPM 工具包是使用 Python 开发的图形界面工具，用于在 PC 环境中监控 AI-G 的输出。它使您能够查看推理结果以及 CPU、NPU 和内存占用等系统性能指标。  
 
**注意**：有关 RTPM 的更多详细信息，请参阅 Software 部分中的 RTPM.md。
 
设备连接如下：

该命令以 CSI 摄像头作为输入启动实时推理。检测到的目标和分类标签等推理结果会传输到主机 PC，并通过 RTPM 界面进行可视化。  
除推理输出外，RTPM 还会实时显示包括 CPU 占用率、NPU 负载和内存占用在内的系统性能指标。

### 用例 4. 使用 RTPM 输入和输出的推理
本用例演示如何使用由主机 PC 通过 RTPM 传输的输入图像运行推理，并通过同一 RTPM 界面将推理结果发送回 PC 进行显示。输入数据可以是图像或视频。  
请参阅 Software 部分中的 RTPM.md 文档来运行 RTPM。然后输入以下命令：
```
$ tcnnapp -i rtpm -o rtpm
```
该命令使用 RTPM 同时作为输入和输出来运行 tcnnapp。数据由主机 PC 通过 RTPM 发送，经 AI-G 开发板上的 NPU 处理后，推理结果被发送回 PC 并通过 RTPM 界面显示。

## 2.2 tcnncameraapp
---
tcnncameraapp 是一个示例应用程序，可用于测试和预览 AI-G 平台支持的摄像头模块。它基于 Video4Linux2 (V4L2) 框架构建，通过连接的 MIPI CSI 接口和 DSI 显示屏实现实时摄像头预览。  
该应用程序主要用于验证摄像头功能、测试显示输出以及调试图像信号质量。根据摄像头模块类型的不同，它还支持同时监控多路摄像头。  
tcnncameraapp 提供的选项如下表所示。
 
| 名称              | 选项    | 范围      | 默认值      | 示例           | 说明                                  |
| ------------------| --------| ----------| ------------| ---------------| --------------------------------------|
| 用法信息          | -?      |     -     |             | -?             | 显示用法信息                          |
| 输入路径          | -p      |     -     | /dev/video0 | -p /dev/video0 | 指定输入路径                          |
| 输出路径          | -P      |     -     | /dev/overlay| -P /dev/overlay| 指定输出路径                          |
| 输入宽度          | -w      | 最大 2560 | 1920        | -w 2560        | 指定输入的宽度                        |
| 输入高度          | -h      | 最大 1440 | 1080        | -h 1080        | 指定输入的高度                        |
| 输出宽度          | -W      | 最大 1920 | 1920        | -W 1920        | 指定输出的宽度                        |
| 输出高度          | -H      | 最大  720 | 720         | -H 720         | 指定输出的高度                        |
| 输出位置 X        | -X      | 最大 1920 | 0           | -X 960         | 指定输出的 X 坐标                     |
| 输出位置 Y        | -Y      | 最大  720 | 0           | -Y 360         | 指定输出的 Y 坐标                     |
<p align="center"><strong>表 2.1 摄像头测试应用程序选项</strong></p><br/>
 
**注意**：输出宽度与其 X 位置之和不得超过 1920，输出高度与其 Y 位置之和不得超过 720。

## 2.3 tcnputestapp
---
tcnputestapp 是一个示例应用程序，用于验证 AI-G 平台上神经处理单元 (NPU) 的基本功能。它利用 tcndnpulib 库，使用预编译的神经网络模型直接测试 NPU 的执行。该应用程序主要用于在不涉及摄像头或显示屏的情况下对 NPU 进行内部验证、调试和性能测试。  
tcnputestapp 提供的选项如下表所示。
 
| 名称           | 选项   | 范围      | 默认值      | 示例                     | 说明                                  |
| ---------------| -------| ----------| ------------| -------------------------| --------------------------------------|
| 用法信息       | -?     |     -     |      -      | -?                       | 显示用法信息                          |
| NPU 编号       | -d     |    0, 1   |      0      | -d 0 / -d 1 / -d 0 1     | 指定网络的 NPU 索引                   |
| 网络路径       | -n     |     -     | /usr/share/yolov5s_quantized| -n /usr/share/mobilenetv2_10_quantized/   | 指定要测试的神经网络。如果选择两个 NPU，则它们使用相同的神经网络路径|
| 测试次数       | -t     | -         | 1           | -t 100                   | 指定神经网络测试的次数|
