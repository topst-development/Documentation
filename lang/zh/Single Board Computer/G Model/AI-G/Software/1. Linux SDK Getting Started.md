# 1. 简介
---
本文档提供构建 AI-G SDK 的指南，包括设置主机环境、构建 SDK、使用固件下载器以及将 AI-G 与 PC 连接。

本文档包含以下内容： 
- 设置主机环境  
- 镜像构建指南  
- 固件下载指南 
- 将 AI-G 开发板与 PC 连接

<br/><br/><br/><br/>

# 2. 设置主机环境 (Windows)
---
本章介绍如何设置主机 PC 环境，并分别提供在 Windows PC 和 Ubuntu PC 上的设置指南。
<br><br/><br/>

## 2.1 Windows 环境
--- 
本文档介绍如何设置 Windows Sub-system for Linux (WSL)，以便在 Windows PC 上使用 Linux。
由于 AI-G Linux SDK 基于 Yocto Project，因此 AI-G SDK 的 Linux 版本遵循 Yocto Project。
您可以安装其他版本的 Linux，但本文档以 Ubuntu 22.04 为基础介绍 AI-G Linux SDK。
如果主机操作系统为 Ubuntu，请转到第 2.2 节。
</br><br/>

### 2.1.1 安装 WSL2 Ubuntu (仅限 Windows 环境)

1. 以“**以管理员权限运行**”方式执行 Windows PowerShell。
2. 启用 WSL2 系统。
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. 启用虚拟机功能。
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. 将 WSL 的默认版本设置为 2 (WSL2)。
    ```
    wsl --set-default-version 2
    ```
5. 在 Microsoft Store 中搜索 Ubuntu 22.04.3 LTS 并下载。

    * 如果需要下载 Linux 内核更新包，请从[此处](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)下载最新的软件包。

6. 在安装 Ubuntu 的过程中，您可以任意选择用户名。

<br/><br/>


### 2.1.2 通过 WSL2 访问 Ubuntu
打开 Windows 命令提示符并输入以下命令以访问 Ubuntu。访问 Ubuntu 后，默认会从 /mnt/c/Users/[user name] 目录开始。
```
wsl  // access ubuntu 
ls   // check contents in your directory
```
请参见图 2.1 以确认结果 (可能因用户而异)。

### 2.1.3 设置区域设置

在 WSL 上运行 Ubuntu 后，应设置区域设置以确保语言和地区配置正确。建议使用 en_US.UTF-8。请执行以下命令以使用 en_US.UTF-8。 

```
sudo locale-gen en_US.UTF-8 && sudo update-locale LANG=en_US.UTF-8 
```

设置区域设置后，可以使用以下命令检查区域设置类型。 

```
echo 'LANG=en_US.UTF-8' | sudo tee -a /etc/default/locale && \  

echo 'LC_ALL=en_US.UTF-8' | sudo tee -a /etc/default/locale 
```
<br/><br/>

### 2.1.4 安装 SSH 和 Samba 

进入 Ubuntu 后，您可以使用 SSH 和 Samba 等其他实用工具，以获得更方便的开发环境。SSH 和 Samba 可让您在远程计算机上执行命令并将文件复制到其他计算机。
 - 以下步骤要求主机 PC 已连接到网络。请使用以下命令检查网络状态：
  ```
  $ sudo apt-get update
  $ sudo apt-get install -y net-tools
  $ ifconfig 
  ```

如果已安装 SSH 和 Samba，或者不打算使用它们，可以跳过本章。

使用以下命令安装 net-tools、SSH 和 Samba。

```
$ sudo apt-get update 
$ sudo apt install -y net-tools openssh-server samba
```


下载 SSH 和 Samba 后，应根据您的环境对各程序进行设置。
<br/><br/>

### 2.1.5 安装实用工具 

一次性安装所需的实用工具。要使用 Yocto Project，主机 PC (个人计算机或开发服务器) 上必须安装以下实用工具。

使用以下命令安装实用工具。

```
$ sudo apt-get install -y gawk wget git diffstat unzip texinfo gcc-multilib build-essential chrpath

$ sudo apt-get install -y socat cpio python3 python3-pip python3-pexpect xz-utils debianutils

$ sudo apt-get install -y iputils-ping python3-git python3-jinja2 libegl1-mesa-dev libsdl1.2-dev pylint

$ sudo apt-get install -y xterm zstd ncftp curl git-lfs vim zip lz4
```
<br/><br/>


### 2.1.6 安装 Repo (可选)

您可以使用 ***Repo*** 下载 AI-G SDK。  
要安装 ***Repo***，请参考以下网站：https://source.android.com/source/downloading.html.  
如果已安装 ***Repo***，则无需重新安装即可使用。  
在安装 ***Repo*** 之前，请确保已正确设置 Python 3.6 或更高版本。

使用以下命令安装 ***Repo***。
```
$ sudo apt-get install repo
```

如果出现错误消息 '/usr/bin/env 'python' no such file or directory'，请使用以下命令使文件 'python' 指向 'python3'。

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
```
如果出现 ***Repo*** 错误，请使用以下命令下载最新版本，并将其直接放入 /usr/bin/ 文件夹。

```
$ mkdir -p ~/bin

$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo > ~/bin/repo

$ chmod a+x ~/bin/repo

$ sudo mv ~/bin/repo /usr/bin/repo
```
请转到 **第 3 章：镜像构建指南**。

# 3. 镜像构建指南
---
本节以主机 PC 上安装的 Ubuntu 操作系统为基础进行说明 (无论是 WSL 还是本地安装的 Ubuntu)。要上传到 AI-G 的镜像使用 Yocto Project 构建，因此该过程必须在 Ubuntu 环境中进行。
<br/><br/><br/>

## 3.1 SDK 构建准备
---
AI-G SDK 基于 Yocto Project 4.0 Kirkstone。因此，要使用 AI-G SDK，必须在主机 PC 上配置 Yocto Project 环境。要下载 SDK、source-mirror 和 tools，必须安装实用工具。为了顺利构建镜像，您的 PC 必须具备 **至少 60 GB 的可用存储空间** 和 **至少 16 GB 的内存**。

<br/><br/><br/>

## 3.2 Yocto Project
---
Yocto Project 是一个专注于嵌入式 Linux 开发的开源项目。 
它结合使用 Open Embedded 项目的一部分 Poky 与构建系统 bitbake 来生成 Linux 镜像。 
使用 Yocto Project，您可以同时构建引导加载程序、内核和 rootfs。 

<br/><br/><br/>

---
图 3.1 显示了 Yocto Project 的任务流程。您可以根据元数据从上游仓库下载源代码，然后进行构建。构建完成后，将生成软件包、镜像和 SDK 作为结果。

## 3.5 构建准备
---
以下章节介绍如何配置 Yocto Project 以构建 AI-G 镜像。
<br/><br/>

### 3.5.1 在 .gitconfig 中设置用户邮箱和用户名
要从官方 TOPST git 下载 AI-G，请配置您的邮箱和名称。
1. 输入以下命令。
```
vi ~/.gitconfig
```
2. 输入以下信息。
```
[user]
    email = User email
    name = User name
```
<br/><br/>

### 3.5.2 从 Git 获取 AI-G
1. 创建名为 **topst-sdk** 的新目录，并将当前目录切换到 **topst-sdk**。
```
$ mkdir topst-sdk
$ cd topst-sdk
```
2. 执行以下命令以初始化仓库。

```
$ repo init -u https://github.com/topst-development/manifests.git -b release/1.3.0 -m linux_yp4.0_topst.xml

```

执行该命令后，将显示以下输出。

# 4. 固件下载器
---
本章介绍如何将 ***FWDN*** 下载到 AI-G 并登录 Linux 控制台。  
***FWDN V8*** 是用于在 Windows 10 或 11 64 位以及 Linux 环境中下载固件的 PC 工具。本章介绍在 Windows 和 Linux 环境中下载的情况。
<br/><br/><br/>

## 4.1 固件下载顺序
---
***FWDN*** 的下载顺序如下:

1. 将启动模式开关设置为 USB 启动模式(FWDN 模式)。
2. 打开 Windows 命令提示符或 Linux 控制台并测试 ***FWDN V8***。
3. 将 ***FWDN V8*** 连接到开发板。
4. 下载 fai 文件。

<br/><br/><br/>

## 4.2 USB 启动模式(FWDN 模式) 
---
您可以使用 ***FWDN*** 将构建好的镜像传输到 AI-G。AI-G 通过 Ethernet 和 UART 提供 ***FWDN***。 

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/Linux%20SDK/3.%20connect%20host%20pc%20to%20topst%20ai-g.png" ></p>
<p align="center"><strong>图 4.1 主机 PC 与 AI-G 之间用于 FWDN 的连接</strong></p><br/>

要使用 ***FWDN V8***，请按以下方式将 AI-G 开发板连接到主机 PC: 

1. 确认主机 PC 上已安装 VTC 驱动程序。如果未安装 VTC 驱动程序，请按第 4.2.1 章所述进行安装。  

2. 准备一根 USB Type-C 线缆和一根 Ethernet 线缆。 

3. 要进入 USB 启动模式，请将 USB Type-C 线缆连接到 AI-G 开发板上的 USB Type-C FWDN 端口和主机 PC。 

4. 将 Ethernet 线缆(RJ45)连接到 AI-G 开发板上的 Ethernet 端口和主机 PC。 

5. 按住 FWDN 开关的同时，将电源线连接到 AI-G 开发板。 

<br/><br/><br/>

### 4.2.1 VCP 驱动程序安装方法

在主机 PC 上以管理员身份运行并安装 Vendor Telechips Certification (VTC) 驱动程序(可在 [VCP 驱动程序](https://drive.google.com/file/d/1muQnY8kuKxDsy3p3FUiQqcG34Zjk-mnR/view?usp=sharing) 获取)。如上所示在 FWDN 模式下连接 USB 后，Telechips VTC USB 驱动程序将按图 4.2 所示进行设置。

## 4.3 FWDN 的执行方法
---
执行 ***FWDN*** 之前，必须先将构建后创建的镜像和 ***FWDN*** 工具从 Ubuntu(WSL2)传输到 Windows 环境。 
如果使用 Ubuntu 主机，可以跳过以下步骤并转到第 4.3.2 章。

1. 解压 "output_aig.fwdn.zip"
```
$ cd ~/topst-sdk
$ mkdir images
$ mv ./output_aig.fwdn.zip ./images 
$ cd images

```

2. 将 "images" 文件夹复制到 Windows C 盘。 
```
$ cd ..
$ cp -r ./images /mnt/c/ 
```
以下步骤请根据主机 PC 的操作系统参考第 4.3.1 章或第 4.3.2 章。
<br/><br/>

3. 执行 Windows PowerShell 并进入 “C:\images”。  
```
$ cd C:\images
```

## 4.4. 通过 UART 连接 AI-G 开发板
--- 
请执行以下步骤，并通过 UART 连接确认固件下载已成功完成。  

1. 在 Windows 环境中安装串口驱动程序(例如 CP210x Windows Driver)和 PL2303_prolific 驱动程序。
2. 安装 Tera Term 或 PuTTY 等终端仿真器。 
3. 连接主机 PC 与 AI-G 开发板上的 UART 引脚。请使用 USB to TTL 线缆。 
4. 将黑色线缆连接到 GND 引脚。 
5. 将白色线缆(RXD)连接到 UART 引脚中的 TX 引脚，将绿色线缆(TXD)连接到 UART 引脚中的 RX 引脚。
6. 运行终端仿真器应用程序。
7. 在 PC 上打开设备管理器，确认用于 UART 的端口号。
8. 将在设备管理器中确认的端口号输入终端仿真器的 **Serial line** 字段。将 **Speed**(bps) 设置为 115200，并设置 **Flow control to None.**
9. 连接电源线。随后，AI-G 将以默认的 eMMC 启动模式启动。
