# 2. 快速开始
---
请按照以下步骤在 AI-G 开发板上运行 Telechips Model Zoo 提供的神经网络模型。
<br/><br/><br/>

## 2.1 克隆代码仓库
---
```
$ git clone https://github.com/telechips-ai/TCC750x-Model-Zoo.git

$ cd TCC750x-Model-Zoo
```
<br/><br/><br/>

## 2.2 将所需模型复制到 AI-G
---
将整个模型文件夹 (yolov5m) 复制到 AI-G。
您可以按原样复制该文件夹，也可以如以下示例所示，将其重命名为 yolov5m_quantized，以与先前发布的神经网络文件夹所使用的格式保持一致。
每个文件夹均包含所需的输出文件 (.so、.bin 等)。

```
$ scp -r [network_output_folder] root@192.168.0.100:/path/to/target/
```
请将 **network_output_folder** 替换为实际的文件夹 (例如 yolov5m/)。

您可以选择 yolov5 模型。
```
$ cd Object_Detection/YOLO/yolov5/
$ ls 
README.md  yolov5l  yolov5m  yolov5n  yolov5s  yolov5x
```
然后运行:
```
$ scp -r yolov5m/ root@192.168.0.100:/home/root/
```
<br/><br/><br/>

## 2.3 使用 tcnputestapp 或 tcnnapp 运行模型:
---
然后在目标开发板 (AI-G) 上运行以下命令:
```
$ tcnputestapp -d 0 1 -n [network_output_folder_path]
```
或 
```
$ tcnnapp -n [network_output_folder_path]
```
