## 3.1 Converter
---
Converter 读取神经网络文件并将其转换为 ”bin”
文件，该格式是 AI-G NPU SW Toolkit 中使用的网络文件格式。
它还会执行网络推理并收集
激活数据的统计信息，这些信息随后用于网络量化。

<strong>1.  Darknet</strong>
```
$ python ./EnlightSDK/converter.py \
  ./input_networks/yolov4.cfg \
  --weight ./input_networks/yolov4.weights \
  --type obj \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/yolov4.enlight \
  --enable-track \
  --mean 0 0 0 \
  --std 1 1 1 \
  --num-class 90
```

<strong>3.  ONNX</strong>

如果您的 ONNX 模型包含不受支持的算子（例如 NonMaxSuppression），则需要使用此方法。

以下过程使用 tc-nn-toolkit 命令行界面进行三个步骤的转换。


首先，将 ONNX 模型转换为 .enlight 格式。

```
$ python ./EnlightSDK/converter.py \
  ./input_networks/mb2-ssd-lite.onnx \
  --type obj \
  --add-detection-post-process ./input_networks/mb2-ssd-lite.anchor \
  --logistic softmax \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/mb2-ssd-lite.enlight \
  --enable-track \
  --mean 0.498 0.498 0.498 \
  --std 0.502 0.502 0.502 \
  --num-class 20 \
  --variance 0.1 0.2
```

然后，使用 --force-output 提取以中间层作为输出的模型，以移除不受支持的算子。

```
python ./EnlightSDK/converter.py \
            ./input_networks/mb2-ssd-lite.onnx \
            --type unknown \
            --output ./output_networks/mb2-ssd-lite_wo_box_decode_score.enlight \
            --dataset-root my_dataset_path \
            --force-output Concat_0___Concat Concat_1___Concat_1
```

最后，对提取出的模型应用锚框、逻辑激活和类别设置等后处理选项，以生成最终的 .enlight 模型。

```
$ python ./EnlightSDK/converter.py \
  ./output_networks/mb2-ssd-lite_wo_box_decode_score.enlight \
  --type obj \
  --add-detection-post-process ./input_networks/mb2-ssd-lite.anchor \
  --logistic softmax \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/mb2-ssd-lite.enlight \
  --enable-track \
  --mean 0.498 0.498 0.498 \
  --std 0.502 0.502 0.502 \
  --num-class 20 \
  --variance 0.1 0.2
```

## 3.2 Quantizer
---
Quantizer 将基于浮点运算的原始网络模型
转换为基于整数的（量化）网络。

**1. Darknet**
```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/yolov4.enlight \
  --output ./output_networks/yolov4_quantized.enlight
```

**2. TensorFlow Lite**
```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1.enlight \
  --output ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight
```

**3. ONNX**
```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/mb2-ssd-lite.enlight \
  --output ./output_networks/mb2-ssd-lite_quantized.enlight
```

## 3.3 Compiler
---
Compiler 将量化后的神经网络编译为 NPU 代码以及
用于在 AI-G NPU 硬件上处理神经网络的网络参数。

**1.  Darknet**
```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/yolov4_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

**2.  TensorFlow Lite**
```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

**3.  ONNX**
```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/mb2-ssd-lite_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5

目录中的 requirements.txt 文件中。

Compiler 输出文件：
- npu_cmd.bin：用于 Telechips NPU 推理代码的推理代码
- quantized_network.bin：网络权重和偏置参数
- network.h：用于后处理的缓冲区大小和网络参数
- post_process.c：后处理代码
- 其他文件：调试信息（仅限内部使用）

在神经网络应用中，“npu_cmd.bin” 和 “quantized_network.bin”
通过 Telechips NPU API 和 Linux 设备驱动程序加载到 DMA 缓冲区中。
“network.h” 和 “post_process.c” 则按照网络对象构建中所示的方式构建为网络对象
文件 (.so)。

## 3.4 网络对象构建
---
本章介绍如何使用已编译的神经网络文件构建
网络对象文件。“build_network” 目录中包含
用于构建网络模型共享库文件 (.so) 的编译环境，
该网络模型用于 AI-G。
<br/><br/>

$ tar -xvf gcc-arm-9.2-2019.12-x86_64-aarch64-none-linux-gnu.tar.xz
$ echo "export PATH=~/gcc-arm-9.2-2019.12-x86_64-aarch64-none-linux-gnu/bin:\$PATH" >> ~/.bashrc
$ source ~/.bashrc

### 3.4.2 构建对象
将编译器输出目录复制到 “build_network” 目录中。  
在运行 make 命令之前，必须删除 build_network 文件夹中现有的 post_process.c 和 network.h 文件。  
然后，在 build_network 文件夹中创建指向已编译的 <network_name>_quantized 目录中 network.h 和 post_process.c 文件的符号链接。

```
$ cd build_network
$ cp ../output_code/<network_name>_quantized/ ./ -ar
$ rm -rf network.h post_process.c
$ ln -s ./<network_name>_quantized/network.h
$ ln -s ./<network_name>_quantized/post_process.c
$ make
$ cp ./net.so ./<network_name>_quantized/
$ ls -l <network_name>_quantized/

# 5. NPU 兼容算子
---
本章介绍 NPU 支持的算子。以下列表包含与该平台兼容的主要运算。
<br/><br/><br/>

## 5.1 AI-G NPU 支持的层类型
---
AI-G NPU 支持以下层类型。

**表 5.1 支持的层类型与规格：**

|        层类型       |                        规格                        |
|-------------------------|-------------------------------------------------------------|
| Convolution             | 卷积核大小：1x1 至 7x7<br/>步长：1 至 4<br/>填充：0 至 3 <br/>膨胀率：1 至 4 |
| ConvTranspose           | 卷积核大小：2x2 至 3x3<br/>步长：2<br/>填充：0 至 1  |
| Depth-wise Convolution  | 卷积核大小：1x1 至 5x5<br/>步长：1 至 2<br/>填充：0 至 2|
| Activation Function     | Bypass<br/>ReLU<br/>ReLU6<br/>Leaky Relu <br/> Sigmoid <br/> Tanh <br/> Mish <br/> Swish <br/> Clip <br/> HardSwish <br/> HardSigmoid| 
| Max Pool 2D             | 卷积核大小：2x2 至 13x13<br/>步长：1 至 2<br/>填充：0 至 6| 
| Average Pool 2D         | 卷积核大小：2x2 至 19x19<br/>步长：1 至 2<br/>填充：0 至 6| 
| Global Average Pool     | 支持                                                   | 
| Element-wise Operation  | 加法：Scalar + Tensor, Vector + Tensor, Tensor + Tensor <br/>  乘法：Scalar * Tensor, Vector * Tensor, Tensor * Tensor                    |  
| Batch Normalization     | 支持                                                   |  
| Concatenation           | 仅支持按通道                                           | 
| Slice                   | 支持                                                   |
| Split                   | 支持                                                   |

<br/><br/><br/>
