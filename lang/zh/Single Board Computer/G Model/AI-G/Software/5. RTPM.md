# 1. 简介
---
实时性能监视器 (RTPM) 工具包是一款基于 Python 的图形应用程序，用于实时监控和可视化 AI-G 的性能指标。通过在 AI-G 开发板与主机 PC 之间建立连接，RTPM 可实现关键性能数据的传输与分析，包括 CPU、NPU、内存利用率以及推理时间。
 
RTPM 提供两种不同的工作模式：
 
**Injection Mode**：在该模式下，主机 PC 将图像数据发送至 AI-G 进行处理。AI-G 使用其 NPU 执行推理，并将结果返回给 PC 进行可视化。
 
**Projection Mode**：在该模式下，AI-G 通过所连接的摄像头采集图像，在内部完成处理，并将推理结果传输至主机 PC 上的 RTPM。
 
本工具包对于希望评估和优化 AI-G 平台上 AI 应用程序性能的开发者和工程师尤为有用。它提供对系统行为的实时洞察，从而实现高效的调试与性能调优。
 
有关详细的设置说明和使用指南，请参阅本文档的后续章节。

## 2.1 性能监控
--- 
实时性能监控工具包 (RTPM) 是一款使用 Python 开发的
基于 GUI 的工具，可在 PC 环境中监控 AI-G 的输出，
并允许您查看 CPU、NPU 和内存性能数据。
 
 
 
**表 2.1 RTPM 的性能数据列表：**
 
|   序号   |  性能数据    |                说明             |
|--------|----------------------|----------------------------------------|
| 1      | Inference Time       | 各模型的推理时间 (ms)     |
| 2      | NPU Utilization      | 各模型的 NPU 利用率         |
| 3      | FPS                  | 基于 NPU 运行的 FPS 信息 |
| 4      | CPU                  | CPU 利用率 (500 ms 周期)         |
| 5      | Memory               | 内存利用率 (500 ms 周期)      |

## 2.4 RTPM 应用程序启动指南
---
本节提供在主机 PC 上设置实时性能监视器 (RTPM) 应用程序的分步说明。

### 2.4.1 安装 RTPM 所需工具
 
- 准备主机 PC 环境。
 
1. 安装 Visual Studio Code。
   * 在 Microsoft Store 中搜索“Visual Studio Code”并安装。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/5.%20Install%20Visual%20Studio%20Code.png"></p>

   2. 通过点击左侧边栏中的 Extensions 图标，或按下以下快捷键打开 Extensions 视图： 
   *Ctrl + Shift + X*.
   3. 在 Extensions 搜索栏中输入 Python。
   4. 找到由 Microsoft 提供的 Python 扩展，然后点击 Install。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/6.%20Install%20Python3.10.png"width="800"></p>

### 2.4.3 使用 Injection Mode
 
1.  将 Input Mode 更改为 Folder（仅图像）。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/13.%20Change%20the%20Input%20Mode%20to%20Folder%20(Only%20Image).png"></p>

2.  选择要进行推理的图像文件夹。
 
    该图像文件夹中不应包含子文件夹。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/14.%20Select%20the%20image%20folder.png"></p>

5.  在 AI-G 上启动 tcnnapp 的 Injection mode。（执行顺序
    不会影响结果。）

