# 1. 简介
---
本文档介绍如何使用 AI-G SDK 提供的示例/测试应用程序。该 SDK 包含 tcnnapp，这是一个示例应用程序，演示如何在摄像头输入、文件输入和 RTPM 等多种模式下使用神经网络处理单元 (NPU) 执行神经网络推理。

## 1.4.1 源文件说明
 
该源文件（“tcnnapp”）实现了在单模式和双模式下使用神经网络进行推理的示例，可处理来自
摄像头或文件的输入。“NnAppMain.c” 文件作为程序的入口点，用于选择模式并输出
结果，而 yolov5s_quantized 和 mobilenetv2_10_quantized 则定义了神经网络模型。摄像头、显示和
缩放器功能已模块化，并作为 API 提供，用于处理视频输入和输出。此外，还包含用于消息处理
和绘制结果的实用函数，以支持整体功能。此结构旨在便于使用神经网络的
各种模式。
 
<br/><br/><br/>
