# 2. D3-G 的启动模式
---
D3-G 支持三种启动模式：
- USB 启动模式 (FWDN)
- eMMC 启动模式 (GPIO_SD0 Group)  
- SNOR 与 eMMC 启动模式（可选）
 
图 2.1 显示了 D3-G 上启动模式电阻的位置。这些电阻位于开发板的背面。D3-G 默认固定为 eMMC 启动模式。如果 eMMC 器件中没有启动镜像，启动模式会自动切换为 USB 启动模式。

## 2.1 USB 启动模式 (FWDN)
---
图 2.2 显示了启动模式开关和 RESET 开关。USB 启动模式用于固件更新。要进入 FWDN 模式，需要同时使用启动模式开关和 RESET 开关。上传镜像时建议使用此方法。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20D3-G/Hardware/Boot%20Mode%20Switch%20and%20RESET%20Switch%20for%20Entering%20FWDN%20Boot%20Mode.png" width="600"></p>
<p align="center"><strong>图 2.2 用于进入 FWDN 启动模式的启动模式开关和 RESET 开关 </strong></p>
 
 
 
以下步骤说明进入 USB 启动模式的开关操作方法。
1. 接通电源后，RESET 开关上方的 LED 点亮。
2. 按住启动模式开关。按下启动模式开关时，可以看到该开关上方的红色 LED 点亮。请持续按住开关以保持 LED 点亮。
3. RESET 开关的 LED 默认为绿色。按一次 RESET 开关后，绿色 LED 熄灭，然后重新点亮。
4. 松开启动模式开关。

## 2.2 SNOR 与 eMMC 启动模式
---
SNOR 与 eMMC 启动模式为可选项。要使用此启动模式，开发板上必须贴装 SNOR IC，并且必须更改启动模式电阻的表面贴装工艺 (SMT)。
