# 4. ファームウェアダウンロード

<br/>

## 4.1 ファームウェアダウンロードのための TOPST AI とコンピュータの接続

Firmware Downloader(**FWDN**)は、コンピュータ上で UART 通信を介して
TOPST AI に ROM イメージを書き込みます。

TOPST AI には Boot Mode ボタンが 1 つあり、Boot Mode ボタンによって次の
2 種類の起動モードをサポートします:

- UART Boot Mode は、コンピュータ上の **FWDN** プログラムを使用して ROM
  イメージを書き込む際に使用します。

- eMMC Boot Mode は、eMMC デバイスに保存されている ROM イメージを使用して
  TOPST AI を起動する際に使用します。

**注記**: USB Type-C ポートは firmware downloader(**FWDN**)に使用されます。

**FWDN** を使用するには、次のように TOPST AI をコンピュータに接続します:

1.  USB Type-C ケーブル 1 本と Ethernet ケーブルを準備します。
2.  USB Type-C ケーブルを使用して、TOPST AI の USB Type-C レセプタクルを
    コンピュータに接続します。
3.  Ethernet ケーブルを使用して、TOPST AI の Ethernet コネクタ(RJ45)を
    コンピュータに接続します。
4.  以下の 2 つの方法のいずれかを使用して、TOPST AI の起動モードを
    変更します。
     1. 方法 1
         * TOPST AI にまだ電源が供給されていない場合は、FWDN ボタンを押しながら TOPST AI に 5V 電源を接続します。
         * FWDN Boot mode ボタンを離します。

     2. 方法 2
         * TOPST AI にすでに電源が供給されている場合は、System Reset ボタンと FWDN Boot mode ボタンを押します。
         * FWDN Boot mode ボタンを離します。

5.  **FWDN** ドキュメントに従って ROM イメージをダウンロードします。
