# 1. TOPST AI NPU Tool Kit

TOPST AI の NPU は HW ニューラルネットワークアクセラレータです。物体検出、
画像分類、顔検出などのビジョンアプリケーション向けニューラルネットワークの
推論に最適化されています。

「TOPST-AI-Common-SW-NPU-Toolkit Guide」ドキュメントでは、NPU Toolkit の
使用方法を説明しています。

<br/><br/>

## 1.1 概要

<p align="center"><strong>図 1.1 TOPST AI SW Tool Kit の概要</strong></p>

- Converter
  * ネットワークファイルを内部ネットワーク形式 (.bin) に変換します
  * ONNX(PyTorch)、TF-Lite、CFG(Darknet) をサポートします

<!-- -->

- Quantizer
  * 量子化されたネットワークを生成します: float から int8 へ

<!-- -->

- Compiler
  * 量子化されたネットワークを入力として NPU Machine Code を生成します
