# 1. サンプルアプリケーション

本章は NPU サンプルアプリケーションのガイド文書です。

TOPST AI SDK は、NPU の機能を検証するためのサンプルアプリケーション
‘tc-nn-app’ を提供します。

この NPU サンプルアプリケーションは、カメラ、画像ファイル、PC ストリームを
入力として使用し、NPU の画像処理結果を LCD、ファイル、PC ストリームに
出力します。

<br/><br/>

## 1.1 概要

NPU サンプルアプリケーションは、Neural Process Unit (NPU) の演算のみを
実行できます。

tc-nn-app のアーキテクチャは以下のとおりです。
