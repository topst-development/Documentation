# 2. リアルタイム性能モニタリングツールキット

TOPST AI Board から取得した画像、NPU、CPU、MEM の性能は Vision Protocol を
介して PC に転送することができ、その結果は PC 上の RTPM ツールキットで
確認できます。

<p align="center"><strong>図 2.1 ホスト PC と TOPST AI Board の接続</strong></p>

## 2.1 性能モニタリング

Real-Time Performance Toolkit（RTPM）は Python で開発された GUI ベースの
ツールであり、PC 環境で TOPST AI の出力をモニタリングし、CPU、NPU、Memory
の性能データを確認できます。

<br/>

**表 2.1 RTPM の性能データ一覧:**

|   No   |    性能データ        |                  説明                  |
|--------|----------------------|----------------------------------------|
| 1      | 推論時間             | 各モデルの推論時間(ms)                 |
| 2      | NPU                  | 各モデルによる NPU 使用率              |
| 3      | FPS                  | NPU 動作に基づく FPS 情報              |
| 4      | CPU                  | CPU 使用率(500ms 周期)                 |
| 5      | Memory               | Memory 使用率(500ms 周期)              |

## 2.2 Injection モード

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image3.png?raw=true"></p>
<p align="center"><strong>図 2.3 Injection モード</strong></p>

Injection モードは、TOPST AI ボードが RTPM から画像を受信した後、
TOPST AI Board で NPU 推論を実行し、その結果を RTPM に
返送するシナリオです。

<br/><br/>

## 2.3 Projection モード

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image4.png?raw=true"></p>
<p align="center"><strong>図 2.4 Projection モード</strong></p>

Projection モードは、ボードがカメラを通じて画像を受信し、最終結果（ボックスを合成した画像）を RTPM に送信するシナリオです。

<br/><br/>

### 2.4.3 Projection モードの実行

1.  input mode として Camera (EVB) を選択します。

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image19.png?raw=true"></p>
<p align="center"><strong>図 2.19 input mode として Camera(EVB) を選択</strong></p>

2.  start ボタンを押します。

3.  TOPST AI ボードで tcnnapp projection モードを実行します。

	```
	# tcnnapp -i camera -o rtpm
	```
 - **注意**: "-i camera" オプションを指定してコマンドを実行すると、入力パスは既定値の /dev/video0 に設定されます。接続されたカメラが /dev/ 配下でどの video デバイスとして認識されているかを確認し、/dev/video0 でない場合は "-p /dev/video*" オプションを指定して進めてください。

<br/>
