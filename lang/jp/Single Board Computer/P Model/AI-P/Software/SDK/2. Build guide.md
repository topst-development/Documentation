# 2. ビルドガイド

<br/><br/>

## 2.1 TOPST AI SDK

TOPST AI SDK は Yocto Project 4.0 kirkstone をベースとしています。
そのため、TOPST AI SDK を使用するには、ホスト PC に Yocto Project 環境を構築する必要があります。
SDK、source-mirror、tools をダウンロードするには、ユーティリティをインストールする必要があります。

メタデータに基づいて upstream からソースをダウンロードし、ビルドを実行できます。
ビルドが完了すると、パッケージ、イメージ、SDK が結果として提供されます。
図 2.1 は Yocto Project のタスクプロセスを示しています。
