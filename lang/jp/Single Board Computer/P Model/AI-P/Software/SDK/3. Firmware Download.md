# 3. ファームウェアダウンロード

本章では、TOPST AI（オープンプラットフォームボード）に FWDN をダウンロードし、Linux
コンソールにログインする方法について説明します。

<br/><br/>

## 3.1 ファームウェアダウンロードの手順

FWDN のダウンロード手順は次のとおりです。

1.  ブートモードスイッチを fwdn ブートモードに設定します。
2.  Windows のコマンドプロンプトを開き、FWDN ND をテストします。
3.  FWDN ND をボードに接続します。
4.  fai ファイルをダウンロードします。

<br/><br/>

## 3.2 Fwdn 起動による TOPST AI とホスト PC の接続

FWDN を使用して、ビルドしたイメージを TCC750x に転送できます。
TCC750x は、イーサネットと UART を使用して FWDN 機能を提供します。

### 3.3.3 ブートモードの変更

ブートモードスイッチを押した状態で電源を供給すると、FWDN 起動プロセスが
開始されます。ブートモードスイッチを押さずに電源を供給すると、通常の起動
プロセスが開始されます。
リセットスイッチを押すとシステムがリセットされます。ファームウェアを
ダウンロードする場合は、ブートモードスイッチとリセットスイッチを同時に
押して FWDN 起動モードにしてください。

### 3.3.4 Windows での FWDN

1.  イメージのビルド後、作成された fwdn フォルダをデスクトップにコピーし、
    そのフォルダ内に以下のファイルを保存します。
    FWDN を使用するには、以下のリンクからファームウェアツールをダウンロードできます。

    - <[FWDN Tool](https://topst-downloads.s3.ap-northeast-2.amazonaws.com/Yocto/pre/topst.ai.pre.20240425001.windows.zip)>
  
    SD_Data.fai イメージを topst.ai.pre.20240425001.windows にコピーします。
    SD_Data.fai は **"{build_dir}/build/tcc7500-main/tmp/deploy/fwdn/"** にあります。


2.  **fwdn_batch.bat** を実行し、**ポート番号**を入力します。

    <p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/Firmware%20Download.image5.png?raw=true"
    style="width:4.22917in;height:3.62292in"</p>

    <p align="center"><strong> 図 3.4 FWDN のポート番号入力</strong></p>

3.  FWDN の完了

    <p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/Firmware%20Download.image6.png?raw=true"
    style="width:5.32292in;height:1.21597in"</p>
 

    <p align="center"><strong> 図 3.5 ファームウェアダウンロードの完了</strong></p>


### 3.3.5 Linux での FWDN

1.  イメージのビルド後、作成された fwdn フォルダをデスクトップにコピーし、
    そのフォルダ内に以下のファイルを保存します。
    FWDN を使用するには、以下のリンクからファームウェアツールをダウンロードできます。

    - <[FWDN Tool](https://topst-downloads.s3.ap-northeast-2.amazonaws.com/Yocto/pre/topst.ai.pre.20240425001.linux.zip)>
  
    SD_Data.fai イメージを topst.ai.pre.20240425001.linux にコピーします。
    SD_Data.fai は **"{build_dir}/build/tcc7500-main/tmp/deploy/fwdn/"** にあります。



2.  **fwdn_nd.sh** を実行し、**ポート番号**を入力します。
