# 2. 起動ガイド

この章では、TOPST AI を起動し、各コアにログインする方法を
説明します。

<br/><br/>

## 2.1 起動シーケンス

起動シーケンスは次のとおりです。

1.  MIPI インターフェースパネルを接続します。
2.  MIPI インターフェースカメラモジュールを接続します。
3.  USB C to A ケーブルをデバッグポートに接続します。
4.  5V 電源を接続します。

## 2.2 UART による TOPST AI の接続

USB デバッグを実行し、Linux 環境で開発を行うには、以下に示すボード上の TOPST AI デバッグポートを使用してコア（CA53）にアクセスできます。
ホスト PC に UART Bridge VCP ドライバ
（https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads で入手可能）
をインストールしてください。
その後、UART を TOPST デバッグボードに接続すると、CP210x USB to UART ドライバが次のように設定されます。

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20Boot.image2.png?raw=true"
style="width:4.11111in;height:4.02083in"</p>
<p align="center"><strong>図 2.2 Windows 環境での USB 接続</strong></p>

ホスト PC のターミナルエミュレータを使用して UART ポートに接続します。
以下は、コアに接続して起動したログ画面です。

<br/>

**例**

- ターミナルエミュレータ: PuTTY または mobaXterm
- 速度: 115200 bps
- データビット: 8
- パリティ: None
- ストップビット: 1
- フロー制御: None
