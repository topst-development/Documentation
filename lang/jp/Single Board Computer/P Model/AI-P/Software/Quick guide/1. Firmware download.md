# 1. FWDN ガイド

本章では、TOPST AI にファームウェアダウンローダ（FWDN）をダウンロードする
方法について説明します。

TOPST AI は、イーサネットと UART を使用して FWDN 機能を提供します。FWDN
モードでは、BL0（Chipboot ROM）が UART を使用してホストから次段の
ファームウェア（BL1）をロードします。（BL1 が初期化を行います。）DRAM を初期化し、
再び UART を使用して FWDN イーサネットに対応する FWDN F/W を DRAM にロードします。
FWDN F/W は TCP/IP または UDP でホストと接続し、FWDN 機能（ストレージへの
データ書き込み、ストレージからのデータ読み出しなど）を実行します。

## 1.1 ファームウェアダウンロードの手順

FWDN のダウンロード手順は次のとおりです。

1.  FWDN モードに入ります（TOPST-AI/Hardware/Overview/4.Firmware Download を参照）。
2.  USB C-to-A ケーブルを USB C タイプの FWDN ポートに接続します。
3.  イーサネットケーブルをイーサネットポートに接続します。
4.  TOPST AI イメージをダウンロードします。

<br/><br/>

## 1.2 FWDN モードへの移行 

FWDN KEY（FWDN Mode Convert）を押しながら電源を接続すると、FWDN モードに
入ります。または、電源が接続されている状態で、FWDN KEY
（FWDN Mode Convert）を押し、RESET KEY（System Reset）を押すことで FWDN
モードに入ります。
