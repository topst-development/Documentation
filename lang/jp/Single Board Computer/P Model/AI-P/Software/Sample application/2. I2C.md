# 2. I2C サンプル

inter-integrated circuit（I2C）は「i-to-c」と読まれることが多いですが、正式な発音は「i-square-c」です。

I2C 通信は、データを送受信する 1 本の SDA ラインと、送受信の
タイミングを同期する 1 本のクロックライン SCL で構成されます。1 つの
マスターと 1 つ以上のスレーブで構成され、最大 127 個のスレーブを
接続できます。

- I2C 通信は 2 本のラインを使用する通信方式です
- 1 つのマスターに複数のスレーブデバイスを接続する方式の長所と短所
  - クロック信号を使用する同期通信方式であるため、タイミングの制約がないという長所
  - スレーブ選択のために常にアドレスデータが付加されるため、長いデータには適さないという短所

3.  i2c_example_app を実行すると、明るさの値を取得します。

    ```
     root@telechips-tcc7500-main:~# ./i2c_example_app
     Target is 144.
    ```

    ```
    root@telechips-tcc7500-main:~# ./i2c_example_app
    ```
