# 3. SPI サンプル

Serial Peripheral Interface(SPI)は、I2C、CAN、UART などと同様のシリアル通信
(serial communication)方式です。マイクロコントローラ、シフトレジスタ、
SD カードなどの小型周辺デバイス間でデータを転送するための
機能です。簡単に言えば、デバイスとデバイス、すなわちチップ(IC)と
チップとの間でデータをやり取りする通信方式の一つです。SPI 通信は
一対多の通信をサポートする同期通信方式であり、複数の通信を行うには
複数のラインが必要になるという欠点があります。また、送信と
受信を同時に行うことができます。配線が容易であるため、単純な
センサーやメモリなどのチップ間通信に
よく使用されます。

<br/><br/>
