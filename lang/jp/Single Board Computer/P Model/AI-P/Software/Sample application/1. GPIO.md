# 1. GPIO の例

GPIO(general-purpose input/output)は、集積回路または電気回路基板上の
デジタル信号ピンであり、入力または出力を含む動作を、実行時に
ユーザーが制御できるように
します。
GPIO は特定の用途にあらかじめ定義されておらず、デフォルトでは
使用されません。
GPIO は、アセンブリレベルの回路ネットワーク設計者(集積回路 GPIO の場合は
回路基板設計者、基板レベル GPIO の場合はシステムインテグレータ、S/I)によって
実装され、その目的と動作は使用時に
定義されます。

GPIO が実行する機能はシステムによって異なる場合があり、一般的に提供される機能は次のとおりです。

- 入出力機能 (high=1, low=0)
- IRQ 信号検出: Power management モードの suspend 状態にあるシステムを
  復帰させるためにも使用できます。
  - Spinlock がかかっている状態でもアクセスできます

上記の機能により、書き込み保護の使用、LED の制御、トランシーバ設定の
  有効化、ハードウェアウォッチドッグ機能、またはスイッチセンシングを
  行うことができます。

次は、ボードの入力と出力をテストする例です。Raspberry Pi のピンマップを
  参照してピン番号を制御することで、入力と出力をテストすることが
  できます。

<br/>

**例**

```
$ echo "90" > /sys/class/gpio/export
$ echo "out" > /sys/class/gpio/gpio90/direction
$ echo 1 > /sys/class/gpio/gpio90/value
$ echo 0 > /sys/class/gpio/gpio90/value
```
