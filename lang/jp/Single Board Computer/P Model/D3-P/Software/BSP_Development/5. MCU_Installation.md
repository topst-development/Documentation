## 5.4 機能の説明

<br/>

### 5.4.1 UART のサポート

TCC8050 MICOM サブシステムは 5 チャネルの UART を備えており、各 UART チャネルは 1 つの ARM® PrimeCell™ UART (PL011) コントローラと 1 つの ARM® PrimeCell™ DMA コントローラ (PL081) で構成されます。UART 通信を介して送受信されるデータは、UART 専用の DMA コントローラによって内部メモリ (SRAM-0 または SRAM-1) との間で転送できます。

### 5.4.1.1 特長

<br/>

### 5.4.1.1.1 UART コントローラ

UART コントローラの特長は次のとおりです。

- プログラマブルな UART 入出力の使用
- CPU 割り込みを削減するための、32×8 送信用および 32×12 受信用の独立した First-In, First-Out (FIFO) メモリバッファ。
- 1 バイト長にするためのプログラマブルな FIFO 無効化。
- プログラマブルなボーレートジェネレータ。これにより、3.6864 MHz を超える基準クロック周波数の分周が可能になります。
- 標準的な非同期通信ビット (スタート、ストップ、パリティ)。
- 送信 FIFO、受信 FIFO、受信タイムアウト、モデムステータス、およびエラー状態の割り込みの個別マスキング。
- Direct Memory Access (DMA) のサポート。
- 誤ったスタートビットの検出
- ラインブレークの生成と検出。
- プログラマブルなハードウェアフロー制御: CTS および RTS のモデム制御機能
- 完全にプログラマブルなシリアルインタフェース特性:
- データは 5、6、7、または 8 ビットでプログラムできます
- 偶数、奇数、スティック、またはパリティなしのビット生成と検出
- 1 または 2 ストップビットの生成
- 最大 UARTCLK/16 までのボーレート生成
- UART を一意に識別する識別レジスタ。オペレーティングシステムが自動的に構成するために使用できます。

<br/>

### 5.4.1.1.2 UART DMA コントローラ

UART DMA コントローラの特長は次のとおりです。

- メモリ間、メモリから UART、UART からメモリへの転送
- DMA コントローラは 2 つのチャネルを備えています。
- リンクリストの使用によるスキャッタ／ギャザー DMA のサポート。これにより、転送元領域と転送先領域が連続したメモリ領域を占有する必要がなくなります。
- データ転送用の 1 つの AHB バスマスタ。このインタフェースは、DMA リクエストが発生したときにデータを転送します
- 32 ビットの AHB マスタバス幅。
- 転送元および転送先に対するインクリメントまたは非インクリメントのアドレッシング。
- プログラマブルな DMA バーストサイズ。DMA バーストサイズをプログラムすることで、データをより効率的に転送できます。通常、バーストサイズは周辺デバイスの FIFO サイズの半分に設定します。
- チャネルごとに内部 4 ワードの FIFO。
- ビッグエンディアンおよびリトルエンディアンのサポート。DMA コントローラはリセット時にリトルエンディアンモードがデフォルトになります。
- DMA エラーと DMA カウントの割り込みリクエストの結合。DMA エラーが発生したとき、または DMA カウントが 0 に達したときに、プロセッサへ割り込みを生成できます。これは通常、転送が完了したことを示すために使用されます。次の 3 つの割り込みリクエスト信号がこれを行います:
- INTTC は転送が完了したときに信号を出力します。
   * **注意**: INTTC 信号は割り込みコントローラには入力されませんが、ステータスレジスタを通じて状態を確認できます。
- INTERR はエラーが発生したときに信号を出力します。
   * **注意**: INTERR 信号は割り込みコントローラには入力されませんが、ステータスレジスタを通じて状態を確認できます。
- INTR は INTTC と INTERR の両方の割り込みリクエスト信号を結合します。INTR 信号は割り込みコントローラに入力されます。
- 割り込みマスキング: DMA エラーおよび DMA ターミナルカウントの割り込みリクエストをマスクできます。
- ロー割り込みステータス: マスキング前の DMA エラーおよび DMA カウントのロー割り込みステータスを読み取ることができます。

### 5.4.1.3 デバッグポートの設定

PIN の設定方法については、第 4 章を参照してください。

```
cr5-bsp/dev.drivers/common/debug.h

#define mcu_printf                          (DBG_SerialPrintf)

cr5-bsp/dev.drivers/common/debug.c

__attribute__ ((naked)) void DBG_SerialPrintf
(
    const int8 *                        format,
    ...
) 
{
    (void)format;
__asm volatile (
            "stmdb  sp!, {r1-r3}    \n"
            "mov    r1, r0          \n"     /* r1 = format string */
            "mov    r2, sp          \n"     /* r2 = arguments */
            "ldr    r0, =DBG_Putc     \n"     /* r0 = function pointer which will put character */
            "str    lr, [sp, #-4]!  \n"     /* save r14 */
            "bl     DBG_Printfi       \n"
            "ldr    lr, [sp], #4    \n"     /* restore r14 */
            "add    sp, sp, #12     \n"     /* restore stack */
            "mov    pc, lr          \n"
            :::"r0", "r1", "r2", "r3" \
    );
}

cr5-bsp/dev.drivers/common/debug.c

sint32 DBG_Putc
(
    sint8                               putChar
)
{
    if (putChar == (sint8)'\n')
    {
        (void)UART_PutChar((uint32)UART_DEBUG_CH, (uint8)'\r');
    }

    (void)UART_PutChar((uint32)UART_DEBUG_CH, (uint8)putChar);

    return 0;
}
```

### 5.4.2 CAN アプリケーション

Controller Area Network (CAN) は、ISO 11898-1 (Bosch CAN プロトコル仕様 2.0 part A、B と同一) に従って通信を行います。さらに、CAN は CAN Flexible Data-rate (FD) プロトコル仕様 1.0 に従った通信もサポートします。

メッセージを処理するすべての機能は、Rx ハンドラと Tx ハンドラによって実装されます。

Rx ハンドラは、メッセージのアクセプタンスフィルタリング、受信したメッセージを CAN コアから Message RAM へ転送する処理を管理し、受信メッセージのステータス情報を提供します。

Tx ハンドラは、送信メッセージを Message RAM から CAN コアへ転送する処理を担当し、送信ステータス情報を提供します。また、タイムスケジュールおよびグローバルシステムタイムに関するすべての機能を実装します。

アクセプタンスフィルタリングは、最大 128 個のフィルタエレメントの組み合わせによって実装され、各エレメントは範囲、ビットマスク、または専用 ID フィルタとして設定できます。

TCC8050 MICOM サブシステムには合計 3 個の CAN FD コントローラが統合されています。CPU は AHB to APB host I/F を介して各 CAN コントローラを設定できます。各 CAN FD コントローラは AHB バスマトリクスを介して MICOM サブシステムに統合された SRAM-0 または SRAM-1 にアクセスし、SRAM-0 または SRAM-1 をメッセージメモリとして使用します。

### 5.4.2.1 機能

CAN アプリケーションの機能は次のとおりです。

- CAN プロトコル バージョン 2.0 part A、B (ISO 11898-1)、Bosch CAN FD 仕様 V1.0、ISO 16845 に準拠
- 最大 64 データバイトの CAN FD をサポート
- CAN エラー検出およびロギング (Stuff/Bit/Format/CRC/ACK)
- 改善されたアクセプタンスフィルタリング
- 設定可能な 2 つの受信 FIFO
- 高優先度メッセージ受信時の個別のシグナリング
- 最大 64 個の専用受信バッファ
- 最大 32 個の専用送信バッファ
- 設定可能な送信 FIFO
- 設定可能な送信キュー
- 設定可能な送信イベント FIFO
- プログラム可能なループバックテストモード
- マスク可能なモジュール割り込み
- 2 つのクロックドメイン (CAN クロックおよびバスクロック)

```
CANErrorType_t CAN_DrvInitChannel
(
    CANController_t *                   psControllerInfo
)
{
    uint8               ucCh;
    uint32              uiMemSize;
    uint32              uiMemAddr;
    CANRegBaseAddr_t *  psConfigBaseRegAddr;
    CANErrorType_t      ret;

    uiMemAddr           = 0UL;
    ret                 = CAN_ERROR_NONE;

    if( ( psControllerInfo != NULL_PTR ) && ( psControllerInfo->cMode == CAN_MODE_NO_INITIALIZATION ) )
    {
        /* Set Config */
        ucCh = psControllerInfo->cChannelHandle;
        psControllerInfo->cRegister = ( CANControllerRegister_t * ) CAN_PortingGetControllerRegister( ucCh );

        /* Set HW_Init */
        ( void ) CAN_PortingInitHW( psControllerInfo );
        ( void ) CAN_PortingSetControllerClock( psControllerInfo, CAN_CONTROLLER_CLOCK );
        ( void ) CAN_PortingResetDriver( psControllerInfo );

        /* Set Memory */
        uiMemSize = CAN_DrvGetSizeOfRamMemory( psControllerInfo );

        if( 0UL < uiMemSize )
        {
            uiMemAddr = CAN_PortingAllocateNonCacheMemory( ucCh, uiMemSize );
        }

        if( uiMemAddr != 0UL )
        {
            psConfigBaseRegAddr = ( CANRegBaseAddr_t * ) CAN_PortingGetMessageRamBaseAddr( ucCh );

            if( psConfigBaseRegAddr != NULL_PTR )
            {
                psConfigBaseRegAddr->rFReg.rfBASE_ADDR = ( SALReg32 ) ( ( uint32 ) ( uiMemAddr >> ( uint32 ) 16UL ) & ( uint32 ) 0xFFFFUL );
            }

            ( void ) CAN_DrvRegisterParameterAll( psControllerInfo );

            ( void ) CAN_DrvStartConfigSetting( psControllerInfo );
            ( void ) CAN_DrvSetControlConfig( psControllerInfo );

            /* Set Buffer */
            ( void ) SAL_MemSet( ( void * ) uiMemAddr, 0, uiMemSize );
            ( void ) CAN_DrvInitBuffer( psControllerInfo, uiMemAddr, uiMemSize );
            ( void ) CAN_MsgInit( psControllerInfo );

            /* Set Filter */
            ( void ) CAN_DrvSetFilterConfig( psControllerInfo );

            /* Set Timing */
            ( void ) CAN_DrvInitTiming( psControllerInfo );

            /* Set Interrupt */
            ( void ) CAN_DrvSetInterruptConfig( psControllerInfo );

            /* Set TimeStamp */
            ( void ) CAN_DrvSetTimeStamp( psControllerInfo );

            /* Set TimeOut */
            ( void ) CAN_DrvSetTimeoutValue( psControllerInfo );

            /* Set WatchDog */
            ( void ) CAN_DrvSetWatchDog( psControllerInfo );

            ( void ) CAN_DrvFinishConfigSetting( psControllerInfo );

            psControllerInfo->cMode = CAN_MODE_OPERATION;
        }
        else
        {
            ret = CAN_ERROR_ALLOC;
        }
    }
    else
    {
        ret = CAN_ERROR_BAD_PARAM;
    }

    return ret;
}

CANErrorType_t CAN_PortingInitHW
(
    const CANController_t *             psControllerInfo
)
{
    CANErrorType_t ret;

    ret = CAN_ERROR_NONE;

    if( psControllerInfo != NULL_PTR )
    {
        switch( psControllerInfo->cChannelHandle )
        {
            case 0:
            {
                PMIO_SetGPK(CAN_0_FS); //Set to normal k-port

                ( void ) GPIO_Config( CAN_0_TX,    ( uint32 ) ( GPIO_FUNC( 2U ) | GPIO_OUTPUT ) ); //can0 tx
                ( void ) GPIO_Config( CAN_0_RX,    ( uint32 ) ( GPIO_FUNC( 2U ) | GPIO_INPUT ) ); //can0 rx
                ( void ) GPIO_Config( CAN_0_STB,   ( uint32 ) ( GPIO_FUNC( 0U ) | GPIO_OUTPUT ) ); //can0 stb
                ( void ) GPIO_Config( CAN_0_INH,   ( uint32 ) ( GPIO_FUNC( 0U ) | GPIO_INPUT ) ); //can0 INH

                ( void ) GPIO_Set( CAN_0_STB, 0UL ); //Set to Low

                break;
            }

            case 1:
            {
                PMIO_SetGPK(CAN_1_FS); //Set to normal k-port

                ( void ) GPIO_Config( CAN_1_TX,    ( uint32 ) ( GPIO_FUNC( 2U ) | GPIO_OUTPUT ) ); //can1 tx
                ( void ) GPIO_Config( CAN_1_RX,    ( uint32 ) ( GPIO_FUNC( 2U ) | GPIO_INPUT ) ); //can1 rx

                /* //CAN_1_STB is not used on EVB
                ( void ) GPIO_Config( CAN_1_STB,   ( uint32 ) ( GPIO_FUNC( 0U ) | GPIO_OUTPUT ) ); //can1 stb

                ( void ) GPIO_Set( CAN_1_STB, 0UL ); //Set to Low
                */

                break;
            }

            case 2:
            {
                PMIO_SetGPK(CAN_2_FS); //Set to normal k-port

                ( void ) GPIO_Config( CAN_2_TX,     ( uint32 ) ( GPIO_FUNC( 2U ) | GPIO_OUTPUT ) ); //can2 tx
                ( void ) GPIO_Config( CAN_2_RX,     ( uint32 ) ( GPIO_FUNC( 2U ) | GPIO_INPUT ) ); //can2 rx

                /* //CAN_2_STB is not used on EVB
                ( void ) GPIO_Config( CAN_2_STB,    ( uint32 ) ( GPIO_FUNC( 0U ) | GPIO_OUTPUT ) ); //can2 stb

                ( void ) GPIO_Set( CAN_2_STB, 0UL ); //Set to Low
                */

                break;
            }

            default:
            {
                ret = CAN_ERROR_BAD_PARAM;

                break;
            }
        }
    }
    else
    {
        ret = CAN_ERROR_NOT_INIT;
    }

    return ret;
}
```
