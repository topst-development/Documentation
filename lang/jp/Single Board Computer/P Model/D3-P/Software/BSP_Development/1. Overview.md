## 1.1 機能ブロック図

TCC8050 は、Car Audio Video Navigation (AVN)、デジタルクラスタ、Around View Monitor (AVM) など、さまざまなソリューションを提供します。TCC8050 は、ARM® Cortex-A72 マルチコアプロセッサおよび Cortex-A53 マルチコアプロセッサ、マイクロプロセッサ用の Cortex-R5、車載セキュリティのためのセキュリティサブシステム内の Hardware Security Module (HSM) の SC000 コア、ストレージ管理用の Cortex-M4、Cortex-M4 サブシステム内の TSDEMUX 用のもう一つの Cortex-M4、そしてマルチメディア体験を最高レベルまで引き上げるハードワイヤードの Video Processing Unit (VPU)/Graphics Processing Unit (GPU) を統合しています。ハードワイヤード VPU は映像のエンコードおよびデコードを可能にし、GPU は OpenGL ES1.1/2.0/3.2 および OpenCL 1.0/1.1/2.0 による 3D グラフィックスを提供します。TCC8050 は、Linux® や Android™ などのさまざまなオペレーティングシステムをサポートします。

TCC8050 は、容易な接続機能を必要とするネットワーク機器に最適化されたプロセッサです。USB 3.0、USB 2.0 Device/Host および USB 2.0 Host コントローラは、マルチメディア機器とストレージ機器の間のデータ伝送を可能にします。Ethernet MAC コントローラは、IEEE802.3 規格に準拠したインターネット接続を提供します。また、PCI Express (PCIe) Gen 3 は、外部 IP 相互接続のための高い帯域幅を提供します。

この革新的で豊富な機能セットは、進化する技術と市場のニーズに応えるため、TCC8050 で利用できるアプリケーションの範囲を拡大します。
