# 2. ソフトウェアアーキテクチャ

図 2.1 は、TCC8050 のソフトウェアアーキテクチャを示しています。3 つのコアは以下の機能で構成され、それぞれが IPC を介して情報をやり取りします。

TCC8050 は CA72 (メインコア) を使用してマルチメディア機能を提供し、CA53 (サブコア) は動作中にメインコアの即時処理 (例: リアカメラ) を提供します。CR5 はリアルタイム OS を提供し、車両との通信に使用される機能を提供します。
