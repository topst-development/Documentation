#  2. 起動ガイド

本章では、TOPST D3 を起動し、各コアにログインする方法について説明します。

<br><br>

## 2.1 起動シーケンス

***FWDN*** のダウンロードシーケンスは次のとおりです。

1. DP モニタ用の DP ケーブルを接続します。
2. デバッグボードと TOPST D3 を接続します。
3. コンソールにログインし、各コアのデバッグを行うため、各 TOPST USB ケーブルをデバッグボードに接続します。
4. 5V 電源を接続します。

<br><br>
