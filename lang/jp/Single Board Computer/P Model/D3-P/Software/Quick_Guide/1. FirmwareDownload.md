# 1. FWDN ガイド

この章では、TOPST D3 に Firmware Downloader（***FWDN***）をダウンロードし、Linux コンソールにログインする方法を説明します。

<br><br>

## 1.1   ファームウェアのダウンロード手順

***FWDN*** のダウンロード手順は次のとおりです。

1. FWDN モードに入ります。
2. USB A-to-A ケーブルを USB 2.0 FWDN ポートに接続します。
3. TOPST イメージをダウンロードします。

<br><br>

## 1.2   FWDN モードへの移行

**SW2**（FWDN Mode Convert）ボタンを押しながら電源を接続して ***FWDN*** モードに入ります。または、電源が接続されている場合は、**SW2** ボタン（FWDN Mode Convert）を押しながら **SW1** ボタン（System Reset）を押すことで ***FWDN*** モードに入ります。

## 1.3 CLI ツールによる Windows 環境での FWDN の実行
  
FWDN を使用するには、以下のリンクからファームウェアツールをダウンロードしてください。

- <[FWDN Tool](https://drive.google.com/file/d/1UzArkpt-Aw67YhAMtlSfkELEHYBMBqT7/view?usp=sharing)>

次のようにして、以下の各 TOPST イメージをダウンロードできます。

- スクリプトの場所: topst.d3.pre.20240425001\fwdn.bat


```
.\fwdn.bat
```
次の図では、.\fwdn.bat コマンドを使用して TOPST イメージ全体をダウンロードしています。
SW1（Reset）ボタンを押して TOPST D3 を再起動すると、Ubuntu ランチャーが実行されます。
