# 2. ビルドガイド

<br/><br/>

## 2.1 TOPST D3 Linux SDK ビルド準備

TOPST D3 Linux SDK は Yocto Project 3.1 Dunfell をベースとしています。したがって、TOPST D3 Linux SDK を使用するには、ホスト PC に Yocto Project 環境を設定する必要があります。SDK、source-mirror、および tools をダウンロードするには、ユーティリティをインストールする必要があります。  

<br/><br/>

## 2.2 Yocto Project  

Yocto Project は、組み込み Linux 開発に重点を置いたオープンソースプロジェクトです。  
Linux イメージを作成するために、Poky である Open Embedded プロジェクトと ***bitbake*** をビルドシステムとして組み合わせて使用します。  
Yocto Project を使用すると、ブートローダー、カーネル、rootfs を同時にビルドできます。  

<br/><br/>

```
sudo add-apt-repository ppa:ubuntu-toolchain-r/test
sudo apt update
sudo apt install g++-11
```
