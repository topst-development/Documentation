# 3. ファームウェアダウンロード

この章では、TOPST D3 (オープンプラットフォームボード) に ***FWDN*** をダウンロードし、Linux コンソールにログインする方法を説明します。  
***FWDN V8*** は、Windows 10 64ビットおよび Linux 環境でファームウェアをダウンロードするための PC ツールです。この章では、Windows および Linux 環境でダウンロードする場合について説明します。

<br/><br/>

## 3.1 ファームウェアダウンロードの手順

***FWDN*** のダウンロード手順は次のとおりです:

1. 起動モードスイッチを USB 起動モードに設定します。
2. Windows プロンプトまたは Linux コンソールを開き、***FWDN V8*** をテストします。
3. ***FWDN V8*** をボードに接続します。
4. fai ファイルをダウンロードします。

<br/><br/>

## 3.2 USB 起動による TOPST D3 とホスト PC の接続

**SW2** を押しながら電源を供給すると、USB 起動プロセスが開始されます。**SW2** を押さずに電源を供給すると、通常の起動プロセスが開始されます。

**SW1** を押すとシステムがリセットされます。ファームウェアをダウンロードする場合は、**SW1** と **SW2** を同時に押して USB モードで起動してください。

## 3.3 FWDN ダウンロードの準備

1. "output.fwdn.zip" を解凍します 
    ```
    $ mkdir images
    $ mv ./output.fwdn.zip ./images
    $ cd images
    $ unzip output.fwdn.zip
    ```
2. "images" フォルダを Windows の C ドライブにコピーします。
    ```
    $ cd ..
    $ cp -r /images /mnt/c/
    ```

## 3.4 Windows 環境での FWDN

## 3.5 Linux 環境での FWDN

Linux 環境では、"./fwdn.sh" コマンドで TOPST イメージをダウンロードできます。

```
$ ./fwdn.sh
```

<br/><br/>

## 3.6 UART による TOPST の接続

1. UART 接続を使用して、ファームウェアのダウンロードが正常に完了したことを確認します。
2. Windows 環境でシリアルポートドライバ (CP210x Windows Driver) をインストールします。([ダウンロードリンク](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads))
3. 起動モードを通常 (eMMC) に変更して再起動します。C to C ケーブルではなく、USB Type-C to USB 2.0 または 3.0 ケーブルを使用してください。
