## 3.3 UART/JTAG サブボード  

UART/JTAG サブボードは、シリアルポートおよび JTAG 用のデバッグ用ボードです。USB Type-C ケーブルで UART/JTAG サブボードをホスト PC に接続することにより、シリアルログを確認できます。   

図 3.3 は、UART/JTAG サブボードの概要を示しています。

<p align="center"><strong>図 3.3 UART/JTAG サブボード (上面図)</strong></p>

表 3.1 は、UART/JTAG サブボードのコネクタについて説明しています。  

**表 3.1 UART/JTAG サブボードの説明:**  

| 項目 | 説明                                           |
|:----:|------------------------------------------------|
| u10  | TOPST D3 を接続する FFC コネクタ               |
| u20  | デバッガを接続する Male Pin Header             |
| u30  | MCU デバッグ用の Debug ポート (USB Type-C)     |
| u40  | A53 Core デバッグ用の Debug ポート (USB Type-C) |
| u50  | A72 Core デバッグ用の Debug ポート (USB Type-C) |

## 3.4 UART/JTAG サブボードと TOPST D3 の接続  

この章では、TOPST D3 と UART/JTAG サブボードを接続する方法について説明します。  

次の手順で、Flexible Flat Cable (FFC) を使用して UART/JTAG サブボードを TOPST D3 に接続します。
1. FFC を 1 本、USB Type-C ケーブルを 1 本準備します。
2. UART/JTAG サブボードの Debug I/F コネクタと TOPST D3 の Debug I/F コネクタに FFC を接続します。 <br/>
    * FFC の青い線が上を向くように接続することが重要です。
3. USB Type-C ケーブルを使用して、UART/JTAG サブボードをホスト PC に接続します。 <br/>
    * 対象のコアに応じて適切な UART ポートを選択するには、表 3.1 を参照してください。たとえば、A72 UART はメインコア (Cortex-A72 Quad) の UART ポートに接続できます。
4. ホスト PC のターミナルアプリケーションでシリアルログメッセージを確認します。

## 3.5 JTAG デバッガと TOPST D3 の接続  

この章では、JTAG デバッガを TOPST D3 に接続する方法について説明します。  

次の手順で、JTAG デバッガを TOPST D3 に接続します。
1. JTAG デバッガを 1 台準備します。
2. 上記の「UART/JTAG サブボードと TOPST D3 の接続」の章を参照して、UART/JTAG サブボードを TOPST D3 に接続します。
3. UART/JTAG サブボードの JTAG Header に JTAG デバッガを接続します。
