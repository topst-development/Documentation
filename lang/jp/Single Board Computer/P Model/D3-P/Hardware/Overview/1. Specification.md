# 1. はじめに


TOPST D3 は、マイクロプロセッサ、メモリ、入出力（I/O）端子を備えた超小型・低消費電力のコンピュータです。TOPST D3 は、モーション、超音波、赤外線、LiDAR、モータドライブ、車載通信トランシーバ、マイク、通信モジュールなど、さまざまなセンサーと組み合わせることができます。  

サポートについては、TOPST ウェブサイト（topst.ai）のハードウェアドキュメントセクションを参照し、TOPST Technical Q&A に質問を投稿してください。

## 1.5 温度範囲と熱特性  
推奨される周囲動作温度範囲は -10°C～55°C です。   
TOPST D3 は、アイドル状態または負荷が軽い場合、Dynamic Voltage and Frequency Scaling（DVFS）ソリューションにより CPU のクロック速度と電圧を下げて発熱を抑えます。TOPST D3 は、追加の冷却装置なしで完全に動作します。車載要件のような拡張動作温度範囲でフル性能で運用する場合は、TOPST までお問い合わせください;topst@topst.ai
