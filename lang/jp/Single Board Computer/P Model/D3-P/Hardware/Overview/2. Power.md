# 2. TOPST D3 への 5V 電源供給



TOPST D3 は 5V Power Jack を通じて電源を供給する構成となっており、5V/3A の電源アダプタが TOPST D3 キットに同梱されています。  


図 2.1 は DC 5V 電源アダプタの電源プラグサイズを示します。  
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/27947dc9-f90f-4c30-b64a-2afd01b93b30"></p>  
<p align="center"><strong>図 2.1 DC 5V 電源供給用プラグサイズ</strong></p>

**注記**: プラグサイズは 2.1 mm ~ 2.5 mm である必要があります。  

<span style="color:red">**警告:**</span> Telechips が提供するアダプタ以外のアダプタを使用した場合、互換性の問題が発生する可能性があります。  


図 2.2 は TOPST D3 上の 5V Power Jack の位置を示します。  
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/e7ab3d03-117d-4f33-ad4c-f97e8a60a8ba"></p>
<p align="center"><strong>図 2.2 TOPST D3 の DC Jack</strong></p>


次の手順に従って TOPST D3 に 5V 電源を供給してください:
1. TOPST D3 キットに同梱されている DC 5V 電源アダプタを確認します。
2. 同梱の電源アダプタを AC コンセントに差し込みます。
3. 電源アダプタの DC ソケットを TOPST D3 の 5V Poser Jack に挿入します。

<br/>

表 2.1 は絶対最大定格を示します。  

<span style="color:red">**警告:**</span> 表 1.1 に記載された値を超えるストレスレベルは、デバイスに恒久的な損傷を与えるおそれがあります。これはストレス定格のみを示すものであり、他の TOPST ガイドの動作に関する項に記載された条件とは異なる条件下でのデバイスの正常な動作を保証するものではありません。  

最大定格条件に長時間さらされると、デバイスの信頼性に影響を与える場合があります。
