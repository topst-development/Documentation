# 4. ファームウェアダウンロードのための TOPST D3 とホスト PC の接続



Firmware Downloader(**FWDN**) は、ホスト PC 上で USB 通信を介して TOPST D3 に ROM イメージを書き込みます。  

TOPST D3 には Boot Mode ボタンが 1 つあり、Boot Mode ボタンによって次の 2 種類の起動モードをサポートします:
- USB Boot Mode は、ホスト PC の **FWDN** プログラムを使用して ROM イメージを書き込むために使用します。
- eMMC Boot Mode は、eMMC デバイスに保存されている ROM イメージを使用して TOPST D3 を起動するために使用します。

**注意**: USB 2.0 D/H ポートはファームウェアダウンローダー (**FWDN**) に使用されます。  

**FWDN** を使用するには、次のように TOPST D3 をホスト PC に接続します:
1. ホスト PC に VTC ドライバがインストールされていることを確認します。VTC ドライバがインストールされていない場合は、topst.ai に掲載されている **FWDN** ガイドラインに従ってインストールしてください。
2. USB Type-A ケーブルを 1 本用意します。
3. USB Type-A ケーブルを使用して、TOPST D3 の USB 2.0 D/H をホスト PC に接続します。
4. 以下の 2 つの方法のいずれかを使用して、TOPST D3 の起動モードを変更します。<br/>
   1. 方法 1
       * TOPST D3 にまだ電源が供給されていない場合は、FWDN ボタンを押しながら TOPST D3 に 5V 電源を接続します。
       * FWDN Boot mode ボタンを離します。<br/>
   2. 方法 2
       * TOPST D3 にすでに電源が供給されている場合は、Reset ボタンと FWDN Boot mode ボタンを押します。
       * FWDN Boot mode ボタンを離します。
5. **FWDN** ガイドに従って ROM イメージをダウンロードします。
