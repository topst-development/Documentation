# 2. TOPST VCP Arduino Core のインストールガイド

本ガイドでは、Arduino 統合開発環境(IDE)で使用する TOPST VCP Arduino core のダウンロードとインストールについて説明します。

<br/><br/>

## 2.1 インストールガイド

### Step 1: Arduino IDE のダウンロード

まず、Arduino ボードをプログラミングするためのプラットフォームとなる Arduino IDE が必要です。

- Arduino の公式 Web サイトにアクセスします: [Arduino Software](https://www.arduino.cc/en/software)
- ご使用のオペレーティングシステム(Windows、macOS、Linux)に適したバージョンを選択します。
- インストーラーをダウンロードして実行します。

<br/>

### Step 2: Arduino IDE のインストール

Arduino IDE をインストールするには、ご使用のオペレーティングシステムに応じて次の手順に従ってください:

#### Windows:
1. ダウンロードした `.exe` ファイルを実行します。
2. インストールの指示に従います。必要なドライバをすべてインストールしてください。

#### macOS:
1. `.dmg` ファイルを開きます。
2. Arduino アプリケーションを Applications フォルダにドラッグします。

#### Linux:
1. `.tar.xz` ファイルを展開します。
2. 展開したディレクトリでターミナルを開きます。
3. `./install.sh` を実行してインストールします。

<br/>

### Step 3: TOPST VCP ボードの追加

TOPST VCP ボードをプログラミングするには、Board Manager を通じてその core を Arduino IDE に追加する必要があります。

1. Arduino IDE を開きます。
2. **File > Preferences** に移動します。
3. 「Additional Board Manager URLs」フィールドに、TOPST VCP core 用の次の URL を追加します:

    ```
    https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
    ```

    (注: 上記の URL は、TOPST VCP core 向けに実際に提供される URL に置き換えてください。)
4. 「OK」をクリックして変更を保存します。
5. **Tools > Board > Boards Manager** に移動します。
6. Boards Manager で「TOPST VCP」を検索します。
7. TOPST VCP の項目が表示されたら「Install」をクリックします。

<br/>

### Step 4: TOPST VCP ボードの選択

インストール後、TOPST VCP ボードを選択する必要があります:

1. **Tools > Board** に移動します。
2. 下にスクロールして「TOPST VCP」を見つけ、選択します。

<br/>

### Step 5: インストールの確認

簡単なスケッチをアップロードして、設定が正しく動作するかテストします:

1. TOPST VCP ボードを USB で PC に接続します。
2. **Tools > Port** で適切なポートを選択します。
3. **File > Examples > 01.Basics > Blink** を開きます。
4. **Upload** ボタンを押して、スケッチをボードに転送します。
5. オンボード LED が点滅し始めれば、ボードは正しく設定されています。

<br/><br/>

## 2.2 トラブルシューティング

セットアップ中に問題が発生した場合は、[Arduino トラブルシューティングガイド](https://www.arduino.cc/en/Guide/Troubleshooting)を参照してください。


詳細情報と高度な機能については、TOPST VCP のドキュメントを参照するか、[Arduino ヘルプセンター](https://support.arduino.cc/hc/en-us)にアクセスしてください。
