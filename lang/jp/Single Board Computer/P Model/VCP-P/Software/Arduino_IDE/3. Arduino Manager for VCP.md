# 3. TOPST VCP Arduino ボードマネージャ

このリポジトリは、TOPST VCP 用の Arduino ボードマネージャを提供します。このボードマネージャにより、Arduino IDE に TOPST VCP ボードのサポートを簡単に追加でき、使い慣れたツールを使ってプログラムの作成とアップロードが行えます。

<br/><br/>

## 3.1 特長

- TOPST VCP のボード定義を簡単にインストールできます。
- Arduino IDE と互換性があります。
- 主要な TOPST VCP ボードモデルをすべてサポートします。

<br/><br/>

## 3.2 インストール

Arduino IDE に TOPST VCP ボードマネージャをインストールするには、次の手順に従ってください:

1. Arduino IDE を **管理者権限で実行** して開きます。
2. `File > Preferences` に移動します。
3. 「Additional Board Manager URLs」フィールドに、次の URL を追加します:
   ```
   https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
   ```
   このフィールドに他の URL がすでにある場合は、カンマで区切ってください。

4. 「OK」をクリックして設定を保存します。
5. `Tools > Board > Boards Manager...` に移動します。
6. Boards Manager で「TOPST VCP」を検索します。
7. TOPST VCP の項目の横にある「Install」をクリックします。

<br/><br/>

## 3.3 使用方法

インストール後、Arduino IDE の `Tools > Board` メニューから TOPST VCP ボードを選択できます。使用しているハードウェアに対応するボードを選択し、通常どおりスケッチの作成とアップロードを行ってください。
