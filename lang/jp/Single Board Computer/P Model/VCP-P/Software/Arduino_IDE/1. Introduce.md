# 1. TOPST VCP Arduino の紹介 

TOPST VCP Arduino プロジェクトへようこそ! 本リポジトリは、高度な車両制御プロセッサ (VCP) である Telechips TCC7045 をベースとした TOPST VCP 向けの Arduino ソフトウェアパッケージの作成に取り組んでいます。私たちの目標は、車載用半導体に特化しながらも、Arduino の簡便さと柔軟性に匹敵する開発環境を提供することです。

<br/><br/>

## 1.1 TOPST VCP について 
TOPST VCP は、車載アプリケーション向けに設計された強力で効率的なプロセッサです。これを Arduino 環境と統合することで、車載分野における開発プロセスの簡素化と迅速化を目指しています。

<br/><br/>

## 1.2 プロジェクトの構成要素 
本プロジェクトは 3 つの主要な構成要素から成り立っています:
1. **Arduino 用 TOPST VCP ブートローダ**: Arduino スケッチを TOPST VCP 上で実行できるようにするカスタムブートローダです。
2. **Arduino Core**: TOPST VCP をサポートするように変更された Arduino のコアソフトウェアです。
3. **TOPST VCP に移植されたライブラリ**: さまざまなアプリケーションで TOPST VCP の性能を最大限に活用できるよう適合されたライブラリ群です。

<br/><br/>

## 1.3 開発環境 
TOPST VCP Arduino プロジェクトにより、開発者は使い慣れた Arduino 統合開発環境 (IDE) でソフトウェアを記述し、それを TOPST VCP 上で直接実行できます。このアプローチは開発プロセスを簡素化し、より幅広い開発者が利用しやすいものにします。

<br/><br/>
