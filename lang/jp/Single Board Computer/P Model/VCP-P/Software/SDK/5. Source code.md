#  5. ソースコードの取得

ソースコードは、あらゆる開発プロジェクトの基盤となるものです。ソースコードには、特定のプラットフォーム向けにソフトウェアをビルドして実行するために必要なすべてのファイル、設定、手順が含まれています。TOPST-VCP ボードにおいては、互換性と最適な性能を確保するために、正しいソースコードを取得することが非常に重要です。

この章では、広く使用されているバージョン管理システムである git を使用してソースコードを取得する手順を説明します。

<br/><br/>

## 5.1 TOPST-VCP ソースコードのクローン

TOPST-VCP ボードのソースコードを取得するには、git clone コマンドを使用します。このコマンドはリモートリポジトリのコピーをローカルマシン上に作成し、コードを直接扱えるようにします。

TOPST-VCP のソースコードをクローンするには、次の手順に従ってください。

1. **ターミナルを開く** : Ubuntu 22.04 システムでターミナルアプリケーションを起動します。
2. **目的のディレクトリへ移動** : ソースコードを保存する適切な場所をシステム上で選択します。たとえば、ユーザーのホームディレクトリに保存する場合は、次のコマンドを使用します

    ```
    $ cd ~
    ```

<p align="center"><strong>図 5.1 目的のディレクトリへ移動</strong></p>


3. **リポジトリのクローン** : 次のコマンドを使用して、提供された git アドレスから TOPST-VCP のソースコードをクローンします

    ```
    $ git clone https://gitlab.com/topst.ai/topst-vcp.git
    ```

4. **クローンしたディレクトリへ移動** : クローン処理が完了したら、次のコマンドを使用してソースコードが格納されているディレクトリへ移動します

    ```
    $ cd topst-vcp
    ```

<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/8ee94839-cdd0-418d-8769-5eba675a8275"></p>

これで、TOPST-VCP ソースコードのローカルコピーがマシン上に用意され、ビルドおよび開発を行う準備が整いました。

<br/><br/>

## 5.2 ソースコード構造の把握

クローン後は、ソースコードのディレクトリ構造と内容を把握しておくと役立ちます。これにより、特定のファイルがどこにあるか、コードベースがどのように構成されているかをより深く理解できます。

- ls などのコマンドを使用してディレクトリの内容を一覧表示します。
- 主要なディレクトリとファイルを確認し、その目的と機能を把握します。

```
$ ls -al
```
