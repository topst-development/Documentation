# 3. 環境設定

TOPST-VCP ボード向けの開発を成功させるには、適切に構成された開発環境が必要です。本章では、必要なツール、ユーティリティ、ソフトウェアパッケージをすべて備えた Ubuntu 22.04 システムをセットアップするための手順を説明します。

<br/><br/>

## 3.1 必須ツールおよびユーティリティのインストール

TOPST-VCP ボードの詳細に入る前に、いくつかの基本的なユーティリティとツールをインストールしておくことが重要です。これらのツールは、他のソフトウェアや設定を構築するための土台となります。

1. **ターミナル** : Ubuntu 22.04 には標準でターミナルが搭載されています。以降の手順の多くはターミナルコマンドを必要とするため、その使い方に慣れておいてください。
2. **テキストエディタ**: Ubuntu には基本的なテキストエディタが付属していますが、好みに応じて “nano”、“vim” などのより高機能なエディタや、“gedit”、“VSCode” などのグラフィカルなエディタのインストールを検討するとよいでしょう。
3. **SSH ツール** : 開発中は、他のシステムやデバイス、特に TOPST- VCP ボードへのリモートアクセスが不可欠になる場合があります。さまざまな SSH ツールがこれを可能にします。
4. **Putty** : SSH をはじめとする各種プロトコルに対応した、広く利用されている無償のオープンソースターミナルエミュレータです。軽量で使いやすいのが特長です。
5. **Tera Term** : より多機能なオープンソースのターミナルエミュレータで、SSH を含むさまざまな通信プロトコルを幅広くサポートします。

具体的なニーズや好みに応じて、SSH アクセス用にこれらのツールから 1 つ以上を選択できます。  

**参考として、本ガイド文書では putty を使用します。**

<br/><br/>

## 3.2 apt を使用したソフトウェアのインストール

“apt” パッケージマネージャは Ubuntu の強力なツールであり、ソフトウェアパッケージのインストール、更新、管理を容易に行えます。

<br/>

### 3.2.1 パッケージリストの更新

新しいソフトウェアをインストールする前に、利用可能なパッケージのリストを更新しておくことをおすすめします。これにより、最新のバージョンと依存関係を取得できます。

```
$ sudo apt update
$ sudo apt upgrade
```

このコマンドは、リポジトリから利用可能なパッケージの最新リストを取得します。

### 3.2.2 一般的な開発ツールのインストール

ほとんどの開発作業、特に TOPST-VCP ボード向けの作業では、いくつかの一般的なツールが不可欠です。

次のコマンドを使用してこれらのツールをインストールします :

```
$ sudo apt install build-essential git
```

このコマンドは buide-essential パッケージと git の両方をインストールします。
