#  6. ソースコードのビルド

ソースコードの取得が完了したら、次の重要なステップはソースコードをビルドし、TOPST-VCP ボード上で最適に動作するようにすることです。

<br/><br/>

## 6.1 Makefile とビルドシステムの理解

Makefile は多くのビルドシステムの基礎となるものです。Makefile には、make ユーティリティにプログラムのコンパイル方法とリンク方法を指示するルールとディレクティブが記述されています。Makefile を活用することで、開発者はビルド処理を自動化し、一貫性と効率性を確保できます。

<br/><br/>

## 6.2 ビルド処理の開始

ソースコードのビルドを開始するには、次の手順に従ってください :

1. **次のコマンドを使用してビルドディレクトリに移動してください :**

    ```
    $ cd build/tcc70xx/gcc/
    ```

2. **次のコマンドを使用して make コマンドを実行してください :**

    ```
    $ make
    ```

このコマンドは、現在のディレクトリにある Makefile を読み込み、ビルド処理を実行します。
