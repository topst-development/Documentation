# 7. TOPST VCP ハードウェアへのダウンロード

ビルドしたソフトウェアを TOPST-VCP ボードへ転送することは、開発プロセスにおいて非常に重要な工程です。本章では、Linux ベースの開発環境を使用して VCP ハードウェアにソフトウェアをダウンロードする方法について、包括的なガイドを提供します。

<br/><br/>

## 7.1 ハードウェアの準備

ダウンロード作業を開始する前に、TOPST-VCP ボードが安定した位置にあり、妨げとなるものがないことを確認してください。すべてのスイッチとコネクタに容易にアクセスできること、および 3.3v 電源ケーブルが正しく接続されていることを確認してください。

<br/><br/>

## 7.2 開発ホスト PC へのハードウェアの接続

1. **USB C ケーブルの接続:** USB C ケーブルを使用して、TOPST-VCP ボードを開発ホスト PC に接続します。
2. **接続の確認**: Linux マシン上で次のコマンドを実行します

    ```
    $ sudo dmesg | grep tty
    ```

## 7.3 ビルドしたソフトウェアの転送

1. **ボードをダウンロードモードに設定 :** TOPST-VCP ボード上で FWDN スイッチを FWDN 位置に切り替えます。PORN ボタンを押してリセットします。これでボードは FWDN ダウンロードモードになります。

</p>
<p align="center"><strong>図 7.2 ボードをダウンロードモードに設定</strong></p>

2. **ダウンロードコマンドの実行** : FWDN ツールを使用して、4MB フラッシュ用のソフトウェアをボードにダウンロードします

    ```
    $ sudo ../../../tools/fwdn_vcp/fwdn --fwdn ../../../tools/fwdn_vcp/vcp_fwdn.rom -w output\tcc70xx_pflash_boot_4M_ECC.rom
    ```

<p align="center"><strong>図 7.3 ダウンロードコマンドの実行</strong></p>

3. **ボードのリセット:** ダウンロード処理が完了したら、FWDN スイッチを NORMAL 位置に戻します。電源を入れ直すか、PORN ボタンを押してボードをリセットします。

## 7.4 ボード上のソフトウェアの検証

ソフトウェアがボードにダウンロードされたら、正しく動作することを検証することが重要です:

1. **minicom のインストール**  
    ```
    $ sudo apt install minicom
    ```
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/20a8f4ad-68da-472d-8b56-7a8fffad0643"></p>
<p align="center"><strong>図 7.5 Minicom のインストール</strong></p>

2.  **シリアル接続を開く** : 次のコマンドを使用してシリアル接続を開始します

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

</p>
<p align="center"><strong>図 7.6 シリアル接続を開く</strong></p>


3. **ターミナル上で次の結果を確認できます** : 接続に成功すると、ボードと対話し、その応答を確認できるようになります。これにより、ソフトウェアがダウンロードされ、TOPST-VCP ボード上で正しく動作していることが確認できます。

## 7.5 よくある問題のトラブルシューティング

入念に準備していても、ダウンロード処理中に問題が発生することがあります。ここでは、よくある問題の解決方法をいくつか紹介します:

**問題:** fwdn ツールが ttyUSB0 デバイスへのアクセス権限がないと報告します。

**解決方法** : この問題は、ご使用のユーザーアカウントにシリアルデバイスへアクセスするために必要な権限がない場合に発生します。ユーザーアカウントを dialout グループに追加することで、これらの権限を付与できます。

1. **ユーザーグループ権限の変更** : 次のコマンドを実行します

    ```
    $ sudo usermod -aG dialout $USER
    ```
<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/a7552057-86de-4c49-876d-d50435bd16e4">
</p>
<p align="center"><strong>図 7.8 ユーザーグループ権限の変更</strong></p>


2. **ログアウトして再ログイン** : グループの変更を有効にするには、現在のセッションからログアウトし、再度ログインする必要があります。その後、ttyUSB0 デバイスへのアクセスを再度お試しください

発生する問題の大半には解決方法または回避方法があることを覚えておいてください。エラーメッセージを理解し、疑問がある場合はドキュメントやオンラインコミュニティを参照することが不可欠です。

**問題** : minicom の使用時に、TOPST-VCP ボードとの通信が正常に行われない、または動作が不安定になります。

**解決方法** :この問題は、minicom のデフォルトのフロー制御がハードウェアに設定されていることが原因で発生する場合があります。TOPST-VCP ボードと円滑に通信するには、フロー制御を "none" に設定する必要があります。


1. **minicom の起動 :**

    次のように入力するだけで minicom ツールを起動できます :

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/7f8fd60c-eb59-474e-99f2-a5ab9cc6abc8">
</p>
<p align="center"><strong>図 7.9 minicom の起動</strong></p>

2. **設定画面へのアクセス :** minicom の実行中に Ctrl-A を押し、続いて “o” を押すと設定画面にアクセスできます。

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/79fa7579-374f-4714-9490-3a1d3fe40a70">
</p>
<p align="center"><strong>図 7.10 設定画面へのアクセス</strong></p>

3. **シリアルポート設定への移動** : オプションの一覧から "Serial port setup" を選択します
4. **フロー制御の変更 :** シリアルポート設定内で “ F” を押し、ハードウェアフロー制御を "No" に切り替えます。

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/9c4ac77c-1e19-4bee-a0f3-f3ad6f3b3791">
</p>
<p align="center"><strong>図 7.11 フロー制御の変更</strong></p>

5. **終了して保存** : 完了したら、設定画面を終了して構成を保存します。これで minicom は TOPST-VCP ボードと正しく通信できるようになります。
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/e9c61695-1637-470c-b91f-34ddeff4a923"></p>
<p align="center"><strong>図 7.12 終了して保存</strong></p>

**注意**: minicom 以外のシリアル通信ツールを使用している場合は、正しく動作させるために同様にフロー制御を "none" に設定してください。
