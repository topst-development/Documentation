# 1. はじめに

<br/><br/>

## 1.1 本ガイドの目的  

本ガイドは、Linux システム上で TOPST-VCP ボード向けのソフトウェア開発環境を構築する方法について、包括的な概要を提供することを目的としています。本書に記載された手順に従うことで、開発者は TOPST-VCP ボードおよび関連するツールチェーンを効果的に扱うために必要なツール、設定、および知識を身につけることができます。

<br/><br/>

## 1.2 TOPST VCP ボードの概要  

TOPST-VCP ボードは、さまざまなアプリケーション向けに設計された、強力かつ汎用性の高い開発ボードです。このボードの中核には、ARM Cortex-R5 アーキテクチャをベースとした TCC7045 チップが搭載されています。この組み合わせにより効率と性能のバランスが確保され、ARM ベースのアプリケーションの性能を活用したい開発者にとって最適な選択肢となります。

## 1.3 ツールチェーンの概要  

TOPST-VCP ボードで効果的に開発を行うには、適切なツールチェーンを用意することが不可欠です。本ガイドでは、クロスコンパイルに gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi を使用することを特に推奨します。このツールチェーンは ARM Cortex-R5 アーキテクチャと互換性があるだけでなく、TCC7045 チップに最適化されたツール群を提供します。
