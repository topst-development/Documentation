# 2. 前提条件

TOPST-VCP ボードのセットアップおよび開発プロセスに取りかかる前に、考慮すべきいくつかの前提条件があります。本章では、スムーズな開発を実現するために推奨される Linux ディストリビューション、ハードウェア要件、および必要となる基礎知識について説明します。

<br/><br/>

## 2.1 Linux ディストリビューションの推奨事項

本ガイドでは、開発環境を **Ubuntu 22.04** 上に構築することを推奨します。このバージョンの Ubuntu は安定したプラットフォームと幅広いコミュニティサポートを提供し、TOPST-VCP ボードおよび関連するツールチェーンとの互換性と使いやすさを保証します。

ダウンロードとインストール:

- Ubuntu の公式ウェブサイトにアクセスし、Ubuntu 22.04 LTS (Long Term Support) ディストリビューションをダウンロードします。
- 提供されているインストール手順に従って、開発用ホスト PC に Ubuntu 22.04 をセットアップします。

## 2.2 ハードウェア要件

TOPST-VCP ボードと接続して開発作業を行うには、以下のハードウェアコンポーネントが必要です :

- TOPST-VCP ボード: ハードウェア作業に適した作業スペースにボードを用意してください。
- USB-C ケーブル: 開発用ホスト PC と TOPST-VCP ボードとの接続に使用します。開発プロセス全体を通じて安定した接続を維持できるよう、品質の良いケーブルを使用してください。

必要なハードウェアを揃えたら、USB-C ケーブルを使用して TOPST-VCP ボードを開発用ホスト PC に接続します。開発中の障害を避けるため、接続が確実であることを確認してください。

<br/><br/>

## 2.3 知識に関する前提条件

始める前に、以下の概念を理解しておくことが重要です:

- Ubuntu の基礎: Ubuntu 22.04 環境内での操作方法に関する基本的な理解。
- TOPST-VCP の起動モード: TOPST-VCP ボードはさまざまな起動モードを提供しており、開発者は特定のプロジェクトに最適なモードを選択できます。

起動モードの選択方法に関する詳細な手順はボードとともに提供されます。提供されているドキュメントを参照し、開発ニーズに適したモードを選択してください
