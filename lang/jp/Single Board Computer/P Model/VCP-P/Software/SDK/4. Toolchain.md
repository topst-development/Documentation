# 4. ツールチェーン

ツールチェーンは開発プロセスにおいて重要な構成要素であり、特に TOPST-VCP ボードのような専用ハードウェアを扱う場合には不可欠です。ツールチェーンは、ターゲットプラットフォーム向けにコードをコンパイル、リンク、デバッグするための一連のツールを提供します。

<br/><br/>

## 4.1 ツールチェーンの概要

ツールチェーンは通常、コンパイラ、リンカ、アセンブラ、デバッガなどのツールで構成されます。これらの構成要素が連携して、ソースコードをターゲットハードウェア上で実行可能なプログラムに変換します。ハードウェアアーキテクチャやプラットフォームは多岐にわたるため、ターゲットボードに適したツールチェーンを選択して設定することが不可欠です

<br/><br/>

## 4.2 ボードに適したツールチェーンの選択

ARM Cortex-R5 アーキテクチャをベースとする TOPST-VCP ボードでは、gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi のツールチェーンを推奨します。

このツールチェーンは ARM アーキテクチャ向けに最適化されており、ボード上の TCC7045 チップとの互換性が確保されます。

<br/><br/>

## 4.3 ツールチェーンのインストールとセットアップ

以下の手順に従って、ツールチェーンのダウンロード、展開、セットアップを行います。

1. **ツールチェーンのダウンロード** : wget コマンドを使用して、Linaro の Web サイトからツールチェーンをダウンロードします :

    ```
    $ wget https://releases.linaro.org/components/toolchain/binaries/7.2-2017.11/arm-eabi/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```

<p align="center"><strong>図 4.1 ツールチェーンのダウンロード中</strong></p>

2. **ツールチェーンの展開** : ダウンロードが完了したら、.tar.xz ファイルの内容を展開します。

    ```
    $ tar -xvf gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```


<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/cd69488b-5f20-4b5e-95dd-6b1a9f37e38c">

<p align="center"><strong>図 4.2 ツールチェーンの展開</strong></p>

3. **ツールチェーンを /opt に移動** : /opt ディレクトリは、Linux におけるオプションソフトウェアの標準的な配置場所です。展開したツールチェーンをこのディレクトリに移動します。

    ```
    $ sudo mv gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi /opt/
    ```

## 4.4 ツールチェーンのインストール確認

ツールチェーンが正しくインストールされたことを確認するには、次の手順を実行します。

1. **ツールチェーンのディレクトリに移動する** :

    ```
    $ cd /opt/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi
    ```

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/466c6ed7-4105-4cbd-9652-401bb18c7e56">
</p>
<p align="center"><strong>図 4.4 ツールチェーンのディレクトリに移動</strong></p>

2. **インストールされた GCC コンパイラのバージョンを確認する** :
    
    ```
    $ ./bin/arm-eabi-gcc --version
    ```

<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/9f00226a-2092-4a82-aa07-26ca33a5d347">
<p align="center"><strong>図 4.5 インストールされた GCC コンパイラのバージョン確認</strong>

インストールが成功していれば、インストールされた GCC のバージョン情報が表示され、gcc-linaro-7.2.1-2017.11 のバージョンと一致していることを確認できます。
