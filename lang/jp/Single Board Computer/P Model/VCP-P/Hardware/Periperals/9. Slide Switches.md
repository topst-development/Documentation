# 9. スライドスイッチ (SW3、SW7、SW8)


TOPST VCP では、SW3 は ILL の ON/OFF を選択するために、SW7 は ACC の ON/OFF を選択するために、SW8 は STR モードの有効化の ON/OFF を選択するために使用します。  

図 9.1 はトグルスイッチ(SW3、SW7、SW8)の位置を示しています。
