# 5. デバッグおよび FWDN 用コネクタ (JC1)  


TOPST VCP では、JC1 は UART 経由のデバッグまたは FWDN に使用されます。  
これは標準の USB Type-C コネクタです。  

図 5.1 は、JC1 の位置を示しています。  
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/8b19656c-59d5-4389-87f3-4939bf501587"></p>  
<p align="center"><strong>図 5.1 USB Type-C コネクタ</strong></p>  

JC1 を通じて FWDN を実行したり、TCC7045 のデバッグメッセージを確認したりできます。  
TOPST VCP では JC1 用に USB to UART ブリッジコントローラが設計されており、USB Type-C ケーブルを使用して JC1 を PC に直接接続できます。
