# 3. 起動モード (SW2)


TOPST VCP はブートモード (BM) を使用する起動設定用のピンを 1 つ備えており、2 つのモードをサポートします:  
UART 起動モードと通常モードです。

スライドスイッチ (SW2) は、TOPST VCP の起動モードを選択するために使用します。

## 3.1 UART 起動モード
このモードは主にファームウェアダウンロード (**FWDN**) モード用です。
このモードでは、UART ポートを使用してユーザー定義領域にプログラムをダウンロードできます。


表 3.2 は UART 起動モード用のスライドスイッチの設定について説明します。
