# 1. はじめに
---
本書では、AI-G SDK に含まれるサンプルアプリケーションおよびテストアプリケーションの使用方法について説明します。これらのアプリケーションは、AI-G のオンボード NPU を使用した AI 推論機能をユーザーが理解し評価できるように設計されています。  
本書には次の情報が含まれます。
- サンプルアプリケーション
  - tcnnapp
  - tcnncameraapp
  - tcnputestapp
<br/><br/><br/><br/>
 
 
# 2. サンプルアプリケーション
---
この章では、AI-G SDK で提供される 3 つのサンプル/テストアプリケーションについて説明します。各アプリケーションは、AI-G の AI 機能をユーザーが評価し活用できるように設計されています。これらのアプリケーションは、NPU 推論テストやリアルタイムカメラ入力など、さまざまなシナリオに対応します。
<br/><br/><br/>
 
## 2.1 tcnnapp
---
tcnnapp は、AI-G プラットフォームの NPU を使用して画像ベースの推論を実行する方法を示すサンプル AI アプリケーションです。さまざまな入出力モードに対応し、YOLOv5s や MobileNetv2 などの学習済みモデルを使用した物体検出を実演します。
<br/><br/>
 
### ユースケース 1. ファイルからファイルへの基本推論
このケースでは、ローカルの画像ファイルに対して推論を実行し、その結果を出力ファイルに保存する方法を示します。カメラやディスプレイのハードウェアを使用せずに基本的な機能テストとモデル検証を行う場合に有用です。  
推論を実行するには、次のコマンドを入力します。
```
$ tcnnapp -i file -p test.png -o file -P result.png
```
 
このコマンドは、入力画像ファイル (test.png) を使用して tcnnapp を実行し、推論結果を出力ファイル (result.png) に保存します。モデルを指定しない場合、アプリケーションは既定の量子化モデルである YOLOv5s と MobileNetv2 を自動的に使用します。

### ユースケース 2. カメラとディスプレイを使用したリアルタイム推論
このケースでは、MIPI CSI カメラと MIPI DSI ディスプレイを接続した状態で tcnnapp を使用し、リアルタイム AI 推論を実行して結果を可視化する方法を示します。アプリケーションはカメラからのライブ映像入力をストリーミングし、NPU 上で既定の量子化モデル (YOLOv5s および MobileNetv2) を使用してリアルタイム推論を実行し、その結果を画面に表示します。  
デバイスの接続は次のとおりです。
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Available%20Applications/Figure%202.%20Device%20Connection.png" width="600"></p>
<p align="center"><strong>図 2.2 AI-G におけるカメラとディスプレイの接続 </strong></p><br/>
 
デバイスを接続した後、次のコマンドを入力します。
```
$ tcnnapp -i camera -o display
```
このコマンドは、CSI カメラを入力としてリアルタイム推論を開始します。取得された映像フレームは、物体検出および分類処理のために NPU へ送られます。
バウンディングボックス、クラスラベル、信頼度スコアなどの推論結果は、出力フレーム上に直接描画されます。
これらの注釈付きフレームは 5 インチ DSI ディスプレイにリアルタイムで表示され、即座に視覚的なフィードバックが得られます。
 
視覚的な出力に加えて、システムは CPU 使用率、NPU 使用率、メモリ状態などの主要な性能指標をログに記録します。これらはシリアルコンソールまたはリモートインターフェースを通じて監視できます。

### ユースケース 3. カメラと RTPM を使用したリアルタイム推論
このケースでは、MIPI CSI カメラを入力として接続し、Real-time Performance Monitor (RTPM) を出力方式として tcnnapp を使用する方法を示します。このアプリケーションはカメラからのライブ映像入力をストリーミングし、NPU 上で既定の量子化モデル (YOLOv5s および MobileNetv2) を使用してリアルタイム推論を実行し、可視化と性能監視のためにその結果を RTPM 経由で PC へ送信します。  
RTPM ツールキットは、PC 環境で AI-G からの出力を監視するために Python で開発された GUI ベースのツールです。推論結果に加えて、CPU、NPU、メモリ使用量などのシステム性能指標も確認できます。  
 
**注意**: RTPM の詳細については、Software セクションの RTPM.md を参照してください。
 
デバイスの接続は次のとおりです。
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Available%20Applications/Figure%204.%20Camera%20and%20RTPM%20Communication%20via%20AI-G.png"width="900"></p>
<p align="center"><strong>図 2.4 AI-G を介したカメラと RTPM の通信 </strong></p><br/>

このコマンドは、CSI カメラを入力としてリアルタイム推論を開始します。検出された物体や分類ラベルなどの推論結果はホスト PC へ送信され、RTPM インターフェース上で可視化されます。  
推論出力に加えて、RTPM は CPU 使用率、NPU 負荷、メモリ使用量を含むシステム性能指標もリアルタイムで表示します。

### ユースケース 4. RTPM の入出力を使用した推論
このケースでは、ホスト PC から RTPM を通じてストリーミングされた入力画像を使用して推論を実行し、その推論結果を同じ RTPM インターフェースを通じて PC へ返して表示する方法を示します。入力データは画像または動画のいずれでもかまいません。  
RTPM を実行するには、Software セクションの RTPM.md ドキュメントを参照してください。その後、次のコマンドを入力します。
```
$ tcnnapp -i rtpm -o rtpm
```
このコマンドは、RTPM を入力と出力の両方として使用して tcnnapp を実行します。データはホスト PC から RTPM を通じて送信され、AI-G ボード上の NPU で処理された後、推論結果が PC へ返されて RTPM インターフェース上に表示されます。

## 2.2 tcnncameraapp
---
tcnncameraapp は、AI-G プラットフォームでサポートされるカメラモジュールをテストおよびプレビューできるサンプルアプリケーションです。Video4Linux2 (V4L2) フレームワーク上に構築されており、接続された MIPI CSI インターフェースと DSI ディスプレイを通じてリアルタイムのカメラプレビューを可能にします。  
このアプリケーションは主に、カメラ機能の検証、ディスプレイ出力のテスト、画像信号品質のデバッグに使用します。また、カメラモジュールの種類に応じて複数のカメラを同時に監視することもできます。  
tcnncameraapp が提供するオプションを次の表に示します。
 
| 名称              | オプション | 範囲    | 既定値      | 例             | 説明                                  |
| ------------------| --------| ----------| ------------| ---------------| --------------------------------------|
| 使用方法の情報    | -?      |     -     |             | -?             | 使用方法の情報を表示します            |
| 入力パス          | -p      |     -     | /dev/video0 | -p /dev/video0 | 入力パスを指定します                  |
| 出力パス          | -P      |     -     | /dev/overlay| -P /dev/overlay| 出力パスを指定します                  |
| 入力幅            | -w      | 最大 2560 | 1920        | -w 2560        | 入力の幅を指定します                  |
| 入力高さ          | -h      | 最大 1440 | 1080        | -h 1080        | 入力の高さを指定します                |
| 出力幅            | -W      | 最大 1920 | 1920        | -W 1920        | 出力の幅を指定します                  |
| 出力高さ          | -H      | 最大  720 | 720         | -H 720         | 出力の高さを指定します                |
| 出力位置 X        | -X      | 最大 1920 | 0           | -X 960         | 出力の X 座標を指定します             |
| 出力位置 Y        | -Y      | 最大  720 | 0           | -Y 360         | 出力の Y 座標を指定します             |
<p align="center"><strong>表 2.1 カメラテストアプリケーションのオプション</strong></p><br/>

## 2.3 tcnputestapp
---
tcnputestapp は、AI-G プラットフォーム上の NPU (Neural Processing Unit) の基本機能を検証するサンプルアプリケーションです。tcndnpulib ライブラリを利用して、コンパイル済みのニューラルネットワークモデルで NPU の実行を直接テストします。このアプリケーションは主に、カメラやディスプレイを使用せずに NPU の内部検証、デバッグ、性能テストを行うことを目的としています。  
tcnputestapp が提供するオプションを次の表に示します。
 
| 名称           | オプション | 範囲  | 既定値      | 例                       | 説明                                  |
| ---------------| -------| ----------| ------------| -------------------------| --------------------------------------|
| 使用方法の情報 | -?     |     -     |      -      | -?                       | 使用方法の情報を表示します            |
| NPU 番号       | -d     |    0, 1   |      0      | -d 0 / -d 1 / -d 0 1     | ネットワークの NPU インデックスを指定します |
| ネットワークパス | -n   |     -     | /usr/share/yolov5s_quantized| -n /usr/share/mobilenetv2_10_quantized/   | テストするニューラルネットワークを指定します。NPU を 2 つ選択した場合は同じニューラルネットワークパスになります|
| テスト回数     | -t     | -         | 1           | -t 100                   | ニューラルネットワークのテスト回数を指定します|
