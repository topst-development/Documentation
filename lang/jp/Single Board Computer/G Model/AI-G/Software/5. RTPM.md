# 1. はじめに
---
Real-Time Performance Monitor (RTPM) ツールキットは、AI-G の性能指標をリアルタイムで監視および可視化するために設計された Python ベースのグラフィカルアプリケーションです。AI-G ボードとホスト PC の間の接続を確立することで、RTPM は CPU、NPU、メモリ使用率、推論時間などの主要な性能データの伝送と解析を可能にします。
 
RTPM は 2 つのモードで動作します。
 
**Injection Mode**: このモードでは、ホスト PC が処理のために画像データを AI-G に送信します。AI-G は NPU を使用して推論を実行し、その結果を可視化のために PC に返します。
 
**Projection Mode**: このモードでは、AI-G が接続されたカメラを通じて画像を取得し、内部で処理を行い、推論結果をホスト PC の RTPM に送信します。
 
本ツールキットは、AI-G プラットフォーム上で AI アプリケーションの性能を評価し最適化しようとする開発者およびエンジニアにとって特に有用です。システムの動作に関するリアルタイムの情報を提供し、効率的なデバッグと性能チューニングを可能にします。
 
詳細なセットアップ手順および使用方法については、本ドキュメントの以降のセクションを参照してください。

## 2.1 性能モニタリング
--- 
Real-Time Performance Monitoring Toolkit (RTPM) は Python を使用して開発された
GUI ベースのツールで、PC 環境で AI-G の出力を監視し、
CPU、NPU、メモリの性能データを確認できます。
 
 
 
**表 2.1 RTPM の性能データ一覧:**
 
|   番号   |  性能データ    |                説明             |
|--------|----------------------|----------------------------------------|
| 1      | Inference Time       | 各モデルの推論時間 (ms)     |
| 2      | NPU Utilization      | 各モデルの NPU 使用率         |
| 3      | FPS                  | NPU 動作に基づく FPS 情報 |
| 4      | CPU                  | CPU 使用率 (500 ms 周期)         |
| 5      | Memory               | メモリ使用率 (500 ms 周期)      |

## 2.4 RTPM アプリケーション起動ガイド
---
本セクションでは、ホスト PC に Real-Time Performance Monitor (RTPM) アプリケーションをセットアップする手順を段階的に説明します。
ツールのインストール、ワークスペースの構成、および AI-G の NPU 性能と推論結果を監視するための RTPM インターフェースの実行方法を含みます。
 
<br/><br/>
 
### 2.4.1 RTPM 用ツールのインストール
 
- ホスト PC の環境を準備します。
 
1. Visual Studio Code をインストールします。
   * Microsoft Store で「Visual Studio Code」を検索してインストールします。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/5.%20Install%20Visual%20Studio%20Code.png"></p>
<p align="center"><strong>図 2.5 Visual Studio Code のインストール</strong></p><br/>
 
2. Python 3.10 をインストールします。
   1. Visual Studio Code を開きます。
   2. 左側のサイドバーにある Extensions アイコンをクリックするか、次のキーを押して Extensions ビューを開きます。 
   *Ctrl + Shift + X*.
   3. Extensions の検索バーに Python と入力します。
   4. Microsoft が提供する Python 拡張機能を見つけ、Install をクリックします。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/6.%20Install%20Python3.10.png"width="800"></p>

### 2.4.3 Injection Mode の使用
 
1.  Input Mode を Folder (画像のみ) に変更します。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/13.%20Change%20the%20Input%20Mode%20to%20Folder%20(Only%20Image).png"></p>
<p align="center"><strong>図 2.13 Input Mode を Folder (画像のみ) に変更</strong></p><br/>
 
2.  推論したい画像フォルダを選択します。
 
    画像フォルダにサブフォルダを含めてはいけません。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/14.%20Select%20the%20image%20folder.png"></p>
<p align="center"><strong>図 2.14 画像フォルダの選択</strong><br/>

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/15.%20Image%20folder%20selected%20at%20rtpm.png"></p>
<p align="center"><strong>図 2.15 推論を実行するファイルの選択</strong></p><br/>

5.  AI-G 上で tcnnapp の Injection mode を開始します。(実行の順序は
    結果に影響しません。)
 
    ```
    # tcnnapp -i rtpm -o rtpm
    ```
