# 1. はじめに
---
本書では、AI-G SDK が提供するサンプル/テストアプリケーションの使用方法について説明します。SDK には、カメラ入力、ファイル入力、RTPM などのさまざまなモードで NPU (Neural Processing Unit) を使用してニューラルネットワークの推論を実行する方法を示すサンプルアプリケーション tcnnapp が含まれています。
 
<br/><br/><br/>
 
## 1.1 概要
---
NPU サンプルアプリケーションは、NPU (Neural Processing Unit)
の処理のみを実行できます。

## 1.4.1 ソースファイルの説明
 
このソースファイル ("tcnnapp") は、カメラまたはファイルからの入力を処理し、シングルモードおよびデュアルモードで
ニューラルネットワークを使用して推論を行う例を実装しています。“NnAppMain.c” ファイルはプログラムのエントリポイントとして機能し、
モードの選択と結果の出力を可能にします。また、yolov5s_quantized と mobilenetv2_10_quantized がニューラルネットワークモデルを
定義します。カメラ、ディスプレイ、スケーラの機能はモジュール化され、映像の入出力を処理するための API として提供されます。さらに、
メッセージ処理と結果の描画のためのユーティリティ関数も含まれ、全体の機能を支えています。この構造は、ニューラルネットワークの
さまざまなモードを簡単に使用できるように設計されています。
 
<br/><br/><br/>
