# 2. AI-G の起動モード
---
AI-G は次の起動モードをサポートします: 
- USB Boot Mode (FWDN)  
- eMMC Boot Mode (GPIO_SD Group)

AI-G ボードはデフォルトで eMMC Boot Mode に固定されています。eMMC デバイスに起動イメージが存在しない場合、起動モードは自動的に FWDN Boot Mode に切り替わります。 

<br/><br/><br/>

## 2.1 USB Boot Mode (FWDN)
--- 
図 2.1 は Boot Mode スイッチと RESET スイッチを示します。USB Boot Mode はファームウェアの更新に使用します。FWDN モードに入るには、Boot mode スイッチと RESET スイッチの両方が必要です。イメージをアップロードする際は、この方法を使用することを推奨します。

<p align="center"><strong>図 2.1 FWDN Boot Mode に入るための Boot Mode スイッチと RESET スイッチ </strong></p><br/>

次の手順では、USB Boot Mode に入るためのスイッチ操作について説明します。 
1. 電源が供給されると、RESET スイッチの上にある LED が点灯します。 
2. Boot Mode スイッチを押し続けます。Boot Mode スイッチを押すと、スイッチの上にある赤色 LED が点灯するのを確認できます。LED を点灯させたままにするため、スイッチを押し続けてください。 
3. RESET スイッチの LED はデフォルトで緑色です。RESET スイッチを一度押すと、緑色 LED が消灯し、その後再び点灯します。 
4. Boot Mode スイッチを離します。
