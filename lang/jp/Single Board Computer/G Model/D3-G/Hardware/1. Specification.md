# 1. はじめに
---
D3-G は、マイクロプロセッサ、メモリ、入出力 (I/O) 端子を備えた超小型・低消費電力のコンピュータです。D3-G は、モーション、超音波、赤外線、LiDAR、モータドライブ、車両通信トランシーバ、マイク、通信モジュールなど、さまざまなセンサーを組み合わせることができます。  

サポートについては、TOPST ウェブサイト (topst.ai) のハードウェアドキュメントセクションを参照し、ご質問は TOPST Technical Q&A に投稿してください。

## 1.4 温度範囲と熱設計  
---
推奨される周囲動作温度範囲は -10 °C ～ 55 °C です。   
D3-G は、アイドル状態または負荷が軽い場合、DVFS (Dynamic Voltage and Frequency Scaling) ソリューションにより CPU のクロック速度と電圧を下げて発熱を低減します。D3-G は追加の冷却装置がなくても問題なく動作します。D3-G を長時間フル性能で動作させる場合は、追加の冷却が必要になることがあります。

## 2.12 USB コネクタ 
---
D3-G は 3 種類の USB をサポートします。 
- USB3.0 (Type-A) Host 1 チャネル (JC3)
  - JC3 は、ホストポート用の USB3.0 Type-A コネクタです。  
  - USB3.0 は下位互換性をサポートするため、このポートは USB SuperSpeed および USB High-Speed デバイスの両方に使用できます。 
- USB2.0 (Type-A) Host 1 チャネル (JC7)
  - JC7 は、USB High-Speed ホストポート用の USB2.0 Type-A コネクタです。 
- USB2.0 (Type-C) FWDN 1 チャネル (JC6)
  - JC6 は USB2.0 FWDN のみをサポートします。このコネクタは、USB Boot Mode でソフトウェアを更新するために使用します。
