# 2. D3-G の起動モード
---
D3-G は 3 つの起動モードをサポートしています。
- USB 起動モード (FWDN)
- eMMC 起動モード (GPIO_SD0 Group)  
- SNOR および eMMC 起動モード（オプション）
 
図 2.1 は、D3-G 上の起動モード用抵抗の位置を示しています。これらの抵抗はボードの裏面に配置されています。D3-G は既定で eMMC 起動モードに固定されています。eMMC デバイスに起動イメージが存在しない場合、起動モードは自動的に USB 起動モードへ切り替わります。

## 2.1 USB 起動モード (FWDN)
---
図 2.2 は、起動モードスイッチと RESET スイッチを示しています。USB 起動モードはファームウェアの更新に使用します。FWDN モードに入るには、起動モードスイッチと RESET スイッチの両方が必要です。イメージをアップロードする際は、この方法を使用することを推奨します。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20D3-G/Hardware/Boot%20Mode%20Switch%20and%20RESET%20Switch%20for%20Entering%20FWDN%20Boot%20Mode.png" width="600"></p>
<p align="center"><strong>図 2.2 FWDN 起動モードに入るための起動モードスイッチと RESET スイッチ </strong></p>
 
 
 
次の手順では、USB 起動モードに入るためのスイッチ操作について説明します。
1. 電源が供給されると、RESET スイッチの上にある LED が点灯します。
2. 起動モードスイッチを押し続けます。起動モードスイッチを押すと、その上にある赤色 LED が点灯するのを確認できます。LED が点灯した状態を保つため、スイッチを押し続けてください。
3. RESET スイッチの LED は既定で緑色です。RESET スイッチを 1 回押すと、緑色 LED が消灯し、その後再び点灯します。
4. 起動モードスイッチから指を離します。

## 2.2 SNOR および eMMC 起動モード
---
SNOR および eMMC 起動モードはオプションです。この起動モードを使用するには、SNOR IC がボードに実装されており、かつ起動モード用抵抗の表面実装技術 (SMT) を変更する必要があります。
