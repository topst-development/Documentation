# คู่มือผู้ใช้ TOPST Imager

TOPST Imager ใช้ติดตั้งระบบปฏิบัติการหรือเฟิร์มแวร์ลงบนบอร์ด TOPST ไม่จำเป็นต้องรู้การเขียนโปรแกรมหรืออิเล็กทรอนิกส์ เปิดคู่มือนี้ไว้และทำตามทีละหน้าจอ

> **สำคัญ:** การแฟลชอาจลบข้อมูลทั้งหมดใน eMMC ของบอร์ด โปรดสำรองไฟล์ที่ต้องการก่อนเริ่ม

> **เกี่ยวกับภาพหน้าจอ:** กรอบแดงและวงกลมตัวเลขเพิ่มไว้เฉพาะในคู่มือนี้ ไม่มีใน TOPST Imager ภาพใช้ธีมสว่างของ Windows ส่วน Linux และธีมมืดใช้ขั้นตอนเหมือนกัน

## 1. คำศัพท์บนหน้าจอ

| คำศัพท์ | ความหมาย |
| --- | --- |
| Board / Device | ผลิตภัณฑ์ TOPST ที่จะติดตั้งอิมเมจ |
| Image | ไฟล์ที่มีระบบปฏิบัติการหรือเฟิร์มแวร์ |
| Flashing | การเขียนอิมเมจที่เลือกลงบนบอร์ด |
| Firmware Download Mode / Boot Mode | สถานะพิเศษของบอร์ดสำหรับแฟลช |
| FWDN | เครื่องมือที่ TOPST Imager เรียกใช้เบื้องหลัง ไม่ต้องเปิดเอง |
| COM port | การเชื่อมต่ออนุกรม USB ของ AI-G และ VCP-G บน Linux แสดงเป็น `/dev/ttyUSB...` หรือ `/dev/ttyACM...` |
| eMMC | หน่วยเก็บข้อมูลภายในบอร์ด |

## 2. บอร์ดที่รองรับ

| บอร์ด | อิมเมจที่กำหนดเอง | การเชื่อมต่อขณะแฟลช |
| --- | --- | --- |
| TOPST D3-G | `.fai` | ไฟเลี้ยงบอร์ดและสายข้อมูล FWDN USB Type-C |
| TOPST AI-G | `.fai` | ไฟเลี้ยงบอร์ด สายข้อมูล FWDN USB Type-C และสาย Ethernet |
| TOPST VCP-G | `.rom` | ไฟเลี้ยงบอร์ดและสายข้อมูล FWDN USB Type-C |

ใช้สาย USB Type-C ที่รองรับ**การรับส่งข้อมูล** สายชาร์จอย่างเดียวใช้ไม่ได้

## 3. เตรียมก่อนเริ่ม

- บอร์ด TOPST ที่ถูกต้องและอะแดปเตอร์จ่ายไฟ
- สายข้อมูล USB Type-C
- สาย Ethernet หากใช้ AI-G
- คอมพิวเตอร์ที่เชื่อมต่ออินเทอร์เน็ตเมื่อใช้อิมเมจทางการ
- พื้นที่ว่างเพียงพอสำหรับทั้งไฟล์ดาวน์โหลดแบบบีบอัดและแพ็กเกจที่แตกแล้ว
- ข้อมูลสำรองของไฟล์สำคัญในบอร์ด

ระหว่างแฟลช:

- อย่าปิดบอร์ดหรือคอมพิวเตอร์
- อย่าถอดสาย USB หรือ Ethernet
- อย่าปิด TOPST Imager
- อย่าให้คอมพิวเตอร์เข้าสู่โหมดพักเครื่อง

# Windows

## 5. ติดตั้ง TOPST Imager

### 5.1 ความต้องการระบบ

- Windows 10 แบบ 64 บิตขึ้นไป
- Windows 11 แบบ 64 บิต

### 5.2 การติดตั้ง

1. ดาวน์โหลดตัวติดตั้ง Windows ทางการของ TOPST Imager
2. ดับเบิลคลิกตัวติดตั้ง
3. อ่านและยอมรับข้อตกลงสิทธิ์การใช้งาน
4. เลือก **Install**
5. เมื่อติดตั้งเสร็จ เลือก **Launch TOPST Imager**

Windows อาจขอสิทธิ์ผู้ดูแลเมื่อเปิดแอปหรือตัวติดตั้ง VTC ตรวจสอบว่าไฟล์มาจากชุดเผยแพร่ทางการของ TOPST ก่อนเลือก **Yes**

## 6. เลือกบอร์ด ระบบปฏิบัติการ และเวอร์ชัน

### 6.1 เลือกบอร์ด

![เลือกบอร์ด TOPST](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20Board%20Selection.png)

1. เลือกบอร์ดให้ตรงกับผลิตภัณฑ์ที่ใช้อยู่
2. ตรวจสอบว่าแถวถูกเน้นและมีคำว่า **Selected** แล้วเลือก **Next**

ดับเบิลคลิกบอร์ดเพื่อไปต่อได้ หากเลือกผิดให้ใช้ **Back** แล้วเลือกใหม่

### 6.2 เลือกระบบปฏิบัติการ

![เลือกระบบปฏิบัติการทางการหรืออิมเมจที่กำหนดเอง](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20OS%20Selection.png)

1. เลือกระบบปฏิบัติการที่ TOPST ให้มา
2. หากใช้ไฟล์ในคอมพิวเตอร์ เลือก **Use Custom Image**
3. เลือก **Next** หรือดับเบิลคลิกแถวที่เลือก

### 6.3 เลือกเวอร์ชัน

![เลือกเวอร์ชันอิมเมจ](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20Version%20Selection.png)

1. เลือกเวอร์ชันที่ต้องการ ตรวจสอบคำอธิบาย วันที่เผยแพร่ ขนาดดาวน์โหลด และขนาดหลังแตกไฟล์
2. เลือก **Flashing**

- **Download size** คือขนาดไฟล์บีบอัดที่รับจากอินเทอร์เน็ต
- **Extracted size** คือพื้นที่ดิสก์โดยประมาณหลังแตกไฟล์

หากโครงการไม่ได้กำหนดรุ่นเฉพาะ ให้ใช้รุ่นเสถียรล่าสุดหรือรุ่นที่แนะนำ

### 6.4 ยืนยันการลบข้อมูล

![ยืนยันคำเตือนลบ eMMC](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20eMMC%20Erase%20Warning.png)

1. เลือก **Cancel** หากต้องตรวจสอบบอร์ด อิมเมจ หรือข้อมูลสำรองอีกครั้ง
2. เลือก **Confirm** เฉพาะเมื่อเข้าใจว่าข้อมูล eMMC ของบอร์ดที่เลือกอาจถูกลบ

การเลือก **Cancel** ในขั้นนี้ไม่ลบข้อมูลบอร์ด

## 7. แฟลช D3-G บน Windows

การตั้งค่ามีสามขั้นตอน

### ขั้นที่ 1: ติดตั้งไดรเวอร์ VTC

![ติดตั้งไดรเวอร์ VTC สำหรับ D3-G](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20D3-G%20Driver%20Installation.png)

1. เลือก **Install Driver**
2. อนุมัติคำขอสิทธิ์ผู้ดูแลของ Windows
3. ติดตั้ง VTC Driver Installer ให้เสร็จ
4. กลับ TOPST Imager
5. เลือก **Driver Installation Complete**

ปกติติดตั้งครั้งเดียวต่อคอมพิวเตอร์ Windows หากยกเลิกคำขอสิทธิ์จะไม่ได้ติดตั้งไดรเวอร์ เมื่อพร้อมให้เลือก **Install Driver** อีกครั้ง

### ขั้นที่ 2: เข้าโหมดบูตและตรวจจับบอร์ด

![เข้าโหมดบูต D3-G และตรวจจับบอร์ด](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20D3-G%20Boot%20Mode.png)

1. ทำตามสัญลักษณ์กะพริบในภาพเคลื่อนไหว
2. กด **BOOT** ค้างไว้
3. ระหว่างกด BOOT ให้กดแล้วปล่อย **RESET**
4. ปล่อย BOOT
5. ต่อสายข้อมูล FWDN USB Type-C ให้แน่น
6. เลือก **Check Again** หากสถานะไม่อัปเดตอัตโนมัติ
7. เมื่อสถานะเชื่อมต่อแล้ว เลือก **Start Flashing**

ตัวจัดการอุปกรณ์ Windows อาจแสดง D3-G ใต้ Universal Serial Bus controllers ด้วยชื่อคล้าย `Telechips TCCxxxx VTC USB Driver`

### ขั้นที่ 3: แฟลช

อิมเมจทางการแสดงความคืบหน้าแยกกันสำหรับ:

1. ดาวน์โหลด
2. แตกไฟล์
3. แฟลช

แต่ละส่วนเปลี่ยนจาก 0% ถึง 100% รอหน้าจอ **Complete** ก่อนถอดการเชื่อมต่อใด ๆ

## 8. แฟลช AI-G บน Windows

การตั้งค่ามีสามขั้นตอน

### ขั้นที่ 1: ตั้งค่า Ethernet

1. ต่อคอมพิวเตอร์กับ AI-G โดยตรงด้วยสาย Ethernet
2. เลือกอะแดปเตอร์มีสายที่ต่อ AI-G ไม่ใช่ Wi-Fi
3. เมื่อมีคำขอ ให้อนุญาตแอปใช้ที่อยู่ชั่วคราว `192.168.0.8/24`
4. ไปต่อเมื่อเครือข่ายพร้อม

เมื่อเสร็จหรือยกเลิก แอปจะคืนค่าการตั้งค่าเครือข่าย Windows ที่เปลี่ยนไว้ชั่วคราว

### ขั้นที่ 2: โหมดบูตและพอร์ต COM

1. ทำตามภาพเคลื่อนไหวโหมดบูต
2. กด **BOOT** ค้างไว้
3. กดแล้วปล่อย **RESET**
4. ปล่อย BOOT
5. เลือกพอร์ต COM ของ AI-G
6. ตรวจสอบไฟเลี้ยง สาย USB Type-C และ Ethernet
7. ไปต่อเพื่อแฟลช

หากมีหลายพอร์ต ให้ถอด USB ของ AI-G ชั่วคราว พอร์ตที่หายไปมักเป็นของ AI-G ต่อใหม่ เข้าโหมดบูตอีกครั้ง แล้วเลือกพอร์ตนั้น

### ขั้นที่ 3: แฟลช

รอจนถึง 100% และหน้าจอ **Complete** ปรากฏ

## 9. แฟลช VCP-G บน Windows

การตั้งค่ามีสองขั้นตอน

### ขั้นที่ 1: โหมดบูตและพอร์ต COM

คำแนะนำโหมดบูตและการเลือกพอร์ตอยู่หน้าจอเดียวกัน

1. ทำตามภาพเคลื่อนไหวเพื่อเข้า Firmware Download Mode
2. กดแล้วปล่อย **RESET** เมื่อคำแนะนำระบุ
3. เลือกพอร์ต COM ของ VCP-G
4. ตรวจสอบไฟเลี้ยงและสายข้อมูล FWDN USB Type-C อีกครั้ง
5. ไปต่อเพื่อแฟลช

### ขั้นที่ 2: แฟลช

รอจนถึง 100% และหน้าจอ **Complete** ปรากฏ

## 10. ใช้อิมเมจที่กำหนดเองบน Windows

1. เลือกบอร์ดที่ถูกต้องก่อน
2. คลิก **Use Custom Image** หนึ่งครั้งในหน้าระบบปฏิบัติการ
3. เลือก **Next** หรือดับเบิลคลิก **Use Custom Image**
4. ลากไฟล์ลงพื้นที่วาง หรือเลือกปุ่มเรียกดู
5. ตรวจสอบชื่อไฟล์แล้วไปต่อ

ใช้ชนิดไฟล์ที่ถูกต้อง:

- D3-G: `.fai`
- AI-G: `.fai`
- VCP-G: `.rom`

ไฟล์อยู่ในเครื่องแล้ว จึงซ่อนแถว **Download** และ **Extraction** ขั้นตอนไดรเวอร์ เครือข่าย โหมดบูต พอร์ต COM และแฟลชของแต่ละบอร์ดยังใช้เหมือนเดิม

# Linux

## 11. ความต้องการ Linux

ชุดเผยแพร่ปัจจุบันรองรับ **x86_64 Linux** ไฟล์ FWDN แบบ Windows `.exe` ใช้บน Linux ไม่ได้

แอปที่เผยแพร่ต้องมีเครื่องมือ Linux ที่เรียกใช้ได้ตามตำแหน่งนี้:

```text
tools/fwdn_d3/fwdn_d3
tools/fwdn_ai/fwdn_ai
tools/fwdn_vcp/fwdn_vcp
```

คอมพิวเตอร์ยังต้องมี:

- `unzip` สำหรับแพ็กเกจ ZIP ทางการ
- `policykit-1` สำหรับหน้าต่างยืนยันผู้ดูแล
- `acl` สำหรับสิทธิ์พอร์ตอนุกรมชั่วคราวของ AI-G และ VCP-G

บน Ubuntu ผู้ดูแลติดตั้งได้ด้วย:

```bash
sudo apt update
sudo apt install unzip policykit-1 acl
```

**อย่า**เปิด TOPST Imager หรือ FWDN ด้วย `sudo` แอปจะขอสิทธิ์ผู้ดูแลเฉพาะเมื่อจำเป็นต้องให้สิทธิ์ชั่วคราวกับอุปกรณ์อนุกรมที่เลือก

## 12. ติดตั้งและเปิดแพ็กเกจ Linux

ชื่อไฟล์อาจต่างกันตามรุ่น ตัวอย่างแพ็กเกจ `.tar.gz`:

```bash
cd ~/Downloads
tar -xzf TOPST-Imager-<version>-Linux-x86_64.tar.gz
cd TOPST-Imager-<version>-Linux-x86_64
chmod +x topst-imager
./topst-imager
```

ใช้ชื่อไฟล์และโฟลเดอร์จริงจากแพ็กเกจที่ดาวน์โหลด แพ็กเกจผู้ใช้ควรมี Qt runtime หากไลบรารี Qt ขาด ให้ดาวน์โหลดแพ็กเกจทางการฉบับสมบูรณ์ แทนการเปิดด้วย root

## 13. เลือกอิมเมจบน Linux

หน้าเลือกบอร์ด ระบบปฏิบัติการ เวอร์ชัน อิมเมจที่กำหนดเอง และคำเตือน eMMC ทำงานเหมือน Windows ในหัวข้อ 6 และ 10

## 14. แฟลช D3-G บน Linux

มีสองขั้นตอนเพราะไม่มีหน้าติดตั้งไดรเวอร์ Windows VTC

### ขั้นที่ 1: โหมดบูตและตรวจจับบอร์ด

1. กด **BOOT** ค้างไว้
2. กดแล้วปล่อย **RESET**
3. ปล่อย BOOT
4. ต่อสายข้อมูล FWDN USB Type-C
5. เลือก **Check Again** หากจำเป็น
6. ไปต่อเมื่อตรวจพบ D3-G

Linux ตรวจพบอุปกรณ์ D3-G FWDN USB โดยตรง หากไม่พบ ให้ตรวจสายข้อมูล ไฟเลี้ยง โหมดบูต และกฎ udev ที่ติดตั้งจากแพ็กเกจ Linux

### ขั้นที่ 2: แฟลช

รอการดาวน์โหลด แตกไฟล์ และแฟลชเสร็จ อิมเมจ `.fai` ที่กำหนดเองแสดงเฉพาะการแฟลช

## 15. แฟลช AI-G บน Linux

การตั้งค่ามีสามขั้นตอน

### ขั้นที่ 1: ตั้งค่า Ethernet

แอปไม่เปลี่ยนที่อยู่ Ethernet ของ Linux อัตโนมัติ ให้ตั้งค่าเครือข่ายเอง:

1. เปิด **การตั้งค่า → เครือข่าย**
2. เปิดการเชื่อมต่อมีสายที่ต่อ AI-G
3. ตั้ง IPv4 เป็น **กำหนดเอง (Manual)**
4. ที่อยู่: `192.168.0.8`
5. Netmask: `255.255.255.0` หรือความยาวพรีฟิกซ์ `24`
6. เว้น Gateway และ DNS ว่าง เว้นแต่ผู้ดูแลเครือข่ายระบุอย่างอื่น
7. ใช้การตั้งค่า เชื่อมต่อเครือข่ายมีสายใหม่ แล้วกลับ TOPST Imager

### ขั้นที่ 2: โหมดบูต พอร์ต COM และสิทธิ์ชั่วคราว

1. ทำตามภาพเคลื่อนไหวโหมดบูต
2. เลือกพอร์ต AI-G เช่น `/dev/ttyUSB0`
3. หากเขียนพอร์ตไม่ได้ เลือก **Grant Temporary Access**
4. อนุมัติหน้าต่างผู้ดูแล Linux
5. เมื่อสิทธิ์พร้อม ปุ่มแฟลชจะใช้งานได้

สิทธิ์ชั่วคราวมีผลเฉพาะอุปกรณ์อนุกรมที่เลือก และคืนสิทธิ์หลังแฟลช ยกเลิก หรือออกจากหน้าแฟลช ไม่ต้องเพิ่มผู้ใช้เข้ากลุ่ม `dialout` ถาวร

### ขั้นที่ 3: แฟลช

รอหน้าจอ **Complete**

## 16. แฟลช VCP-G บน Linux

มีสองขั้นตอนเช่นเดียวกับ Windows

### ขั้นที่ 1: โหมดบูต พอร์ต COM และสิทธิ์ชั่วคราว

1. ทำตามคำแนะนำโหมดบูต
2. เลือกพอร์ต VCP-G เช่น `/dev/ttyUSB0`
3. หากมี **Grant Temporary Access** ให้เลือกและอนุมัติหน้าต่างผู้ดูแล
4. ไปต่อเมื่อเข้าถึงพอร์ตที่เลือกได้

### ขั้นที่ 2: แฟลช

รอจนถึง 100% และหน้าจอ **Complete** อิมเมจ `.rom` ที่กำหนดเองแสดงเฉพาะการแฟลช

## 17. ดาวน์โหลด ลองใหม่ และไฟล์ชั่วคราว

สำหรับอิมเมจทางการ แอปจะ:

1. สร้างโฟลเดอร์ทำงานชั่วคราว
2. ดาวน์โหลดแพ็กเกจ ZIP
3. แตกแพ็กเกจลงโฟลเดอร์ชั่วคราว
4. เรียกไฟล์ปฏิบัติการ FWDN ของบอร์ดนั้น
5. ลบข้อมูลดาวน์โหลดและข้อมูลที่แตกชั่วคราวหลังแฟลชสำเร็จหรือยกเลิก

หากอินเทอร์เน็ตขาดขณะดาวน์โหลด ให้เปิดแอปไว้และต่อเครือข่ายใหม่ แอปลองใหม่อัตโนมัติและดาวน์โหลดต่อจากส่วนที่ค้างเมื่อเซิร์ฟเวอร์รองรับ สถานะแสดงตามภาษาแอปที่เลือก

ข้อผิดพลาดแฟลชบางชนิดที่แก้ไขได้จะเก็บแพ็กเกจที่เตรียมไว้ชั่วคราว เพื่อกลับไปขั้นตอนตั้งค่าที่ระบุโดยไม่ต้องดาวน์โหลดใหม่

## 18. เมื่อหน้าต่างข้อผิดพลาดปรากฏ

แอปตรวจพบข้อผิดพลาด FWDN ที่รู้จักแล้วเปิดหน้าต่างทันที หากมีนับถอยหลังสามวินาที ให้อ่านข้อความ หลังนับจบจะกลับสู่ขั้นตอนแก้ไขที่ต้องใช้ ตรวจรายการแล้วเลือก **OK**

### ข้อผิดพลาดเชื่อมต่อ D3-G

ตรวจสอบ:

1. ไฟเลี้ยงบอร์ด
2. สาย FWDN USB Type-C
3. การเข้า Firmware Download Mode

แอปกลับสู่ขั้นตอนโหมดบูต D3-G

### ข้อผิดพลาดเชื่อมต่อหรือซิงโครไนซ์ AI-G

ตรวจสอบ:

1. ไฟเลี้ยงบอร์ด
2. การเข้า Firmware Download Mode
3. พอร์ต COM ที่ถูกต้อง

หากเป็น `Failed open port` ให้ตรวจสาย FWDN USB Type-C และพอร์ตที่เลือก หากเป็น `TCP Socket Open Fail` ให้ตรวจสาย Ethernet อะแดปเตอร์ และการตั้งค่า `192.168.0.8/24`

### ข้อผิดพลาดเชื่อมต่อ VCP-G

ตรวจสอบ:

1. ไฟเลี้ยงบอร์ด
2. การเข้า Firmware Download Mode
3. พอร์ต COM ที่ถูกต้อง

หากมี `GetLastError : 22` ให้ตรวจการเชื่อมต่อ FWDN USB Type-C

### ไม่มีพอร์ต COM

1. ตรวจไฟเลี้ยง
2. ต่อสายข้อมูล USB ใหม่
3. เข้า Firmware Download Mode ซ้ำ
4. รีเฟรชรายการพอร์ต
5. บน Linux เลือก **Grant Temporary Access** หลังเลือกพอร์ต

### แฟลชล้มเหลวทั้งหมด

หากเป็น `Failed to write in eFlash` หรือ `Failed FWDN` ให้ทำตามข้อความและเริ่มจากขั้นตอนตั้งค่าแฟลชแรก อย่าถอดบอร์ดขณะยังเขียนข้อมูลอยู่

## 19. ไฟล์บันทึก

เมื่อขอความช่วยเหลือ ให้แนบข้อความผิดพลาดทั้งหมด ชื่อบอร์ด เวอร์ชันอิมเมจ ระบบปฏิบัติการ และไฟล์บันทึก

ตำแหน่งบันทึก Windows:

```text
%LOCALAPPDATA%\Telechips\TOPST Imager\logs\topst-imager.log
```

ตำแหน่งบันทึก Linux โดยทั่วไป:

```text
~/.local/share/Telechips/TOPST Imager/logs/topst-imager.log
```

หากยังต้องการความช่วยเหลือ ใช้ **App Options → Ask the Community** หรือไป [ชุมชน TOPST](https://community.topst.ai/)

## 20. หลังแฟลชเสร็จ

1. ยืนยันว่าเห็นหน้าจอ **Complete**
2. รอแอประบุว่าทำงานเสร็จแล้ว
3. ปิดบอร์ดอย่างปลอดภัย
4. ถอดสาย FWDN หรือจัดสายใหม่สำหรับใช้ปกติ
5. เปิดบอร์ดและตรวจว่าระบบปฏิบัติการใหม่เริ่มทำงาน

จำกฎสามข้อ:

1. เลือกบอร์ดและอิมเมจอย่างรอบคอบ
2. ห้ามถอดไฟหรือสายระหว่างแฟลช
3. เมื่อเกิดข้อผิดพลาด ตรวจทุกรายการจากบนลงล่าง
