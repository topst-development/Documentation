# คู่มือผู้ใช้ TOPST Imager

TOPST Imager เป็นแอปพลิเคชันสำหรับติดตั้งระบบปฏิบัติการหรือเฟิร์มแวร์ลงบนบอร์ด TOPST
ไม่จำเป็นต้องมีความรู้ด้านคอมพิวเตอร์หรืออุปกรณ์อิเล็กทรอนิกส์ ให้ทำตามคู่มือนี้และคำแนะนำในแอปทีละขั้นตอนอย่างช้า ๆ

> **สำคัญ:** การแฟลชอาจลบข้อมูลทั้งหมดใน eMMC ของบอร์ด โปรดสำรองไฟล์ที่ต้องการก่อนเริ่ม

## 1. คำศัพท์ที่ควรรู้

| คำในแอป | ความหมาย |
| --- | --- |
| Board | อุปกรณ์ TOPST ที่จะติดตั้งระบบปฏิบัติการ |
| Image | ไฟล์ระบบปฏิบัติการที่จะติดตั้งลงบนบอร์ด |
| Flashing | กระบวนการเขียนไฟล์อิมเมจลงบนบอร์ด |
| Boot mode | สถานะพิเศษที่ให้คอมพิวเตอร์ติดตั้งอิมเมจลงบนบอร์ดได้ |
| FWDN | เครื่องมือภายในสำหรับติดตั้งอิมเมจ ไม่ต้องเรียกใช้งานเอง |
| COM port | ชื่อที่คอมพิวเตอร์ใช้ระบุบอร์ดที่เชื่อมต่อผ่าน USB |
| eMMC | หน่วยเก็บข้อมูลภายในบอร์ด |

## 2. บอร์ดและไฟล์อิมเมจที่รองรับ

| บอร์ด | รูปแบบอิมเมจที่กำหนดเอง | การเชื่อมต่อที่ต้องใช้ |
| --- | --- | --- |
| TOPST D3-G | `.fai` | สาย USB Type-C สำหรับรับส่งข้อมูลที่พอร์ต FWDN |
| TOPST AI-G | `.fai` | สาย USB Type-C สำหรับรับส่งข้อมูลที่พอร์ต FWDN และสาย Ethernet |
| TOPST VCP-G | `.rom` | สาย USB Type-C สำหรับรับส่งข้อมูลที่พอร์ต FWDN |

> สาย USB ที่ชาร์จไฟได้อย่างเดียวใช้ไม่ได้ ต้องใช้ **สาย USB Type-C ที่รองรับการรับส่งข้อมูล**

## 3. เตรียมก่อนเริ่ม

- บอร์ด TOPST ที่ต้องการแฟลชและอะแดปเตอร์จ่ายไฟ
- สาย USB Type-C ที่รองรับการรับส่งข้อมูล
- คอมพิวเตอร์ที่เชื่อมต่ออินเทอร์เน็ต
- สาย Ethernet หากใช้ AI-G
- พื้นที่ว่างในคอมพิวเตอร์เพียงพอสำหรับดาวน์โหลดและแตกไฟล์อิมเมจทางการ
- ข้อมูลสำรองของไฟล์สำคัญในบอร์ด

ระหว่างแฟลช ห้ามปิดบอร์ด ถอดสาย USB หรือ Ethernet ปิด TOPST Imager ปิดคอมพิวเตอร์ หรือปล่อยให้คอมพิวเตอร์เข้าสู่โหมดพักเครื่อง

## 4. ขั้นตอนพื้นฐาน

Windows และ Linux ใช้ขั้นตอนพื้นฐานเหมือนกัน

1. เปิด TOPST Imager
2. เลือกบอร์ด
3. เลือกระบบปฏิบัติการหรือ **Custom Image**
4. เลือกเวอร์ชันที่จะติดตั้ง
5. ทำตามคำแนะนำเรื่องการเชื่อมต่อและโหมดบูตในแอป
6. เริ่มแฟลช
7. รอจนหน้าจอ **Complete** ปรากฏ

คลิกรายการหนึ่งครั้งแล้วเลือก **Next** หรือดับเบิลคลิกรายการเพื่อไปหน้าถัดไปได้

# คำแนะนำสำหรับ Windows

## 1. ติดตั้ง TOPST Imager บน Windows

### 1.1 ระบบที่รองรับ

- Windows 10 แบบ 64 บิตขึ้นไป
- Windows 11 แบบ 64 บิต

### 1.2 ติดตั้งแอป

1. ดาวน์โหลด `TOPST Imager.exe` สำหรับ Windows จากเว็บไซต์ทางการของ TOPST
2. ดับเบิลคลิกไฟล์ที่ดาวน์โหลด
3. อ่านและยอมรับข้อตกลงสิทธิ์การใช้งาน
4. เลือกสร้างทางลัดบนเดสก์ท็อปหากต้องการ
5. เลือก **Install**
6. เมื่อติดตั้งเสร็จ เลือก **Launch TOPST Imager** แล้วจบขั้นตอนติดตั้ง

หาก Windows แสดงข้อความป้องกัน ให้ตรวจสอบก่อนว่าไฟล์มาจากเว็บไซต์ทางการของ TOPST อย่าเรียกใช้หากยืนยันแหล่งที่มาไม่ได้

ตำแหน่งติดตั้งเริ่มต้น:

```text
%LOCALAPPDATA%\Programs\TOPST Imager
```

## 2. ภาษาและธีมหน้าจอ

1. เลือก **App Options** ที่มุมล่างซ้าย
2. เลือกภาษา
3. เลือก **Save**

> กรอบสีแดงและตัวเลขในภาพหน้าจอเพิ่มไว้เพื่ออธิบายในคู่มือนี้ ไม่มีในแอปจริง

![เลือกภาษาและตัวเลือกความช่วยเหลือใน TOPST Imager](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20App%20Options.png)

1. **Language:** เลือกภาษาที่ต้องการ
2. **Ask the Community:** เปิดชุมชน TOPST เมื่อต้องการความช่วยเหลือ
3. **Save:** ใช้ภาษาที่เลือก

รองรับภาษาเกาหลี อังกฤษ ญี่ปุ่น จีนตัวย่อ จีนตัวเต็ม ไทย และเยอรมัน ธีมสว่างหรือมืดจะปรับตามธีมของระบบ Windows โดยอัตโนมัติ

## 3. ติดตั้งอิมเมจทางการ

### 3.1 เลือกบอร์ด

1. ตรวจสอบรูปและชื่อบอร์ด
2. คลิกบอร์ดที่ต้องการหนึ่งครั้ง
3. ตรวจสอบว่าสีของรายการที่เลือกเปลี่ยนแล้ว
4. เลือก **Next**

![เลือกบอร์ด D3-G และปุ่ม Next](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20Board%20Selection.png)

1. เลือก**รายการบอร์ด**ที่ต้องการ
2. ตรวจสอบการเลือกแล้วเลือก **Next**

หากเลือกผิด ให้เลือก **Back** เพื่อย้อนกลับไปเลือกใหม่

### 3.2 เลือกระบบปฏิบัติการและเวอร์ชัน

1. เลือกระบบปฏิบัติการแล้วเลือก **Next**
2. เลือกเวอร์ชันที่จะติดตั้ง
3. ตรวจสอบวันที่เผยแพร่และขนาดไฟล์

![เลือกระบบปฏิบัติการทางการหรืออิมเมจที่กำหนดเอง](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20OS%20Selection.png)

1. หากใช้อิมเมจทางการ ให้เลือก**ระบบปฏิบัติการ**ที่ต้องการ
2. หากใช้ไฟล์ในคอมพิวเตอร์ ให้เลือก **Use Custom Image**
3. ตรวจสอบการเลือกแล้วเลือก **Next**

![เลือกเวอร์ชันระบบปฏิบัติการและปุ่ม Flashing](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20Version%20Selection.png)

1. เลือก**เวอร์ชัน** แล้วตรวจสอบขนาดดาวน์โหลดและวันที่เผยแพร่
2. หากถูกต้อง ให้เลือก **Flashing**

- **Download size:** ขนาดไฟล์บีบอัดที่ดาวน์โหลดจากอินเทอร์เน็ต
- **Extracted size:** พื้นที่โดยประมาณที่ต้องใช้ในคอมพิวเตอร์หลังแตกไฟล์

ไม่จำเป็นต้องใช้เวอร์ชันใหม่ที่สุดเสมอไป หากไม่มีคำแนะนำอื่น ให้เลือกเวอร์ชันที่แนะนำหรือเวอร์ชันเสถียรล่าสุด

### 3.3 ยืนยันคำเตือนการลบข้อมูล

ก่อนแฟลช แอปจะเตือนว่าข้อมูลใน eMMC ของบอร์ดอาจถูกลบ

1. ตรวจสอบบอร์ดและอิมเมจอีกครั้ง
2. ตรวจสอบว่าไม่มีข้อมูลที่ต้องเก็บไว้ในบอร์ด
3. เมื่อพร้อม ให้เลือกปุ่มยืนยัน

![คำเตือนการลบ eMMC พร้อมปุ่ม Cancel และ Confirm](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20eMMC%20Erase%20Warning.png)

1. เลือก **Cancel** หากยังไม่พร้อมหรือต้องการตรวจสอบอีกครั้ง
2. เลือก **Confirm** เมื่อเข้าใจแล้วว่าข้อมูลใน eMMC อาจถูกลบ

หากไม่แน่ใจ ให้เลือก **Cancel** การยกเลิกในขั้นนี้จะไม่ลบข้อมูลบอร์ด

## 4. แฟลช D3-G

### 4.1 ขั้นที่ 1: ติดตั้งไดรเวอร์

1. เลือก **Install Driver**
2. หาก Windows ขอสิทธิ์ผู้ดูแลระบบ ตรวจสอบข้อความแล้วเลือก **Yes**
3. ทำตามตัวติดตั้งไดรเวอร์ VTC จนเสร็จทุกขั้นตอน
4. กลับมาที่ TOPST Imager
5. เลือก **Driver Installation Complete**

![คำแนะนำติดตั้งไดรเวอร์ VTC สำหรับ D3-G](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20D3-G%20Driver%20Installation.png)

1. เลือก **Install Driver** เพื่อเปิดตัวติดตั้งก่อน
2. ทำให้ครบทุกขั้นตอน แล้วจึงเลือก **Driver Installation Complete**

โดยปกติติดตั้งเพียงครั้งเดียวต่อคอมพิวเตอร์แต่ละเครื่อง

### 4.2 ขั้นที่ 2: เข้าโหมดบูตและตรวจจับบอร์ด

ดูรูปบอร์ดและสัญลักษณ์กะพริบบนหน้าจอขณะทำตามขั้นตอน

1. **กดปุ่ม BOOT** บนบอร์ด
2. กด BOOT ค้างไว้
3. **กดแล้วปล่อยปุ่ม RESET**
4. ปล่อย BOOT
5. ตรวจสอบว่าสาย USB Type-C เชื่อมต่อกับคอมพิวเตอร์และบอร์ดแน่นดี
6. ตรวจสอบว่าแอปตรวจพบบอร์ดหรือไม่

![หน้าจอโหมดบูตและตรวจจับบอร์ด D3-G](https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/Quick%20Guide/TOPST%20Imager%20D3-G%20Boot%20Mode.png)

1. ทำตามลำดับโหมดบูตโดยดูรูปและสัญลักษณ์กะพริบ
2. เมื่อเปลี่ยนการเชื่อมต่อ ให้เลือก **Check Again**
3. เมื่อตรวจพบบอร์ด จะใช้ **Continue Flashing** ได้

ในตัวจัดการอุปกรณ์ Windows อาจแสดงชื่อคล้าย `Telechips TCCxxxx VTC USB Driver`

### 4.3 ขั้นที่ 3: แฟลชอิมเมจ

1. เลือก **Start Flashing**
2. ดูความคืบหน้าการดาวน์โหลด แตกไฟล์ และแฟลช
3. รอจนหน้าจอเสร็จสมบูรณ์ปรากฏ

## 5. แฟลช AI-G

AI-G ใช้ทั้ง USB และ Ethernet

### 5.1 ขั้นที่ 1: ตั้งค่า Ethernet

1. เชื่อมต่อคอมพิวเตอร์กับ AI-G ด้วยสาย Ethernet
2. เลือกอะแดปเตอร์ Ethernet ที่เชื่อมต่อกับ AI-G
3. ทำตามคำแนะนำเพื่อตั้งค่าที่อยู่คอมพิวเตอร์เป็น `192.168.0.8/24`
4. ยืนยันว่าตั้งค่าเครือข่ายเสร็จแล้ว

เลือก**อะแดปเตอร์ Ethernet แบบมีสายที่เชื่อมต่อ AI-G** ไม่ใช่ Wi-Fi

### 5.2 ขั้นที่ 2: เข้าโหมดบูตและเลือกพอร์ต COM

1. กด BOOT โดยดูภาพเคลื่อนไหว
2. กด BOOT ค้างไว้ แล้วกดและปล่อย RESET
3. ปล่อย BOOT
4. เลือกพอร์ต USB COM ของ AI-G ที่ตรวจพบใหม่
5. ตรวจสอบไฟเลี้ยง สาย USB Type-C และสาย Ethernet อีกครั้ง

หากมีหลายพอร์ต ให้ถอดสาย USB ของ AI-G ชั่วคราว พอร์ตที่หายไปคือของ AI-G ต่อสายใหม่และทำขั้นตอนเข้าโหมดบูตซ้ำก่อนดำเนินการต่อ

### 5.3 ขั้นที่ 3: แฟลชอิมเมจ

1. เลือก **Start Flashing**
2. รอจนความคืบหน้าถึง 100%
3. เริ่มบอร์ดใหม่หลังหน้าจอเสร็จสมบูรณ์ปรากฏ

## 6. แฟลช VCP-G

### 6.1 ขั้นที่ 1: เข้าโหมดบูต

1. ดูรูปบอร์ดบนหน้าจอ
2. กด BOOT ค้างไว้
3. กดแล้วปล่อย RESET
4. ปล่อย BOOT
5. เลือก **Next**

### 6.2 ขั้นที่ 2: เลือกพอร์ต COM

1. เลือกพอร์ต USB COM ของ VCP-G
2. หากไม่มีพอร์ต ให้ต่อสาย USB Type-C ใหม่
3. รีเฟรชรายการแล้วเลือกพอร์ตที่ถูกต้อง

### 6.3 ขั้นที่ 3: แฟลชอิมเมจ

1. เลือก **Start Flashing**
2. รอจนถึง 100%
3. เริ่มบอร์ดใหม่หลังหน้าจอเสร็จสมบูรณ์ปรากฏ

## 7. ติดตั้งอิมเมจที่กำหนดเอง

ใช้สำหรับไฟล์อิมเมจในเครื่องที่ไม่ได้อยู่ในรายการทางการ

1. คลิก **Custom Image** หนึ่งครั้งในหน้าเลือกระบบปฏิบัติการ
2. เลือก **Next** หรือดับเบิลคลิกรายการ
3. ลากไฟล์ลงในกรอบเส้นประ หรือใช้ **Browse for FAI Image** / **Browse for ROM Image** เพื่อเลือกไฟล์
4. ตรวจสอบชื่อไฟล์
5. เลือก **Next** แล้วทำตามคำแนะนำการเชื่อมต่อของบอร์ด

เลือกชนิดให้ถูกต้อง: D3-G และ AI-G ใช้ `.fai` ส่วน VCP-G ใช้ `.rom`
เนื่องจากไฟล์อยู่ในเครื่องแล้ว หน้าจอแฟลชจะไม่แสดงขั้นตอนดาวน์โหลดและแตกไฟล์

## 8. แก้ไขปัญหาบน Windows

### ตรวจไม่พบบอร์ด

1. ตรวจสอบว่าบอร์ดมีไฟเลี้ยง
2. ตรวจสอบว่าสาย USB ไม่ใช่สายชาร์จอย่างเดียว
3. ตรวจสอบว่าเชื่อมต่อพอร์ต FWDN USB Type-C
4. ทำขั้นตอนเข้าโหมดบูตซ้ำ
5. สำหรับ D3-G ตรวจสอบว่าติดตั้งไดรเวอร์ VTC แล้ว

### ไม่มีพอร์ต COM ในรายการ

1. ถอดและต่อสาย USB ใหม่
2. ตรวจสอบไฟเลี้ยงบอร์ด
3. เข้าโหมดบูตอีกครั้ง
4. รีเฟรชรายการพอร์ต COM

### AI-G แสดงข้อผิดพลาดเครือข่าย

1. ตรวจสอบสาย Ethernet ระหว่างคอมพิวเตอร์กับ AI-G
2. ตรวจสอบว่าเลือกอะแดปเตอร์มีสาย ไม่ใช่ Wi-Fi
3. ตรวจสอบที่อยู่คอมพิวเตอร์ `192.168.0.8/24`
4. ทำตามแอปโดยเริ่มจากขั้นที่ 1 ใหม่

### ข้อความ `Failed open port` หรือ `GetLastError : 22`

ตรวจสอบสาย FWDN USB Type-C ต่อใหม่ แล้วเริ่มจากขั้นตอนเข้าโหมดบูตอีกครั้ง

### ดาวน์โหลดไม่คืบหน้า

1. ตรวจสอบอินเทอร์เน็ต
2. ตรวจสอบพื้นที่ว่างในคอมพิวเตอร์
3. รอสักครู่แล้วเลือก **Retry**

### ต้องการย้อนกลับระหว่างแฟลช

หลังเริ่มแฟลช การย้อนกลับจะแสดงหน้าต่างยืนยันยกเลิก ก่อนยกเลิกให้ตรวจสอบว่าบอร์ดอยู่ในสถานะปลอดภัยและทำตามคำแนะนำบนหน้าจอ

### ต้องการความช่วยเหลือเกี่ยวกับข้อผิดพลาด

1. คัดลอกรายละเอียดจากหน้าต่างข้อผิดพลาด
2. เปิดโฟลเดอร์บันทึกจาก **App Options**
3. เตรียมข้อความข้อผิดพลาดและไฟล์บันทึก
4. สอบถามที่ [ชุมชน TOPST](https://community.topst.ai/)

ตำแหน่งบันทึกปกติบน Windows:

```text
%LOCALAPPDATA%\Telechips\TOPST Imager\logs\topst-imager.log
```

# คำแนะนำสำหรับ Linux

## 1. เตรียมก่อนใช้งาน Linux

หน้าจอและขั้นตอนพื้นฐานเหมือน Windows แต่การเตรียมบางอย่างต่างกัน ปุ่มเลือกบอร์ด ระบบปฏิบัติการ และเวอร์ชันอยู่ตำแหน่งเดียวกับภาพ Windows ด้านบน Linux จะข้ามหน้าติดตั้งไดรเวอร์ Windows ของ D3-G ไปยังโหมดบูตและตรวจจับบอร์ดโดยตรง

- ไม่ต้องติดตั้งไดรเวอร์ Windows VTC
- D3-G ต้องมีสิทธิ์ USB บน Linux
- AI-G และ VCP-G ต้องมีสิทธิ์พอร์ตอนุกรม
- แพ็กเกจต้องมีไฟล์ปฏิบัติการ FWDN สำหรับ Linux
- ต้องใช้ `unzip` หรือ `bsdtar` เพื่อแตกไฟล์อิมเมจทางการ

หากไม่ถนัดคำสั่ง ให้ผู้ดูแลระบบหรือนักพัฒนาทำหัวข้อ **การตั้งค่า Linux สำหรับผู้ดูแลระบบ** ด้านล่างให้หนึ่งครั้ง จากนั้นผู้ใช้ทั่วไปทำตามหน้าจอได้

## 2. ติดตั้งและเปิดบน Linux

ตัวอย่างต่อไปนี้ใช้ Ubuntu

### 2.1 แตกไฟล์แพ็กเกจ

1. ดาวน์โหลดแพ็กเกจ Linux ที่เหมาะกับคอมพิวเตอร์จากเว็บไซต์ทางการ
2. เปิดโฟลเดอร์ดาวน์โหลด
3. เปิดเทอร์มินัลแล้วใช้คำสั่ง:

```bash
cd ~/Downloads
tar -xzf TOPST-Imager-<version>-Linux-<architecture>.tar.gz
```

แทน `<version>` และ `<architecture>` ด้วยค่าจากชื่อไฟล์จริง พิมพ์ส่วนต้นของชื่อแล้วกด `Tab` เพื่อเติมชื่ออัตโนมัติได้

### 2.2 เปิดแอป

เข้าโฟลเดอร์ที่แตกไฟล์แล้วเริ่มแอป:

```bash
cd TOPST-Imager-<version>-Linux-<architecture>
chmod +x topst-imager
./topst-imager
```

หากแจ้งว่าไม่มีไลบรารี `Qt` แสดงว่าแพ็กเกจไม่มี Qt runtime ผู้ใช้ทั่วไปควรขอ**แพ็กเกจ Linux ที่มี Qt 6.12 runtime** จากผู้จัดจำหน่าย แทนการติดตั้งเอง

## 3. การตั้งค่า Linux สำหรับผู้ดูแลระบบ

โดยปกติทำเพียงครั้งเดียว

### 3.1 ติดตั้งเครื่องมือแตกไฟล์

```bash
sudo apt update
sudo apt install unzip
```

### 3.2 สิทธิ์พอร์ตอนุกรมสำหรับ AI-G และ VCP-G

```bash
sudo usermod -aG dialout "$USER"
```

หลังใช้คำสั่ง ให้ออกจากระบบแล้วเข้าสู่ระบบใหม่ หรือรีสตาร์ตคอมพิวเตอร์

### 3.3 สิทธิ์ USB สำหรับ D3-G

1. เชื่อมต่อ D3-G ในโหมดบูต
2. ตรวจสอบ USB ID ในเทอร์มินัล:

```bash
lsusb
```

3. ใช้ vendor ID และ product ID ที่ตรวจพบสร้างไฟล์ `/etc/udev/rules.d/99-topst.rules`

```text
SUBSYSTEM=="usb", ATTR{idVendor}=="VENDOR_ID", ATTR{idProduct}=="PRODUCT_ID", MODE="0666"
```

4. โหลดกฎใหม่:

```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
```

อย่าใส่ค่า `VENDOR_ID` และ `PRODUCT_ID` แบบสุ่ม หากไม่ทราบค่าที่ถูกต้องของ D3-G ให้ติดต่อฝ่ายสนับสนุน TOPST

### 3.4 ตรวจสอบไฟล์ Linux FWDN

แพ็กเกจต้องมีไฟล์ปฏิบัติการ Linux ที่ไม่มีนามสกุลในตำแหน่งต่อไปนี้:

```text
tools/fwdn_d3/fwdn_d3
tools/fwdn_ai/fwdn_ai
tools/fwdn_vcp/fwdn_vcp
```

หากมีไฟล์แล้ว ให้สิทธิ์เรียกใช้:

```bash
chmod +x tools/fwdn_d3/fwdn_d3
chmod +x tools/fwdn_ai/fwdn_ai
chmod +x tools/fwdn_vcp/fwdn_vcp
```

หากไม่มีไฟล์เหล่านี้ จะไม่สามารถแฟลชบน Linux ได้ และใช้ไฟล์ Windows `.exe` แทนไม่ได้

## 4. แฟลช D3-G บน Linux

ไม่ใช้ขั้นตอนติดตั้งไดรเวอร์ Windows VTC

1. เลือกอิมเมจ D3-G
2. ดูภาพเคลื่อนไหวแล้วกด BOOT
3. กด BOOT ค้างไว้ แล้วกดและปล่อย RESET
4. ปล่อย BOOT
5. ตรวจสอบว่าตรวจพบบอร์ด
6. เริ่มแฟลชและรอจนเสร็จ

หากไม่พบ ให้ตรวจสอบกฎสิทธิ์ USB สาย Type-C ไฟเลี้ยง และโหมดบูต

## 5. แฟลช AI-G บน Linux

TOPST Imager ไม่เปลี่ยนที่อยู่ Ethernet อัตโนมัติบน Linux ต้องตั้งค่าด้วยตนเองใน Ubuntu

1. เปิด **การตั้งค่า → เครือข่าย**
2. เปิดการตั้งค่าเครือข่ายมีสายที่เชื่อมต่อ AI-G
3. ตั้งวิธี IPv4 เป็น **กำหนดเอง (Manual)**
4. ใส่ที่อยู่ `192.168.0.8`
5. ใส่ netmask `255.255.255.0` หรือ `24` หากใช้ความยาวพรีฟิกซ์
6. เว้น Gateway และ DNS ว่างหากไม่มีคำแนะนำอื่น
7. ใช้การตั้งค่า แล้วปิดและเปิดการเชื่อมต่อมีสายใหม่
8. กลับ TOPST Imager และตรวจสอบสถานะ Ethernet
9. เข้าโหมดบูตตามคำแนะนำบนหน้าจอ
10. เลือกพอร์ต `/dev/ttyUSB...` หรือ `/dev/ttyACM...` ของ AI-G
11. เริ่มแฟลช

## 6. แฟลช VCP-G บน Linux

1. เข้าโหมดบูตตามหน้าจอ
2. เลือกพอร์ตแบบ `/dev/ttyUSB...` หรือ `/dev/ttyACM...`
3. ตรวจสอบพอร์ตแล้วเริ่มแฟลช
4. รอหน้าจอเสร็จสมบูรณ์

หากไม่มีพอร์ต ให้ตรวจสอบว่าเข้ากลุ่ม `dialout` และออกจากระบบแล้วเข้าสู่ระบบใหม่แล้ว

## 7. แก้ไขปัญหาบน Linux

### ข้อความ `Permission denied`

- AI-G หรือ VCP-G: ตรวจสอบว่าผู้ใช้อยู่ในกลุ่ม `dialout`
- D3-G: ตรวจสอบว่ากฎสิทธิ์ USB ของ udev ทำงานแล้ว
- ไฟล์ FWDN: ตรวจสอบว่าให้สิทธิ์ด้วย `chmod +x` แล้ว

### ไม่พบไฟล์ Linux FWDN

ตรวจสอบไฟล์ปฏิบัติการ Linux ใน `tools/fwdn_*` ของโฟลเดอร์แพ็กเกจ ไฟล์ Windows `.exe` ใช้บน Linux ไม่ได้

### ไม่มีพอร์ตบอร์ด

ใช้คำสั่งนี้แสดงรายการพอร์ต:

```bash
ls /dev/ttyUSB* /dev/ttyACM* 2>/dev/null
```

เปรียบเทียบก่อนและหลังต่อ USB พอร์ตที่เพิ่มขึ้นมามักเป็นพอร์ตบอร์ด

### ธีมสว่างหรือมืดไม่เปลี่ยนตามระบบ

แอปใช้ข้อมูลธีมจากเดสก์ท็อป Linux ผ่าน Qt บางสภาพแวดล้อมอาจไม่เปลี่ยนทันที ให้ลองเปิดแอปใหม่

## 8. หลังแฟลชเสร็จ

1. ตรวจสอบข้อความสำเร็จ
2. รอให้ TOPST Imager ทำงานเสร็จทั้งหมด
3. ปิดบอร์ดอย่างปลอดภัย
4. ถอดสาย FWDN หรือจัดสายใหม่สำหรับใช้งานปกติ
5. เปิดบอร์ดและตรวจสอบว่าระบบปฏิบัติการใหม่เริ่มทำงาน

อิมเมจทางการจะดาวน์โหลดและแตกไฟล์ในโฟลเดอร์ชั่วคราว เมื่อแฟลชสำเร็จ ไฟล์ดาวน์โหลดและโฟลเดอร์ที่แตกไว้จะถูกลบอัตโนมัติ

## 9. สามสิ่งที่ต้องจำ

1. **ตรวจสอบว่าเลือกบอร์ดและอิมเมจถูกต้อง**
2. **อย่าถอดไฟหรือสายระหว่างแฟลช**
3. **หากเกิดข้อผิดพลาด ให้ตรวจสอบรายการบนหน้าจอจากบนลงล่าง**

หากต้องการความช่วยเหลือ ให้เตรียมข้อความข้อผิดพลาดและไฟล์บันทึก แล้วสอบถามที่ [ชุมชน TOPST](https://community.topst.ai/)
