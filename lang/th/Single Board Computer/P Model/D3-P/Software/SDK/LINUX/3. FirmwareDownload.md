# 3. การดาวน์โหลดเฟิร์มแวร์

บทนี้อธิบายวิธีการดาวน์โหลด ***FWDN*** ไปยัง TOPST D3 (บอร์ดแพลตฟอร์มแบบเปิด) และการเข้าสู่ระบบคอนโซล Linux  
***FWDN V8*** เป็นเครื่องมือบน PC สำหรับดาวน์โหลดเฟิร์มแวร์ในสภาพแวดล้อม Windows 10 64 บิต และ Linux บทนี้อธิบายกรณีการดาวน์โหลดในสภาพแวดล้อม Windows และ Linux

<br/><br/>

## 3.1 ลำดับขั้นตอนการดาวน์โหลดเฟิร์มแวร์

ลำดับขั้นตอนการดาวน์โหลดของ ***FWDN*** มีดังนี้:

1. ตั้งค่าสวิตช์โหมดการบูตเป็นโหมดการบูตผ่าน USB
2. เปิดพรอมต์ของ Windows หรือคอนโซล Linux แล้วทดสอบ ***FWDN V8***
3. เชื่อมต่อ ***FWDN V8*** เข้ากับบอร์ด
4. ดาวน์โหลดไฟล์ fai

<br/><br/>

## 3.2 การเชื่อมต่อ TOPST D3 กับเครื่อง PC โฮสต์ด้วยการบูตผ่าน USB

หากกด **SW2** ค้างไว้แล้วจ่ายไฟ กระบวนการบูตผ่าน USB จะเริ่มต้นขึ้น หากจ่ายไฟโดยไม่กด **SW2** กระบวนการบูตตามปกติจะเริ่มต้นขึ้น

การกด **SW1** จะทำให้ระบบรีเซ็ต หากต้องการดาวน์โหลดเฟิร์มแวร์ ให้กด **SW1** และ **SW2** พร้อมกันเพื่อบูตเข้าสู่โหมด USB

## 3.3 การเตรียมพร้อมสำหรับการดาวน์โหลด FWDN

1. แตกไฟล์ "output.fwdn.zip" 
    ```
    $ mkdir images
    $ mv ./output.fwdn.zip ./images
    $ cd images
    $ unzip output.fwdn.zip
    ```
2. คัดลอกโฟลเดอร์ "images" ไปยังไดรฟ์ C ของ Windows
    ```
    $ cd ..
    $ cp -r /images /mnt/c/
    ```

## 3.5 FWDN ในสภาพแวดล้อม Linux

ในสภาพแวดล้อม Linux คุณสามารถดาวน์โหลดอิมเมจ TOPST ได้ด้วยคำสั่ง "./fwdn.sh"

```
$ ./fwdn.sh
```

<br/><br/>

## 3.6 การเชื่อมต่อ TOPST ด้วย UART

1. ใช้การเชื่อมต่อ UART เพื่อตรวจสอบว่าการดาวน์โหลดเฟิร์มแวร์เสร็จสมบูรณ์เรียบร้อยแล้ว
2. ติดตั้งไดรเวอร์พอร์ตอนุกรม (CP210x Windows Driver) ในสภาพแวดล้อม Windows([ลิงก์ดาวน์โหลด](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads))
3. เปลี่ยนโหมดการบูตเป็นแบบปกติ (eMMC) แล้วรีบูต ให้ใช้สาย USB Type-C to USB 2.0 หรือ 3.0 ไม่ใช่สาย C to C
