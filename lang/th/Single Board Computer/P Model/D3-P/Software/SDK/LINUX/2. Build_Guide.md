# 2. คู่มือการบิลด์

<br/><br/>

## 2.1 การเตรียมการบิลด์ TOPST D3 Linux SDK

TOPST D3 Linux SDK พัฒนาขึ้นบนพื้นฐานของ Yocto Project 3.1 Dunfell ดังนั้นจึงต้องตั้งค่าสภาพแวดล้อมของ Yocto Project บนเครื่อง PC โฮสต์เพื่อใช้งาน TOPST D3 Linux SDK ในการดาวน์โหลด SDK, source-mirror และ tools คุณต้องติดตั้งยูทิลิตีที่จำเป็นก่อน  

<br/><br/>

## 2.2 Yocto Project  

Yocto Project เป็นโครงการโอเพนซอร์สที่มุ่งเน้นการพัฒนา Linux แบบฝังตัว  
โดยใช้การผสมผสานระหว่างโครงการ Open Embedded ซึ่งก็คือ Poky และ ***bitbake*** เป็นระบบบิลด์เพื่อสร้างอิมเมจ Linux  
เมื่อใช้ Yocto Project คุณสามารถบิลด์บูตโหลดเดอร์ เคอร์เนล และ rootfs ได้พร้อมกัน  

<br/><br/>

## 2.3 กระบวนการทำงาน

รูปที่ 2.1 แสดงกระบวนการทำงานของ Yocto Project คุณสามารถดาวน์โหลดซอร์สจาก upstream ตามข้อมูลเมตาดาตาและทำการบิลด์ได้ เมื่อการบิลด์เสร็จสมบูรณ์ ระบบจะให้แพ็กเกจ อิมเมจ และ SDK เป็นผลลัพธ์

เมื่อคุณเรียกใช้ 'easy-setup.sh' คุณจะเห็นหน้าจอด้านล่างนี้  
```
$ ./easy-setup.sh
```

```
sudo add-apt-repository ppa:ubuntu-toolchain-r/test
sudo apt update
sudo apt install g++-11
```
