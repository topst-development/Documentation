#  1. การตั้งค่าสภาพแวดล้อมของโฮสต์

<br><br>

## 1.1 การติดตั้ง Ubuntu

เนื่องจาก TOPST D3 Linux SDK พัฒนาบนพื้นฐานของ Yocto Project เวอร์ชัน Linux ของ TOPST D3 SDK จึงเป็นไปตาม Yocto project

คุณสามารถติดตั้ง Linux เวอร์ชันอื่นได้ แต่ในเอกสารนี้จะอธิบาย TOPST D3 Linux SDK โดยอิงตาม Ubuntu 22.04

เวอร์ชันของลินุกซ์ดิสทริบิวชัน:

- Ubuntu 22.04 (LTS)

<br/><br/>

## 1.2 การติดตั้ง WSL2 Ubuntu 

1. เรียกใช้ Windows PowerShell ด้วย "**เรียกใช้ด้วยสิทธิ์ผู้ดูแลระบบ**"
2. เปิดใช้งานระบบ WSL2
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. เปิดใช้งานคุณสมบัติ Virtual Machine
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. ตั้งค่า WSL 2 เป็นเวอร์ชันเริ่มต้น
    ```
    wsl --set-default-version 2
    ```
5. ค้นหา Ubuntu 22.04.3 LTS ใน Microsoft Store แล้วดาวน์โหลด

    * หากคุณจำเป็นต้องดาวน์โหลดแพ็กเกจอัปเดตเคอร์เนล Linux ให้ดาวน์โหลดแพ็กเกจล่าสุด[ที่นี่](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)

## 1.3 การตั้งค่าสภาพแวดล้อม Linux

<br>

### 1.3.1 การติดตั้ง SSH และ Samba

หลังจากติดตั้งเครื่องเสมือนแล้ว คุณสามารถใช้ยูทิลิตีเพิ่มเติม เช่น SSH และ Samba เพื่อให้สภาพแวดล้อมการพัฒนาสะดวกยิ่งขึ้น SSH และ Samba ช่วยให้คุณสามารถรันคำสั่งบนคอมพิวเตอร์ระยะไกลและคัดลอกไฟล์ไปยังคอมพิวเตอร์เครื่องอื่นได้

หากติดตั้ง SSH และ Samba ไว้แล้ว หรือคุณจะไม่ใช้งาน คุณสามารถข้ามบทนี้ได้

ใช้คำสั่งต่อไปนี้เพื่อติดตั้ง net-tools, SSH และ Samba

```
$ sudo apt install -y net-tools openssh-server samba
```


หลังจากดาวน์โหลด SSH และ Samba แล้ว คุณควรตั้งค่าแต่ละโปรแกรมให้เหมาะกับสภาพแวดล้อมของคุณ

<br>

### 1.3.2 ยูทิลิตี

ติดตั้งยูทิลิตีทั้งหมดในคราวเดียว หากต้องการใช้ Yocto Project จะต้องติดตั้งยูทิลิตีต่อไปนี้บนเครื่อง PC โฮสต์ (คอมพิวเตอร์ส่วนบุคคลหรือเซิร์ฟเวอร์สำหรับการพัฒนา)

ใช้คำสั่งต่อไปนี้เพื่อติดตั้งยูทิลิตี

```
$ sudo apt-get install -y gawk wget git diffstat unzip texinfo gcc-multilib build-essential chrpath

$ sudo apt-get install -y socat cpio python3 python3-pip python3-pexpect xz-utils debianutils

$ sudo apt-get install -y iputils-ping python3-git python3-jinja2 libegl1-mesa libsdl1.2-dev pylint

$ sudo apt-get install -y xterm zstd ncftp curl git-lfs vim zip
```

### 1.3.3 การติดตั้ง Repo

หากติดตั้ง Repo ไว้แล้ว คุณสามารถใช้งานได้โดยไม่ต้องติดตั้งใหม่  
ก่อนติดตั้ง Repo ควรตั้งค่าเวอร์ชันของ Python ที่ติดตั้งไว้ (3.6 ขึ้นไป) ให้ถูกต้อง

ใช้คำสั่งต่อไปนี้เพื่อติดตั้ง repo
```
$ sudo apt-get install repo
```

หากคุณพบข้อความแสดงข้อผิดพลาด '/usr/bin/env 'python' no such file or directory' ให้ใช้คำสั่งต่อไปนี้เพื่อให้ไฟล์ 'python' ชี้ไปยัง 'python3'

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
```
หากเกิดข้อผิดพลาดของ Repo ให้ใช้คำสั่งต่อไปนี้เพื่อดาวน์โหลดเวอร์ชันล่าสุดและวางไว้ในโฟลเดอร์ /usr/bin/ โดยตรง

```
$ mkdir -p ~/bin

$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo > ~/bin/repo

$ chmod a+x ~/bin/repo

$ sudo mv ~/bin/repo /usr/bin/repo
```

### 1.3.4 กฎ Udev สำหรับอุปกรณ์ USB ของ Telechips
หลังจากคุณรันคำสั่งต่อไปนี้ คุณไม่จำเป็นต้องใช้คำสั่ง 'sudo' เมื่อดาวน์โหลด FWDN ใน Linux
```
$ echo "SUBSYSTEM==\"usb\", ATTR{idVendor}==\"140e\", MODE=\"0666\", OWNER=\"${USER}\"" | sudo tee /etc/udev/rules.d/99-topst.rules
$ sudo udevadm control --reload-rules && sudo udevadm trigger
```
