#  2. คู่มือการบูต

บทนี้อธิบายวิธีการบูต TOPST D3 และเข้าสู่ระบบสำหรับแต่ละคอร์

<br><br>

## 2.1 ลำดับการบูต

ลำดับการดาวน์โหลดของ ***FWDN*** มีดังนี้

1. เชื่อมต่อสาย DP สำหรับจอภาพ DP
2. เชื่อมต่อบอร์ดดีบักกับ TOPST D3
3. เชื่อมต่อสาย USB ของ TOPST แต่ละเส้นเข้ากับบอร์ดดีบัก เพื่อเข้าสู่ระบบคอนโซลและทำการดีบักสำหรับแต่ละคอร์
4. เชื่อมต่อแหล่งจ่ายไฟ 5V

<br><br>

## 2.2 การเชื่อมต่อ TOPST ด้วย UART

เพื่อทำการดีบักผ่าน USB และพัฒนาบนสภาพแวดล้อม Linux ท่านสามารถเข้าถึงคอร์ที่ต้องการ (CA72/CA53/MCU) ได้โดยใช้บอร์ดดีบัก TOPST ที่แสดงด้านล่าง

<br><div align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/6e2d9a76-da7f-4eb4-ad84-2e2930608643">
    <p><strong>รูปที่ 2.1 บอร์ดดีบัก TOPST</strong></p>
</div><br>

ติดตั้งไดรเวอร์ UART Bridge VCP (หาได้ที่ https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads) บนเครื่อง PC โฮสต์

หลังจากนั้น เมื่อท่านเชื่อมต่อ ไดรเวอร์ CP210x USB to UART จะถูกตั้งค่าดังนี้

<br><div align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/16b4b37d-26ca-4258-b0fa-a512e9bcf31c">
    <p><strong>รูปที่ 2.2 การเชื่อมต่อ USB ในสภาพแวดล้อม Windows</strong></p>
</div><br>

เชื่อมต่อพอร์ต UART แต่ละพอร์ตโดยใช้โปรแกรมจำลองเทอร์มินัลบนเครื่อง PC โฮสต์ ภาพด้านล่างคือหน้าจอบันทึกที่ได้จากการบูตโดยเชื่อมต่อกับคอร์หลักและคอร์รอง (**ตัวอย่าง**: โปรแกรมจำลองเทอร์มินัล: PuTTY, Speed: 115200 bps, Data bits: 8, Parity: None, Stop bits: 1, Flow Control: None)

## 2.3 การเชื่อมต่อ TOPST ด้วยพอร์ต DP

เมื่อเฟิร์มแวร์โหลดตามปกติแล้ว ให้เชื่อมต่อสาย DisplayPort เข้ากับจอภาพและบอร์ด TOPST D3 จากนั้น Ubuntu จะโหลดขึ้นบนจอภาพดังที่แสดงด้านล่าง Ubuntu ทำงานบนคอร์หลักตามที่อธิบายไว้ข้างต้น
