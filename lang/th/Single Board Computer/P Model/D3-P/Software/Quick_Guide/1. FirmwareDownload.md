# 1. คู่มือ FWDN

บทนี้อธิบายวิธีการดาวน์โหลด Firmware Downloader (***FWDN***) ไปยัง TOPST D3 และการเข้าสู่ระบบคอนโซล Linux

<br><br>

## 1.1   ลำดับการดาวน์โหลดเฟิร์มแวร์

ลำดับการดาวน์โหลดของ ***FWDN*** มีดังนี้

1. เข้าสู่โหมด FWDN
2. เชื่อมต่อสาย USB A-to-A เข้ากับพอร์ต USB 2.0 FWDN
3. ดาวน์โหลดอิมเมจ TOPST

<br><br>

## 1.2   การเข้าสู่โหมด FWDN

กดปุ่ม **SW2** (FWDN Mode Convert) แล้วต่อแหล่งจ่ายไฟเพื่อเข้าสู่โหมด ***FWDN*** หรืออีกวิธีหนึ่ง หากต่อแหล่งจ่ายไฟอยู่แล้ว ให้กดปุ่ม **SW2** (FWDN Mode Convert) แล้วกดปุ่ม **SW1** (System Reset) เพื่อเข้าสู่โหมด ***FWDN***

### 1.2.1 การเชื่อมต่อ USB ในสภาพแวดล้อม Windows

ติดตั้งไดรเวอร์ Vendor Telechips Certification (VTC) (ดาวน์โหลดได้ที่ [telechips driver](https://drive.google.com/file/d/1muQnY8kuKxDsy3p3FUiQqcG34Zjk-mnR/view?usp=sharing)) บนเครื่อง PC โฮสต์ โดยเรียกใช้ในฐานะผู้ดูแลระบบ เมื่อคุณเชื่อมต่อ USB ในโหมด FWDN ตามที่แสดงด้านบน ไดรเวอร์ Telechips VTC USB จะถูกตั้งค่าดังที่แสดงในรูปที่ 1.2

### 1.2.2 การเชื่อมต่อ USB ในสภาพแวดล้อม Linux

เมื่อคุณเชื่อมต่อ USB ในโหมด FWDN ตามที่แสดงด้านบน ไดรเวอร์ Telechips VTC USB จะถูกตั้งค่าดังที่แสดงในรูปที่ 1.3

## 1.3 การรัน FWDN ในสภาพแวดล้อม Windows ด้วยเครื่องมือ CLI
  
ในการใช้งาน FWDN ให้ดาวน์โหลดเครื่องมือเฟิร์มแวร์จากลิงก์ด้านล่าง

- <[FWDN Tool](https://drive.google.com/file/d/1UzArkpt-Aw67YhAMtlSfkELEHYBMBqT7/view?usp=sharing)>

คุณสามารถดาวน์โหลดอิมเมจ TOPST แต่ละรายการต่อไปนี้ได้โดยใช้วิธีดังนี้

- ตำแหน่งสคริปต์: topst.d3.pre.20240425001\fwdn.bat


```
.\fwdn.bat
```
ในรูปต่อไปนี้ อิมเมจ TOPST ทั้งหมดถูกดาวน์โหลดโดยใช้คำสั่ง .\fwdn.bat
เมื่อรีบูต TOPST D3 โดยกดปุ่ม SW1 (Reset) ตัวเรียกใช้งาน Ubuntu จะถูกเรียกทำงาน
