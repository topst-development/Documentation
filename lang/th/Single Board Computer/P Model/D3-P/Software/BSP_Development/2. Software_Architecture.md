# 2. สถาปัตยกรรมซอฟต์แวร์

รูปที่ 2.1 แสดงสถาปัตยกรรมซอฟต์แวร์ของ TCC8050 คอร์ทั้งสามประกอบด้วยคุณสมบัติดังต่อไปนี้ โดยแต่ละคอร์แลกเปลี่ยนข้อมูลกันผ่าน IPC

TCC8050 ใช้ CA72 (คอร์หลัก) เพื่อให้บริการฟังก์ชันมัลติมีเดีย และ CA53 (คอร์รอง) ทำหน้าที่ประมวลผลแบบทันทีแทนคอร์หลักในระหว่างการทำงาน (เช่น กล้องมองหลัง) ส่วน CR5 ให้บริการ OS แบบเรียลไทม์เพื่อรองรับความสามารถที่ใช้ในการสื่อสารกับรถยนต์
