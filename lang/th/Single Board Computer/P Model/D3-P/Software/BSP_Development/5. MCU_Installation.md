### 5.4.1 การรองรับ UART

ระบบย่อย TCC8050 MICOM มี UART จำนวน 5 ช่องสัญญาณ และแต่ละช่องสัญญาณ UART ประกอบด้วยตัวควบคุม ARM® PrimeCell™ UART (PL011) หนึ่งตัวและตัวควบคุม ARM® PrimeCell™ DMA (PL081) หนึ่งตัว ข้อมูลที่ส่ง/รับผ่านการสื่อสาร UART สามารถถ่ายโอนไปยังหรือมาจากหน่วยความจำภายใน (SRAM-0 หรือ SRAM-1) ได้โดยตัวควบคุม DMA เฉพาะของ UART

### 5.4.1.1 คุณสมบัติ

<br/>

### 5.4.1.1.1 ตัวควบคุม UART

คุณสมบัติของตัวควบคุม UART มีดังนี้:

- การใช้งานอินพุต/เอาต์พุต UART ที่โปรแกรมได้
- บัฟเฟอร์หน่วยความจำแบบ First-In, First-Out (FIFO) แยกกันสำหรับการส่ง 32×8 และการรับ 32×12 เพื่อลดการอินเทอร์รัปต์ของ CPU
- การปิดใช้งาน FIFO ที่โปรแกรมได้ เพื่อให้มีความลึก 1 ไบต์
- ตัวสร้างอัตราบอดที่โปรแกรมได้ ซึ่งช่วยให้สามารถหารความถี่คล็อกอ้างอิงที่มากกว่า 3.6864 MHz ได้
- บิตการสื่อสารแบบอะซิงโครนัสมาตรฐาน (start, stop และ parity)
- การมาสก์อินเทอร์รัปต์อย่างอิสระสำหรับ FIFO ส่ง, FIFO รับ, การหมดเวลาในการรับ, สถานะโมเด็ม และเงื่อนไขข้อผิดพลาด
- รองรับ Direct Memory Access (DMA)
- การตรวจจับบิตเริ่มต้นที่ผิดพลาด
- การสร้างและการตรวจจับ line break
- การควบคุมการไหลของข้อมูลด้วยฮาร์ดแวร์ที่โปรแกรมได้: ฟังก์ชันควบคุมโมเด็มของ CTS และ RTS
- คุณลักษณะของอินเทอร์เฟซอนุกรมที่โปรแกรมได้อย่างสมบูรณ์:
- สามารถโปรแกรมข้อมูลได้เป็น 5, 6, 7 หรือ 8 บิต
- การสร้างและการตรวจจับบิตพาริตีแบบคู่ คี่ แบบคงที่ หรือไม่มีพาริตี
- การสร้างบิตหยุด 1 หรือ 2 บิต
- การสร้างอัตราบอดได้สูงสุดถึง UARTCLK/16
- รีจิสเตอร์ระบุตัวตนที่ระบุ UART ได้อย่างเฉพาะเจาะจง ระบบปฏิบัติการสามารถใช้รีจิสเตอร์เหล่านี้เพื่อกำหนดค่าตนเองโดยอัตโนมัติได้

<br/>

### 5.4.1.1.2 ตัวควบคุม UART DMA

คุณสมบัติของตัวควบคุม UART DMA มีดังนี้:

- การถ่ายโอนแบบหน่วยความจำไปยังหน่วยความจำ, หน่วยความจำไปยัง UART และ UART ไปยังหน่วยความจำ
- ตัวควบคุม DMA มีสองช่องสัญญาณ
- รองรับ scatter หรือ gather DMA ผ่านการใช้ linked list ซึ่งหมายความว่าพื้นที่ต้นทางและปลายทางไม่จำเป็นต้องอยู่ในพื้นที่หน่วยความจำที่ต่อเนื่องกัน
- บัสมาสเตอร์ AHB หนึ่งชุดสำหรับการถ่ายโอนข้อมูล อินเทอร์เฟซนี้จะถ่ายโอนข้อมูลเมื่อมีคำขอ DMA เกิดขึ้น
- ความกว้างบัสมาสเตอร์ AHB ขนาด 32 บิต
- การกำหนดแอดเดรสแบบเพิ่มค่าหรือไม่เพิ่มค่าสำหรับต้นทางและปลายทาง
- ขนาดเบิร์สต์ของ DMA ที่โปรแกรมได้ สามารถโปรแกรมขนาดเบิร์สต์ของ DMA เพื่อถ่ายโอนข้อมูลได้อย่างมีประสิทธิภาพมากขึ้น โดยทั่วไปขนาดเบิร์สต์จะถูกตั้งค่าเป็นครึ่งหนึ่งของขนาด FIFO ในอุปกรณ์ต่อพ่วง
- FIFO ภายในขนาดสี่เวิร์ดต่อหนึ่งช่องสัญญาณ
- รองรับทั้งแบบ big-endian และ little-endian ตัวควบคุม DMA จะใช้โหมด little-endian เป็นค่าเริ่มต้นเมื่อรีเซ็ต
- คำขออินเทอร์รัปต์ของข้อผิดพลาด DMA และการนับ DMA แบบรวมกัน ท่านสามารถสร้างอินเทอร์รัปต์ไปยังโปรเซสเซอร์เมื่อเกิดข้อผิดพลาด DMA หรือเมื่อการนับ DMA ถึง 0 ซึ่งโดยทั่วไปใช้เพื่อระบุว่าการถ่ายโอนเสร็จสิ้นแล้ว สัญญาณคำขออินเทอร์รัปต์สามสัญญาณต่อไปนี้ทำหน้าที่ดังกล่าว:
- INTTC ส่งสัญญาณเมื่อการถ่ายโอนเสร็จสมบูรณ์
   * **หมายเหตุ**: สัญญาณ INTTC ไม่ได้ถูกป้อนเข้าสู่ตัวควบคุมอินเทอร์รัปต์ แต่สามารถตรวจสอบสถานะได้ผ่านรีจิสเตอร์สถานะ
- INTERR ส่งสัญญาณเมื่อเกิดข้อผิดพลาด
   * **หมายเหตุ**: สัญญาณ INTERR ไม่ได้ถูกป้อนเข้าสู่ตัวควบคุมอินเทอร์รัปต์ แต่สามารถตรวจสอบสถานะได้ผ่านรีจิสเตอร์สถานะ
- INTR รวมสัญญาณคำขออินเทอร์รัปต์ทั้ง INTTC และ INTERR เข้าด้วยกัน โดยสัญญาณ INTR จะถูกป้อนเข้าสู่ตัวควบคุมอินเทอร์รัปต์
- การมาสก์อินเทอร์รัปต์: ท่านสามารถมาสก์คำขออินเทอร์รัปต์ของข้อผิดพลาด DMA และการนับสิ้นสุดของ DMA ได้
- สถานะอินเทอร์รัปต์ดิบ: ท่านสามารถอ่านสถานะอินเทอร์รัปต์ดิบของข้อผิดพลาด DMA และการนับ DMA ก่อนการมาสก์ได้

    uint8           port_cfg;   //config of debug port

    UART_StatusInit(ucCh);

    rom_header  = (SNORRomInfo_t *)MCU_BSP_SNOR_BASE;
    port_cfg  = 0;

    if (ucCh == UART_DEBUG_CH)
    {
        // Find Debug port from special location of SNOR Flash.
        if (rom_header->riRomId != SNOR_ROM_ID)
        {
            /* Secondary SNOR ROM Header */

            if (rom_header->riRomId != SNOR_ROM_ID)
            {

            {
                port_cfg = (uint8)rom_header->riDebugPort;
            }
        }
        else
        {
            port_cfg = (uint8)rom_header->riDebugPort;
        }
    }
    else if (ucCh < UART_CH_MAX)
    {
        port_cfg = ucPortCfg;
    }
    else
    {
        port_cfg = 0xFF;    //Error

### 5.4.2 แอปพลิเคชัน CAN

Controller Area Network (CAN) ทำการสื่อสารตามมาตรฐาน ISO 11898-1 (เหมือนกับข้อมูลจำเพาะของโปรโตคอล Bosch CAN 2.0 part A, B) นอกจากนี้ CAN ยังรองรับการสื่อสารตามข้อมูลจำเพาะของโปรโตคอล CAN Flexible Data-rate (FD) 1.0 ด้วย

ฟังก์ชันทั้งหมดที่จัดการข้อความถูกนำไปใช้งานโดย Rx Handler และ Tx Handler

Rx Handler ทำหน้าที่จัดการการกรองการยอมรับข้อความ การถ่ายโอนข้อความที่ได้รับจาก CAN Core ไปยัง Message RAM รวมถึงการให้ข้อมูลสถานะของข้อความที่ได้รับ

Tx Handler ทำหน้าที่ถ่ายโอนข้อความที่จะส่งจาก Message RAM ไปยัง CAN Core รวมถึงการให้ข้อมูลสถานะการส่ง โดยจะนำฟังก์ชันทั้งหมดที่เกี่ยวกับตารางเวลาและเวลาระบบส่วนกลางไปใช้งาน

การกรองการยอมรับถูกนำไปใช้งานด้วยการผสมผสานขององค์ประกอบตัวกรองสูงสุด 128 รายการ โดยแต่ละรายการสามารถกำหนดค่าเป็นช่วง เป็นบิตมาสก์ หรือเป็นตัวกรอง ID เฉพาะได้

มีตัวควบคุม CAN FD รวมทั้งหมดสามตัวรวมอยู่ในระบบย่อย MICOM ของ TCC8050 CPU สามารถกำหนดค่าตัวควบคุม CAN แต่ละตัวผ่าน AHB to APB host I/F ตัวควบคุม CAN FD แต่ละตัวเข้าถึง SRAM-0 หรือ SRAM-1 ที่รวมอยู่ในระบบย่อย MICOM ผ่านบัสเมทริกซ์ AHB และใช้ SRAM-0 หรือ SRAM-1 เป็นหน่วยความจำข้อความ

### 5.4.2.1 คุณสมบัติ

คุณสมบัติของแอปพลิเคชัน CAN มีดังนี้

- สอดคล้องกับโปรโตคอล CAN เวอร์ชัน 2.0 part A, B (ISO 11898-1), ข้อมูลจำเพาะ Bosch CAN FD V1.0, ISO 16845
- รองรับ CAN FD ที่มีข้อมูลสูงสุด 64 ไบต์
- การตรวจจับและบันทึกข้อผิดพลาดของ CAN (Stuff/Bit/Format/CRC/ACK)
- การกรองการยอมรับที่ได้รับการปรับปรุง
- FIFO รับที่กำหนดค่าได้สองชุด
- การส่งสัญญาณแยกต่างหากเมื่อได้รับข้อความที่มีลำดับความสำคัญสูง
- บัฟเฟอร์รับเฉพาะสูงสุด 64 ชุด
- บัฟเฟอร์ส่งเฉพาะสูงสุด 32 ชุด
- FIFO ส่งที่กำหนดค่าได้
- คิวส่งที่กำหนดค่าได้
- FIFO เหตุการณ์การส่งที่กำหนดค่าได้
- โหมดทดสอบ loopback ที่โปรแกรมได้
- อินเทอร์รัปต์ของโมดูลที่มาสก์ได้
- โดเมนสัญญาณนาฬิกาสองโดเมน (สัญญาณนาฬิกา CAN และสัญญาณนาฬิกาบัส)

CANErrorType_t CAN_DrvInitChannel
(
    CANController_t *                   psControllerInfo
)
{
    uint8               ucCh;
    uint32              uiMemSize;
    uint32              uiMemAddr;
    CANRegBaseAddr_t *  psConfigBaseRegAddr;
    CANErrorType_t      ret;

    uiMemAddr           = 0UL;
    ret                 = CAN_ERROR_NONE;

    if( ( psControllerInfo != NULL_PTR ) && ( psControllerInfo->cMode == CAN_MODE_NO_INITIALIZATION ) )
    {
        /* Set Config */
        ucCh = psControllerInfo->cChannelHandle;
        psControllerInfo->cRegister = ( CANControllerRegister_t * ) CAN_PortingGetControllerRegister( ucCh );

        /* Set HW_Init */
        ( void ) CAN_PortingInitHW( psControllerInfo );
        ( void ) CAN_PortingSetControllerClock( psControllerInfo, CAN_CONTROLLER_CLOCK );
        ( void ) CAN_PortingResetDriver( psControllerInfo );

        /* Set Memory */
        uiMemSize = CAN_DrvGetSizeOfRamMemory( psControllerInfo );

        if( 0UL < uiMemSize )
        {
            uiMemAddr = CAN_PortingAllocateNonCacheMemory( ucCh, uiMemSize );
        }

        if( uiMemAddr != 0UL )
        {
            psConfigBaseRegAddr = ( CANRegBaseAddr_t * ) CAN_PortingGetMessageRamBaseAddr( ucCh );

            if( psConfigBaseRegAddr != NULL_PTR )
            {
                psConfigBaseRegAddr->rFReg.rfBASE_ADDR = ( SALReg32 ) ( ( uint32 ) ( uiMemAddr >> ( uint32 ) 16UL ) & ( uint32 ) 0xFFFFUL );
            }

            ( void ) CAN_DrvRegisterParameterAll( psControllerInfo );

            ( void ) CAN_DrvStartConfigSetting( psControllerInfo );
            ( void ) CAN_DrvSetControlConfig( psControllerInfo );

            /* Set Buffer */
            ( void ) SAL_MemSet( ( void * ) uiMemAddr, 0, uiMemSize );
            ( void ) CAN_DrvInitBuffer( psControllerInfo, uiMemAddr, uiMemSize );
            ( void ) CAN_MsgInit( psControllerInfo );

            /* Set Filter */
            ( void ) CAN_DrvSetFilterConfig( psControllerInfo );

            /* Set Timing */
            ( void ) CAN_DrvInitTiming( psControllerInfo );

            /* Set Interrupt */
            ( void ) CAN_DrvSetInterruptConfig( psControllerInfo );

            /* Set TimeStamp */
            ( void ) CAN_DrvSetTimeStamp( psControllerInfo );

            /* Set TimeOut */
            ( void ) CAN_DrvSetTimeoutValue( psControllerInfo );

            /* Set WatchDog */
            ( void ) CAN_DrvSetWatchDog( psControllerInfo );

            ( void ) CAN_DrvFinishConfigSetting( psControllerInfo );

            psControllerInfo->cMode = CAN_MODE_OPERATION;
        }
        else
        {
            ret = CAN_ERROR_ALLOC;
        }
    }
    else
    {
        ret = CAN_ERROR_BAD_PARAM;
    }

    return ret;
}
