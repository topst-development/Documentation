## 1.1 แผนภาพบล็อกการทำงาน

TCC8050 มอบโซลูชันที่หลากหลาย เช่น Car Audio Video Navigation (AVN) ดิจิทัลคลัสเตอร์ และ Around View Monitor (AVM) โดย TCC8050 ผสานรวมโปรเซสเซอร์มัลติคอร์ ARM® Cortex-A72 และโปรเซสเซอร์มัลติคอร์ Cortex-A53 รวมถึง Cortex-R5 สำหรับไมโครโปรเซสเซอร์ คอร์ SC000 ของ Hardware Security Module (HSM) ในระบบย่อยด้านความปลอดภัยสำหรับความปลอดภัยยานยนต์ Cortex-M4 สำหรับการจัดการหน่วยเก็บข้อมูล Cortex-M4 อีกตัวหนึ่งสำหรับ TSDEMUX ในระบบย่อย Cortex-M4 และ Video Processing Unit (VPU)/Graphics Processing Unit (GPU) แบบฮาร์ดไวร์ เพื่อยกระดับประสบการณ์มัลติมีเดียให้สูงสุด โดยฮาร์ดไวร์ VPU รองรับการเข้ารหัสและถอดรหัสวิดีโอ และ GPU ให้กราฟิก 3 มิติด้วย OpenGL ES1.1/2.0/3.2 และ OpenCL 1.0/1.1/2.0 ทั้งนี้ TCC8050 รองรับระบบปฏิบัติการหลากหลาย เช่น Linux® และ Android™

TCC8050 เป็นโปรเซสเซอร์ที่ปรับให้เหมาะสมสำหรับอุปกรณ์เครือข่ายที่ต้องการฟังก์ชันการเชื่อมต่อที่ใช้งานง่าย โดยคอนโทรลเลอร์ USB 3.0, USB 2.0 Device/Host และ USB 2.0 Host ช่วยให้สามารถส่งข้อมูลระหว่างอุปกรณ์มัลติมีเดียกับอุปกรณ์เก็บข้อมูลได้ คอนโทรลเลอร์ Ethernet MAC ให้การเชื่อมต่ออินเทอร์เน็ตที่สอดคล้องกับมาตรฐาน IEEE802.3 นอกจากนี้ PCI Express (PCIe) Gen 3 ยังให้แบนด์วิดท์สูงสำหรับการเชื่อมต่อ IP ภายนอก

ชุดคุณสมบัติที่ล้ำสมัยและครบครันนี้ช่วยขยายประเภทของแอปพลิเคชันที่สามารถใช้งานร่วมกับ TCC8050 ได้ เพื่อตอบสนองต่อเทคโนโลยีและความต้องการของตลาดที่เปลี่ยนแปลงไป
