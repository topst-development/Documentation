# TOPST D3 
<br/>

TOPST D3 คือ SBC สมรรถนะสูงที่มีหลาย CPU ได้แก่ Cortex-A72 quad & Cortex-A53, Cortex-R5  

<br/>

หากต้องการไปยังหน้าเอกสารหลัก โปรดดูตารางด้านล่าง
<br/>

[อิมเมจอย่างเป็นทางการของ TOPST D3](https://drive.google.com/file/d/1eJimz-nC3WcH8Kp6yauGftyIznoC6FB7/view?usp=drive_link) : หากคุณต้องการเมาต์อิมเมจที่บิลด์ไว้ล่วงหน้าอย่างรวดเร็ว คุณสามารถดาวน์โหลดได้ที่นี่
