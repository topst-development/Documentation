# 8. CAN
  

TOPST D3 มีขั้วต่อ CAN เฉพาะสำหรับ FFC (Flat Flexible Cable) แบบ 20 พิน ซึ่งรองรับการสื่อสารกับ Electric Control Unit (ECU)  

<br/><br/>

## 8.1 ขั้วต่อ CAN I/F
