# 6. ขั้วต่อ DisplayPort

TOPST D3 มี DisplayPort หนึ่งช่องซึ่งรองรับ DP 1.4 ที่ความละเอียดสูงสุด 4Kp60  


รูปที่ 6.1 แสดงวิธีเปิดใช้งานการแสดงผลโดยใช้ DisplayPort บน TOPST-D3 หากคุณต้องการเชื่อมต่อกับอุปกรณ์แสดงผลอื่นที่รองรับเฉพาะ HDMI คุณสามารถใช้สายแปลง DP to HDMI ได้
