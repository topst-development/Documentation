# 3. การดีบัก
TOPST D3 มีขั้วต่อ UART/JTAG เฉพาะสำหรับ FFC แบบ 20 พิน ซึ่งเป็นพอร์ตอนุกรมสำหรับการดีบัก

<br/><br/>

## 3.1 ขั้วต่อ Debugger I/F (UART/JTAG) ไปยังเครื่อง PC โฮสต์  

รูปที่ 3.1 แสดง FFC ระยะพิตช์ 0.5 mm แบบ 20 พิน (ด้าน A–ด้าน B) ที่ใช้สำหรับการดีบัก

## 3.2 พอร์ต Debug บน TOPST D3

## 3.3 บอร์ดย่อย UART/JTAG  

บอร์ดย่อย UART/JTAG เป็นบอร์ดสำหรับการดีบักผ่านพอร์ตอนุกรมและ JTAG คุณสามารถตรวจสอบล็อกอนุกรมได้โดยเชื่อมต่อบอร์ดย่อย UART/JTAG เข้ากับเครื่อง PC โฮสต์ด้วยสาย USB Type-C   

รูปที่ 3.3 แสดงภาพรวมของบอร์ดย่อย UART/JTAG

ตารางที่ 3.1 อธิบายขั้วต่อของบอร์ดย่อย UART/JTAG  

**ตารางที่ 3.1 คำอธิบายบอร์ดย่อย UART/JTAG:**  

| รายการ | คำอธิบาย                                     |
|:----:|------------------------------------------------|
| u10  | ขั้วต่อ FFC สำหรับเชื่อมต่อ TOPST D3            |
| u20  | Male Pin Header สำหรับเชื่อมต่อดีบักเกอร์       |
| u30  | พอร์ต Debug (USB Type-C) สำหรับการดีบัก MCU     |
| u40  | พอร์ต Debug (USB Type-C) สำหรับการดีบัก A53 Core |
| u50  | พอร์ต Debug (USB Type-C) สำหรับการดีบัก A72 Core |  

<br/><br/>

## 3.4 การเชื่อมต่อบอร์ดย่อย UART/JTAG เข้ากับ TOPST D3  

บทนี้อธิบายวิธีเชื่อมต่อ TOPST D3 เข้ากับบอร์ดย่อย UART/JTAG  

เชื่อมต่อบอร์ดย่อย UART/JTAG เข้ากับ TOPST D3 โดยใช้ Flexible Flat Cable (FFC) ดังนี้:
1. เตรียม FFC หนึ่งเส้นและสาย USB Type-C หนึ่งเส้น
2. เชื่อมต่อ FFC เข้ากับขั้วต่อ Debug I/F บนบอร์ดย่อย UART/JTAG และขั้วต่อ Debug I/F บน TOPST D3 <br/>
    * สิ่งสำคัญคือต้องเชื่อมต่อโดยให้เส้นสีน้ำเงินของ FFC หันขึ้นด้านบน
3. เชื่อมต่อบอร์ดย่อย UART/JTAG เข้ากับเครื่อง PC โฮสต์โดยใช้สาย USB Type-C <br/>
    * ดูตารางที่ 3.1 เพื่อเลือกพอร์ต UART ที่เหมาะสมตามคอร์เป้าหมาย ตัวอย่างเช่น A72 UART สามารถเชื่อมต่อกับพอร์ต UART ของคอร์หลัก (Cortex-A72 Quad) ได้
4. ตรวจสอบข้อความล็อกอนุกรมผ่านแอปพลิเคชันเทอร์มินัลบนเครื่อง PC โฮสต์

รูปที่ 3.4 แสดงตำแหน่งของ Debug บน TOPST D3 ที่เชื่อมต่อกับ Debug บนบอร์ดย่อย UART/JTAG

## 3.5 การเชื่อมต่อดีบักเกอร์ JTAG เข้ากับ TOPST D3  

บทนี้อธิบายวิธีเชื่อมต่อดีบักเกอร์ JTAG เข้ากับ TOPST D3  

เชื่อมต่อดีบักเกอร์ JTAG เข้ากับ TOPST D3 ดังนี้:
1. เตรียมดีบักเกอร์ JTAG หนึ่งเครื่อง
2. โดยอ้างอิงบท "การเชื่อมต่อบอร์ดย่อย UART/JTAG เข้ากับ TOPST D3" ด้านบน ให้เชื่อมต่อบอร์ดย่อย UART/JTAG เข้ากับ TOPST D3
3. เชื่อมต่อดีบักเกอร์ JTAG เข้ากับ JTAG Header บนบอร์ดย่อย UART/JTAG

รูปที่ 3.5 แสดงตำแหน่งของ JTAG Header บนบอร์ดย่อย UART/JTAG
