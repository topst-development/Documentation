# 1. บทนำ


TOPST D3 เป็นคอมพิวเตอร์ขนาดเล็กพิเศษและใช้พลังงานต่ำ ประกอบด้วยไมโครโปรเซสเซอร์ หน่วยความจำ และขั้วอินพุต/เอาต์พุต (I/O) TOPST D3 สามารถใช้ร่วมกับเซ็นเซอร์ได้หลากหลายชนิด เช่น การตรวจจับการเคลื่อนไหว อัลตราซาวด์ อินฟราเรด LiDAR ตัวขับมอเตอร์ ตัวรับส่งสัญญาณสื่อสารในยานยนต์ ไมโครโฟน และโมดูลสื่อสาร  

หากต้องการการสนับสนุน โปรดดูส่วนเอกสารฮาร์ดแวร์ของเว็บไซต์ TOPST (topst.ai) และตั้งคำถามได้ที่ TOPST Technical Q&A

## 1.5 ช่วงอุณหภูมิและการระบายความร้อน  
ช่วงอุณหภูมิแวดล้อมในการทำงานที่แนะนำคือ -10°C ถึง 55°C   
TOPST D3 จะลดความเร็วสัญญาณนาฬิกาของ CPU และแรงดันไฟฟ้าเพื่อลดความร้อนที่เกิดขึ้น เมื่อ TOPST D3 อยู่ในสถานะว่างหรือมีภาระงานเบา ผ่านโซลูชัน Dynamic Voltage and Frequency Scaling (DVFS) TOPST D3 ทำงานได้อย่างสมบูรณ์แบบโดยไม่ต้องใช้อุปกรณ์ระบายความร้อนเพิ่มเติม หากคุณต้องการใช้งานที่ประสิทธิภาพเต็มที่ในช่วงอุณหภูมิการทำงานที่กว้างขึ้น เช่น ข้อกำหนดด้านยานยนต์ โปรดติดต่อ TOPST;topst@topst.ai
