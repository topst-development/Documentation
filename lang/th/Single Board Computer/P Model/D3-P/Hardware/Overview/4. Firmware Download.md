# 4. การเชื่อมต่อ TOPST D3 เข้ากับเครื่อง PC โฮสต์เพื่อดาวน์โหลดเฟิร์มแวร์



Firmware Downloader(**FWDN**) เขียนอิมเมจ ROM ลงใน TOPST D3 ผ่านการสื่อสาร USB บนเครื่อง PC โฮสต์  

TOPST D3 มีปุ่ม Boot Mode หนึ่งปุ่ม และรองรับโหมดการบูตสองแบบผ่านปุ่ม Boot Mode ดังนี้:
- USB Boot Mode ใช้สำหรับเขียนอิมเมจ ROM โดยใช้โปรแกรม **FWDN** บนเครื่อง PC โฮสต์ของคุณ
- eMMC Boot Mode ใช้สำหรับบูต TOPST D3 โดยใช้อิมเมจ ROM ที่จัดเก็บอยู่ในอุปกรณ์ eMMC

**หมายเหตุ**: พอร์ต USB 2.0 D/H ใช้สำหรับตัวดาวน์โหลดเฟิร์มแวร์ (**FWDN**)  

หากต้องการใช้ **FWDN** ให้เชื่อมต่อ TOPST D3 เข้ากับเครื่อง PC โฮสต์ ดังนี้:
1. ตรวจสอบว่าได้ติดตั้งไดรเวอร์ VTC บนเครื่อง PC โฮสต์แล้ว หากยังไม่ได้ติดตั้งไดรเวอร์ VTC ให้ติดตั้งตามแนวทาง **FWDN** ที่มีอยู่บน topst.ai
2. เตรียมสาย USB Type-A จำนวนหนึ่งเส้น
3. เชื่อมต่อ USB 2.0 D/H บน TOPST D3 เข้ากับเครื่อง PC โฮสต์โดยใช้สาย USB Type-A
4. ใช้วิธีใดวิธีหนึ่งจากสองวิธีด้านล่างเพื่อเปลี่ยนโหมดการบูตของ TOPST D3<br/>
   1. วิธีที่ 1
       * หาก TOPST D3 ยังไม่ได้รับไฟเลี้ยง ให้กดปุ่ม FWDN ค้างไว้แล้วต่อไฟเลี้ยง 5V เข้ากับ TOPST D3
       * ปล่อยปุ่ม FWDN Boot mode<br/>
   2. วิธีที่ 2
       * หาก TOPST D3 ได้รับไฟเลี้ยงอยู่แล้ว ให้กดปุ่ม Reset และปุ่ม FWDN Boot mode
       * ปล่อยปุ่ม FWDN Boot mode
5. ดาวน์โหลดอิมเมจ ROM ของคุณตามคู่มือ **FWDN**

รูปที่ 4.1 แสดงลักษณะของปุ่ม Reset ปุ่ม FWDN และ USB 2.0 D/H บน TOPST D3
