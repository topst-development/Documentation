# 2. คู่มือการติดตั้ง TOPST VCP Arduino Core

คู่มือนี้จะช่วยให้คุณดาวน์โหลดและติดตั้ง TOPST VCP Arduino core เพื่อใช้งานกับ Arduino Integrated Development Environment (IDE)

<br/><br/>

## 2.1 คู่มือการติดตั้ง

### Step 1: ดาวน์โหลด Arduino IDE

ก่อนอื่น คุณต้องมี Arduino IDE ซึ่งทำหน้าที่เป็นแพลตฟอร์มสำหรับเขียนโปรแกรมบอร์ด Arduino ของคุณ

- เยี่ยมชมเว็บไซต์ทางการของ Arduino: [Arduino Software](https://www.arduino.cc/en/software)
- เลือกเวอร์ชันที่เหมาะสมกับระบบปฏิบัติการของคุณ (Windows, macOS, Linux)
- ดาวน์โหลดและเรียกใช้ตัวติดตั้ง

<br/>

### Step 2: ติดตั้ง Arduino IDE

ทำตามขั้นตอนต่อไปนี้ตามระบบปฏิบัติการของคุณเพื่อติดตั้ง Arduino IDE:

#### Windows:
1. เรียกใช้ไฟล์ `.exe` ที่ดาวน์โหลดมา
2. ทำตามคำแนะนำในการติดตั้ง ตรวจสอบให้แน่ใจว่าคุณติดตั้งไดรเวอร์ที่จำเป็นทั้งหมด

#### macOS:
1. เปิดไฟล์ `.dmg`
2. ลากแอปพลิเคชัน Arduino ไปยังโฟลเดอร์ Applications

#### Linux:
1. แตกไฟล์ `.tar.xz`
2. เปิดเทอร์มินัลในไดเรกทอรีที่แตกไฟล์ไว้
3. เรียกใช้ `./install.sh` เพื่อติดตั้ง

<br/>

### Step 3: การเพิ่มบอร์ด TOPST VCP

หากต้องการเขียนโปรแกรมบอร์ด TOPST VCP คุณต้องเพิ่ม core ของบอร์ดลงใน Arduino IDE ผ่าน Board Manager

1. เปิด Arduino IDE
2. ไปที่ **File > Preferences**
3. ในช่อง "Additional Board Manager URLs" ให้เพิ่ม URL ต่อไปนี้สำหรับ TOPST VCP core:

    ```
    https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
    ```

    (หมายเหตุ: แทนที่ URL ด้านบนด้วย URL จริงที่ให้ไว้สำหรับ TOPST VCP core)
4. คลิก "OK" เพื่อบันทึกการเปลี่ยนแปลง
5. ไปที่ **Tools > Board > Boards Manager**
6. ค้นหา "TOPST VCP" ใน Boards Manager
7. คลิก "Install" เมื่อรายการ TOPST VCP ปรากฏขึ้น

<br/>

### Step 4: การเลือกบอร์ด TOPST VCP

หลังจากติดตั้งแล้ว คุณต้องเลือกบอร์ด TOPST VCP:

1. ไปที่ **Tools > Board**
2. เลื่อนลงเพื่อค้นหา "TOPST VCP" แล้วเลือก

<br/>

### Step 5: ตรวจสอบการติดตั้ง

ทดสอบว่าการตั้งค่าของคุณทำงานได้หรือไม่โดยการอัปโหลดสเก็ตช์อย่างง่าย:

1. เชื่อมต่อบอร์ด TOPST VCP เข้ากับ PC ของคุณผ่าน USB
2. เลือกพอร์ตที่เหมาะสมภายใต้ **Tools > Port**
3. เปิด **File > Examples > 01.Basics > Blink**
4. กดปุ่ม **Upload** เพื่อถ่ายโอนสเก็ตช์ไปยังบอร์ด
5. หากไฟ LED บนบอร์ดเริ่มกะพริบ แสดงว่าบอร์ดได้รับการตั้งค่าอย่างถูกต้อง

<br/><br/>

## 2.2 การแก้ไขปัญหา

หากคุณพบปัญหาใด ๆ ระหว่างการตั้งค่า คุณสามารถดูได้ที่[คู่มือการแก้ไขปัญหา Arduino](https://www.arduino.cc/en/Guide/Troubleshooting)
