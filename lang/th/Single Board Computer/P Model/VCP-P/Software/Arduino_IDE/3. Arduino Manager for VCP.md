# 3. ตัวจัดการบอร์ด Arduino สำหรับ TOPST VCP

ที่เก็บข้อมูลนี้เป็นแหล่งรวมตัวจัดการบอร์ด Arduino สำหรับ TOPST VCP ตัวจัดการบอร์ดนี้ช่วยให้ผู้ใช้สามารถเพิ่มการรองรับบอร์ด TOPST VCP ให้กับ Arduino IDE ได้อย่างง่ายดาย ทำให้สามารถเขียนและอัปโหลดโปรแกรมด้วยเครื่องมือที่คุ้นเคย

<br/><br/>

## 3.1 คุณสมบัติ

- ติดตั้งข้อกำหนดบอร์ดสำหรับ TOPST VCP ได้อย่างง่ายดาย
- ใช้งานร่วมกับ Arduino IDE ได้
- รองรับบอร์ดรุ่นหลักทั้งหมดของ TOPST VCP

<br/><br/>

## 3.2 การติดตั้ง

หากต้องการติดตั้งตัวจัดการบอร์ด TOPST VCP ใน Arduino IDE ให้ปฏิบัติตามขั้นตอนต่อไปนี้:

1. เปิด Arduino IDE โดย **เรียกใช้ด้วยสิทธิ์ผู้ดูแลระบบ**
2. ไปที่ `File > Preferences`
3. ในช่อง "Additional Board Manager URLs" ให้เพิ่ม URL ต่อไปนี้:
   ```
   https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
   ```
   หากในช่องดังกล่าวมี URL อื่นอยู่แล้ว ให้คั่นด้วยเครื่องหมายจุลภาค

4. คลิก "OK" เพื่อบันทึกการตั้งค่า
5. ไปที่ `Tools > Board > Boards Manager...`
6. ค้นหา "TOPST VCP" ใน Boards Manager
7. คลิก "Install" ที่อยู่ถัดจากรายการ TOPST VCP

<br/><br/>

## 3.3 การใช้งาน

หลังจากติดตั้งแล้ว คุณสามารถเลือกบอร์ด TOPST VCP ได้จากเมนู `Tools > Board` ใน Arduino IDE เลือกบอร์ดที่ตรงกับฮาร์ดแวร์ของคุณ จากนั้นดำเนินการเขียนและอัปโหลดสเก็ตช์ตามปกติ

<br/><br/>
