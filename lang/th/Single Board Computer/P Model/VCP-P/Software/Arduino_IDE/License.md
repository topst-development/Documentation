ขอมอบสิทธิ์โดยไม่มีค่าใช้จ่ายแก่บุคคลใดก็ตามที่ได้รับสำเนา
ของซอฟต์แวร์นี้และไฟล์เอกสารที่เกี่ยวข้อง (ต่อไปนี้เรียกว่า "ซอฟต์แวร์") ในการดำเนินการ
กับซอฟต์แวร์โดยไม่มีข้อจำกัด รวมถึงแต่ไม่จำกัดเพียงสิทธิ์ในการ
ใช้ คัดลอก แก้ไข รวม เผยแพร่ แจกจ่าย ให้อนุญาตช่วง และ/หรือจำหน่าย
สำเนาของซอฟต์แวร์ และอนุญาตให้บุคคลที่ได้รับซอฟต์แวร์
กระทำการดังกล่าวได้ ภายใต้เงื่อนไขต่อไปนี้

ประกาศลิขสิทธิ์ข้างต้นและประกาศการอนุญาตนี้จะต้องรวมอยู่ใน
สำเนาทั้งหมดหรือส่วนสำคัญของซอฟต์แวร์

ซอฟต์แวร์นี้จัดหาให้ "ตามสภาพที่เป็นอยู่" โดยไม่มีการรับประกันใด ๆ ไม่ว่าโดยชัดแจ้งหรือ
โดยปริยาย รวมถึงแต่ไม่จำกัดเพียงการรับประกันด้านความเหมาะสมในเชิงพาณิชย์
ความเหมาะสมสำหรับวัตถุประสงค์เฉพาะ และการไม่ละเมิดสิทธิ์ ไม่ว่าในกรณีใด
ผู้สร้างสรรค์หรือผู้ถือลิขสิทธิ์จะไม่รับผิดต่อการเรียกร้อง ความเสียหาย หรือความรับผิดอื่นใด
ไม่ว่าจะในการดำเนินคดีตามสัญญา การละเมิด หรือกรณีอื่น อันเกิดจาก
หรือเกี่ยวเนื่องกับซอฟต์แวร์ หรือการใช้งานหรือการดำเนินการอื่นใดใน
ซอฟต์แวร์นี้
