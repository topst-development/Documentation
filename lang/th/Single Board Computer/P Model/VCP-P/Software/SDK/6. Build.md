#  6. การบิลด์ซอร์สโค้ด

เมื่อได้รับซอร์สโค้ดเรียบร้อยแล้ว ขั้นตอนสำคัญถัดไปคือการบิลด์ซอร์สโค้ดเพื่อให้ทำงานได้อย่างเหมาะสมที่สุดบนบอร์ด TOPST-VCP

<br/><br/>

## 6.1 ทำความเข้าใจ Makefile และระบบบิลด์

Makefile เป็นรากฐานสำคัญของระบบบิลด์จำนวนมาก โดยประกอบด้วยกฎและคำสั่งที่บอกยูทิลิตี make ว่าจะคอมไพล์และลิงก์โปรแกรมอย่างไร การใช้ Makefile ทำให้นักพัฒนาสามารถทำให้กระบวนการบิลด์เป็นแบบอัตโนมัติ ซึ่งช่วยให้เกิดความสอดคล้องและมีประสิทธิภาพ

<br/><br/>

## 6.2 การเริ่มกระบวนการบิลด์

หากต้องการเริ่มบิลด์ซอร์สโค้ด ให้ปฏิบัติตามขั้นตอนต่อไปนี้ :

1. **ใช้คำสั่งต่อไปนี้เพื่อเข้าไปยังไดเรกทอรีสำหรับบิลด์ :**

    ```
    $ cd build/tcc70xx/gcc/
    ```

2. **ใช้คำสั่งต่อไปนี้เพื่อรันคำสั่ง make :**

    ```
    $ make
    ```

คำสั่งนี้จะอ่าน Makefile ในไดเรกทอรีปัจจุบันและดำเนินกระบวนการบิลด์

3. **ตรวจสอบผลลัพธ์ของการบิลด์** : เมื่อกระบวนการบิลด์เสร็จสมบูรณ์ คุณจะพบไฟล์ผลลัพธ์ต่อไปนี้บนเทอร์มินัล
    - output/tcc70xx_pflash_boot.rom
    - output/tcc70xx_pflash_boot_2M_ECC.rom
    - output/tcc70xx_pflash_boot_3M_ECC.rom
    - output/tcc70xx_pflash_boot_4M_ECC.rom

    ตรวจสอบให้แน่ใจว่ามีไฟล์เหล่านี้อยู่ เนื่องจากไฟล์เหล่านี้มีความสำคัญอย่างยิ่งต่อขั้นตอนการพัฒนาถัดไป

    $ ls output/ -al
