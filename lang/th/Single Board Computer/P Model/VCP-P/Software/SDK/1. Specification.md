# 1. บทนำ

<br/><br/>

## 1.1 วัตถุประสงค์ของคู่มือ  

คู่มือนี้มีวัตถุประสงค์เพื่อให้ภาพรวมที่ครอบคลุมเกี่ยวกับการตั้งค่าสภาพแวดล้อมการพัฒนาซอฟต์แวร์สำหรับบอร์ด TOPST-VCP บนระบบ Linux โดยการปฏิบัติตามขั้นตอนที่ระบุไว้ในเอกสารนี้ นักพัฒนาจะได้รับเครื่องมือ การกำหนดค่า และความเข้าใจที่จำเป็นต่อการทำงานกับบอร์ด TOPST-VCP และทูลเชนที่เกี่ยวข้องได้อย่างมีประสิทธิภาพ

<br/><br/>

## 1.2 ภาพรวมของบอร์ด TOPST VCP  

บอร์ด TOPST-VCP โดดเด่นในฐานะบอร์ดพัฒนาที่ทรงพลังและใช้งานได้หลากหลาย ออกแบบมาเพื่อรองรับการใช้งานที่หลากหลาย หัวใจสำคัญของบอร์ดนี้คือชิป TCC7045 ซึ่งสร้างขึ้นบนสถาปัตยกรรม ARM Cortex-R5 การผสานรวมนี้ช่วยสร้างสมดุลระหว่างประสิทธิภาพและสมรรถนะ ทำให้เป็นตัวเลือกอันดับต้น ๆ สำหรับนักพัฒนาที่ต้องการใช้ประโยชน์จากพลังของแอปพลิเคชันที่ใช้ ARM

## 1.3 ภาพรวมของทูลเชน  

เพื่อการพัฒนาบนบอร์ด TOPST-VCP อย่างมีประสิทธิภาพ การมีทูลเชนที่เหมาะสมถือเป็นสิ่งสำคัญอย่างยิ่ง คู่มือนี้แนะนำให้ใช้ gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi สำหรับการคอมไพล์ข้ามแพลตฟอร์มโดยเฉพาะ ทูลเชนนี้ไม่เพียงแต่ใช้งานร่วมกับสถาปัตยกรรม ARM Cortex-R5 ได้เท่านั้น แต่ยังมีชุดเครื่องมือที่ปรับให้เหมาะกับชิป TCC7045 อีกด้วย
