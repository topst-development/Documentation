# 2. ข้อกำหนดเบื้องต้น

ก่อนเริ่มกระบวนการตั้งค่าและพัฒนาสำหรับบอร์ด TOPST-VCP มีข้อกำหนดเบื้องต้นหลายประการที่ต้องพิจารณา บทนี้จะแนะนำคุณเกี่ยวกับดิสทริบิวชัน Linux ที่แนะนำ ข้อกำหนดด้านฮาร์ดแวร์ และความรู้พื้นฐานที่จำเป็นเพื่อให้การพัฒนาเป็นไปอย่างราบรื่น

<br/><br/>

## 2.1 คำแนะนำเกี่ยวกับดิสทริบิวชัน Linux

สำหรับคู่มือฉบับนี้ เราแนะนำให้ตั้งค่าสภาพแวดล้อมการพัฒนาบน **Ubuntu 22.04** Ubuntu เวอร์ชันนี้มอบแพลตฟอร์มที่เสถียรพร้อมการสนับสนุนจากชุมชนอย่างกว้างขวาง ซึ่งช่วยให้มั่นใจได้ถึงความเข้ากันได้และความสะดวกในการใช้งานร่วมกับบอร์ด TOPST-VCP และทูลเชนที่เกี่ยวข้อง

การดาวน์โหลดและการติดตั้ง:

- เข้าไปที่เว็บไซต์ทางการของ Ubuntu เพื่อดาวน์โหลดดิสทริบิวชัน Ubuntu 22.04 LTS (Long Term Support)
- ปฏิบัติตามแนวทางการติดตั้งที่ให้ไว้เพื่อติดตั้ง Ubuntu 22.04 บนเครื่อง PC โฮสต์สำหรับการพัฒนาของคุณ

## 2.2 ข้อกำหนดด้านฮาร์ดแวร์

ในการเชื่อมต่อกับบอร์ด TOPST-VCP และดำเนินงานด้านการพัฒนา ส่วนประกอบฮาร์ดแวร์ต่อไปนี้เป็นสิ่งจำเป็น :

- บอร์ด TOPST-VCP: โปรดตรวจสอบให้แน่ใจว่าคุณมีบอร์ดอยู่ในมือ โดยควรอยู่ในพื้นที่ทำงานที่เหมาะสมกับการทำงานด้านฮาร์ดแวร์
- สาย USB-C: ใช้สำหรับเชื่อมต่อระหว่างเครื่อง PC โฮสต์สำหรับการพัฒนากับบอร์ด TOPST-VCP โปรดตรวจสอบว่าสายมีคุณภาพดีเพื่อรักษาการเชื่อมต่อที่เสถียรตลอดกระบวนการพัฒนา

เมื่อเตรียมฮาร์ดแวร์ที่จำเป็นเรียบร้อยแล้ว ให้เชื่อมต่อบอร์ด TOPST-VCP เข้ากับเครื่อง PC โฮสต์สำหรับการพัฒนาโดยใช้สาย USB-C โปรดตรวจสอบว่าการเชื่อมต่อแน่นหนาเพื่อหลีกเลี่ยงการหยุดชะงักที่อาจเกิดขึ้นระหว่างการพัฒนา

<br/><br/>

## 2.3 ข้อกำหนดด้านความรู้

ก่อนเริ่มต้น คุณควรทำความคุ้นเคยกับแนวคิดต่อไปนี้:

- พื้นฐาน Ubuntu: ความเข้าใจพื้นฐานเกี่ยวกับวิธีการใช้งานและดำเนินการภายในสภาพแวดล้อม Ubuntu 22.04
- โหมดการบูตของ TOPST-VCP: บอร์ด TOPST-VCP มีโหมดการบูตหลากหลายรูปแบบ ซึ่งช่วยให้นักพัฒนาสามารถเลือกโหมดที่เหมาะสมที่สุดสำหรับโครงการเฉพาะของตนได้

คำแนะนำโดยละเอียดเกี่ยวกับวิธีการเลือกโหมดการบูตจะให้มาพร้อมกับบอร์ด โปรดศึกษาเอกสารที่ให้ไว้และเลือกโหมดที่เหมาะสมกับความต้องการในการพัฒนาของคุณ
