#  5. การรับซอร์สโค้ด

ซอร์สโค้ดถือเป็นแกนหลักของโครงการพัฒนาทุกโครงการ โดยประกอบด้วยไฟล์ การกำหนดค่า และคำสั่งทั้งหมดที่จำเป็นสำหรับการบิลด์และรันซอฟต์แวร์บนแพลตฟอร์มหนึ่ง ๆ ในบริบทของบอร์ด TOPST-VCP การรับซอร์สโค้ดที่ถูกต้องมีความสำคัญอย่างยิ่งเพื่อให้มั่นใจถึงความเข้ากันได้และประสิทธิภาพสูงสุด

บทนี้จะแนะนำขั้นตอนการดึงซอร์สโค้ดโดยใช้ git ซึ่งเป็นระบบควบคุมเวอร์ชันที่ใช้กันอย่างแพร่หลาย

<br/><br/>

## 5.1 การโคลนซอร์สโค้ด TOPST-VCP

ในการรับซอร์สโค้ดสำหรับบอร์ด TOPST-VCP คุณจะใช้คำสั่ง git clone คำสั่งนี้จะสร้างสำเนาของรีโพซิทอรีระยะไกลไว้บนเครื่องของคุณ ทำให้คุณสามารถทำงานกับโค้ดได้โดยตรง

ทำตามขั้นตอนต่อไปนี้เพื่อโคลนซอร์สโค้ด TOPST-VCP

1. **เปิดเทอร์มินัล** : เปิดแอปพลิเคชันเทอร์มินัลบนระบบ Ubuntu 22.04 ของคุณ
2. **ไปยังไดเรกทอรีที่ต้องการ** : เลือกตำแหน่งที่เหมาะสมบนระบบของคุณสำหรับจัดเก็บซอร์สโค้ด ตัวอย่างเช่น หากต้องการจัดเก็บไว้ในโฮมไดเรกทอรีของผู้ใช้ ให้ใช้คำสั่ง

    ```
    $ cd ~
    ```

<p align="center"><strong>รูปที่ 5.1 ไปยังไดเรกทอรีที่ต้องการ</strong></p>


3. **โคลนรีโพซิทอรี** : ใช้คำสั่งต่อไปนี้เพื่อโคลนซอร์สโค้ด TOPST-VCP จากที่อยู่ git ที่ให้ไว้

    ```
    $ git clone https://gitlab.com/topst.ai/topst-vcp.git
    ```

4. **ไปยังไดเรกทอรีที่โคลนมา** : เมื่อกระบวนการโคลนเสร็จสมบูรณ์ ให้ใช้คำสั่งต่อไปนี้เพื่อไปยังไดเรกทอรีที่มีซอร์สโค้ดอยู่

    ```
    $ cd topst-vcp
    ```

<br/><br/>

## 5.2 การทำความคุ้นเคยกับโครงสร้างซอร์สโค้ด

หลังจากโคลนแล้ว การทำความคุ้นเคยกับโครงสร้างไดเรกทอรีและเนื้อหาของซอร์สโค้ดจะเป็นประโยชน์ ซึ่งจะช่วยให้คุณเข้าใจได้ดีขึ้นว่าไฟล์ใดอยู่ที่ตำแหน่งใด และโค้ดเบสมีการจัดระเบียบอย่างไร

- ใช้คำสั่งอย่างเช่น ls เพื่อแสดงรายการเนื้อหาของไดเรกทอรี
- สำรวจไดเรกทอรีและไฟล์สำคัญเพื่อทำความเข้าใจวัตถุประสงค์และการทำงานของสิ่งเหล่านั้น

```
$ ls -al
```
