# 4. ทูลเชน

ทูลเชนเป็นองค์ประกอบสำคัญในกระบวนการพัฒนา โดยเฉพาะอย่างยิ่งเมื่อทำงานกับฮาร์ดแวร์เฉพาะทางอย่างบอร์ด TOPST-VCP ทูลเชนมีชุดเครื่องมือที่ช่วยให้นักพัฒนาสามารถคอมไพล์ ลิงก์ และดีบักโค้ดสำหรับแพลตฟอร์มเป้าหมายได้

<br/><br/>

## 4.1 ภาพรวมของทูลเชน

โดยทั่วไปทูลเชนประกอบด้วยคอมไพเลอร์ ลิงเกอร์ แอสเซมเบลอร์ และดีบักเกอร์ รวมถึงเครื่องมืออื่น ๆ องค์ประกอบเหล่านี้ทำงานร่วมกันเพื่อแปลงซอร์สโค้ดให้เป็นโปรแกรมที่สามารถทำงานบนฮาร์ดแวร์เป้าหมายได้ เนื่องจากมีสถาปัตยกรรมฮาร์ดแวร์และแพลตฟอร์มที่หลากหลาย จึงจำเป็นอย่างยิ่งที่จะต้องเลือกและกำหนดค่าทูลเชนให้เหมาะสมกับบอร์ดเป้าหมาย

<br/><br/>

## 4.2 การเลือกทูลเชนสำหรับบอร์ด

สำหรับบอร์ด TOPST-VCP ซึ่งใช้สถาปัตยกรรม ARM Cortex-R5 ทูลเชนที่แนะนำคือ gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi

ทูลเชนนี้ได้รับการปรับให้เหมาะกับสถาปัตยกรรม ARM และรับประกันความเข้ากันได้กับชิป TCC7045 บนบอร์ด

<br/><br/>

## 4.3 การติดตั้งและตั้งค่าทูลเชน

ทำตามขั้นตอนด้านล่างเพื่อดาวน์โหลด แตกไฟล์ และตั้งค่าทูลเชน:

1. **ดาวน์โหลดทูลเชน** : ใช้คำสั่ง wget เพื่อดาวน์โหลดทูลเชนจากเว็บไซต์ Linaro :

    ```
    $ wget https://releases.linaro.org/components/toolchain/binaries/7.2-2017.11/arm-eabi/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```

2. **แตกไฟล์ทูลเชน** : เมื่อดาวน์โหลดเสร็จสิ้น ให้แตกเนื้อหาของไฟล์ .tar.xz

    ```
    $ tar -xvf gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```

    <img src="https://github.com/topst-development/Documentation/assets/161264431/cd69488b-5f20-4b5e-95dd-6b1a9f37e38c">

3. **ย้ายทูลเชนไปยัง /opt** : ไดเรกทอรี /opt เป็นตำแหน่งมาตรฐานสำหรับซอฟต์แวร์เสริมบน Linux ให้ย้ายทูลเชนที่แตกไฟล์แล้วไปยังไดเรกทอรีนี้

    ```
    $ sudo mv gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi /opt/
    ```

## 4.4 การตรวจสอบการติดตั้งทูลเชน

เพื่อให้แน่ใจว่าทูลเชนได้รับการติดตั้งอย่างถูกต้อง:

1. **ไปยังไดเรกทอรีของทูลเชน** :

    ```
    $ cd /opt/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi
    ```

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/466c6ed7-4105-4cbd-9652-401bb18c7e56">
</p>
<p align="center"><strong>รูปที่ 4.4 ไปยังไดเรกทอรีของทูลเชน</strong></p>

2. **ตรวจสอบเวอร์ชันของคอมไพเลอร์ GCC ที่ติดตั้ง** :
    
    ```
    $ ./bin/arm-eabi-gcc --version
    ```

<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/9f00226a-2092-4a82-aa07-26ca33a5d347">
<p align="center"><strong>รูปที่ 4.5 ตรวจสอบเวอร์ชันของคอมไพเลอร์ GCC ที่ติดตั้ง</strong>

หากการติดตั้งสำเร็จ คุณจะเห็นข้อมูลเกี่ยวกับเวอร์ชันของ GCC ที่ติดตั้ง ซึ่งยืนยันว่าตรงกับเวอร์ชัน gcc-linaro-7.2.1-2017.11
