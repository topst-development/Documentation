# 3. การตั้งค่าสภาพแวดล้อม

การพัฒนาสำหรับบอร์ด TOPST-VCP ให้ประสบความสำเร็จนั้นจำเป็นต้องมีสภาพแวดล้อมการพัฒนาที่มีโครงสร้างที่ดี บทนี้จะแนะนำท่านตามขั้นตอนที่จำเป็นในการตั้งค่าระบบ Ubuntu 22.04 พร้อมด้วยเครื่องมือ ยูทิลิตี และแพ็กเกจซอฟต์แวร์ที่จำเป็นทั้งหมด

<br/><br/>

## 3.1 การติดตั้งเครื่องมือและยูทิลิตีที่จำเป็น

ก่อนที่จะลงลึกในรายละเอียดของบอร์ด TOPST-VCP สิ่งสำคัญอย่างยิ่งคือการติดตั้งยูทิลิตีและเครื่องมือพื้นฐานบางอย่างไว้ก่อน เครื่องมือเหล่านี้เป็นรากฐานสำหรับการติดตั้งซอฟต์แวร์และการกำหนดค่าอื่น ๆ ต่อไป

1. **เทอร์มินัล** : Ubuntu 22.04 มาพร้อมกับเทอร์มินัลในตัว โปรดทำความคุ้นเคยกับการใช้งาน เนื่องจากขั้นตอนต่อไปนี้จำนวนมากจะต้องใช้คำสั่งผ่านเทอร์มินัล
2. **โปรแกรมแก้ไขข้อความ**: แม้ว่า Ubuntu จะมาพร้อมกับโปรแกรมแก้ไขข้อความพื้นฐาน แต่ท่านอาจพิจารณาติดตั้งโปรแกรมแก้ไขที่มีความสามารถมากกว่า เช่น “nano”, “vim” หรือแบบกราฟิก เช่น “gedit” หรือ “VSCode” ตามความชอบของท่าน
3. **เครื่องมือ SSH** : การเข้าถึงระบบหรืออุปกรณ์อื่นจากระยะไกล โดยเฉพาะบอร์ด TOPST- VCP อาจมีความจำเป็นอย่างยิ่งในระหว่างการพัฒนา เครื่องมือ SSH หลากหลายชนิดสามารถช่วยได้ ดังนี้
4. **Putty** : โปรแกรมจำลองเทอร์มินัลแบบโอเพนซอร์สที่ใช้งานได้ฟรีและเป็นที่นิยม รองรับ SSH และโปรโตคอลอื่น ๆ มีขนาดเล็กและใช้งานง่าย
5. **Tera Term** : โปรแกรมจำลองเทอร์มินัลแบบโอเพนซอร์สที่มีคุณสมบัติหลากหลายกว่า และรองรับโปรโตคอลการสื่อสารต่าง ๆ รวมถึง SSH ได้อย่างครอบคลุม

ท่านสามารถเลือกใช้เครื่องมือเหล่านี้หนึ่งอย่างหรือมากกว่าสำหรับการเข้าถึงผ่าน SSH ได้ตามความต้องการและความชอบเฉพาะของท่าน  

**สำหรับการอ้างอิงของท่าน เอกสารคู่มือฉบับนี้ใช้ putty**

<br/><br/>

## 3.2 การติดตั้งซอฟต์แวร์โดยใช้ apt

ตัวจัดการแพ็กเกจ “apt” เป็นเครื่องมือที่ทรงประสิทธิภาพใน Ubuntu ซึ่งช่วยให้ท่านติดตั้ง อัปเดต และจัดการแพ็กเกจซอฟต์แวร์ได้อย่างง่ายดาย

<br/>

### 3.2.1 การอัปเดตรายการแพ็กเกจ

ก่อนติดตั้งซอฟต์แวร์ใหม่ใด ๆ ควรอัปเดตรายการแพ็กเกจที่มีอยู่เสียก่อน ซึ่งจะช่วยให้แน่ใจว่าท่านได้รับเวอร์ชันและแพ็กเกจที่ต้องพึ่งพาล่าสุด

```
$ sudo apt update
$ sudo apt upgrade
```

คำสั่งนี้จะดึงรายการแพ็กเกจที่มีอยู่ล่าสุดจากที่เก็บแพ็กเกจ

### 3.2.2 การติดตั้งเครื่องมือพัฒนาทั่วไป

สำหรับงานพัฒนาส่วนใหญ่ โดยเฉพาะอย่างยิ่งสำหรับบอร์ด TOPST-VCP เครื่องมือทั่วไปบางอย่างถือว่าจำเป็น

ติดตั้งเครื่องมือเหล่านี้โดยใช้คำสั่งต่อไปนี้ :

```
$ sudo apt install build-essential git
```

คำสั่งนี้จะติดตั้งทั้งแพ็กเกจ buide-essential และ git
