# 7. การดาวน์โหลดไปยังฮาร์ดแวร์ TOPST VCP

การถ่ายโอนซอฟต์แวร์ที่บิลด์แล้วไปยังบอร์ด TOPST-VCP เป็นขั้นตอนที่สำคัญอย่างยิ่งในกระบวนการพัฒนา บทนี้ให้คู่มือที่ครอบคลุมเกี่ยวกับวิธีการดาวน์โหลดซอฟต์แวร์ลงบนฮาร์ดแวร์ VCP โดยใช้สภาพแวดล้อมการพัฒนาที่ทำงานบน Linux

<br/><br/>

## 7.1 การเตรียมฮาร์ดแวร์

ก่อนเริ่มกระบวนการดาวน์โหลด โปรดตรวจสอบให้แน่ใจว่าบอร์ด TOPST-VCP อยู่ในตำแหน่งที่มั่นคงและปราศจากสิ่งรบกวนที่อาจเกิดขึ้น ตรวจสอบให้แน่ใจว่าสวิตช์และขั้วต่อทั้งหมดเข้าถึงได้ง่าย และสายไฟ 3.3v ต้องเชื่อมต่ออย่างถูกต้อง

<br/><br/>

## 7.2 การเชื่อมต่อฮาร์ดแวร์เข้ากับเครื่อง PC โฮสต์สำหรับการพัฒนา

1. **การเชื่อมต่อสาย USB C:** ใช้สาย USB C เพื่อเชื่อมต่อบอร์ด TOPST-VCP เข้ากับเครื่อง PC โฮสต์สำหรับการพัฒนา
2. **ตรวจสอบการเชื่อมต่อ**: บนเครื่อง Linux ให้รันคำสั่งต่อไปนี้

    ```
    $ sudo dmesg | grep tty
    ```

## 7.3 การถ่ายโอนซอฟต์แวร์ที่บิลด์แล้ว

1. **ตั้งค่าบอร์ดให้อยู่ในโหมดดาวน์โหลด :** บนบอร์ด TOPST-VCP ให้เลื่อนสวิตช์ FWDN ไปยังตำแหน่ง FWDN กดปุ่ม PORN เพื่อรีเซ็ต ขณะนี้บอร์ดอยู่ในโหมดดาวน์โหลด FWDN แล้ว

2. **รันคำสั่งดาวน์โหลด** : ใช้เครื่องมือ FWDN เพื่อดาวน์โหลดซอฟต์แวร์สำหรับแฟลช 4MB ลงบนบอร์ด

    ```
    $ sudo ../../../tools/fwdn_vcp/fwdn --fwdn ../../../tools/fwdn_vcp/vcp_fwdn.rom -w output\tcc70xx_pflash_boot_4M_ECC.rom
    ```

## 7.4 การตรวจสอบซอฟต์แวร์บนบอร์ด

เมื่อดาวน์โหลดซอฟต์แวร์ลงบอร์ดแล้ว การตรวจสอบว่าทำงานได้อย่างถูกต้องถือเป็นสิ่งสำคัญอย่างยิ่ง:

1. **ติดตั้ง minicom**  
    ```
    $ sudo apt install minicom
    ```

<p align="center"><strong>รูปที่ 7.5 การติดตั้ง Minicom</strong></p>

2.  **เปิดการเชื่อมต่อแบบอนุกรม** : ใช้คำสั่งต่อไปนี้เพื่อเริ่มการเชื่อมต่อแบบอนุกรม

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

## 7.5 การแก้ไขปัญหาที่พบบ่อย

แม้จะเตรียมการอย่างละเอียดรอบคอบแล้ว คุณอาจพบปัญหาระหว่างกระบวนการดาวน์โหลดเป็นครั้งคราว ต่อไปนี้คือวิธีแก้ไขปัญหาที่พบบ่อยบางประการ:

**ปัญหา:** เครื่องมือ fwdn รายงานว่าไม่มีสิทธิ์ในการเข้าถึงอุปกรณ์ ttyUSB0

**วิธีแก้ไข** : ปัญหานี้เกิดขึ้นเมื่อบัญชีผู้ใช้ของคุณไม่มีสิทธิ์ที่จำเป็นในการเข้าถึงอุปกรณ์แบบอนุกรม คุณสามารถให้สิทธิ์เหล่านี้แก่บัญชีผู้ใช้ของคุณได้โดยการเพิ่มบัญชีนั้นเข้าไปในกลุ่ม dialout

1. **แก้ไขสิทธิ์ของกลุ่มผู้ใช้** : รันคำสั่งต่อไปนี้

    ```
    $ sudo usermod -aG dialout $USER
    ```

    <img src="https://github.com/topst-development/Documentation/assets/161264431/a7552057-86de-4c49-876d-d50435bd16e4">

<p align="center"><strong>รูปที่ 7.8 การแก้ไขสิทธิ์ของกลุ่มผู้ใช้</strong></p>


2. **ออกจากระบบและเข้าสู่ระบบใหม่** : เพื่อให้การเปลี่ยนแปลงกลุ่มมีผล คุณจะต้องออกจากระบบเซสชันปัจจุบันแล้วเข้าสู่ระบบใหม่อีกครั้ง หลังจากนั้นให้ลองเข้าถึงอุปกรณ์ ttyUSB0 อีกครั้ง

โปรดจำไว้ว่าปัญหาส่วนใหญ่ที่คุณพบจะมีวิธีแก้ไขหรือวิธีหลีกเลี่ยง สิ่งสำคัญคือต้องทำความเข้าใจข้อความแสดงข้อผิดพลาด และปรึกษาเอกสารประกอบหรือชุมชนออนไลน์เมื่อมีข้อสงสัย

**ปัญหา** : เมื่อใช้ minicom การสื่อสารกับบอร์ด TOPST-VCP ไม่เป็นไปอย่างถูกต้องหรือมีพฤติกรรมผิดปกติ

**วิธีแก้ไข** :ปัญหานี้อาจเกิดขึ้นเนื่องจากการควบคุมการไหลของข้อมูลเริ่มต้นใน minicom ถูกตั้งค่าเป็นแบบฮาร์ดแวร์ เพื่อการสื่อสารที่ราบรื่นกับบอร์ด TOPST-VCP คุณต้องตั้งค่าการควบคุมการไหลของข้อมูลเป็น "none"


1. **เปิดใช้งาน minicom :**

    เริ่มใช้เครื่องมือ minicom โดยเพียงพิมพ์ :

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```
