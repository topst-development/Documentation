# 3. โหมดการบูต (SW2)


TOPST VCP มีพินหนึ่งพินสำหรับการกำหนดค่าการบูตโดยใช้ Boot Mode (BM) และรองรับ 2 โหมด:  
โหมดการบูตแบบ UART และโหมดปกติ

สวิตช์เลื่อน (SW2) ใช้สำหรับเลือกโหมดการบูตของ TOPST VCP

## 3.1 โหมดการบูตแบบ UART
โหมดนี้ใช้สำหรับโหมดดาวน์โหลดเฟิร์มแวร์ (**FWDN**) เป็นหลัก
ในโหมดนี้ คุณสามารถดาวน์โหลดโปรแกรมลงในพื้นที่ที่ผู้ใช้กำหนดได้โดยใช้พอร์ต UART


ตารางที่ 3.2 อธิบายการตั้งค่าสวิตช์เลื่อนสำหรับโหมดการบูตแบบ UART  

 **ตารางที่ 3.2 การกำหนดค่า UART สำหรับโหมดการบูต:**
