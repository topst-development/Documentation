# 5. ขั้วต่อ (JC1) สำหรับการดีบักและ FWDN  


บน TOPST VCP นั้น JC1 ใช้สำหรับการดีบักหรือ FWDN ผ่าน UART  
ขั้วต่อนี้เป็น USB Type-C แบบมาตรฐาน  

รูปที่ 5.1 แสดงตำแหน่งของ JC1  
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/8b19656c-59d5-4389-87f3-4939bf501587"></p>  
<p align="center"><strong>รูปที่ 5.1 ขั้วต่อ USB Type-C</strong></p>  

คุณสามารถทำ FWDN หรือตรวจสอบข้อความดีบักของ TCC7045 ผ่าน JC1 ได้  
บน TOPST VCP มีการออกแบบตัวควบคุมบริดจ์ USB to UART สำหรับ JC1 และคุณสามารถเชื่อมต่อ JC1 เข้ากับ PC ได้โดยตรงด้วยสาย USB Type-C
