# 2. คู่มือการบิลด์

<br/><br/>

## 2.1 TOPST AI SDK

TOPST AI SDK พัฒนาขึ้นบนพื้นฐานของ Yocto Project 4.0 kirkstone
ดังนั้น จึงต้องตั้งค่าสภาพแวดล้อม Yocto Project บนเครื่อง PC โฮสต์เพื่อใช้งาน TOPST AI SDK
หากต้องการดาวน์โหลด SDK, source-mirror และ tools ท่านต้องติดตั้งยูทิลิตีก่อน

ท่านสามารถดาวน์โหลดซอร์สจาก upstream ตามข้อมูลเมทาดาทา และดำเนินการบิลด์ได้
เมื่อการบิลด์เสร็จสิ้น จะได้รับแพ็กเกจ อิมเมจ และ SDK เป็นผลลัพธ์
รูปที่ 2.1 แสดงกระบวนการทำงานของ Yocto Project

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/Build%20guide.image1.png" width="600"</p>
<p align="center"><strong>รูปที่ 2.1 กระบวนการทำงานของ Yocto Project</strong></p>
