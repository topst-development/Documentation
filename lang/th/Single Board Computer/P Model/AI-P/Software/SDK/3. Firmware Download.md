# 3. การดาวน์โหลดเฟิร์มแวร์

บทนี้อธิบายวิธีการดาวน์โหลด FWDN ไปยัง TOPST AI (บอร์ดแพลตฟอร์มแบบเปิด)
และวิธีการเข้าสู่ระบบคอนโซล Linux

<br/><br/>

## 3.1 ลำดับการดาวน์โหลดเฟิร์มแวร์

ลำดับการดาวน์โหลดของ FWDN มีดังนี้

1.  ตั้งค่าสวิตช์โหมดบูตเป็นโหมดบูต fwdn
2.  เปิด Windows prompt แล้วทดสอบ FWDN ND
3.  เชื่อมต่อ FWDN ND เข้ากับบอร์ด
4.  ดาวน์โหลดไฟล์ fai

<br/><br/>

## 3.2 การเชื่อมต่อ TOPST AI กับเครื่อง PC โฮสต์ด้วยการบูต Fwdn

คุณสามารถถ่ายโอนอิมเมจที่บิลด์แล้วไปยัง TCC750x โดยใช้ FWDN
TCC750x ให้บริการฟังก์ชัน FWDN โดยใช้อีเทอร์เน็ตและ UART

### 3.3.3 การเปลี่ยนโหมดบูต

หากคุณกดสวิตช์โหมดบูตแล้วจ่ายไฟ กระบวนการบูต FWDN จะ
เริ่มต้นขึ้น หากคุณจ่ายไฟโดยไม่กดสวิตช์โหมดบูต กระบวนการบูต
แบบปกติจะเริ่มต้นขึ้น
การกดสวิตช์รีเซ็ตจะทำให้ระบบรีเซ็ต หากคุณต้องการ
ดาวน์โหลดเฟิร์มแวร์ ให้กดสวิตช์โหมดบูตและสวิตช์รีเซ็ตพร้อมกัน
เพื่อเข้าสู่โหมดบูต FWDN

### 3.3.4 FWDN บน Windows

1.  หลังจากบิลด์อิมเมจแล้ว ให้คัดลอกโฟลเดอร์ fwdn ที่สร้างขึ้นไปยังเดสก์ท็อป และ
    บันทึกไฟล์ด้านล่างไว้ภายในโฟลเดอร์นั้น
    ในการใช้ FWDN คุณสามารถดาวน์โหลดเครื่องมือเฟิร์มแวร์ได้จากลิงก์ด้านล่าง

    - <[FWDN Tool](https://topst-downloads.s3.ap-northeast-2.amazonaws.com/Yocto/pre/topst.ai.pre.20240425001.windows.zip)>
  
    คัดลอกอิมเมจ SD_Data.fai ไปยัง topst.ai.pre.20240425001.windows
    SD_Data.fai อยู่ที่ **"{build_dir}/build/tcc7500-main/tmp/deploy/fwdn/"**


2.  รัน **fwdn_batch.bat** และป้อน**หมายเลขพอร์ต**
