# 1. การตั้งค่าสภาพแวดล้อม 

<br/><br/>


## 1.1 การติดตั้ง Ubuntu

เนื่องจาก TOPST AI Linux SDK พัฒนาขึ้นบนพื้นฐานของ Yocto Project เวอร์ชัน Linux ของ TOPST AI SDK จึงเป็นไปตามโครงการ Yocto

คุณสามารถติดตั้ง Linux เวอร์ชันอื่นได้ แต่ในเอกสารนี้จะอธิบาย TOPST AI Linux SDK โดยอ้างอิงจาก Ubuntu 22.04

เวอร์ชันของ Linux distribution:

- Ubuntu 22.04 (LTS)

<br/><br/>

## 1.2 การติดตั้ง WSL2 Ubuntu 

1. เรียกใช้ Windows PowerShell ด้วย "Run with administrator privileges"
2. เปิดใช้งานระบบ WSL2
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. เปิดใช้งานคุณสมบัติ Virtual Machine
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. ตั้งค่า WSL 2 เป็นเวอร์ชันเริ่มต้น
    ```
    wsl --set-default-version 2
    ```
5. ค้นหา Ubuntu 22.04.3 LTS ใน Microsoft Store แล้วดาวน์โหลด

    * หากคุณต้องการดาวน์โหลดแพ็กเกจอัปเดตเคอร์เนล Linux ให้ดาวน์โหลดแพ็กเกจล่าสุด[ที่นี่](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)

## 1.3 การตั้งค่าสภาพแวดล้อม Linux

<br/>

### 1.3.1 การติดตั้ง SSH และ Samba 

การทำงานในสภาพแวดล้อม Linux นั้นช้า แต่คุณสามารถใช้ SSH และ Samba เพื่อ
ทำงานในสภาพแวดล้อมที่สะดวกยิ่งขึ้นได้ SSH และ

Samba ช่วยให้คุณเรียกใช้คำสั่งบนคอมพิวเตอร์ระยะไกลและคัดลอกไฟล์
ไปยังคอมพิวเตอร์เครื่องอื่นได้

หากติดตั้ง SSH และ Samba ไว้แล้ว หรือคุณจะไม่ใช้งาน คุณสามารถ
ข้ามบทนี้ได้

```
 $ sudo apt-get install -y net-tools openssh-server samba 
```

หลังจากดาวน์โหลด SSH และ Samba แล้ว คุณควรตั้งค่าแต่ละโปรแกรมให้เหมาะกับ
สภาพแวดล้อมของคุณ

<br/>

### 1.3.2 การติดตั้งยูทิลิตีสำหรับ Yocto Project 

ติดตั้งยูทิลิตีทั้งหมดในคราวเดียว หากต้องการใช้ Yocto Project จะต้องติดตั้งยูทิลิตีต่อไปนี้
บน Host PC (คอมพิวเตอร์ส่วนบุคคลหรือ

เซิร์ฟเวอร์สำหรับการพัฒนา)

```
$ sudo apt-get install -y gawk wget git-core diffstat unzip texinfo gcc-multilib
$ sudo apt-get install -y build-essential chrpath socat cpio python3 python3-pip python3-pexpect
$ sudo apt-get install -y xz-utils debianutils iputils-ping python3-git python3-jinja2 libegl1-mesa libsdl1.2-dev pylint xterm

```

### 1.3.3 การติดตั้ง Repo

คุณสามารถดาวน์โหลด TOPST AI SDK ผ่าน Repo ได้

หากต้องการติดตั้ง repo โปรดดูที่เว็บไซต์ต่อไปนี้:
<https://source.android.com/source/downloading.html>

หากติดตั้ง repo ไว้แล้ว คุณสามารถใช้งานได้โดยไม่ต้องติดตั้งใหม่

ก่อนติดตั้ง repo จะต้องตั้งค่าเวอร์ชัน Python ที่ติดตั้งไว้ (3.6 ขึ้นไป) ให้ถูกต้อง

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
$ sudo apt-get install repo
```

<br/>

หากเกิดข้อผิดพลาดของ repo ให้ดาวน์โหลดเวอร์ชันล่าสุดและวางลงในโฟลเดอร์ /usr/bin/ โดยตรง

```
$ mkdir -p ~/bin
$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo &gt;~/bin/repo
$ chmod a+x ~/bin/repo
$ sudo mv ~/bin/repo /usr/bin/repo
```
