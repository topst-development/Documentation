# 3. ตัวอย่าง SPI

Serial Peripheral Interface (SPI) เป็นวิธีการสื่อสารแบบอนุกรม (serial
communication) เช่นเดียวกับ I2C, CAN และ UART เป็นฟังก์ชันสำหรับ
การถ่ายโอนข้อมูลระหว่างอุปกรณ์ต่อพ่วงขนาดเล็ก เช่น ไมโครคอนโทรลเลอร์
ชิฟต์รีจิสเตอร์ และการ์ด SD กล่าวอย่างง่ายคือ เป็นหนึ่งในวิธีการสื่อสาร
เพื่อแลกเปลี่ยนข้อมูลระหว่างอุปกรณ์กับอุปกรณ์ นั่นคือระหว่างชิป (IC)
กับชิป การสื่อสารแบบ SPI เป็นวิธีการสื่อสารแบบซิงโครนัส
ที่รองรับการสื่อสารแบบหนึ่งต่อหลาย ซึ่งมีข้อเสียคือต้องใช้สายสัญญาณ
หลายเส้นสำหรับการสื่อสารหลายช่องทาง และสามารถส่งและรับได้พร้อมกัน
การเดินสายทำได้ง่าย จึงมักถูกนำไปใช้ในการสื่อสารระหว่างชิป
เช่น เซ็นเซอร์อย่างง่ายและหน่วยความจำ
