# 1. ตัวอย่าง GPIO

GPIO(general-purpose input/output) คือพินสัญญาณดิจิทัลบนวงจรรวม
หรือแผ่นวงจรไฟฟ้า ซึ่งอนุญาตให้ผู้ใช้ควบคุมการทำงาน
รวมถึงอินพุตหรือเอาต์พุต ได้ในขณะ
รันไทม์
GPIO ไม่ได้ถูกกำหนดไว้ล่วงหน้าสำหรับวัตถุประสงค์เฉพาะ และไม่ได้ถูกใช้งาน
โดยค่าเริ่มต้น
GPIO ถูกนำไปใช้งานโดยผู้ออกแบบเครือข่ายวงจรระดับประกอบ
(ผู้ออกแบบแผ่นวงจรสำหรับ GPIO ของวงจรรวม และผู้รวมระบบ
สำหรับ GPIO ระดับซับสเตรต, S/I) ซึ่งวัตถุประสงค์และพฤติกรรมจะถูกกำหนด
เมื่อมีการใช้งาน

ฟังก์ชันที่ GPIO ทำงานอาจแตกต่างกันไปตามระบบ และฟังก์ชันที่มีให้โดยทั่วไปมีดังต่อไปนี้

- ฟังก์ชันอินพุต/เอาต์พุต (high=1, low=0)
- การตรวจจับสัญญาณ IRQ: สามารถใช้เพื่อปลุกระบบที่อยู่ในสถานะ suspend
  ในโหมด Power management ได้ด้วย
  - สามารถเข้าถึงได้แม้ในขณะที่ Spinlock ถูกล็อกอยู่

ฟังก์ชันข้างต้นช่วยให้คุณสามารถใช้การป้องกันการเขียน ควบคุม
  LED เปิดใช้งานการตั้งค่าทรานซีฟเวอร์ ฟังก์ชันฮาร์ดแวร์วอตช์ด็อก หรือ
  การตรวจจับสวิตช์ได้

ต่อไปนี้เป็นตัวอย่างการทดสอบอินพุตและเอาต์พุตของ
  บอร์ด คุณสามารถทดสอบอินพุตและเอาต์พุตได้โดยการควบคุมหมายเลขพิน
  โดยอ้างอิงจากผังพินของ Raspberry Pi

<br/>

**ตัวอย่าง**

```
$ echo "90" > /sys/class/gpio/export
$ echo "out" > /sys/class/gpio/gpio90/direction
$ echo 1 > /sys/class/gpio/gpio90/value
$ echo 0 > /sys/class/gpio/gpio90/value
```
