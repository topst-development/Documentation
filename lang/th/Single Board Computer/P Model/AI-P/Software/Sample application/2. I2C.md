# 2. ตัวอย่าง I2C

inter-integrated circuit (I2C) มักอ่านว่า "i-to-c" แต่การออกเสียงอย่างเป็นทางการคือ "i-square-c"

การสื่อสารแบบ I2C ประกอบด้วยสาย SDA หนึ่งเส้นสำหรับรับส่งข้อมูล และ
สายสัญญาณนาฬิกา SCL หนึ่งเส้นสำหรับซิงโครไนซ์จังหวะเวลาในการรับส่ง
ข้อมูล ประกอบด้วยมาสเตอร์หนึ่งตัวและสเลฟหนึ่งตัวหรือมากกว่า และ
สามารถเชื่อมต่อสเลฟได้สูงสุด 127 ตัว

- การสื่อสารแบบ I2C เป็นวิธีการสื่อสารที่ใช้สายสองเส้น
- ข้อดีและข้อเสียของการเชื่อมต่ออุปกรณ์สเลฟหลายตัวเข้ากับมาสเตอร์ตัวเดียว
  - ข้อดีคือไม่มีข้อจำกัดด้านจังหวะเวลา เนื่องจากเป็นวิธีการสื่อสารแบบซิงโครนัสที่ใช้สัญญาณนาฬิกา
  - ข้อเสียคือไม่เหมาะกับข้อมูลที่ยาว เนื่องจากต้องแนบข้อมูลแอดเดรสสำหรับเลือกสเลฟทุกครั้ง

2.  แผนภาพด้านล่างแสดงวิธีการต่อสายบนเบรดบอร์ดเพื่อให้ทำงานร่วมกับ
    i2c_example_app ได้

    - โมดูลเซ็นเซอร์ที่ใช้คือ PCF8591 โดย PCF8591 เป็นโมดูลแปลงอนาล็อกเป็นดิจิทัลขนาด 8 bit หรือดิจิทัลเป็นอนาล็อกขนาด 8 bit ซึ่งหมายความว่าแต่ละพินสามารถอ่านค่าอนาล็อกได้สูงสุดถึง 256

3.  เมื่อคุณรัน i2c_example_app โปรแกรมจะรับค่าความสว่าง

    ```
     root@telechips-tcc7500-main:~# ./i2c_example_app
     Target is 144.
    ```

4.  หากคุณใช้มือปิดโมดูลแล้วรัน ค่าจะเพิ่มขึ้น

    ```
    root@telechips-tcc7500-main:~# ./i2c_example_app
    Target is 228.
    ```
