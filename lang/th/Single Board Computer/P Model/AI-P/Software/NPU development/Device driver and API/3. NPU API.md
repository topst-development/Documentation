# 3. NPU API

Linux API มีไว้เพื่อวัตถุประสงค์ในการควบคุม NPU โดยใช้
ฟังก์ชัน C ระดับสูง และลำดับขั้นตอนการใช้งาน NPU ผ่าน Linux
API มีดังต่อไปนี้
