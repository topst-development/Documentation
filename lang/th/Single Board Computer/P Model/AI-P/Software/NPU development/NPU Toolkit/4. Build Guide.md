## 4.1 ตัวแปลง

ตัวแปลงจะอ่านไฟล์โครงข่ายประสาทเทียมและแปลงเป็นไฟล์ ”bin”
ซึ่งเป็นรูปแบบไฟล์เครือข่ายที่ใช้ใน TOPST AI NPU SW Toolkit
นอกจากนี้ยังทำการอนุมานเครือข่ายและรวบรวมสถิติของข้อมูล
แอกทิเวชัน ซึ่งจะถูกนำไปใช้ในการควอนไทซ์เครือข่ายในภายหลัง

<br/>

<strong>1.  Darknet</strong>

```
$ python ./EnlightSDK/converter.py \
  ./input_networks/yolov4.cfg \
  --weight ./input_networks/yolov4.weights \
  --type obj \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/yolov4.enlight \
  --enable-track \
  --mean 0 0 0 \
  --std 1 1 1 \
  --num-class 90
```

## 4.2 ตัวควอนไทซ์

ตัวควอนไทซ์จะแปลงโมเดลเครือข่ายต้นฉบับที่ใช้การคำนวณแบบทศนิยม
ให้เป็นเครือข่ายที่ใช้จำนวนเต็ม (ผ่านการควอนไทซ์)

<br/>

**1.  Darknet**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/yolov4.enlight \
  --output ./output_networks/yolov4_quantized.enlight
```

<br/>

**2.  TensorFlow Lite**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1.enlight \
  --output ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight
```

<br/>

**3.  ONNX**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/mb2-ssd-lite.enlight \
  --output ./output_networks/mb2-ssd-lite_quantized.enlight
```

## 4.3 คอมไพเลอร์

คอมไพเลอร์จะคอมไพล์โครงข่ายประสาทเทียมที่ผ่านการควอนไทซ์ให้เป็นโค้ด NPU และ
พารามิเตอร์เครือข่ายสำหรับการประมวลผลโครงข่ายประสาทเทียมบน TOPST NPU HW

<br/>

**1.  Darknet**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/yolov4_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

**2.  TensorFlow Lite**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

**3.  ONNX**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/mb2-ssd-lite_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

ไฟล์ที่สร้างขึ้นจะถูกจัดเก็บไว้ในไดเรกทอรี
“output_code/\<network_name\>”

ไฟล์เอาต์พุตของคอมไพเลอร์:

- npu_cmd.bin: โค้ดการอนุมาน TELECHIPS NPU
- quantized_network.bin: พารามิเตอร์น้ำหนักและไบแอสของเครือข่าย
- network.h: ขนาดบัฟเฟอร์และพารามิเตอร์เครือข่ายสำหรับการประมวลผลภายหลัง
- post_process.c: โค้ดการประมวลผลภายหลัง
- ไฟล์อื่น ๆ: ข้อมูลการดีบัก (สำหรับภายในเท่านั้น)

ในแอปพลิเคชันโครงข่ายประสาทเทียม “npu_cmd.bin” และ “quantized_network.bin”
จะถูกโหลดเข้าสู่บัฟเฟอร์ DMA โดยใช้ TELECHIPS NPU API และไดรเวอร์อุปกรณ์
ของ Linux ส่วน “network.h” และ “post_process.c” จะถูกบิลด์เป็นไฟล์อ็อบเจกต์
เครือข่าย (.so) ตามที่แสดงใน Network Object Build
