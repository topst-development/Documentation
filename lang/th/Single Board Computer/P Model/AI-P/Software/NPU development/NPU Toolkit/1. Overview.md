# 1. TOPST AI NPU Tool Kit

NPU ของ TOPST AI เป็นตัวเร่งความเร็วโครงข่ายประสาทเทียมแบบฮาร์ดแวร์ ซึ่งได้รับ
การปรับให้เหมาะสมสำหรับการอนุมานของโครงข่ายประสาทเทียมในงานด้านวิชัน เช่น
การตรวจจับวัตถุ การจำแนกภาพ และการตรวจจับใบหน้า

เอกสาร “TOPST-AI-Common-SW-NPU-Toolkit Guide” อธิบายวิธี
การใช้งาน NPU Toolkit
