# 2. ชุดเครื่องมือตรวจสอบประสิทธิภาพแบบเรียลไทม์

ข้อมูลประสิทธิภาพของภาพ NPU CPU และ MEM ที่ได้จาก TOPST AI Board สามารถ
ส่งไปยัง PC ผ่าน Vision Protocol และสามารถดูผลลัพธ์ได้
ในชุดเครื่องมือ RTPM บน PC

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image1.png?raw=true"></p>

<p align="center"><strong>รูปที่ 2.1 การเชื่อมต่อระหว่างเครื่อง PC โฮสต์ กับ TOPST AI Board</strong></p>

- **ดาวน์โหลด RTPM** : <[RTPM](https://drive.google.com/file/d/1x3gaMhw53YloNul8m75R5fCPqzNl0RI9/view?usp=sharing)>
- การดาวน์โหลดถูกบล็อก โปรดติดต่อชุมชน

<br/><br/>

## 2.1 การตรวจสอบประสิทธิภาพ

Real-Time Performance Toolkit (RTPM) เป็นเครื่องมือแบบ GUI ที่พัฒนาด้วย
Python ซึ่งตรวจสอบเอาต์พุตของ TOPST AI ในสภาพแวดล้อม PC
และช่วยให้ตรวจสอบข้อมูลประสิทธิภาพของ CPU, NPU และ Memory ได้

<br/>

**ตารางที่ 2.1 รายการข้อมูลประสิทธิภาพของ RTPM:**

| ลำดับ  |  ข้อมูลประสิทธิภาพ   |               คำอธิบาย                 |
|--------|----------------------|----------------------------------------|
| 1      | เวลาการอนุมาน        | เวลาการอนุมานของแต่ละโมเดล (ms)        |
| 2      | NPU                  | อัตราการใช้งาน NPU ของแต่ละโมเดล       |
| 3      | FPS                  | ข้อมูล FPS ตามการทำงานของ NPU          |
| 4      | CPU                  | อัตราการใช้งาน CPU (รอบ 500ms)         |
| 5      | Memory               | อัตราการใช้งาน Memory (รอบ 500ms)      |

## 2.2 โหมด Injection

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image3.png?raw=true"></p>

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image4.png?raw=true"></p>

### 2.4.3 รันโหมด Projection

1.  เลือก Camera (EVB) สำหรับ input mode

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image19.png?raw=true"></p>
