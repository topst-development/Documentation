# 1. แอปพลิเคชันตัวอย่าง

บทนี้เป็นเอกสารแนะนำสำหรับแอปพลิเคชันตัวอย่างของ NPU

TOPST AI SDK มีแอปพลิเคชันตัวอย่างสำหรับตรวจสอบการทำงานของ NPU
ชื่อว่า ‘tc-nn-app’

แอปพลิเคชันตัวอย่าง NPU นี้ใช้กล้อง ไฟล์ภาพ และ PC Stream เป็น
อินพุต เพื่อส่งผลลัพธ์การประมวลผลภาพของ NPU ออกไปยัง LCD ไฟล์ และ PC
Stream

<br/><br/>
