# 2. คู่มือการบูต

บทนี้อธิบายวิธีการบูต TOPST AI และการเข้าสู่ระบบ
สำหรับแต่ละคอร์

<br/><br/>

## 2.1 ลำดับการบูต

ลำดับการบูตมีดังนี้

1.  เชื่อมต่อแผงหน้าจออินเทอร์เฟซ MIPI
2.  เชื่อมต่อโมดูลกล้องอินเทอร์เฟซ MIPI
3.  เชื่อมต่อสาย USB C to A เข้ากับพอร์ตดีบัก
4.  เชื่อมต่อแหล่งจ่ายไฟ 5V

## 2.2 การเชื่อมต่อ TOPST AI ด้วย UART

ในการดีบักผ่าน USB และพัฒนาบนสภาพแวดล้อม Linux คุณสามารถเข้าถึงคอร์ (CA53) ได้โดยใช้พอร์ตดีบัก TOPST AI บนบอร์ดตามที่แสดงด้านล่าง
ติดตั้งไดรเวอร์ UART Bridge VCP (ดาวน์โหลดได้ที่
https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads)
บนเครื่อง PC โฮสต์
จากนั้น เมื่อคุณเชื่อมต่อ UART เข้ากับบอร์ดดีบัก TOPST ไดรเวอร์ CP210x USB to UART จะถูกตั้งค่าดังต่อไปนี้

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20Boot.image2.png?raw=true"
style="width:4.11111in;height:4.02083in"</p>
<p align="center"><strong>รูปที่ 2.2 การเชื่อมต่อ USB ในสภาพแวดล้อม Windows</strong></p>

เชื่อมต่อพอร์ต UART โดยใช้เทอร์มินัลอีมูเลเตอร์บนเครื่อง PC โฮสต์
ภาพด้านล่างคือหน้าจอบันทึกที่ได้จากการบูตโดยเชื่อมต่อกับคอร์

<br/>

**ตัวอย่าง**

- เทอร์มินัลอีมูเลเตอร์: PuTTY หรือ mobaXterm
- ความเร็ว: 115200 bps
- บิตข้อมูล: 8
- พาริตี: None
- สต็อปบิต: 1
- การควบคุมการไหลของข้อมูล: None
