# 1. คู่มือ FWDN

บทนี้อธิบายวิธีการดาวน์โหลด Firmware Downloader (FWDN) ไปยัง
TOPST AI

TOPST AI ให้บริการฟังก์ชัน FWDN โดยใช้อีเทอร์เน็ตและ UART ในโหมด FWDN
นั้น BL0 (Chipboot ROM) จะโหลดเฟิร์มแวร์ระดับถัดไป (BL1) จากโฮสต์
โดยใช้ UART (BL1 จะเริ่มต้นระบบ) จากนั้นเริ่มต้น DRAM และโหลด FWDN F/W
ซึ่งรองรับอีเทอร์เน็ตของ FWDN ไปยัง DRAM โดยใช้ UART อีกครั้ง FWDN F/W จะเชื่อมต่อกับโฮสต์
ด้วย TCP/IP หรือ UDP และดำเนินการฟังก์ชัน FWDN (เช่น การเขียนข้อมูลลง
สตอเรจ การอ่านข้อมูลจากสตอเรจ เป็นต้น)

## 1.1 ลำดับการดาวน์โหลดเฟิร์มแวร์

ลำดับการดาวน์โหลดของ FWDN มีดังนี้

1.  เข้าสู่โหมด FWDN (ดูที่ TOPST-AI/Hardware/Overview/4.Firmware Download)
2.  เชื่อมต่อสาย USB C-to-A เข้ากับพอร์ต FWDN แบบ USB C-type
3.  เชื่อมต่อสายอีเทอร์เน็ตเข้ากับพอร์ตอีเทอร์เน็ต
4.  ดาวน์โหลดอิมเมจ TOPST AI

<br/><br/>

## 1.2 การเข้าสู่โหมด FWDN 

กด FWDN KEY (FWDN Mode Convert) แล้วต่อแหล่งจ่ายไฟเพื่อเข้าสู่
โหมด FWDN หรืออีกวิธีหนึ่ง หากต่อแหล่งจ่ายไฟอยู่แล้ว ให้กด FWDN KEY
(FWDN Mode Convert) แล้วกด RESET KEY (System Reset) เพื่อเข้าสู่
โหมด FWDN

## 1.3 การตั้งค่าอีเทอร์เน็ตและ UART

  - แผงควบคุม 🡪 เครือข่ายและอินเทอร์เน็ต 🡪 การเชื่อมต่อเครือข่าย 🡪 ตั้งค่าคุณสมบัติอุปกรณ์อีเทอร์เน็ตสำหรับ FWDN
