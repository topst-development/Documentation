# 4. การดาวน์โหลดเฟิร์มแวร์

<br/>

## 4.1 การเชื่อมต่อ TOPST AI เข้ากับคอมพิวเตอร์เพื่อดาวน์โหลดเฟิร์มแวร์

Firmware Downloader (**FWDN**) จะเขียนอิมเมจ ROM ลงใน TOPST AI ผ่าน
การสื่อสาร UART บนคอมพิวเตอร์

TOPST AI มีปุ่ม Boot Mode หนึ่งปุ่ม และรองรับโหมดการบูตสอง
ประเภทผ่านปุ่ม Boot Mode ดังนี้:

- UART Boot Mode ใช้สำหรับเขียนอิมเมจ ROM โดยใช้โปรแกรม **FWDN**
  บนคอมพิวเตอร์ของคุณ

- eMMC Boot Mode ใช้สำหรับบูต TOPST AI ด้วยอิมเมจ ROM ที่
  จัดเก็บอยู่ในอุปกรณ์ eMMC

**หมายเหตุ**: พอร์ต USB Type-C ใช้สำหรับ firmware downloader (**FWDN**)

หากต้องการใช้ **FWDN** ให้เชื่อมต่อ TOPST AI เข้ากับคอมพิวเตอร์ดังนี้:

1.  เตรียมสาย USB Type-C หนึ่งเส้น และสาย Ethernet
2.  เชื่อมต่อ USB Type-C Receptacle บน TOPST AI เข้ากับคอมพิวเตอร์ของคุณ
    โดยใช้สาย USB Type-C
3.  เชื่อมต่อขั้วต่อ Ethernet (RJ45) บน TOPST AI เข้ากับคอมพิวเตอร์ของคุณ
    โดยใช้สาย Ethernet
4.  ใช้วิธีใดวิธีหนึ่งจากสองวิธีด้านล่างเพื่อเปลี่ยนโหมดการบูตของ
    TOPST AI
     1. วิธีที่ 1
         * หาก TOPST AI ยังไม่ได้รับไฟเลี้ยง ให้กดปุ่ม FWDN ค้างไว้แล้วต่อไฟ 5V เข้ากับ TOPST AI
         * ปล่อยปุ่ม FWDN Boot mode

     2. วิธีที่ 2
         * หาก TOPST AI ได้รับไฟเลี้ยงอยู่แล้ว ให้กดปุ่ม System Reset และปุ่ม FWDN Boot mode
         * ปล่อยปุ่ม FWDN Boot mode

5.  ดาวน์โหลดอิมเมจ ROM ของคุณตามเอกสาร **FWDN**

รูปที่ 4.1 แสดงตำแหน่งของปุ่ม Reset ปุ่ม FWDN พอร์ต Ethernet
และพอร์ต USB Type-C บน TOPST AI
