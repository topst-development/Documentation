# TOPST AI
<br/>

TOPST AI คือคอมพิวเตอร์บอร์ดเดียวที่มาพร้อม NPU สำหรับการประมวลผลด้านวิชัน
<br/>

หากต้องการไปยังหน้าเอกสารหลัก โปรดดูตารางด้านล่าง
<br/>
<br/>

<br/>

[ภาพรวมฮาร์ดแวร์](https://topst.ai/tech/docs?TOPST-AI&Hardware&Overview&1.%20Specification) : ข้อมูลจำเพาะของฮาร์ดแวร์ ข้อมูลอุปกรณ์ต่อพ่วง ฯลฯ

[อิมเมจอย่างเป็นทางการของ TOPST AI](https://flab-dev.net/tech/docs?TOPST-AI&Software) : หากคุณต้องการเมาต์อิมเมจที่บิลด์ไว้ล่วงหน้าอย่างรวดเร็ว คุณสามารถดาวน์โหลดได้ที่นี่

[คู่มือการบิลด์ Linux SDK](https://topst.ai/tech/docs?TOPST-AI&Software&SDK&1.%20Enviroment%20Setting) : หากต้องการบิลด์ SDK ด้วยตนเอง โปรดดูหน้านี้
