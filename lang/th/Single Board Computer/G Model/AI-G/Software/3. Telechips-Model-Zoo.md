# 1. บทนำ
---
เอกสารฉบับนี้นำเสนอชุดโมเดลโครงข่ายประสาทเทียมที่ปรับให้เหมาะสมสำหรับ AI-G ที่เก็บโค้ดซึ่งแนะนำไว้ในบทที่ 2.1 ประกอบด้วยโมเดลหลากหลายสำหรับงานต่าง ๆ เช่น การจำแนกประเภทและการตรวจจับวัตถุ ที่เก็บโค้ดนี้จัดเตรียมไว้ในรูปแบบที่พร้อมรันบนบอร์ดประเมินผล และมีผลการทดสอบเปรียบเทียบสมรรถนะที่แสดงถึงประสิทธิภาพและความคุ้มค่าของ AI-G
<br/><br/><br/>

# 2. การเริ่มต้นใช้งาน
---
ปฏิบัติตามขั้นตอนต่อไปนี้เพื่อรันโมเดลโครงข่ายประสาทเทียมที่ Telechips Model Zoo จัดเตรียมไว้บนบอร์ด AI-G
<br/><br/><br/>

## 2.1 การโคลน Repository
---
```
$ git clone https://github.com/telechips-ai/TCC750x-Model-Zoo.git

$ cd TCC750x-Model-Zoo
```
<br/><br/><br/>

## 2.2 การคัดลอกโมเดลที่ต้องการไปยัง AI-G
---
คัดลอกโฟลเดอร์โมเดล (yolov5m) ทั้งหมดไปยัง AI-G
คุณสามารถคัดลอกโฟลเดอร์ตามเดิม หรือเปลี่ยนชื่อเป็น yolov5m_quantized เพื่อให้ตรงกับรูปแบบที่ใช้ในโฟลเดอร์โครงข่ายประสาทเทียมที่เผยแพร่ก่อนหน้านี้ ดังตัวอย่างต่อไปนี้
แต่ละโฟลเดอร์ประกอบด้วยไฟล์เอาต์พุตที่จำเป็น (.so, .bin เป็นต้น)

```
$ scp -r [network_output_folder] root@192.168.0.100:/path/to/target/
```
แทนที่ **network_output_folder** ด้วยโฟลเดอร์จริง (เช่น yolov5m/)

คุณสามารถเลือกโมเดล yolov5 ได้
```
$ cd Object_Detection/YOLO/yolov5/
$ ls 
README.md  yolov5l  yolov5m  yolov5n  yolov5s  yolov5x
```
จากนั้นรัน:
```
$ scp -r yolov5m/ root@192.168.0.100:/home/root/
```
<br/><br/><br/>

## 2.3 การรันโมเดลด้วย tcnputestapp หรือ tcnnapp:
---
จากนั้นรันคำสั่งต่อไปนี้บนบอร์ดเป้าหมาย (AI-G):
```
$ tcnputestapp -d 0 1 -n [network_output_folder_path]
```
หรือ 
```
$ tcnnapp -n [network_output_folder_path]
```
