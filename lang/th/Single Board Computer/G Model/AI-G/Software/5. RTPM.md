# 1. บทนำ
---
ชุดเครื่องมือ Real-Time Performance Monitor (RTPM) เป็นแอปพลิเคชันแบบกราฟิกที่พัฒนาด้วย Python ออกแบบมาเพื่อเฝ้าติดตามและแสดงผลตัววัดประสิทธิภาพของ AI-G แบบเรียลไทม์ โดยการเชื่อมต่อระหว่างบอร์ด AI-G กับเครื่อง PC โฮสต์ RTPM จะช่วยให้สามารถส่งและวิเคราะห์ข้อมูลประสิทธิภาพที่สำคัญ ซึ่งรวมถึงอัตราการใช้งาน CPU, NPU, หน่วยความจำ และเวลาในการอนุมาน
 
RTPM ทำงานได้ในสองโหมดที่แตกต่างกัน:
 
**Injection Mode**: ในโหมดนี้ เครื่อง PC โฮสต์จะส่งข้อมูลภาพไปยัง AI-G เพื่อประมวลผล AI-G จะทำการอนุมานโดยใช้ NPU ของตนเอง แล้วส่งผลลัพธ์กลับไปยัง PC เพื่อแสดงผล
 
**Projection Mode**: ในโหมดนี้ AI-G จะรับภาพผ่านกล้องที่เชื่อมต่ออยู่ ประมวลผลภายในตัวเอง แล้วส่งผลลัพธ์ของการอนุมานไปยัง RTPM บนเครื่อง PC โฮสต์
 
ชุดเครื่องมือนี้มีประโยชน์อย่างยิ่งสำหรับนักพัฒนาและวิศวกรที่ต้องการประเมินและปรับปรุงประสิทธิภาพของแอปพลิเคชัน AI บนแพลตฟอร์ม AI-G โดยให้ข้อมูลเชิงลึกเกี่ยวกับพฤติกรรมของระบบแบบเรียลไทม์ ซึ่งช่วยให้การดีบักและการปรับจูนประสิทธิภาพเป็นไปอย่างมีประสิทธิผล
 
สำหรับคำแนะนำในการตั้งค่าและแนวทางการใช้งานโดยละเอียด โปรดดูหัวข้อถัดไปของเอกสารฉบับนี้
 
<br/><br/><br/><br/>

## 2.1 การเฝ้าติดตามประสิทธิภาพ
--- 
ชุดเครื่องมือ Real-Time Performance Monitoring Toolkit (RTPM) เป็นเครื่องมือที่ทำงานบน GUI
ซึ่งพัฒนาด้วย Python เพื่อเฝ้าติดตามเอาต์พุตของ AI-G ในสภาพแวดล้อม PC
และช่วยให้คุณตรวจสอบข้อมูลประสิทธิภาพของ CPU, NPU และหน่วยความจำได้
 
 
 
**ตารางที่ 2.1 รายการข้อมูลประสิทธิภาพของ RTPM:**
 
|   ลำดับ   |  ข้อมูลประสิทธิภาพ    |                คำอธิบาย             |
|--------|----------------------|----------------------------------------|
| 1      | Inference Time       | เวลาในการอนุมานของแต่ละโมเดล (ms)     |
| 2      | NPU Utilization      | อัตราการใช้งาน NPU ของแต่ละโมเดล         |
| 3      | FPS                  | ข้อมูล FPS ตามการทำงานของ NPU |
| 4      | CPU                  | อัตราการใช้งาน CPU (รอบ 500 ms)         |
| 5      | Memory               | อัตราการใช้งานหน่วยความจำ (รอบ 500 ms)      |

## 2.4 คู่มือการเปิดใช้งานแอปพลิเคชัน RTPM
---
