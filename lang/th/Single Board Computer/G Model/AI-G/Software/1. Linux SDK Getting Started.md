# 1. บทนำ
---
เอกสารนี้ให้แนวทางสำหรับการบิลด์ AI-G SDK ซึ่งรวมถึงการตั้งค่าสภาพแวดล้อมของโฮสต์ การบิลด์ SDK การใช้เครื่องมือดาวน์โหลดเฟิร์มแวร์ และการเชื่อมต่อ AI-G เข้ากับ PC

เอกสารนี้ประกอบด้วยข้อมูลต่อไปนี้: 
- การตั้งค่าสภาพแวดล้อมของโฮสต์  
- คู่มือการบิลด์อิมเมจ  
- คู่มือการดาวน์โหลดเฟิร์มแวร์ 
- การเชื่อมต่อบอร์ด AI-G เข้ากับ PC

<br/><br/><br/><br/>

# 2. การตั้งค่าสภาพแวดล้อมของโฮสต์ (Windows)
---
บทนี้อธิบายวิธีตั้งค่าสภาพแวดล้อมของเครื่อง PC โฮสต์ โดยแยกคู่มือสำหรับการตั้งค่าบน Windows PC และ Ubuntu PC
<br><br/><br/>

## 2.1 สภาพแวดล้อม Windows
--- 
เอกสารนี้อธิบายวิธีตั้งค่า Windows Sub-system for Linux (WSL) เพื่อใช้งาน Linux บนเครื่อง Windows PC
เนื่องจาก AI-G Linux SDK พัฒนาบนพื้นฐานของ Yocto Project ดังนั้นเวอร์ชัน Linux ของ AI-G SDK จึงเป็นไปตาม Yocto Project
คุณสามารถติดตั้ง Linux เวอร์ชันอื่นได้ แต่ในเอกสารนี้จะอธิบาย AI-G Linux SDK โดยอ้างอิงจาก Ubuntu 22.04
หากระบบปฏิบัติการของโฮสต์เป็น Ubuntu ให้ไปยังหัวข้อ 2.2
</br><br/>

### 2.1.1 การติดตั้ง WSL2 Ubuntu (เฉพาะสภาพแวดล้อม Windows)

1. เรียกใช้ Windows PowerShell ด้วย "**เรียกใช้ด้วยสิทธิ์ผู้ดูแลระบบ**"
2. เปิดใช้งานระบบ WSL2
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. เปิดใช้งานคุณสมบัติเครื่องเสมือน
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. ตั้งค่าให้ WSL ใช้เวอร์ชันเริ่มต้นเป็น 2 (WSL2)
    ```
    wsl --set-default-version 2
    ```
5. ค้นหา Ubuntu 22.04.3 LTS ใน Microsoft Store แล้วดาวน์โหลด

    * หากคุณจำเป็นต้องดาวน์โหลดแพ็กเกจอัปเดตเคอร์เนลของ Linux ให้ดาวน์โหลดแพ็กเกจล่าสุด[ที่นี่](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)

6. คุณสามารถเลือกชื่อผู้ใช้ใดก็ได้ระหว่างการติดตั้ง Ubuntu

<br/><br/>


### 2.1.2 การเข้าถึง Ubuntu ผ่าน WSL2
เปิด Command Prompt ของ Windows แล้วป้อนคำสั่งต่อไปนี้เพื่อเข้าถึง Ubuntu เมื่อเข้าสู่ Ubuntu ระบบจะเริ่มต้นที่ไดเรกทอรี /mnt/c/Users/[user name] โดยค่าเริ่มต้น
```
wsl  // access ubuntu 
ls   // check contents in your directory
```

### 2.1.3 การตั้งค่าโลแคล

หลังจากรัน Ubuntu บน WSL แล้ว คุณควรตั้งค่าโลแคลเพื่อให้การตั้งค่าภาษาและภูมิภาคถูกต้อง แนะนำให้ใช้ en_US.UTF-8 ให้รันคำสั่งต่อไปนี้เพื่อใช้ en_US.UTF-8 

```
sudo locale-gen en_US.UTF-8 && sudo update-locale LANG=en_US.UTF-8 
```

หลังจากตั้งค่าโลแคลแล้ว คุณสามารถตรวจสอบชนิดของโลแคลได้ด้วยคำสั่งต่อไปนี้ 

```
echo 'LANG=en_US.UTF-8' | sudo tee -a /etc/default/locale && \  

echo 'LC_ALL=en_US.UTF-8' | sudo tee -a /etc/default/locale 
```
<br/><br/>

### 2.1.4 การติดตั้ง SSH และ Samba 

หลังจากเข้าสู่ Ubuntu แล้ว คุณสามารถใช้ยูทิลิตีเพิ่มเติม เช่น SSH และ Samba เพื่อให้สภาพแวดล้อมการพัฒนาสะดวกยิ่งขึ้น SSH และ Samba ช่วยให้คุณรันคำสั่งบนคอมพิวเตอร์ระยะไกลและคัดลอกไฟล์ไปยังคอมพิวเตอร์เครื่องอื่นได้
 - ขั้นตอนต่อไปนี้กำหนดให้เครื่อง PC โฮสต์เชื่อมต่อกับเครือข่าย ตรวจสอบสถานะเครือข่ายของคุณด้วยคำสั่งต่อไปนี้:
  ```
  $ sudo apt-get update
  $ sudo apt-get install -y net-tools
  $ ifconfig 
  ```

หากติดตั้ง SSH และ Samba ไว้แล้ว หรือคุณไม่ต้องการใช้งาน คุณสามารถข้ามบทนี้ได้

ใช้คำสั่งต่อไปนี้เพื่อติดตั้ง net-tools, SSH และ Samba

```
$ sudo apt-get update 
$ sudo apt install -y net-tools openssh-server samba
```


หลังจากดาวน์โหลด SSH และ Samba แล้ว คุณควรตั้งค่าแต่ละโปรแกรมให้เหมาะกับสภาพแวดล้อมของคุณ
<br/><br/>

### 2.1.5 การติดตั้งยูทิลิตี 

ติดตั้งยูทิลิตีทั้งหมดในครั้งเดียว หากต้องการใช้ Yocto Project จะต้องติดตั้งยูทิลิตีต่อไปนี้บนเครื่อง PC โฮสต์ (คอมพิวเตอร์ส่วนบุคคลหรือเซิร์ฟเวอร์สำหรับพัฒนา)

ใช้คำสั่งต่อไปนี้เพื่อติดตั้งยูทิลิตี

```
$ sudo apt-get install -y gawk wget git diffstat unzip texinfo gcc-multilib build-essential chrpath

$ sudo apt-get install -y socat cpio python3 python3-pip python3-pexpect xz-utils debianutils

$ sudo apt-get install -y iputils-ping python3-git python3-jinja2 libegl1-mesa-dev libsdl1.2-dev pylint

$ sudo apt-get install -y xterm zstd ncftp curl git-lfs vim zip lz4
```
<br/><br/>


### 2.1.6 การติดตั้ง Repo (ตัวเลือกเสริม)

คุณสามารถดาวน์โหลด AI-G SDK ได้โดยใช้ ***Repo***  
หากต้องการติดตั้ง ***Repo*** โปรดดูเว็บไซต์ต่อไปนี้: https://source.android.com/source/downloading.html.  
หากติดตั้ง ***Repo*** ไว้แล้ว คุณสามารถใช้งานได้โดยไม่ต้องติดตั้งใหม่  
ก่อนติดตั้ง ***Repo*** ให้ตรวจสอบว่าได้ตั้งค่า Python เวอร์ชัน 3.6 ขึ้นไปอย่างถูกต้องแล้ว

ใช้คำสั่งต่อไปนี้เพื่อติดตั้ง ***Repo***
```
$ sudo apt-get install repo
```

หากพบข้อความแสดงข้อผิดพลาด '/usr/bin/env 'python' no such file or directory' ให้ใช้คำสั่งต่อไปนี้เพื่อให้ไฟล์ 'python' ชี้ไปยัง 'python3'

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
```
หากเกิดข้อผิดพลาดของ ***Repo*** ให้ใช้คำสั่งต่อไปนี้เพื่อดาวน์โหลดเวอร์ชันล่าสุดและวางไว้ในโฟลเดอร์ /usr/bin/ โดยตรง

```
$ mkdir -p ~/bin

$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo > ~/bin/repo

$ chmod a+x ~/bin/repo

$ sudo mv ~/bin/repo /usr/bin/repo
```

### 2.2.6 กฎ Udev สำหรับอุปกรณ์ USB ของ Telechips (ตัวเลือกเสริม)
หลังจากรันคำสั่งต่อไปนี้ คุณไม่จำเป็นต้องใช้คำสั่ง **sudo** อีกต่อไปเมื่อดาวน์โหลด ***FWDN*** บน Linux (เครื่อง PC โฮสต์)
```
$ echo "SUBSYSTEM==\"usb\", ATTR{idVendor}==\"140e\", MODE=\"0666\", OWNER=\"${USER}\"" | sudo tee /etc/udev/rules.d/99-topst.rules
$ sudo udevadm control --reload-rules && sudo udevadm trigger
```

# 3. คู่มือการบิลด์อิมเมจ
---
หัวข้อนี้อธิบายโดยอ้างอิงจากระบบปฏิบัติการ Ubuntu ที่ติดตั้งบนเครื่อง PC โฮสต์ (ไม่ว่าจะเป็น WSL หรือ Ubuntu ที่ติดตั้งในเครื่อง) อิมเมจที่จะอัปโหลดไปยัง AI-G จะถูกบิลด์ด้วย Yocto Project ดังนั้นกระบวนการนี้จึงต้องดำเนินการในสภาพแวดล้อม Ubuntu
<br/><br/><br/>

## 3.1 การเตรียมการบิลด์ SDK
---
AI-G SDK พัฒนาบนพื้นฐานของ Yocto Project 4.0 Kirkstone ดังนั้นจึงต้องตั้งค่าสภาพแวดล้อม Yocto Project บนเครื่อง PC โฮสต์เพื่อใช้งาน AI-G SDK หากต้องการดาวน์โหลด SDK, source-mirror และ tools คุณต้องติดตั้งยูทิลิตีก่อน เพื่อให้การบิลด์อิมเมจเป็นไปอย่างราบรื่น เครื่อง PC ของคุณต้องมี **พื้นที่จัดเก็บว่างอย่างน้อย 60 GB** และ **RAM อย่างน้อย 16 GB**

<br/><br/><br/>

## 3.2 Yocto Project
---
Yocto Project เป็นโครงการโอเพนซอร์สที่มุ่งเน้นการพัฒนา Linux แบบฝังตัว 
โครงการนี้ใช้ Poky ซึ่งเป็นส่วนหนึ่งของโครงการ Open Embedded ร่วมกับ bitbake ในฐานะระบบบิลด์เพื่อสร้างอิมเมจ Linux 
เมื่อใช้ Yocto Project คุณสามารถบิลด์บูตโหลดเดอร์ เคอร์เนล และ rootfs ได้พร้อมกัน 

<br/><br/><br/>

## 3.3 กระบวนการทำงานของ Yocto Project
---
รูปที่ 3.1 แสดงกระบวนการทำงานของ Yocto Project คุณสามารถดาวน์โหลดซอร์สโค้ดจากรีโพซิทอรีต้นทางตามข้อมูลเมทาดาทา แล้วจึงบิลด์ เมื่อการบิลด์เสร็จสิ้น จะได้แพ็กเกจ อิมเมจ และ SDK เป็นผลลัพธ์

# 4. ตัวดาวน์โหลดเฟิร์มแวร์
---
บทนี้อธิบายวิธีการดาวน์โหลด ***FWDN*** ไปยัง AI-G และเข้าสู่ระบบคอนโซล Linux  
***FWDN V8*** เป็นทูลบน PC สำหรับดาวน์โหลดเฟิร์มแวร์ในสภาพแวดล้อม Windows 10 หรือ 11 แบบ 64 บิต และ Linux บทนี้อธิบายกรณีการดาวน์โหลดในสภาพแวดล้อม Windows และ Linux
<br/><br/><br/>

## 4.1 ลำดับการดาวน์โหลดเฟิร์มแวร์
---
ลำดับการดาวน์โหลดของ ***FWDN*** มีดังนี้:

1. ตั้งค่าสวิตช์โหมดบูตเป็นโหมดบูต USB (โหมด FWDN)
2. เปิดพรอมต์ของ Windows หรือคอนโซล Linux แล้วทดสอบ ***FWDN V8***
3. เชื่อมต่อ ***FWDN V8*** เข้ากับบอร์ด
4. ดาวน์โหลดไฟล์ fai

<br/><br/><br/>

## 4.2 โหมดบูต USB (โหมด FWDN) 
---
ท่านสามารถถ่ายโอนอิมเมจที่บิลด์แล้วไปยัง AI-G ได้โดยใช้ ***FWDN*** โดย AI-G ให้บริการ ***FWDN*** ผ่าน Ethernet และ UART 

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/Linux%20SDK/3.%20connect%20host%20pc%20to%20topst%20ai-g.png" ></p>
<p align="center"><strong>รูปที่ 4.1 การเชื่อมต่อระหว่างเครื่อง PC โฮสต์กับ AI-G สำหรับ FWDN</strong></p><br/>

หากต้องการใช้ ***FWDN V8*** ให้เชื่อมต่อบอร์ด AI-G เข้ากับเครื่อง PC โฮสต์ดังนี้: 

1. ตรวจสอบว่าได้ติดตั้งไดรเวอร์ VTC บนเครื่อง PC โฮสต์แล้ว หากยังไม่ได้ติดตั้งไดรเวอร์ VTC ให้ติดตั้งตามที่แสดงในบทที่ 4.2.1  

2. เตรียมสาย USB Type-C หนึ่งเส้นและสาย Ethernet หนึ่งเส้น 

3. หากต้องการเข้าสู่โหมดบูต USB ให้เชื่อมต่อสาย USB Type-C เข้ากับพอร์ต USB Type-C FWDN บนบอร์ด AI-G และเครื่อง PC โฮสต์ 

4. เชื่อมต่อสาย Ethernet (RJ45) เข้ากับพอร์ต Ethernet บนบอร์ด AI-G และเครื่อง PC โฮสต์ 

5. เชื่อมต่อสายไฟเข้ากับบอร์ด AI-G ขณะที่กดสวิตช์ FWDN ค้างไว้

## 4.3 วิธีรัน FWDN
---
ก่อนรัน ***FWDN*** ท่านต้องถ่ายโอนอิมเมจและทูล ***FWDN*** ที่ท่านสร้างขึ้นหลังการบิลด์จาก Ubuntu (WSL2) ไปยังสภาพแวดล้อม Windows ก่อน 
หากท่านใช้โฮสต์ Ubuntu ท่านสามารถข้ามขั้นตอนต่อไปนี้และไปยังบทที่ 4.3.2 ได้

1. แตกไฟล์ "output_aig.fwdn.zip"
```
$ cd ~/topst-sdk
$ mkdir images
$ mv ./output_aig.fwdn.zip ./images 
$ cd images
$ unzip output_aig.fwdn.zip
```

2. คัดลอกโฟลเดอร์ "images" ไปยังไดรฟ์ C ของ Windows 
```
$ cd ..
$ cp -r ./images /mnt/c/ 
```
สำหรับขั้นตอนต่อไปนี้ โปรดดูบทที่ 4.3.1 หรือบทที่ 4.3.2 ตามระบบปฏิบัติการของเครื่อง PC โฮสต์ของท่าน
<br/><br/>

3. รัน Windows PowerShell แล้วไปที่ “C:\images”  
```
$ cd C:\images 
```
4. ป้อนคำสั่ง **.\fwdn_nd.bat** เพื่อเริ่มการดาวน์โหลดเฟิร์มแวร์ ไฟล์ “fwdn_nd.bat” เป็นไฟล์ปฏิบัติการที่ดาวน์โหลดเฟิร์มแวร์โดยอัตโนมัติด้วย ***FWDN V8***

## 4.4. การเชื่อมต่อบอร์ด AI-G ด้วย UART
--- 
ดำเนินการตามขั้นตอนต่อไปนี้ และตรวจสอบว่าการดาวน์โหลดเฟิร์มแวร์เสร็จสมบูรณ์โดยใช้การเชื่อมต่อ UART  

1. ติดตั้งไดรเวอร์พอร์ตอนุกรม (ตัวอย่างเช่น CP210x Windows Driver) และไดรเวอร์ PL2303_prolific ในสภาพแวดล้อม Windows
2. ติดตั้งโปรแกรมจำลองเทอร์มินัล เช่น Tera Term หรือ PuTTY 
3. เชื่อมต่อเครื่อง PC โฮสต์กับพิน UART บนบอร์ด AI-G โดยใช้สาย USB to TTL 
4. เชื่อมต่อสายสีดำเข้ากับพิน GND 
5. เชื่อมต่อสายสีขาว (RXD) เข้ากับพิน TX ของพิน UART และเชื่อมต่อสายสีเขียว (TXD) เข้ากับพิน RX ของพิน UART
6. รันแอปพลิเคชันจำลองเทอร์มินัล
7. เปิด Device Manager บน PC ของท่านและตรวจสอบหมายเลขพอร์ตที่ใช้สำหรับ UART
8. ป้อนหมายเลขพอร์ตที่ตรวจสอบแล้วใน Device Manager ลงในช่อง **Serial line** ของโปรแกรมจำลองเทอร์มินัล ตั้งค่า **Speed** (bps) เป็น 115200 และตั้งค่า **Flow control to None.**
9. เชื่อมต่อสายไฟ จากนั้น AI-G จะบูตในโหมดบูต eMMC ตามค่าเริ่มต้น
