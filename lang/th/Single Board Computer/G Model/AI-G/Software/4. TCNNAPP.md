# 1. บทนำ
---

## 1.4.1 คำอธิบายไฟล์ต้นฉบับ
 
ไฟล์ต้นฉบับนี้ ("tcnnapp") ใช้งานตัวอย่างการใช้โครงข่ายประสาทเทียมในโหมดเดี่ยวและโหมดคู่เพื่อการอนุมาน โดยประมวลผลอินพุต
จากกล้องหรือจากไฟล์ ไฟล์ “NnAppMain.c” ทำหน้าที่เป็นจุดเริ่มต้นของโปรแกรม ซึ่งช่วยให้เลือกโหมดและแสดงผลลัพธ์ได้
ในขณะที่ yolov5s_quantized และ mobilenetv2_10_quantized กำหนดโมเดลโครงข่ายประสาทเทียม ฟังก์ชันของกล้อง จอแสดงผล และ
ตัวปรับขนาดถูกจัดเป็นโมดูลและจัดเตรียมไว้เป็น API สำหรับจัดการอินพุตและเอาต์พุตวิดีโอ นอกจากนี้ยังมีฟังก์ชันอรรถประโยชน์สำหรับ
การจัดการข้อความและการวาดผลลัพธ์รวมอยู่ด้วยเพื่อรองรับการทำงานโดยรวม โครงสร้างนี้ออกแบบมาเพื่อให้ใช้งาน
โหมดต่าง ๆ ของโครงข่ายประสาทเทียมได้อย่างง่ายดาย
 
<br/><br/><br/>
