## 3.1 Converter
---
Converter จะอ่านไฟล์โครงข่ายประสาทเทียมและแปลงเป็นไฟล์ ”bin”
ซึ่งเป็นรูปแบบไฟล์เครือข่ายที่ใช้ใน AI-G NPU SW Toolkit
นอกจากนี้ยังทำการอนุมานเครือข่ายและเก็บรวบรวมสถิติของ
ข้อมูลแอกทิเวชัน ซึ่งจะถูกนำไปใช้ในการควอนไทซ์เครือข่ายในภายหลัง

<strong>1.  Darknet</strong>
```
$ python ./EnlightSDK/converter.py \
  ./input_networks/yolov4.cfg \
  --weight ./input_networks/yolov4.weights \
  --type obj \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/yolov4.enlight \
  --enable-track \
  --mean 0 0 0 \
  --std 1 1 1 \
  --num-class 90
```

<strong>3.  ONNX</strong>

วิธีนี้จำเป็นต้องใช้หากโมเดล ONNX ของท่านมีโอเปอเรเตอร์ที่ไม่รองรับ (เช่น NonMaxSuppression)

กระบวนการต่อไปนี้ประกอบด้วยการแปลงสามขั้นตอนโดยใช้อินเทอร์เฟซบรรทัดคำสั่งของ tc-nn-toolkit


ขั้นแรก ให้แปลงโมเดล ONNX เป็นรูปแบบ .enlight

```
$ python ./EnlightSDK/converter.py \
  ./input_networks/mb2-ssd-lite.onnx \
  --type obj \
  --add-detection-post-process ./input_networks/mb2-ssd-lite.anchor \
  --logistic softmax \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/mb2-ssd-lite.enlight \
  --enable-track \
  --mean 0.498 0.498 0.498 \
  --std 0.502 0.502 0.502 \
  --num-class 20 \
  --variance 0.1 0.2
```

จากนั้น ให้ใช้ --force-output เพื่อแยกโมเดลที่มีเลเยอร์ระหว่างกลางเป็นเอาต์พุต เพื่อลบโอเปอเรเตอร์ที่ไม่รองรับออก

```
python ./EnlightSDK/converter.py \
            ./input_networks/mb2-ssd-lite.onnx \
            --type unknown \
            --output ./output_networks/mb2-ssd-lite_wo_box_decode_score.enlight \
            --dataset-root my_dataset_path \
            --force-output Concat_0___Concat Concat_1___Concat_1
```

สุดท้าย ให้ใช้ตัวเลือกการประมวลผลภายหลัง เช่น แองเคอร์บ็อกซ์ การแอกทิเวชันแบบโลจิสติก และการตั้งค่าคลาส กับโมเดลที่แยกออกมา เพื่อสร้างโมเดล .enlight สุดท้าย

```
$ python ./EnlightSDK/converter.py \
  ./output_networks/mb2-ssd-lite_wo_box_decode_score.enlight \
  --type obj \
  --add-detection-post-process ./input_networks/mb2-ssd-lite.anchor \
  --logistic softmax \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/mb2-ssd-lite.enlight \
  --enable-track \
  --mean 0.498 0.498 0.498 \
  --std 0.502 0.502 0.502 \
  --num-class 20 \
  --variance 0.1 0.2
```

ไฟล์เอาต์พุตของ Compiler:
- npu_cmd.bin: โค้ดการอนุมานสำหรับโค้ดการอนุมานของ Telechips NPU
- quantized_network.bin: พารามิเตอร์น้ำหนักและไบแอสของเครือข่าย
- network.h: ขนาดบัฟเฟอร์และพารามิเตอร์เครือข่ายสำหรับการประมวลผลภายหลัง
- post_process.c: โค้ดการประมวลผลภายหลัง
- ไฟล์อื่น ๆ: ข้อมูลการดีบัก (สำหรับภายในเท่านั้น)

ในแอปพลิเคชันโครงข่ายประสาทเทียม “npu_cmd.bin” และ “quantized_network.bin”
จะถูกโหลดเข้าสู่บัฟเฟอร์ DMA โดยใช้ API ของ Telechips NPU และไดรเวอร์อุปกรณ์ Linux
ส่วน “network.h” และ “post_process.c” จะถูกบิลด์เป็นไฟล์อ็อบเจกต์เครือข่าย
(.so) ตามที่แสดงในหัวข้อการบิลด์อ็อบเจกต์เครือข่าย
