# 1. บทนำ
---
เอกสารนี้ให้คำแนะนำการใช้งานสำหรับแอปพลิเคชันตัวอย่างและแอปพลิเคชันทดสอบที่รวมอยู่ใน AI-G SDK แอปพลิเคชันเหล่านี้ออกแบบมาเพื่อช่วยให้ผู้ใช้เข้าใจและประเมินความสามารถด้านการอนุมาน AI โดยใช้ NPU ที่ติดตั้งอยู่บน AI-G  
เอกสารนี้ประกอบด้วยข้อมูลต่อไปนี้:
- แอปพลิเคชันตัวอย่าง
  - tcnnapp
  - tcnncameraapp
  - tcnputestapp
<br/><br/><br/><br/>
 
 
# 2. แอปพลิเคชันตัวอย่าง
---
หัวข้อนี้อธิบายแอปพลิเคชันตัวอย่าง/ทดสอบทั้งสามรายการที่มีให้ใน AI-G SDK แต่ละแอปพลิเคชันออกแบบมาเพื่อช่วยให้ผู้ใช้ประเมินและใช้ประโยชน์จากความสามารถด้าน AI ของ AI-G แอปพลิเคชันเหล่านี้ครอบคลุมสถานการณ์ต่าง ๆ เช่น การทดสอบการอนุมานด้วย NPU และการรับอินพุตจากกล้องแบบเรียลไทม์
<br/><br/><br/>
 
## 2.1 tcnnapp
---
tcnnapp เป็นแอปพลิเคชัน AI ตัวอย่างที่สาธิตวิธีการทำการอนุมานจากภาพโดยใช้ NPU บนแพลตฟอร์ม AI-G รองรับโหมดอินพุต/เอาต์พุตหลากหลายรูปแบบ และแสดงการตรวจจับวัตถุโดยใช้โมเดลที่ผ่านการฝึกมาแล้ว เช่น YOLOv5s และ MobileNetv2
<br/><br/>
 
### กรณีการใช้งานที่ 1 การอนุมานพื้นฐานจากไฟล์ไปยังไฟล์
กรณีนี้สาธิตวิธีการรันการอนุมานกับไฟล์ภาพในเครื่องและบันทึกผลลัพธ์ลงในไฟล์เอาต์พุต ซึ่งมีประโยชน์สำหรับการทดสอบการทำงานพื้นฐานและการตรวจสอบโมเดลโดยไม่ต้องใช้ฮาร์ดแวร์กล้องหรือจอแสดงผล  
หากต้องการทำการอนุมาน ให้ป้อนคำสั่งต่อไปนี้:
```
$ tcnnapp -i file -p test.png -o file -P result.png
```
 
คำสั่งนี้รัน tcnnapp โดยใช้ไฟล์ภาพอินพุต (test.png) และบันทึกผลการอนุมานลงในไฟล์เอาต์พุต (result.png) หากไม่ได้ระบุโมเดล แอปพลิเคชันจะใช้โมเดลควอนไทซ์เริ่มต้น YOLOv5s และ MobileNetv2 โดยอัตโนมัติ  
ผลลัพธ์มีดังนี้:

### กรณีการใช้งานที่ 2 การอนุมานแบบเรียลไทม์ด้วยกล้องและจอแสดงผล
กรณีนี้สาธิตวิธีการใช้ tcnnapp ร่วมกับกล้อง MIPI CSI และจอแสดงผล MIPI DSI ที่เชื่อมต่ออยู่ เพื่อทำการอนุมาน AI แบบเรียลไทม์และแสดงผลลัพธ์เป็นภาพ แอปพลิเคชันจะสตรีมวิดีโออินพุตสดจากกล้อง ทำการอนุมานแบบเรียลไทม์โดยใช้โมเดลควอนไทซ์เริ่มต้น (YOLOv5s และ MobileNetv2) บน NPU และแสดงผลลัพธ์บนหน้าจอ  
การเชื่อมต่ออุปกรณ์มีดังนี้:
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Available%20Applications/Figure%202.%20Device%20Connection.png" width="600"></p>
<p align="center"><strong>รูปที่ 2.2 การเชื่อมต่อกล้องและจอแสดงผลบน AI-G </strong></p><br/>
 
หลังจากเชื่อมต่ออุปกรณ์แล้ว ให้ป้อนคำสั่งต่อไปนี้:
```
$ tcnnapp -i camera -o display
```
คำสั่งนี้เริ่มการอนุมานแบบเรียลไทม์โดยใช้กล้อง CSI เป็นอินพุต เฟรมวิดีโอที่จับได้จะถูกส่งเข้าสู่ NPU เพื่อทำงานตรวจจับและจำแนกวัตถุ
ผลการอนุมาน เช่น กรอบขอบเขต ป้ายกำกับคลาส และคะแนนความเชื่อมั่น จะถูกวาดลงบนเฟรมเอาต์พุตโดยตรง
เฟรมที่มีคำอธิบายประกอบเหล่านี้จะแสดงแบบเรียลไทม์บนจอแสดงผล DSI ขนาด 5 นิ้ว ทำให้คุณได้รับผลตอบกลับทางภาพในทันที
 
นอกเหนือจากเอาต์พุตทางภาพแล้ว ระบบยังบันทึกตัวชี้วัดประสิทธิภาพที่สำคัญ เช่น การใช้งาน CPU อัตราการใช้งาน NPU และสถานะหน่วยความจำ ซึ่งสามารถตรวจสอบได้ผ่านคอนโซลอนุกรมหรืออินเทอร์เฟซระยะไกล

### กรณีการใช้งานที่ 3 การอนุมานแบบเรียลไทม์ด้วยกล้องและ RTPM
กรณีนี้สาธิตวิธีการใช้ tcnnapp ร่วมกับกล้อง MIPI CSI ที่เชื่อมต่ออยู่เป็นอินพุต และใช้ Real-time Performance Monitor (RTPM) เป็นวิธีการแสดงเอาต์พุต แอปพลิเคชันนี้จะสตรีมวิดีโออินพุตสดจากกล้อง ทำการอนุมานแบบเรียลไทม์โดยใช้โมเดลควอนไทซ์เริ่มต้น (YOLOv5s และ MobileNetv2) บน NPU และส่งผลลัพธ์ไปยัง PC ผ่าน RTPM เพื่อการแสดงผลและการตรวจสอบประสิทธิภาพ  
ทูลคิต RTPM เป็นเครื่องมือแบบ GUI ที่พัฒนาด้วย Python สำหรับตรวจสอบเอาต์พุตจาก AI-G ในสภาพแวดล้อม PC ช่วยให้คุณสังเกตผลการอนุมานรวมถึงตัวชี้วัดประสิทธิภาพของระบบ เช่น การใช้งาน CPU, NPU และหน่วยความจำ  
 
**หมายเหตุ**: สำหรับรายละเอียดเพิ่มเติมเกี่ยวกับ RTPM โปรดดู RTPM.md ในส่วน Software
 
การเชื่อมต่ออุปกรณ์มีดังนี้:
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Available%20Applications/Figure%204.%20Camera%20and%20RTPM%20Communication%20via%20AI-G.png"width="900"></p>
<p align="center"><strong>รูปที่ 2.4 การสื่อสารระหว่างกล้องและ RTPM ผ่าน AI-G </strong></p><br/>
 
หลังจากเชื่อมต่อกล้องแล้ว ให้ป้อนคำสั่งต่อไปนี้:
```

```
 
คำสั่งนี้เริ่มการอนุมานแบบเรียลไทม์โดยใช้กล้อง CSI เป็นอินพุต ผลการอนุมาน เช่น วัตถุที่ตรวจพบและป้ายกำกับการจำแนก จะถูกส่งไปยังเครื่อง PC โฮสต์และแสดงผลผ่านอินเทอร์เฟซ RTPM  
นอกเหนือจากเอาต์พุตการอนุมานแล้ว RTPM ยังแสดงตัวชี้วัดประสิทธิภาพของระบบ ซึ่งรวมถึงการใช้งาน CPU ภาระงานของ NPU และการใช้หน่วยความจำแบบเรียลไทม์

### กรณีการใช้งานที่ 4 การอนุมานด้วยอินพุตและเอาต์พุตผ่าน RTPM
กรณีนี้สาธิตวิธีการรันการอนุมานโดยใช้ภาพอินพุตที่สตรีมมาจากเครื่อง PC โฮสต์ผ่าน RTPM และส่งผลการอนุมานกลับไปยัง PC เพื่อแสดงผลผ่านอินเทอร์เฟซ RTPM เดียวกัน ข้อมูลอินพุตอาจเป็นภาพนิ่งหรือวิดีโอก็ได้  
โปรดดูเอกสาร RTPM.md ในส่วน Software เพื่อเรียกใช้ RTPM จากนั้นให้ป้อนคำสั่งต่อไปนี้:
```
$ tcnnapp -i rtpm -o rtpm
```
คำสั่งนี้รัน tcnnapp โดยใช้ RTPM เป็นทั้งอินพุตและเอาต์พุต ข้อมูลจะถูกส่งจากเครื่อง PC โฮสต์ผ่าน RTPM ประมวลผลโดย NPU บนบอร์ด AI-G จากนั้นผลการอนุมานจะถูกส่งกลับไปยัง PC และแสดงผลผ่านอินเทอร์เฟซ RTPM

## 2.2 tcnncameraapp
---
tcnncameraapp เป็นแอปพลิเคชันตัวอย่างที่ช่วยให้คุณทดสอบและดูตัวอย่างภาพจากโมดูลกล้องที่รองรับบนแพลตฟอร์ม AI-G สร้างขึ้นบนเฟรมเวิร์ก Video4Linux2 (V4L2) และรองรับการดูตัวอย่างภาพจากกล้องแบบเรียลไทม์ผ่านอินเทอร์เฟซ MIPI CSI และจอแสดงผล DSI ที่เชื่อมต่ออยู่  
แอปพลิเคชันนี้ใช้เป็นหลักสำหรับการตรวจสอบการทำงานของกล้อง การทดสอบเอาต์พุตของจอแสดงผล และการดีบักคุณภาพสัญญาณภาพ อีกทั้งยังรองรับการตรวจสอบกล้องหลายตัวพร้อมกันโดยขึ้นอยู่กับชนิดของโมดูลกล้อง

## 2.3 tcnputestapp
---
tcnputestapp เป็นแอปพลิเคชันตัวอย่างที่ตรวจสอบการทำงานพื้นฐานของ Neural Processing Unit (NPU) บนแพลตฟอร์ม AI-G โดยใช้ไลบรารี tcndnpulib เพื่อทดสอบการทำงานของ NPU โดยตรงด้วยโมเดลโครงข่ายประสาทเทียมที่คอมไพล์ไว้ล่วงหน้า แอปพลิเคชันนี้มีจุดประสงค์หลักสำหรับการตรวจสอบภายใน การดีบัก และการทดสอบประสิทธิภาพของ NPU โดยไม่ต้องใช้กล้องหรือจอแสดงผล  
ตัวเลือกที่ tcnputestapp มีให้แสดงอยู่ในตารางต่อไปนี้
 
| ชื่อ            | ตัวเลือก| ช่วงค่า   | ค่าเริ่มต้น  | ตัวอย่าง                  | คำอธิบาย                               |
| ---------------| -------| ----------| ------------| -------------------------| --------------------------------------|
| ข้อมูลวิธีใช้งาน | -?     |     -     |      -      | -?                       | แสดงข้อมูลวิธีใช้งาน                     |
