# 2. โหมดการบูตใน AI-G
---
AI-G รองรับโหมดการบูตต่อไปนี้: 
- USB Boot Mode (FWDN)  
- eMMC Boot Mode (GPIO_SD Group)

บอร์ด AI-G ถูกกำหนดให้อยู่ใน eMMC Boot Mode โดยค่าเริ่มต้น หากไม่มีอิมเมจสำหรับบูตอยู่ในอุปกรณ์ eMMC โหมดการบูตจะถูกสลับไปเป็น FWDN Boot Mode โดยอัตโนมัติ 

<br/><br/><br/>

## 2.1 USB Boot Mode (FWDN)
--- 
รูปที่ 2.1 แสดงสวิตช์ Boot Mode และสวิตช์ RESET โดย USB Boot Mode ใช้สำหรับการอัปเดตเฟิร์มแวร์ การเข้าสู่โหมด FWDN จำเป็นต้องใช้ทั้งสวิตช์ Boot mode และสวิตช์ RESET ขอแนะนำให้ใช้วิธีนี้เมื่ออัปโหลดอิมเมจ

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Hardware/2.11%20AI-G%20Boot%20Mode.png" width="550"></p>
<p align="center"><strong>รูปที่ 2.1 สวิตช์ Boot Mode และสวิตช์ RESET สำหรับการเข้าสู่ FWDN Boot Mode </strong></p><br/>

ขั้นตอนต่อไปนี้อธิบายการใช้งานสวิตช์เพื่อเข้าสู่ USB Boot Mode 
1. เมื่อมีการจ่ายไฟ LED ที่อยู่เหนือสวิตช์ RESET จะติดสว่าง 
2. กดสวิตช์ Boot Mode ค้างไว้ เมื่อคุณกดสวิตช์ Boot Mode คุณจะเห็น LED สีแดงเหนือสวิตช์ Boot Mode ติดสว่าง ให้กดสวิตช์ค้างไว้เพื่อให้ LED ติดสว่างต่อไป 
3. LED ของสวิตช์ RESET เป็นสีเขียวโดยค่าเริ่มต้น หากคุณกดสวิตช์ RESET หนึ่งครั้ง LED สีเขียวจะดับลงแล้วติดสว่างอีกครั้ง 
4. ปล่อยสวิตช์ Boot Mode 

รูปที่ 2.2 แสดงลำดับการทำงานของสวิตช์ Boot Mode และสวิตช์ RESET สำหรับการเข้าสู่ USB Boot Mode (FWDN)
