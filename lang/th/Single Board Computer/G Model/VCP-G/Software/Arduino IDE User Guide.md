# 1. บทนำ
---
เอกสารนี้อธิบายวิธีใช้ Arduino IDE สำหรับ TOPST Vehicle Control Processor (VCP) ซึ่งเป็นโปรเซสเซอร์ที่ทรงพลังและมีประสิทธิภาพ ออกแบบมาสำหรับงานด้านยานยนต์ และพัฒนาบนพื้นฐานของ TCC7045 โดยมีเป้าหมายเพื่อผสาน VCP-G เข้ากับสภาพแวดล้อมของ Arduino เพื่อมอบสภาพแวดล้อมการพัฒนาที่เรียบง่ายและยืดหยุ่นเทียบเท่ากับ Arduino แต่ออกแบบมาเฉพาะสำหรับเซมิคอนดักเตอร์ยานยนต์ พร้อมทั้งทำให้กระบวนการพัฒนาง่ายและรวดเร็วยิ่งขึ้น  

เอกสารนี้ประกอบด้วยข้อมูลต่อไปนี้:  
- คู่มือการติดตั้ง

# 2. คู่มือการติดตั้ง
---
บทนี้อธิบายวิธีดาวน์โหลดและติดตั้งแพ็กเกจ VCP-G Arduino เพื่อใช้งานร่วมกับ Arduino Integrated Development Environment (IDE)

</br></br></br>

## 2.1 คู่มือการติดตั้ง
---
**ขั้นตอนที่ 1: ดาวน์โหลด Arduino IDE**

ก่อนอื่น คุณต้องมี Arduino IDE ซึ่งทำหน้าที่เป็นแพลตฟอร์มสำหรับเขียนโปรแกรมลงบอร์ด Arduino ของคุณ  
1. เข้าไปที่เว็บไซต์ทางการของ Arduino : [Arduino Software](https://www.arduino.cc/en/software)
2. เลือกเวอร์ชันที่เหมาะสมกับระบบปฏิบัติการของคุณ (Windoiws, macOS หรือ Linux)
3. ดาวน์โหลดและเรียกใช้ตัวติดตั้ง

**ขั้นตอนที่ 2: ติดตั้ง Arduino IDE**  
ทำตามขั้นตอนต่อไปนี้ตามระบบปฏิบัติการของคุณเพื่อติดตั้ง Arduino IDE:  

- Windows:
    1. เรียกใช้ไฟล์ .exe ที่ดาวน์โหลดมา
    2. ทำตามคำแนะนำในการติดตั้ง ตรวจสอบให้แน่ใจว่าได้ติดตั้งไดรเวอร์ที่จำเป็นทั้งหมด
- macOS:
    1. เปิดไฟล์ .dmg
    2. ลากแอปพลิเคชัน Arduino ไปยังโฟลเดอร์ Applications
- Linux:
    1. แตกไฟล์ .tar.xz
    2. เปิดเทอร์มินัลในไดเรกทอรีที่แตกไฟล์ไว้
    3. เรียกใช้ ./install.sh เพื่อติดตั้ง

**ขั้นตอนที่ 3: เพิ่มไฟล์ .json ของ VCP-G ลงใน Arduino IDE**  
ในการเขียนโปรแกรมลง VCP-G คุณต้องเพิ่มไฟล์ .json ของ VCP-G ลงใน Arduino IDE ผ่าน Board Manager
1. เปิด Arduino IDE
2. ไปที่ **File > Preferences**
3. ในช่อง **"Additional Board Manager URLs"** ให้เพิ่ม URL ต่อไปนี้:
    ```
    https://raw.githubusercontent.com/topst-development/VCP-Arduino_Board_Manager/develop/package_topst_vcp_index.json
    ```
4. คลิก **OK** เพื่อบันทึกการเปลี่ยนแปลง
5. ไปที่ **Tools > Board > Boards Manager.**
6. ค้นหา “TOPST VCP-G” ใน Boards Manager
7. เมื่อรายการ TOPST VCP-G ปรากฏขึ้น ให้เลือก v1.0.0 จากเมนูแบบเลื่อนลงแล้วคลิก **Install**

**ขั้นตอนที่ 4: เลือก VCP-G**  
หลังการติดตั้ง คุณต้องเลือกบอร์ด TOPST VCP-G:  
1. ไปที่ **Tools > Board** ใน Arduino IDE
2. เลื่อนลงเพื่อค้นหา "TOPST VCP-G" แล้วเลือก

**ขั้นตอนที่ 5: ตรวจสอบการติดตั้ง**  
ทดสอบว่าการตั้งค่าของคุณทำงานได้หรือไม่ โดยการอัปโหลดสเก็ตช์อย่างง่าย:
1. เชื่อมต่อบอร์ด VCP-G เข้ากับ PC ของคุณโดยใช้ USB
2. เลือกพอร์ตที่เหมาะสมภายใต้ **Tools > Port**
3.	เปิด **File > Examples > 01.Basics > Blink**
4.	คลิก **Upload** เพื่อถ่ายโอนสเก็ตช์ไปยังบอร์ด  
    **หมายเหตุ:** หากกระบวนการอัปโหลดค้างอยู่ในสถานะกำลังอัปโหลดไม่สิ้นสุด แสดงว่าโหมด FWDN ยังไม่ถูกเปิดใช้งาน ให้ถอดสายไฟออก กดสวิตช์ FWDN ค้างไว้ เสียบสายไฟกลับเข้าไป แล้วจึงปล่อยปุ่ม หากยังคงเกิดปัญหา ให้ลองเรียกใช้ Arduino IDE ด้วยสิทธิ์ผู้ดูแลระบบ
5.	หากไฟ LED บนบอร์ดเริ่มกะพริบ แสดงว่าตั้งค่าบอร์ดถูกต้องแล้ว
