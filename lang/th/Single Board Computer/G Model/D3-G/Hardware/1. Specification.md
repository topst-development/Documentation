# 1. บทนำ
---
D3-G เป็นคอมพิวเตอร์ขนาดเล็กพิเศษและใช้พลังงานต่ำ ประกอบด้วยไมโครโปรเซสเซอร์ หน่วยความจำ และขั้วต่อสัญญาณเข้า/ออก (I/O) D3-G สามารถใช้ร่วมกับเซ็นเซอร์ได้หลากหลายชนิด ได้แก่ เซ็นเซอร์ตรวจจับการเคลื่อนไหว อัลตราซาวด์ อินฟราเรด LiDAR ชุดขับมอเตอร์ ทรานซีฟเวอร์สื่อสารในยานยนต์ ไมโครโฟน และโมดูลสื่อสาร  

หากต้องการความช่วยเหลือ โปรดดูส่วนเอกสารด้านฮาร์ดแวร์บนเว็บไซต์ TOPST (topst.ai) และส่งคำถามไปยัง TOPST Technical Q&A

## 1.4 ช่วงอุณหภูมิและการระบายความร้อน  
---
ช่วงอุณหภูมิแวดล้อมในการทำงานที่แนะนำคือ -10 °C ถึง 55 °C   
D3-G จะลดความเร็วสัญญาณนาฬิกาและแรงดันไฟฟ้าของ CPU เพื่อลดความร้อนที่เกิดขึ้น เมื่อ D3-G อยู่ในสถานะว่างหรือมีภาระงานน้อย ผ่านโซลูชัน Dynamic Voltage and Frequency Scaling (DVFS) D3-G ทำงานได้อย่างสมบูรณ์โดยไม่ต้องใช้อุปกรณ์ระบายความร้อนเพิ่มเติม หากต้องการให้ D3-G ทำงานเต็มประสิทธิภาพเป็นเวลานาน อาจจำเป็นต้องมีการระบายความร้อนเพิ่มเติม

## 2.12 ขั้วต่อ USB 
---
D3-G รองรับ USB สามประเภท ได้แก่ 
- USB3.0 (Type-A) Host จำนวน 1 ช่องสัญญาณ (JC3)
  - JC3 เป็นขั้วต่อ USB3.0 Type-A สำหรับพอร์ตโฮสต์  
  - USB3.0 รองรับความเข้ากันได้ย้อนหลัง ดังนั้นพอร์ตนี้จึงสามารถใช้ได้กับอุปกรณ์ทั้งแบบ USB SuperSpeed และ USB High-Speed 
- USB2.0 (Type-A) Host จำนวน 1 ช่องสัญญาณ (JC7)
  - JC7 เป็นขั้วต่อ USB2.0 Type-A สำหรับพอร์ตโฮสต์ USB High-Speed 
- USB2.0 (Type-C) FWDN จำนวน 1 ช่องสัญญาณ (JC6)
  - JC6 รองรับเฉพาะ USB2.0 FWDN เท่านั้น ขั้วต่อนี้ใช้สำหรับอัปเดตซอฟต์แวร์ใน USB Boot Mode
