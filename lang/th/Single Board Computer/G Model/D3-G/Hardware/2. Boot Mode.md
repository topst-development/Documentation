# 2. โหมดการบูตใน D3-G
---
D3-G รองรับโหมดการบูตสามโหมด ดังนี้
- โหมดการบูตแบบ USB (FWDN)
- โหมดการบูตแบบ eMMC (GPIO_SD0 Group)  
- โหมดการบูตแบบ SNOR และ eMMC (ตัวเลือกเสริม)
 
รูปที่ 2.1 แสดงตำแหน่งของตัวต้านทานสำหรับโหมดการบูตบน D3-G ตัวต้านทานเหล่านี้อยู่ที่ด้านล่างของบอร์ด โดยค่าเริ่มต้น D3-G จะถูกกำหนดให้เป็นโหมดการบูตแบบ eMMC หากไม่มีอิมเมจสำหรับการบูตอยู่ในอุปกรณ์ eMMC โหมดการบูตจะสลับไปเป็นโหมดการบูตแบบ USB โดยอัตโนมัติ

## 2.1 โหมดการบูตแบบ USB (FWDN)
---
รูปที่ 2.2 แสดงสวิตช์โหมดการบูตและสวิตช์ RESET โหมดการบูตแบบ USB ใช้สำหรับการอัปเดตเฟิร์มแวร์ ในการเข้าสู่โหมด FWDN จำเป็นต้องใช้ทั้งสวิตช์โหมดการบูตและสวิตช์ RESET ขอแนะนำให้ใช้วิธีนี้เมื่ออัปโหลดอิมเมจ
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20D3-G/Hardware/Boot%20Mode%20Switch%20and%20RESET%20Switch%20for%20Entering%20FWDN%20Boot%20Mode.png" width="600"></p>
<p align="center"><strong>รูปที่ 2.2 สวิตช์โหมดการบูตและสวิตช์ RESET สำหรับการเข้าสู่โหมดการบูต FWDN </strong></p>
 
 
 
ขั้นตอนต่อไปนี้อธิบายการใช้งานสวิตช์เพื่อเข้าสู่โหมดการบูตแบบ USB
1. เมื่อจ่ายไฟเข้า LED ที่อยู่เหนือสวิตช์ RESET จะติดสว่าง
2. กดสวิตช์โหมดการบูตค้างไว้ เมื่อกดสวิตช์โหมดการบูต จะเห็น LED สีแดงที่อยู่เหนือสวิตช์โหมดการบูตติดสว่าง ให้กดสวิตช์ค้างไว้เพื่อให้ LED ติดสว่างอยู่
3. LED ของสวิตช์ RESET เป็นสีเขียวโดยค่าเริ่มต้น หากกดสวิตช์ RESET หนึ่งครั้ง LED สีเขียวจะดับลงแล้วติดสว่างขึ้นอีกครั้ง
4. ปล่อยสวิตช์โหมดการบูต
 
รูปที่ 2.3 แสดงลำดับการทำงานของสวิตช์โหมดการบูตและสวิตช์ RESET สำหรับการเข้าสู่โหมดการบูตแบบ USB (FWDN)

<p align="center"><strong>รูปที่ 2.3 ลำดับการเข้าสู่โหมดการบูตแบบ USB (FWDN)  </strong></p>

## 2.2 โหมดการบูตแบบ SNOR และ eMMC
---
โหมดการบูตแบบ SNOR และ eMMC เป็นตัวเลือกเสริม ในการใช้โหมดการบูตนี้ ต้องติดตั้ง SNOR IC บนบอร์ด และต้องเปลี่ยนการประกอบแบบยึดติดผิวหน้า (SMT) ของตัวต้านทานสำหรับโหมดการบูต
รูปที่ 2.4 แสดงการเปลี่ยนแปลงที่จำเป็นสำหรับการใช้โหมดการบูตแบบ SNOR และ eMMC
