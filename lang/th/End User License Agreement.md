# ข้อตกลงอนุญาตให้ใช้สิทธิสำหรับผู้ใช้ปลายทาง (EULA) 

### ปรับปรุงล่าสุด:2025-06-16

ข้อตกลงอนุญาตให้ใช้สิทธิสำหรับผู้ใช้ปลายทางฉบับนี้ ("ข้อตกลง") เป็นข้อตกลงที่มีผลผูกพันตามกฎหมายระหว่างท่าน ("ผู้รับอนุญาต") กับ Telechips, Inc. ("ผู้ให้อนุญาต") เกี่ยวกับการใช้ชุดพัฒนาซอฟต์แวร์ (ต่อไปนี้เรียกว่า "SDK") ผู้ให้อนุญาตเป็นเจ้าของลิขสิทธิ์ใน SDK นี้ และได้เผยแพร่ภายใต้เงื่อนไขของข้อตกลงฉบับนี้ การคลิก "ข้าพเจ้ายอมรับ" การดาวน์โหลด การติดตั้ง หรือการใช้ SDK ในลักษณะอื่นใด ถือว่าท่านตกลงที่จะผูกพันตามเงื่อนไขเหล่านี้ SDK นี้จัดให้มีขึ้นเพื่อการใช้งาน การแก้ไข และการเผยแพร่โดยไม่มีข้อจำกัด เว้นแต่จะถูกจำกัดโดยกฎหมายที่ใช้บังคับและเงื่อนไขด้านล่าง หากท่านไม่ยอมรับเงื่อนไขเหล่านี้ โปรดอย่าใช้ SDK 

</br>

### 1. การอนุญาตให้ใช้สิทธิ 

ผู้ให้อนุญาตมอบสิทธิแก่ผู้รับอนุญาตในการใช้ แก้ไข และเผยแพร่ SDK โดยเป็นสิทธิที่ถาวร ครอบคลุมทั่วโลก ปลอดค่าสิทธิ ไม่จำกัดแต่เพียงผู้เดียว และเพิกถอนไม่ได้ ทั้งนี้ภายใต้เงื่อนไขของข้อตกลงฉบับนี้ การอนุญาตนี้ครอบคลุมการใช้เพื่อวัตถุประสงค์ส่วนบุคคลและเพื่อการศึกษาโดยไม่มีข้อจำกัด เว้นแต่จะถูกห้ามตามกฎหมาย 

 
</br>

### 2. เงื่อนไขของการอนุญาตให้ใช้สิทธิ 

ผู้รับอนุญาตตกลงตามเงื่อนไขต่อไปนี้ในการใช้ SDK: 

การปฏิบัติตามข้อกำหนดเรื่องการแสดงที่มา: ผู้รับอนุญาตต้องรวมข้อความแสดงที่มาใด ๆ ที่ Telechips, Inc. กำหนดไว้ใน SDK เวอร์ชันที่เผยแพร่หรือสำเนาที่แก้ไขแล้ว 

การปฏิบัติตามกฎหมาย: ผู้รับอนุญาตตกลงที่จะไม่ใช้ เผยแพร่ หรือโอน SDK ในลักษณะใดก็ตามที่ฝ่าฝืนกฎหมายหรือระเบียบที่ใช้บังคับ ซึ่งรวมถึงแต่ไม่จำกัดเพียงกฎหมายว่าด้วยการควบคุมการส่งออกและมาตรการคว่ำบาตร 

</br>


### 3. การสิ้นสุดข้อตกลง 

ข้อตกลงฉบับนี้มีผลใช้บังคับจนกว่าจะสิ้นสุดลง ผู้ให้อนุญาตอาจบอกเลิกข้อตกลงฉบับนี้ได้ทันที หากผู้รับอนุญาตไม่ปฏิบัติตามเงื่อนไขข้อใดข้อหนึ่งของข้อตกลงฉบับนี้ เมื่อข้อตกลงสิ้นสุดลง ผู้รับอนุญาตต้องยุติการใช้ SDK ทั้งหมด และลบสำเนาทั้งหมดที่อยู่ในความครอบครองหรือการควบคุมของตน 

</br>
 

### 4. การปฏิเสธการรับประกัน 

SDK จัดให้มีขึ้นตาม "สภาพที่เป็นอยู่" และ "เท่าที่มีให้ใช้ได้" โดยปราศจากการรับประกันใด ๆ ไม่ว่าโดยชัดแจ้งหรือโดยปริยาย ซึ่งรวมถึงแต่ไม่จำกัดเพียงการรับประกันด้านความเหมาะสมในเชิงพาณิชย์ ความเหมาะสมกับวัตถุประสงค์เฉพาะอย่าง กรรมสิทธิ์ หรือการไม่ละเมิดสิทธิ ผู้ให้อนุญาตไม่รับประกันว่า SDK จะปราศจากข้อผิดพลาดหรือจะทำงานโดยไม่หยุดชะงัก หรือว่าข้อบกพร่องใด ๆ จะได้รับการแก้ไข 

</br>


### 5. การควบคุมการส่งออก 

ผู้รับอนุญาตตกลงที่จะปฏิบัติตามกฎหมายและระเบียบว่าด้วยการควบคุมการส่งออกและมาตรการคว่ำบาตรที่ใช้บังคับทั้งหมดอย่างครบถ้วน ซึ่งรวมถึงแต่ไม่จำกัดเพียงกฎหมายและระเบียบของสาธารณรัฐเกาหลี สหรัฐอเมริกา และเขตอำนาจอื่นที่เกี่ยวข้อง เพื่อให้แน่ใจว่า SDK จะไม่ถูกใช้ ส่งออก หรือส่งออกซ้ำ ไม่ว่าโดยทางตรงหรือทางอ้อม อันเป็นการฝ่าฝืนกฎหมายหรือระเบียบดังกล่าว ผู้รับอนุญาตขอรับรองและรับประกันว่า: 
 
(ก) ผู้รับอนุญาตมิได้ตั้งอยู่ใน อยู่ภายใต้การควบคุมของ หรือเป็นคนชาติหรือผู้มีถิ่นที่อยู่ในประเทศใดก็ตามที่อยู่ภายใต้มาตรการคว่ำบาตรหรือการห้ามค้าขายแบบครอบคลุมของรัฐบาลสหรัฐอเมริกาหรือรัฐบาลเกาหลี (ซึ่งรวมถึงแต่ไม่จำกัดเพียง คิวบา อิหร่าน เกาหลีเหนือ ซีเรีย หรือภูมิภาคไครเมียของยูเครน); 

(ข) ผู้รับอนุญาตมิได้ถูกระบุชื่ออยู่ในบัญชีรายชื่อบุคคลที่ถูกจำกัดของรัฐบาลสหรัฐอเมริกาหรือรัฐบาลเกาหลีใด ๆ ซึ่งรวมถึง Denied Persons List หรือ Entity List ของกระทรวงพาณิชย์สหรัฐอเมริกา, Specially Designated Nationals List ของกระทรวงการคลังสหรัฐอเมริกา หรือบัญชีรายชื่อบุคคลที่ถูกจำกัดของเกาหลี; 

(ค) ผู้รับอนุญาตจะไม่ใช้ SDK เพื่อวัตถุประสงค์ใด ๆ ที่ต้องห้ามตามกฎหมายว่าด้วยการควบคุมการส่งออกที่ใช้บังคับ ซึ่งรวมถึงแต่ไม่จำกัดเพียงการแพร่ขยายอาวุธนิวเคลียร์ อาวุธเคมี หรืออาวุธชีวภาพ หรือการพัฒนาเทคโนโลยีขีปนาวุธ; และ 

(ง) ผู้รับอนุญาตจะไม่ส่งออกซ้ำหรือโอน SDK ให้แก่บุคคลใด โดยมิได้ตรวจสอบให้แน่ใจก่อนว่าเป็นไปตามกฎหมายว่าด้วยการส่งออกที่ใช้บังคับ และได้รับอนุญาตจากภาครัฐตามที่จำเป็นแล้ว 

</br>

### 6. ข้อจำกัดความรับผิด 

ไม่ว่าในกรณีใดก็ตาม ผู้ให้อนุญาตจะไม่รับผิดต่อความเสียหายทางอ้อม ความเสียหายที่เป็นผลพลอยได้ ความเสียหายพิเศษ ความเสียหายอันเป็นผลสืบเนื่อง หรือความเสียหายเชิงลงโทษใด ๆ ซึ่งรวมถึงแต่ไม่จำกัดเพียงการสูญเสียกำไร ข้อมูล หรือการใช้งาน ที่ผู้รับอนุญาตหรือบุคคลภายนอกใด ๆ ได้รับ ไม่ว่าจะเป็นการฟ้องร้องตามสัญญา ตามมูลละเมิด หรือประการอื่นใด อันเกิดจากการใช้ SDK ของผู้รับอนุญาต 

</br>

### 7. กฎหมายที่ใช้บังคับและเขตอำนาจศาล 

ข้อตกลงฉบับนี้อยู่ภายใต้บังคับและตีความตามกฎหมายของสาธารณรัฐเกาหลี ข้อพิพาทใด ๆ ที่เกิดขึ้นจากหรือเกี่ยวข้องกับข้อตกลงฉบับนี้ให้อยู่ในเขตอำนาจเด็ดขาดของศาลที่ตั้งอยู่ในสาธารณรัฐเกาหลี  
</br>

### 8. การคุ้มครองผู้ใช้ 

เงื่อนไขบางประการในข้อตกลงฉบับนี้อาจอยู่ภายใต้การตีความตามกฎหมายเกาหลีว่าด้วยการคุ้มครองผู้บริโภคและความเป็นธรรมของสัญญา ในกรณีที่ข้อกำหนดใดถูกศาลเกาหลีวินิจฉัยว่าไม่อาจบังคับใช้ได้ ข้อกำหนดดังกล่าวจะได้รับการแก้ไขเพียงเท่าที่จำเป็นเพื่อให้บังคับใช้ได้ และข้อกำหนดที่เหลือยังคงมีผลใช้บังคับอย่างสมบูรณ์ 
</br>

### 9. ข้อตกลงทั้งหมด 

ข้อตกลงฉบับนี้ถือเป็นข้อตกลงทั้งหมดระหว่างผู้รับอนุญาตกับผู้ให้อนุญาตเกี่ยวกับเรื่องที่เป็นสาระสำคัญในข้อตกลงนี้ และใช้แทนข้อตกลง คำรับรอง หรือความเข้าใจใด ๆ ก่อนหน้านี้หรือในเวลาเดียวกัน ไม่ว่าจะเป็นลายลักษณ์อักษรหรือด้วยวาจา 
</br>
