#  2. 開機指南

本章說明如何啟動 TOPST D3，以及如何登入各個核心。

<br><br>

## 2.1 開機順序

***FWDN*** 的下載順序如下：

1. 為 DP 顯示器連接 DP 纜線。
2. 連接除錯板與 TOPST D3。
3. 將各條 TOPST USB 纜線連接至除錯板，以登入主控台並對各核心進行除錯。
4. 連接 5V 電源。

<br><br>
