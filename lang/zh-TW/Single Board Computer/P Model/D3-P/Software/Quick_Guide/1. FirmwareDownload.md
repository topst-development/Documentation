# 1. FWDN 指南

本章說明如何使用韌體下載工具（***FWDN***）將韌體下載至 TOPST D3，並登入 Linux 主控台。

<br><br>

## 1.1   韌體下載流程

***FWDN*** 的下載流程如下：

1. 進入 FWDN 模式。
2. 將 USB A-to-A 傳輸線連接至 USB 2.0 FWDN 連接埠。
3. 下載 TOPST 映像檔。

<br><br>

## 1.2   進入 FWDN 模式

請按住 **SW2**（FWDN Mode Convert）按鈕並接上電源，即可進入 ***FWDN*** 模式。或者，若電源已連接，請按住 **SW2** 按鈕（FWDN Mode Convert）並按下 **SW1** 按鈕（System Reset），以進入 ***FWDN*** 模式。

## 1.3 在 Windows 環境中使用 CLI 工具執行 FWDN
  
若要使用 FWDN，請從下列連結下載韌體工具：

- <[FWDN 工具](https://drive.google.com/file/d/1UzArkpt-Aw67YhAMtlSfkELEHYBMBqT7/view?usp=sharing)>

您可以依照下列方式下載各個 TOPST 映像檔。

- 指令碼位置：topst.d3.pre.20240425001\fwdn.bat


```
.\fwdn.bat
```
在下圖中，使用 .\fwdn.bat 指令下載完整的 TOPST 映像檔。
按下 SW1（Reset）按鈕重新啟動 TOPST D3 後，Ubuntu 啟動器便會執行。
