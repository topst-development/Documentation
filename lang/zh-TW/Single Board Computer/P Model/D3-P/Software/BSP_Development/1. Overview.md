## 1.1 功能方塊圖

TCC8050 提供多樣化的解決方案，例如車用影音導航系統 (AVN)、數位儀表板與環景影像監視器 (AVM)。TCC8050 整合了 ARM® Cortex-A72 多核心處理器與 Cortex-A53 多核心處理器、作為微處理器的 Cortex-R5、車用資安用安全子系統中硬體安全模組 (HSM) 的 SC000 核心、用於儲存管理的 Cortex-M4、Cortex-M4 子系統中另一顆用於 TSDEMUX 的 Cortex-M4，以及硬體化的視訊處理單元 (VPU)／圖形處理單元 (GPU)，將多媒體體驗提升至極致。硬體化的 VPU 可進行視訊編碼與解碼，GPU 則提供支援 OpenGL ES1.1/2.0/3.2 與 OpenCL 1.0/1.1/2.0 的 3D 圖形功能。TCC8050 支援 Linux® 與 Android™ 等多種作業系統。

TCC8050 是針對需要便利連線功能的網路裝置所最佳化的處理器：USB 3.0、USB 2.0 Device/Host 與 USB 2.0 Host 控制器可在多媒體裝置與儲存裝置之間傳輸資料。乙太網路 MAC 控制器提供符合 IEEE802.3 標準的網際網路連線。此外，PCI Express (PCIe) Gen 3 為外部 IP 互連提供高頻寬。

這套創新且豐富的功能組合，擴展了 TCC8050 可應用的類別範圍，以滿足不斷演進的技術與市場需求。
