# 2. 軟體架構

圖 2.1 顯示 TCC8050 的軟體架構。這三個核心具備下列功能，並透過 IPC 彼此交換資訊。

TCC8050 使用 CA72（主核心）提供多媒體功能，CA53（副核心）則在運作期間提供主核心的即時處理（例如倒車攝影機）。CR5 提供即時作業系統，以支援與車輛通訊所需的功能。
