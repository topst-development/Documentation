#  1. 設定主機環境

<br><br>

## 1.1 安裝 Ubuntu

由於 TOPST D3 Linux SDK 以 Yocto Project 為基礎，TOPST D3 SDK 的 Linux 版本依循 Yocto Project。

您可以安裝其他版本的 Linux，但本文件是以 Ubuntu 22.04 為基礎說明 TOPST D3 Linux SDK。

Linux 發行版本：

- Ubuntu 22.04 (LTS)

<br/><br/>

## 1.2 安裝 WSL2 Ubuntu 

1. 以「**以系統管理員權限執行**」的方式執行 Windows PowerShell
2. 啟用 WSL2 系統。
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. 啟用虛擬機器功能。
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. 將 WSL 2 設為預設版本。
    ```
    wsl --set-default-version 2
    ```
5. 在 Microsoft Store 中搜尋 Ubuntu 22.04.3 LTS 並下載。

    * 若您需要下載 Linux 核心更新套件，請由[此處](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)下載最新的套件。


<br/><br/>

## 1.3 設定 Linux 環境

<br>

### 1.3.1 安裝 SSH 與 Samba

安裝虛擬機器之後，您可以使用 SSH 與 Samba 等額外的公用程式，讓開發環境更為便利。SSH 與 Samba 可讓您在遠端電腦上執行命令，並將檔案複製到其他電腦。

若 SSH 與 Samba 已安裝，或您不會使用它們，可以略過本章。

請使用下列命令安裝 net-tools、SSH 與 Samba。

```
$ sudo apt install -y net-tools openssh-server samba
```


下載 SSH 與 Samba 之後，您應依照自己的環境設定各個程式。

<br>

### 1.3.2 公用程式

請一次安裝這些公用程式。若要使用 Yocto Project，下列公用程式必須安裝於主機 PC（個人電腦或開發伺服器）上。

請使用下列命令安裝公用程式。

```
$ sudo apt-get install -y gawk wget git diffstat unzip texinfo gcc-multilib build-essential chrpath

$ sudo apt-get install -y socat cpio python3 python3-pip python3-pexpect xz-utils debianutils

$ sudo apt-get install -y iputils-ping python3-git python3-jinja2 libegl1-mesa libsdl1.2-dev pylint

$ sudo apt-get install -y xterm zstd ncftp curl git-lfs vim zip
```

<br>

### 1.3.3 安裝 Repo

若 Repo 已安裝，您可以直接使用，不需重新安裝。  
在安裝 Repo 之前，應先正確設定已安裝的 Python 版本（3.6 或以上）。

請使用下列命令安裝 repo。
```
$ sudo apt-get install repo
```

若您看到錯誤訊息 '/usr/bin/env 'python' no such file or directory'，請使用下列命令讓檔案 'python' 指向 'python3'。

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
```
若發生 Repo 錯誤，請使用下列命令下載最新版本，並直接放入 /usr/bin/ 資料夾。

```
$ mkdir -p ~/bin

$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo > ~/bin/repo

$ chmod a+x ~/bin/repo

$ sudo mv ~/bin/repo /usr/bin/repo
```

### 1.3.4 Telechips USB 裝置的 Udev 規則
執行下列命令後，在 Linux 中下載 FWDN 時就不需要使用 'sudo' 命令。
```
$ echo "SUBSYSTEM==\"usb\", ATTR{idVendor}==\"140e\", MODE=\"0666\", OWNER=\"${USER}\"" | sudo tee /etc/udev/rules.d/99-topst.rules
$ sudo udevadm control --reload-rules && sudo udevadm trigger
```
