# 2. 建置指南

<br/><br/>

## 2.1 TOPST D3 Linux SDK 建置準備

TOPST D3 Linux SDK 以 Yocto Project 3.1 Dunfell 為基礎。因此，若要使用 TOPST D3 Linux SDK，必須在主機 PC 上建立 Yocto Project 環境。若要下載 SDK、source-mirror 與工具，您必須先安裝相關公用程式。  

<br/><br/>

## 2.2 Yocto Project  

Yocto Project 是一個專注於嵌入式 Linux 開發的開放原始碼專案。  
它結合了 Open Embedded 專案（即 Poky）與 ***bitbake*** 作為建置系統，用以製作 Linux 映像檔。  
透過 Yocto Project，您可以同時建置 bootloader、核心與 rootfs。  

<br/><br/>

```
sudo add-apt-repository ppa:ubuntu-toolchain-r/test
sudo apt update
sudo apt install g++-11
```
