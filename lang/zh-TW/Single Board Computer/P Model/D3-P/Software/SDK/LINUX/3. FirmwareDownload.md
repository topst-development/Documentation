# 3. 韌體下載

本章說明如何將 ***FWDN*** 下載至 TOPST D3（開放平台開發板），以及如何登入 Linux 主控台。  
***FWDN V8*** 是可在 Windows 10 64-bit 與 Linux 環境中下載韌體的 PC 工具。本章說明在 Windows 與 Linux 環境中進行下載的情況。

<br/><br/>

## 3.1 韌體下載流程

***FWDN*** 的下載流程如下：

1. 將開機模式開關設定為 USB 開機模式。
2. 開啟 Windows 命令提示字元或 Linux 主控台，並測試 ***FWDN V8***。
3. 將 ***FWDN V8*** 連接至開發板。
4. 下載 fai 檔案。

<br/><br/>

## 3.2 以 USB 開機方式連接 TOPST D3 與主機 PC

若按住 **SW2** 再供電，將啟動 USB 開機程序。若未按 **SW2** 直接供電，則會啟動一般開機程序。

按下 **SW1** 會使系統重置。若要下載韌體，請同時按下 **SW1** 與 **SW2** 以 USB 模式開機。

## 3.3 FWDN 下載前準備

1. 解壓縮 "output.fwdn.zip" 
    ```
    $ mkdir images
    $ mv ./output.fwdn.zip ./images
    $ cd images
    $ unzip output.fwdn.zip
    ```
2. 將 "images" 資料夾複製到 Windows C 磁碟機。
    ```
    $ cd ..
    $ cp -r /images /mnt/c/
    ```

## 3.5 Linux 環境中的 FWDN

在 Linux 環境中，可使用 "./fwdn.sh" 指令下載 TOPST 映像檔。

```
$ ./fwdn.sh
```

<br/><br/>

## 3.6 使用 UART 連接 TOPST

1. 請使用 UART 連線確認韌體下載是否已成功完成。
2. 請在 Windows 環境中安裝序列埠驅動程式 (CP210x Windows Driver)。([下載連結](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads))
3. 請將開機模式變更為一般模式 (eMMC) 並重新開機。請使用 USB Type-C 轉 USB 2.0 或 3.0 的纜線，而非 C 對 C 纜線。
