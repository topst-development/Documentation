# 1. 簡介


TOPST D3 是一款超小型、低功耗的電腦，具備微處理器、記憶體與輸入/輸出（I/O）端子。TOPST D3 可搭配多種感測器，包括動作、超音波、紅外線、LiDAR、馬達驅動、車用通訊收發器、麥克風與通訊模組。  

如需支援，請參閱 TOPST 網站（topst.ai）的硬體文件章節，並將問題張貼至 TOPST Technical Q&A。

## 1.5 溫度範圍與散熱  
建議的環境操作溫度範圍為 -10°C 至 55°C。   
當 TOPST D3 處於閒置狀態或工作負載較輕時，會透過動態電壓與頻率調整（DVFS）解決方案降低 CPU 時脈速度與電壓，以減少發熱量。TOPST D3 無須額外的散熱裝置即可完美運作。若您希望在如車用需求等更寬廣的操作溫度範圍下以全效能運作，請聯絡 TOPST；topst@topst.ai
