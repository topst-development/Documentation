## 3.3 UART/JTAG 子板  

UART/JTAG 子板是用於序列連接埠與 JTAG 的除錯板。您可以使用 USB Type-C 線材將 UART/JTAG 子板連接至主機 PC，以檢視序列日誌。   

圖 3.3 為 UART/JTAG 子板的概觀。

表 3.1 說明 UART/JTAG 子板的接頭。  

**表 3.1 UART/JTAG 子板說明：**  

| 項目 | 說明                                           |
|:----:|------------------------------------------------|
| u10  | 連接 TOPST D3 的 FFC 接頭                      |
| u20  | 連接除錯器的公頭排針                            |
| u30  | MCU 除錯用的 Debug 連接埠（USB Type-C）         |
| u40  | A53 核心除錯用的 Debug 連接埠（USB Type-C）     |
| u50  | A72 核心除錯用的 Debug 連接埠（USB Type-C）     |  

<br/><br/>

## 3.4 將 UART/JTAG 子板連接至 TOPST D3  

本章說明如何連接 TOPST D3 與 UART/JTAG 子板。  

請依下列方式，使用軟性排線（FFC）將 UART/JTAG 子板連接至 TOPST D3：
1. 準備一條 FFC 與一條 USB Type-C 線材。
2. 將 FFC 連接至 UART/JTAG 子板上的 Debug I/F 接頭，以及 TOPST D3 上的 Debug I/F 接頭。 <br/>
    * 請務必讓 FFC 的藍色線面朝上連接。
3. 使用 USB Type-C 線材，將 UART/JTAG 子板連接至您的主機 PC。 <br/>
    * 請參閱表 3.1，依目標核心選擇適當的 UART 連接埠。例如，A72 UART 可連接至主核心（Cortex-A72 Quad）的 UART Port。
4. 透過主機 PC 上的終端機應用程式檢視序列日誌訊息。

## 3.5 將 JTAG 除錯器連接至 TOPST D3  

本章說明如何將 JTAG 除錯器連接至 TOPST D3。  

請依下列方式，將 JTAG 除錯器連接至 TOPST D3：
1. 準備一台 JTAG 除錯器。
2. 請參閱上方「將 UART/JTAG 子板連接至 TOPST D3」章節，將 UART/JTAG 子板連接至 TOPST D3。
3. 將 JTAG 除錯器連接至 UART/JTAG 子板上的 JTAG Header。
