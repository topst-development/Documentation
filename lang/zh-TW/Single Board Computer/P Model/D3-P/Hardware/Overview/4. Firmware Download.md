# 4. 將 TOPST D3 連接至主機 PC 以進行韌體下載



韌體下載工具（**FWDN**）會在主機 PC 上透過 USB 通訊，將 ROM 映像檔寫入 TOPST D3。  

TOPST D3 具有一個 Boot Mode 按鈕，並可透過該按鈕支援下列兩種開機模式：
- USB Boot Mode 用於在您的主機 PC 上使用 **FWDN** 程式寫入 ROM 映像檔。
- eMMC Boot Mode 用於使用儲存在 eMMC 裝置中的 ROM 映像檔啟動 TOPST D3。

**註**：USB 2.0 D/H 連接埠用於韌體下載工具（**FWDN**）  

若要使用 **FWDN**，請依下列方式將 TOPST D3 連接至主機 PC：
1. 請確認主機 PC 上已安裝 VTC 驅動程式。若尚未安裝 VTC 驅動程式，請依照 topst.ai 上提供的 **FWDN** 指南進行安裝
2. 請準備一條 USB Type-A 傳輸線。
3. 請使用 USB Type-A 傳輸線，將 TOPST D3 上的 USB 2.0 D/H 連接至主機 PC。
4. 請使用下列兩種方法之一來變更 TOPST D3 的開機模式。<br/>
   1. 方法 1
       * 若 TOPST D3 尚未通電，請按住 FWDN 按鈕，並將 5V 電源接至 TOPST D3。
       * 放開 FWDN Boot mode 按鈕。<br/>
   2. 方法 2
       * 若 TOPST D3 已經通電，請按下 Reset 按鈕與 FWDN Boot mode 按鈕。
       * 放開 FWDN Boot mode 按鈕。
5. 請依照 **FWDN** 指南下載您的 ROM 映像檔。
