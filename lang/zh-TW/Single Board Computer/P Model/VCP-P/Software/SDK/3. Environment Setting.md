# 3. 環境設定

要順利進行 TOPST-VCP 開發板的開發，需要架構良好的開發環境。本章將引導您完成必要步驟，在您的 Ubuntu 22.04 系統上安裝所有必備的工具、公用程式與軟體套件。

<br/><br/>

## 3.1 安裝必備工具與公用程式

在深入了解 TOPST-VCP 開發板的細節之前，先安裝一些基本的公用程式與工具相當重要。這些工具是建置其他軟體與設定的基礎。

1. **終端機**：Ubuntu 22.04 內建終端機。請熟悉其用法，因為後續許多步驟都需要使用終端機命令。
2. **文字編輯器**：雖然 Ubuntu 內建基本的文字編輯器，您可能會想依個人偏好安裝功能更完整的編輯器，例如「nano」、「vim」，或是「gedit」、「VSCode」等圖形化編輯器。
3. **SSH 工具**：開發過程中，遠端存取其他系統或裝置（特別是 TOPST- VCP 開發板）可能相當重要。多種 SSH 工具都可以協助達成：
4. **Putty**：一款熱門、免費且開放原始碼的終端機模擬器，除其他通訊協定外亦支援 SSH。它輕巧且易於使用。
5. **Tera Term**：一款開放原始碼的終端機模擬器，功能更為豐富，並廣泛支援包含 SSH 在內的各種通訊協定。

您可以依照自己的特定需求與偏好，選擇其中一種或多種工具進行 SSH 存取。  

**謹供參考，本指南文件使用 putty。**

<br/><br/>

## 3.2 使用 apt 安裝軟體

「apt」套件管理員是 Ubuntu 中功能強大的工具，可讓您輕鬆安裝、更新與管理軟體套件。

<br/>

### 3.2.1 更新套件清單

在安裝任何新軟體之前，先更新可用套件清單是良好的做法。這可確保您取得最新的版本與相依套件。

```
$ sudo apt update
$ sudo apt upgrade
```

此命令會從軟體庫擷取最新的可用套件清單。

### 3.2.2 安裝常用開發工具

對大多數開發工作而言，特別是針對 TOPST-VCP 開發板，某些常用工具是不可或缺的。

請使用下列命令安裝這些工具：

```
$ sudo apt install build-essential git
```

此命令會同時安裝 buide-essential 套件與 git。
