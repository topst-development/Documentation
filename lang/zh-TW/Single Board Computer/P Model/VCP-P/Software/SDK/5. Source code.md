#  5. 取得原始碼

原始碼是所有開發專案的骨幹。它包含為特定平台建置與執行軟體所需的全部檔案、設定與指示。就 TOPST-VCP 開發板而言，取得正確的原始碼對於確保相容性與最佳效能至關重要。

本章將引導您使用廣泛採用的版本控制系統 git 取得原始碼。

<br/><br/>

## 5.1 複製 TOPST-VCP 原始碼

若要取得 TOPST-VCP 開發板的原始碼，您將使用 git clone 命令。此命令會在您的本機電腦上建立遠端儲存庫的副本，讓您可以直接使用這些程式碼。

請依照下列步驟複製 TOPST-VCP 原始碼：

1. **開啟終端機**：在您的 Ubuntu 22.04 系統上啟動終端機應用程式。
2. **切換至目標目錄**：在您的系統上選擇要儲存原始碼的適當位置。例如，若您想儲存在使用者家目錄中，請使用下列命令

    ```
    $ cd ~
    ```

3. **複製儲存庫**：請使用下列命令，從提供的 git 位址複製 TOPST-VCP 原始碼

    ```
    $ git clone https://gitlab.com/topst.ai/topst-vcp.git
    ```

4. **切換至複製後的目錄**：複製程序完成後，請使用下列命令切換至包含原始碼的目錄

    ```
    $ cd topst-vcp
    ```

<p align="center"><strong>圖 5.3 切換至複製後的目錄</strong></p>

現在您的電腦上已有一份 TOPST-VCP 原始碼的本機副本，可供建置與開發使用。

<br/><br/>

## 5.2 熟悉原始碼結構

複製之後，先熟悉原始碼的目錄結構與內容會很有幫助。這能讓您更清楚特定檔案所在的位置，以及程式碼庫的組織方式。

- 請使用 ls 之類的命令列出目錄的內容。
- 探索主要的目錄與檔案，以了解它們的用途與功能。

```
$ ls -al
```
