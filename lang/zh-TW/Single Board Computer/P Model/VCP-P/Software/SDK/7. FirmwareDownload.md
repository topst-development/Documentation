# 7. 下載至 TOPST VCP 硬體

將建置完成的軟體傳輸至 TOPST-VCP 開發板是開發流程中的重要步驟。本章提供完整指南，說明如何在 Linux 開發環境中將軟體下載至 VCP 硬體。

<br/><br/>

## 7.1 硬體準備

在開始下載程序之前，請確認 TOPST-VCP 開發板放置穩固且不受任何可能的干擾。請確認所有開關與接頭皆易於操作，且 3.3v 電源線已正確連接。

<br/><br/>

## 7.2 將硬體連接至開發主機 PC

1. **USB C 排線連接：** 請使用 USB C 排線將 TOPST-VCP 開發板連接至您的開發主機 PC。
2. **確認連線**：請在您的 Linux 電腦上執行下列指令

    ```
    $ sudo dmesg | grep tty
    ```

## 7.3 傳輸建置完成的軟體

1. **將開發板設定為下載模式：** 請在 TOPST-VCP 開發板上，將 FWDN 開關切換至 FWDN 位置。按下 PORN 按鈕使其重置。此時開發板即進入 FWDN 下載模式。

2. **執行下載指令**：請使用 FWDN 工具，將適用於 4MB flash 的軟體下載至開發板

    ```
    $ sudo ../../../tools/fwdn_vcp/fwdn --fwdn ../../../tools/fwdn_vcp/vcp_fwdn.rom -w output\tcc70xx_pflash_boot_4M_ECC.rom
    ```

3. **重置開發板：** 下載程序完成後，請將 FWDN 開關切回 NORMAL 位置。請重新開啟電源或按下 PORN 按鈕以重置開發板。

## 7.4 驗證開發板上的軟體

軟體下載至開發板後，務必驗證其是否正確運作：

1. **安裝 minicom**  
    ```
    $ sudo apt install minicom
    ```
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/20a8f4ad-68da-472d-8b56-7a8fffad0643"></p>
<p align="center"><strong>圖 7.5 安裝 Minicom</strong></p>

2.  **開啟序列連線**：請使用下列指令建立序列連線

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

3. **現在您可以在終端機上看到下列結果**：若連線成功，您應該能夠與開發板互動並觀察其回應。這表示軟體已下載完成，並在 TOPST-VCP 開發板上正確運作。

## 7.5 常見問題排除

即使準備得再周全，您在下載過程中仍可能偶爾遇到問題。以下提供一些常見問題的解決方式：

**問題：** fwdn 工具回報沒有權限存取 ttyUSB0 裝置。

**解決方式**：此問題發生於您的使用者帳號沒有存取序列裝置所需的權限。您可以將該帳號加入 dialout 群組，以授予這些權限。

1. **修改使用者群組權限**：請執行下列指令

    ```
    $ sudo usermod -aG dialout $USER
    ```
<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/a7552057-86de-4c49-876d-d50435bd16e4">
</p>
<p align="center"><strong>圖 7.8 修改使用者群組權限</strong></p>


2. **登出後重新登入**：群組變更需要先登出目前的工作階段再重新登入才會生效。完成後，請再次嘗試存取 ttyUSB0 裝置

請記得，您遇到的大多數問題都有解決方式或替代做法。當有疑問時，務必理解錯誤訊息，並查閱文件或請教線上社群。

**問題**：使用 minicom 時，與 TOPST-VCP 開發板之間無法正常通訊或出現異常行為。

**解決方式**：此問題可能是因為 minicom 的預設流量控制設定為 hardware。若要與 TOPST-VCP 開發板順暢通訊，您必須將流量控制設定為「none」。


1. **啟動 minicom：**

    請直接輸入下列指令啟動 minicom 工具：

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/7f8fd60c-eb59-474e-99f2-a5ab9cc6abc8">
</p>
<p align="center"><strong>圖 7.9 啟動 minicom</strong></p>

2. **進入設定畫面：** 在 minicom 中，請按下 Ctrl-A 後再按 “o” 以進入設定畫面。

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/79fa7579-374f-4714-9490-3a1d3fe40a70">
</p>
<p align="center"><strong>圖 7.10 進入設定畫面</strong></p>

3. **前往 Serial Port Setup**：請從選項清單中選擇「Serial port setup」
4. **修改流量控制：** 在 serial port setup 中，請按下 “ F” 將硬體流量控制切換為「No」。

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/9c4ac77c-1e19-4bee-a0f3-f3ad6f3b3791">
</p>
<p align="center"><strong>圖 7.11 修改流量控制</strong></p>

5. **離開並儲存**：完成後，請離開設定畫面並儲存設定。此時 minicom 應可與 TOPST-VCP 開發板正常通訊。
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/e9c61695-1637-470c-b91f-34ddeff4a923"></p>
<p align="center"><strong>圖 7.12 離開並儲存</strong></p>

**註**：若您使用 minicom 以外的其他序列通訊工具，請同樣將其流量控制設定為「none」以確保正確運作。
