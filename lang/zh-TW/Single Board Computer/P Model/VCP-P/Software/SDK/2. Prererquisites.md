# 2. 事前準備

在開始進行 TOPST-VCP 開發板的設定與開發流程之前，有幾項事前準備需要考量。本章將引導您瞭解建議的 Linux 發行版、硬體需求，以及確保開發過程順利所需的基礎知識。

<br/><br/>

## 2.1 Linux 發行版建議

在本指南中，我們建議您在 **Ubuntu 22.04** 上建置開發環境。此版本的 Ubuntu 提供穩定的平台與廣泛的社群支援，可確保與 TOPST- VCP 開發板及相關工具鏈的相容性與易用性。

下載與安裝：

- 請造訪 Ubuntu 官方網站，下載 Ubuntu 22.04 LTS（長期支援）發行版。
- 請依照所提供的安裝指引，在您的開發主機 PC 上安裝 Ubuntu 22.04。

## 2.2 硬體需求

若要與 TOPST-VCP 開發板連接並執行開發作業，下列硬體元件不可或缺：

- TOPST-VCP 開發板：請確認您手邊已備妥開發板，最好置於便於進行硬體操作的工作環境中。
- USB-C 傳輸線：用於連接您的開發主機 PC 與 TOPST-VCP 開發板。請確保傳輸線品質良好，以在整個開發過程中維持穩定的連接。

備妥必要的硬體後，請使用 USB-C 傳輸線將 TOPST-VCP 開發板連接至您的開發主機 PC。請確認連接穩固，以避免開發過程中發生任何中斷。

<br/><br/>

## 2.3 知識需求

開始之前，請務必先熟悉下列概念：

- Ubuntu 基礎：對於如何在 Ubuntu 22.04 環境中瀏覽與操作的基本瞭解。
- TOPST-VCP 的開機模式：TOPST-VCP 開發板提供多種開機模式，開發人員可依專案需求選擇最合適的模式。

關於如何選擇開機模式的詳細說明，會隨開發板一併提供。請務必參閱所提供的文件，並依您的開發需求選擇適當的模式
