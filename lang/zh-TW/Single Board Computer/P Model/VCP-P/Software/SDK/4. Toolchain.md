# 4. 工具鏈

工具鏈是開發流程中的關鍵組成，在使用 TOPST-VCP 開發板這類特殊硬體時尤其重要。它提供一整套工具，讓開發者能夠針對目標平台編譯、連結並除錯自己的程式碼。

<br/><br/>

## 4.1 工具鏈概觀

工具鏈通常由編譯器、連結器、組譯器與除錯器等工具組成。這些元件相互搭配，將原始程式碼轉換為可在目標硬體上執行的可執行程式。由於硬體架構與平台種類繁多，因此針對目標開發板選擇並設定合適的工具鏈相當重要

<br/><br/>

## 4.2 為開發板選擇工具鏈

TOPST-VCP 開發板以 ARM Cortex-R5 架構為基礎，建議使用的工具鏈為 gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi。

此工具鏈已針對 ARM 架構最佳化，並確保與開發板上的 TCC7045 晶片相容。

<br/><br/>

## 4.3 安裝與設定工具鏈

請依照下列步驟下載、解壓縮並設定工具鏈：

1. **下載工具鏈**：請使用 wget 指令從 Linaro 網站下載工具鏈：

    ```
    $ wget https://releases.linaro.org/components/toolchain/binaries/7.2-2017.11/arm-eabi/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```

2. **解壓縮工具鏈**：下載完成後，請解開 .tar.xz 檔案的內容。

    ```
    $ tar -xvf gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```

3. **將工具鏈移至 /opt**：/opt 目錄是 Linux 上放置選用軟體的標準位置。請將解壓縮後的工具鏈移至此目錄。

    ```
    $ sudo mv gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi /opt/
    ```

## 4.4 驗證工具鏈安裝

若要確認工具鏈已正確安裝：

1. **切換至工具鏈目錄**：

    ```
    $ cd /opt/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi
    ```

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/466c6ed7-4105-4cbd-9652-401bb18c7e56">
</p>
<p align="center"><strong>圖 4.4 切換至工具鏈目錄</strong></p>

2. **檢查已安裝的 GCC 編譯器版本**：
    
    ```
    $ ./bin/arm-eabi-gcc --version
    ```

若安裝成功，您應該會看到已安裝 GCC 的版本資訊，確認其與 gcc-linaro-7.2.1-2017.11 版本一致。
