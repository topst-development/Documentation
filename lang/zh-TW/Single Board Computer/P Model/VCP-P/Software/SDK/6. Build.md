#  6. 建置原始碼

成功取得原始碼後，下一個關鍵步驟就是進行建置，確保其能在 TOPST-VCP 開發板上以最佳狀態執行。

<br/><br/>

## 6.1 認識 Makefile 與建置系統

Makefile 是許多建置系統的基石。它包含各項規則與指令，用來告訴 make 工具如何編譯與連結程式。透過運用 Makefile，開發人員可以自動化建置流程，確保一致性與效率。

<br/><br/>

## 6.2 啟動建置流程

若要開始建置原始碼，請依照下列步驟：

1. **請使用下列指令切換至建置目錄：**

    ```
    $ cd build/tcc70xx/gcc/
    ```

2. **請使用下列指令執行 make 指令：**

    ```
    $ make
    ```

此指令會讀取目前目錄中的 Makefile 並執行建置流程。

3. **驗證建置輸出**：建置流程完成後，您應該會在終端機上看到下列輸出檔案
    - output/tcc70xx_pflash_boot.rom
    - output/tcc70xx_pflash_boot_2M_ECC.rom
    - output/tcc70xx_pflash_boot_3M_ECC.rom
    - output/tcc70xx_pflash_boot_4M_ECC.rom

    請確認這些檔案存在，因為它們對後續的開發階段至關重要。
