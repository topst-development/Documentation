# 1. 簡介

<br/><br/>

## 1.1 本指南的目的  

本指南旨在全面說明如何在 Linux 系統上為 TOPST-VCP 開發板建置軟體開發環境。依照本文件所述步驟操作，開發者將具備必要的工具、設定與知識，以有效地使用 TOPST-VCP 開發板及其相關工具鏈。

<br/><br/>

## 1.2 TOPST VCP 開發板概觀  

TOPST-VCP 開發板是一款功能強大且用途廣泛的開發板，專為多種應用量身打造。開發板的核心是採用 ARM Cortex-R5 架構的 TCC7045 晶片。此組合兼顧效率與效能，是希望運用 ARM 架構應用效能的開發者的首選。

## 1.3 工具鏈概觀  

若要在 TOPST-VCP 開發板上進行有效的開發，具備合適的工具鏈至關重要。本指南特別建議使用 gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi 進行交叉編譯。此工具鏈不僅相容於 ARM Cortex-R5 架構，也提供一套針對 TCC7045 晶片最佳化的工具。
