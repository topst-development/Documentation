# 1. TOPST VCP Arduino 簡介 

歡迎使用 TOPST VCP Arduino 專案！本儲存庫致力於為 TOPST VCP 建立 Arduino 軟體套件，其以 Telechips TCC7045 這款先進的車用控制處理器（VCP）為基礎。我們的目標是提供一個兼具 Arduino 簡易性與彈性的開發環境，並專為車用半導體量身打造。

<br/><br/>

## 1.1 關於 TOPST VCP 
TOPST VCP 是專為車用應用設計的強大且高效率處理器。透過與 Arduino 環境整合，我們期望簡化並加速車用領域的開發流程。

<br/><br/>

## 1.2 專案組成 
本專案由三個主要部分組成：
1. **TOPST VCP Bootloader for Arduino**：可讓 Arduino sketch 在 TOPST VCP 上執行的自訂啟動載入程式。
2. **Arduino Core**：經過修改以支援 TOPST VCP 的 Arduino 核心軟體。
3. **Libraries Ported to TOPST VCP**：一組經過調整的函式庫，可在各種應用中充分發揮 TOPST VCP 的能力。

<br/><br/>

## 1.3 開發環境 
TOPST VCP Arduino 專案讓開發人員能在熟悉的 Arduino 整合開發環境（IDE）中撰寫軟體，並直接在 TOPST VCP 上執行。此方式簡化了開發流程，讓更廣泛的開發人員都能輕鬆上手。

<br/><br/>
