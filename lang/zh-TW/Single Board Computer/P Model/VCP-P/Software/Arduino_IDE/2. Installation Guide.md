# 2. TOPST VCP Arduino Core 安裝指南

本指南將協助您下載並安裝 TOPST VCP Arduino core，以搭配 Arduino 整合開發環境（IDE）使用。

<br/><br/>

## 2.1 安裝指南

### 步驟 1：下載 Arduino IDE

首先，您需要 Arduino IDE，它是為 Arduino 開發板撰寫程式的平台。

- 請造訪 Arduino 官方網站：[Arduino Software](https://www.arduino.cc/en/software)
- 請選擇適合您作業系統（Windows、macOS、Linux）的版本。
- 下載並執行安裝程式。

<br/>

### 步驟 2：安裝 Arduino IDE

請依照您的作業系統，按下列步驟安裝 Arduino IDE：

#### Windows：
1. 執行下載的 `.exe` 檔案。
2. 依照安裝提示進行。請確認已安裝所有必要的驅動程式。

#### macOS：
1. 開啟 `.dmg` 檔案。
2. 將 Arduino 應用程式拖曳至您的「應用程式」資料夾。

#### Linux：
1. 解壓縮 `.tar.xz` 檔案。
2. 在解壓縮後的目錄中開啟終端機。
3. 執行 `./install.sh` 進行安裝。

<br/>

### 步驟 3：新增 TOPST VCP 開發板

若要為 TOPST VCP 開發板撰寫程式，您需要透過 Board Manager 將其核心加入 Arduino IDE。

1. 開啟 Arduino IDE。
2. 前往 **File > Preferences**。
3. 在「Additional Board Manager URLs」欄位中，加入下列 TOPST VCP 核心的 URL：

    ```
    https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
    ```

    （註：請將上方的 URL 替換為 TOPST VCP 核心實際提供的 URL。）
4. 按一下「OK」以儲存變更。
5. 前往 **Tools > Board > Boards Manager**。
6. 在 Boards Manager 中搜尋「TOPST VCP」。
7. 當 TOPST VCP 項目出現時，請按一下「Install」。

<br/>

### 步驟 4：選擇 TOPST VCP 開發板

安裝完成後，您需要選擇 TOPST VCP 開發板：

1. 前往 **Tools > Board**。
2. 向下捲動找到「TOPST VCP」並選取。

<br/>

### 步驟 5：驗證安裝

請上傳一個簡單的 sketch，測試您的設定是否正常運作：

1. 透過 USB 將 TOPST VCP 開發板連接至您的 PC。
2. 在 **Tools > Port** 下選擇對應的連接埠。
3. 開啟 **File > Examples > 01.Basics > Blink**。
4. 按下 **Upload** 按鈕，將 sketch 傳輸至開發板。
5. 若板載 LED 開始閃爍，表示開發板已正確設定。

<br/><br/>

## 2.2 疑難排解

若您在設定過程中遇到任何問題，可參考 [Arduino Troubleshooting Guide](https://www.arduino.cc/en/Guide/Troubleshooting)。


如需更多資訊與進階功能，請參閱 TOPST VCP 文件，或造訪 [Arduino Help Center](https://support.arduino.cc/hc/en-us)。
