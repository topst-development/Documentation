# 3. TOPST VCP Arduino 開發板管理員

本儲存庫提供 TOPST VCP 的 Arduino Board Manager。此開發板管理員可讓使用者輕鬆地在 Arduino IDE 中加入對 TOPST VCP 開發板的支援，以便使用熟悉的工具撰寫並上傳程式。

<br/><br/>

## 3.1 功能特色

- 可輕鬆安裝 TOPST VCP 的開發板定義。
- 相容於 Arduino IDE。
- 支援所有主要的 TOPST VCP 開發板型號。

<br/><br/>

## 3.2 安裝

若要在 Arduino IDE 中安裝 TOPST VCP 開發板管理員，請依照下列步驟操作：

1. 請以 **系統管理員權限執行** 的方式開啟 Arduino IDE。
2. 前往 `File > Preferences`。
3. 在「Additional Board Manager URLs」欄位中加入下列 URL：
   ```
   https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
   ```
   若此欄位中已有其他 URL，請以逗號分隔。

4. 按一下「OK」以儲存偏好設定。
5. 前往 `Tools > Board > Boards Manager...`。
6. 在 Boards Manager 中搜尋「TOPST VCP」。
7. 按一下 TOPST VCP 項目旁的「Install」。

<br/><br/>

## 3.3 使用方式

安裝完成後，您可以在 Arduino IDE 的 `Tools > Board` 選單中選擇您的 TOPST VCP 開發板。請選擇與您硬體相符的開發板，接著即可如常撰寫並上傳您的 sketch。
