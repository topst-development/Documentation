# 3. 開機模式（SW2）


TOPST VCP 具有一支用於開機設定的接腳，透過 Boot Mode（BM）支援 2 種模式：  
UART 開機模式與一般模式。

滑動開關（SW2）用於選擇 TOPST VCP 的開機模式。

## 3.1 UART 開機模式
此模式主要用於韌體下載（**FWDN**）模式。
在此模式下，您可以透過 UART 連接埠將程式下載至使用者定義的區域。
