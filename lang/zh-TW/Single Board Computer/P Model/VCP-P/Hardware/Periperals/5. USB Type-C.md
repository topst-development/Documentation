# 5. 用於除錯與 FWDN 的連接器 (JC1)  


在 TOPST VCP 上，JC1 用於透過 UART 進行除錯或 FWDN。  
此為標準的 USB Type-C 連接器。  

圖 5.1 顯示 JC1 的位置。  
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/8b19656c-59d5-4389-87f3-4939bf501587"></p>  
<p align="center"><strong>圖 5.1 USB Type-C 連接器</strong></p>  

您可以透過 JC1 執行 FWDN，或檢查 TCC7045 的除錯訊息。  
在 TOPST VCP 上，JC1 設計有 USB 轉 UART 橋接控制器，您可以使用 USB Type-C 傳輸線將 JC1 直接連接至 PC。
