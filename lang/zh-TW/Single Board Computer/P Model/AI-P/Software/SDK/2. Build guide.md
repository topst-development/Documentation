# 2. 建置指南

<br/><br/>

## 2.1 TOPST AI SDK

TOPST AI SDK 以 Yocto Project 4.0 kirkstone 為基礎。 
因此，若要使用 TOPST AI SDK，必須在主機 PC 上設定 Yocto Project 環境。 
若要下載 SDK、source-mirror 與 tools，必須先安裝相關公用程式。

您可以依據 metadata 從上游下載原始碼並執行建置。
建置完成後，會提供 package、image 與 SDK 作為產出結果。
圖 2.1 顯示 Yocto Project 的工作流程。
