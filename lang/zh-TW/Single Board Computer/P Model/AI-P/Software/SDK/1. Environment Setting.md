# 1. 環境設定 

<br/><br/>


## 1.1 安裝 Ubuntu

由於 TOPST AI Linux SDK 以 Yocto Project 為基礎，TOPST AI SDK 的 Linux 版本會依循 Yocto Project。

您可以安裝其他版本的 Linux，但本文件是以 Ubuntu 22.04 為基礎來說明 TOPST AI Linux SDK。

Linux 發行版本：

- Ubuntu 22.04 (LTS)

<br/><br/>

## 1.2 安裝 WSL2 Ubuntu 

1. 以「以系統管理員身分執行」的方式啟動 Windows PowerShell
2. 啟用 WSL2 系統。
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. 啟用虛擬機器功能。
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. 將 WSL 2 設為預設版本
    ```
    wsl --set-default-version 2
    ```
5. 在 Microsoft Store 中搜尋 Ubuntu 22.04.3 LTS 並下載。

    * 若您需要下載 Linux 核心更新套件，請由[此處](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)下載最新套件。


<br/><br/>

## 1.3 設定 Linux 環境

<br/>

### 1.3.1 安裝 SSH 與 Samba 

在 Linux 環境中作業速度較慢，但您可以使用 SSH 與 Samba，
在更為便利的環境中工作。SSH 與

Samba 可讓您在遠端電腦上執行指令，並將檔案複製
到其他電腦。

若已安裝 SSH 與 Samba，或您不打算使用它們，則可
略過本章。

```
 $ sudo apt-get install -y net-tools openssh-server samba 
```

下載 SSH 與 Samba 之後，您應將各程式設定為符合您的
環境。

<br/>

### 1.3.2 安裝 Yocto Project 所需的公用程式 

請一次安裝所有公用程式。若要使用 Yocto Project，下列
公用程式必須安裝於主機 PC（個人電腦或

開發伺服器）上。

```
$ sudo apt-get install -y gawk wget git-core diffstat unzip texinfo gcc-multilib
$ sudo apt-get install -y build-essential chrpath socat cpio python3 python3-pip python3-pexpect
$ sudo apt-get install -y xz-utils debianutils iputils-ping python3-git python3-jinja2 libegl1-mesa libsdl1.2-dev pylint xterm

```

<br/>

### 1.3.3 安裝 Repo

您可以透過 Repo 下載 TOPST AI SDK。

若要安裝 repo，請參考下列網站：
<https://source.android.com/source/downloading.html>

若 repo 已安裝，則無須重新安裝即可使用。

在安裝 repo 之前，應正確設定已安裝的 Python 版本（3.6 或以上）。

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
$ sudo apt-get install repo
```

<br/>

若發生 repo 錯誤，請下載最新版本並直接放入 /usr/bin/ 目錄中。

```
$ mkdir -p ~/bin
$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo &gt;~/bin/repo
$ chmod a+x ~/bin/repo
$ sudo mv ~/bin/repo /usr/bin/repo
```
