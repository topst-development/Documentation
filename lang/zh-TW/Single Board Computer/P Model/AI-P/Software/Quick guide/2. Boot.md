# 2. 開機指南

本章說明如何啟動 TOPST AI，以及如何登入
各個核心。

<br/><br/>

## 2.1 開機順序

開機順序如下：

1.  連接 MIPI 介面面板。
2.  連接 MIPI 介面相機模組。
3.  將 USB C to A 纜線連接至除錯連接埠。
4.  連接 5V 電源。

## 2.2 使用 UART 連接 TOPST AI

若要進行 USB 除錯並開發 Linux 環境，您可以使用下方所示開發板上的 TOPST AI 除錯連接埠存取核心（CA53）。
請安裝 UART Bridge VCP 驅動程式（可於
https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads)
取得），安裝於主機 PC 上。
之後，當您將 UART 連接至 TOPST 除錯板時，CP210x USB to UART 驅動程式會設定如下。

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20Boot.image2.png?raw=true"
style="width:4.11111in;height:4.02083in"</p>
<p align="center"><strong>圖 2.2 Windows 環境中的 USB 連接</strong></p>

請使用主機 PC 上的終端機模擬器連接 UART 連接埠。
下方所示為連接至核心後開機的日誌畫面。

<br/>

**範例**

- 終端機模擬器：PuTTY 或 mobaXterm
- 速率：115200 bps
- 資料位元：8
- 同位檢查：None
- 停止位元：1
- 流量控制：None
