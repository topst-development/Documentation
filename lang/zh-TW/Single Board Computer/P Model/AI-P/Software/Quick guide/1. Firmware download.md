# 1. FWDN 指南

本章說明如何將韌體下載工具（Firmware Downloader，FWDN）下載至
TOPST AI。

TOPST AI 透過乙太網路與 UART 提供 FWDN 功能。在 FWDN
模式下，BL0（Chipboot ROM）會透過 UART 從主機載入下一階段的韌體（BL1）
（由 BL1 進行初始化）。接著再次透過 UART 初始化 DRAM，並將支援
FWDN 乙太網路的 FWDN F/W 載入 DRAM。FWDN F/W 會以 TCP/IP 或 UDP 與主機
建立連線，並執行 FWDN 功能（例如將資料寫入
儲存裝置、從儲存裝置讀取資料等）。

## 1.1 韌體下載流程

FWDN 的下載流程如下：

1.  進入 FWDN 模式（請參閱 TOPST-AI/Hardware/Overview/4.Firmware Download）。
2.  將 USB C-to-A 傳輸線連接至 USB C 型 FWDN 連接埠。
3.  將乙太網路線連接至乙太網路連接埠。
4.  下載 TOPST AI 映像檔。

<br/><br/>

## 1.2 進入 FWDN 模式 

按住 FWDN KEY（FWDN 模式切換）並接上電源，即可進入
FWDN 模式。或者，若電源已接上，可先按住 FWDN KEY
（FWDN 模式切換），再按下 RESET KEY（系統重置）以進入
FWDN 模式。
