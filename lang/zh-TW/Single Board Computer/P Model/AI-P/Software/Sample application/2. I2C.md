# 2. I2C 範例

積體電路匯流排（I2C）常被讀作「i-to-c」，但正式的唸法是「i-square-c」。

I2C 通訊由一條用於傳送與接收資料的 SDA 訊號線，
以及一條用於同步傳送與接收時序的 SCL 時脈線所組成。
它由一個主控端與一個或多個從屬端構成，
最多可連接 127 個從屬端。

- I2C 通訊是使用兩條訊號線的通訊方式
- 將多個從屬裝置連接至單一主控端的優點與缺點
  - 由於是使用時脈訊號的同步通訊方式，具有不受時序限制的優點
  - 缺點是選擇從屬端時一律附加位址資料，因此不適合傳輸長資料

2.  下圖說明如何將麵包板接線，以搭配
    i2c_example_app 使用。

    - 使用的感測器模組為 PCF8591。PCF8591 是 8 位元類比轉數位或 8 位元數位轉類比的轉換模組，意即每一支腳位最多可讀取 256 階的類比值。

3.  執行 i2c_example_app 時，會取得亮度數值。

    ```
     root@telechips-tcc7500-main:~# ./i2c_example_app
     Target is 144.
    ```

4.  若您以手遮住模組後再執行，數值會增加。

    ```
    root@telechips-tcc7500-main:~# ./i2c_example_app
    Target is 228.
    ```
