# 1. GPIO 範例

GPIO（general-purpose input/output，通用輸入／輸出）是積體電路或
電路板上的數位訊號腳位，可讓使用者在執行期間
控制其運作方式，包括輸入或
輸出。
GPIO 並未預先定義為特定用途，在預設情況下
也不會被使用。
GPIO 由組裝層級的電路網路設計者實作
（積體電路 GPIO 由電路板設計者負責，基板層級 GPIO 則由系統
整合商 S/I 負責），其用途與行為會在使用時
加以定義。

GPIO 所執行的功能可能會因系統而異，一般提供的功能如下。

- 輸入／輸出功能（high=1、low=0）
- IRQ 訊號偵測：也可用於在電源管理模式下喚醒處於
  暫停狀態的系統。
  - 即使 Spinlock 卡住時仍可存取

上述功能可讓您使用寫入保護、控制
  LED、啟用收發器設定、硬體看門狗功能，或是
  開關偵測。

以下是測試開發板輸入與輸出的範例。您可以參考
  Raspberry Pi 腳位圖，透過控制腳位編號來測試
  輸入與輸出。

<br/>

**範例**

```
$ echo "90" > /sys/class/gpio/export
$ echo "out" > /sys/class/gpio/gpio90/direction
$ echo 1 > /sys/class/gpio/gpio90/value
$ echo 0 > /sys/class/gpio/gpio90/value
```
