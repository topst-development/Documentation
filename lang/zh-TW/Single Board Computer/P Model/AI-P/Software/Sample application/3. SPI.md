# 3. SPI 範例

Serial Peripheral Interface（SPI）與 I2C、CAN、UART 相同，
是一種序列通訊（serial communication）方式，
用於在微控制器、移位暫存器、SD 卡等小型週邊裝置之間
傳輸資料。簡單來說，它是裝置與裝置之間，
也就是晶片（IC）與晶片之間交換資料的通訊方式之一。
SPI 通訊屬於同步通訊方式，支援一對多通訊，
其缺點在於進行多重通訊時需要較多的訊號線。
此外，SPI 可以同時進行傳送與接收。由於接線容易，
因此常用於簡單感測器與記憶體等晶片之間的
通訊。
