# 4. 建置指南

<br/><br/>

## 4.1 轉換器（Converter）

Converter 會讀取神經網路檔案，並將其轉換為 ”bin”
檔案，此為 TOPST AI NPU SW Toolkit 所使用的網路檔案格式。
此外，它也會執行網路推論並收集啟動值資料的統計
資訊，這些資訊之後會用於網路量化。

<br/>

<strong>1.  Darknet</strong>

```
$ python ./EnlightSDK/converter.py \
  ./input_networks/yolov4.cfg \
  --weight ./input_networks/yolov4.weights \
  --type obj \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/yolov4.enlight \
  --enable-track \
  --mean 0 0 0 \
  --std 1 1 1 \
  --num-class 90
```

## 4.2 量化器（Quantizer）

Quantizer 會將以浮點運算為基礎的原始網路模型，轉換為以
整數為基礎的（量化）網路。

<br/>

**1.  Darknet**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/yolov4.enlight \
  --output ./output_networks/yolov4_quantized.enlight
```

<br/>

**2.  TensorFlow Lite**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1.enlight \
  --output ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight
```

<br/>

**3.  ONNX**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/mb2-ssd-lite.enlight \
  --output ./output_networks/mb2-ssd-lite_quantized.enlight
```

<br/><br/>

## 4.3 編譯器（Compiler）

Compiler 會將量化後的神經網路編譯為 NPU 程式碼與網路參數，
以便在 TOPST NPU HW 上處理神經網路。

<br/>

**1.  Darknet**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/yolov4_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

**2.  TensorFlow Lite**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

**3.  ONNX**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/mb2-ssd-lite_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

產生的檔案會儲存於 “output_code/\<network_name\>”
目錄中。

Compiler 輸出檔案：

- npu_cmd.bin: TELECHIPS NPU 推論程式碼
- quantized_network.bin: 網路權重與偏差參數
- network.h: 後處理用的緩衝區大小與網路參數
- post_process.c: 後處理程式碼
- 其他檔案: 除錯資訊（僅供內部使用）

在神經網路應用程式中，“npu_cmd.bin” 與 “quantized_network.bin”
會透過 TELECHIPS NPU API 與 Linux 裝置驅動程式載入 DMA 緩衝區。
“network.h” 與 “post_process.c” 會如 Network Object Build 所述，建置為
網路物件檔 (.so)。
