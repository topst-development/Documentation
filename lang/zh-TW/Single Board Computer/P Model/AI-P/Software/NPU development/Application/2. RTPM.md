## 2.1 效能監控

Real-Time Performance Toolkit (RTPM) 是以 Python 開發的 GUI 工具，
可在 PC 環境中監控 TOPST AI 的輸出，
讓您檢視 CPU、NPU 與記憶體的效能資料。

<br/>

**表 2.1 RTPM 的效能資料清單：**

|   編號 |  效能資料            |                說明                    |
|--------|----------------------|----------------------------------------|
| 1      | Inference Time       | 各模型的推論時間 (ms)                  |
| 2      | NPU                  | 各模型的 NPU 使用率                    |
| 3      | FPS                  | 以 NPU 運算為基礎的 FPS 資訊           |
| 4      | CPU                  | CPU 使用率（500ms 週期）               |
| 5      | Memory               | 記憶體使用率（500ms 週期）             |

<br/>

## 2.2 Injection 模式

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image3.png?raw=true"></p>
<p align="center"><strong>圖 2.3 Injection 模式</strong></p>

Injection 模式是指 TOPST AI 開發板從 RTPM 接收影像，
接著在 TOPST AI 開發板上執行 NPU 推論，
並將結果回傳至 RTPM 的情境。

<br/><br/>

## 2.3 Projection 模式

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image4.png?raw=true"></p>
<p align="center"><strong>圖 2.4 Projection 模式</strong></p>

Projection 模式是指開發板透過攝影機接收影像，並將最終結果（含方框的合成影像）傳送至 RTPM 的情境。

### 2.4.3 執行 Projection 模式

1.  請在 input mode 中選擇 Camera (EVB)。

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image19.png?raw=true"></p>
<p align="center"><strong>圖 2.19 在 input mode 中選擇 Camera(EVB)</strong></p>

2.  請按下 start 按鈕。

3.  請在 TOPST AI 開發板上執行 tcnnapp projection 模式。

	```
	# tcnnapp -i camera -o rtpm
	```
 - **注意**：以 "-i camera" 選項執行命令時，輸入路徑會設為預設值 /dev/video0。請確認所連接的攝影機在 /dev/ 下被辨識為哪一個 video 裝置，若不是 /dev/video0，請改用 "-p /dev/video*" 選項執行。
