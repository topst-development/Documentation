# 2. D3-G 的開機模式
---
D3-G 支援三種開機模式：
- USB 開機模式（FWDN）
- eMMC 開機模式（GPIO_SD0 Group）  
- SNOR 與 eMMC 開機模式（選用）
 
圖 2.1 顯示 D3-G 上開機模式相關電阻的位置。這些電阻位於開發板底面。D3-G 預設固定為 eMMC 開機模式。若 eMMC 裝置中沒有開機映像檔，開機模式會自動切換為 USB 開機模式。

## 2.1 USB 開機模式（FWDN）
---
圖 2.2 顯示開機模式開關與 RESET 開關。USB 開機模式用於韌體更新。若要進入 FWDN 模式，需同時使用開機模式開關與 RESET 開關。上傳映像檔時建議使用此方式。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20D3-G/Hardware/Boot%20Mode%20Switch%20and%20RESET%20Switch%20for%20Entering%20FWDN%20Boot%20Mode.png" width="600"></p>
<p align="center"><strong>圖 2.2 進入 FWDN 開機模式的開機模式開關與 RESET 開關 </strong></p>
 
 
 
下列步驟說明進入 USB 開機模式的開關操作方式。
1. 供電後，RESET 開關上方的 LED 會亮起。
2. 按住開機模式開關。按下開機模式開關時，可看到開關上方的紅色 LED 亮起。請持續按住開關，讓 LED 保持亮起。
3. RESET 開關的 LED 預設為綠色。若按下 RESET 開關一次，綠色 LED 會熄滅後再次亮起。
4. 放開開機模式開關。

## 2.2 SNOR 與 eMMC 開機模式
---
SNOR 與 eMMC 開機模式為選用。若要使用此開機模式，開發板上必須裝有 SNOR IC，且開機模式電阻的表面黏著技術（SMT）配置必須變更。
