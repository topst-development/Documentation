# 2. 範例應用程式
---
本節說明 AI-G SDK 提供的三個範例／測試應用程式。每個應用程式都可協助使用者評估並運用 AI-G 的 AI 功能，涵蓋 NPU 推論測試與即時攝影機輸入等多種情境。
<br/><br/><br/>
 
## 2.1 tcnnapp
---
tcnnapp 是一個 AI 範例應用程式，示範如何在 AI-G 平台上使用 NPU 執行以影像為基礎的推論。它支援多種輸入／輸出模式，並展示如何運用 YOLOv5s 與 MobileNetv2 等預先訓練模型進行物件偵測。
<br/><br/>
 
### 使用案例 1. 基本的檔案對檔案推論
此案例示範如何對本機影像檔案執行推論，並將結果儲存為輸出檔案；此方式適合在不使用攝影機或顯示器硬體的情況下，進行基本功能測試與模型驗證。  
若要執行推論，請輸入下列指令：
```
$ tcnnapp -i file -p test.png -o file -P result.png
```
 
此指令會以輸入影像檔案（test.png）執行 tcnnapp，並將推論結果儲存至輸出檔案（result.png）。若您未指定模型，應用程式會自動使用預設的量化模型 YOLOv5s 與 MobileNetv2。

### 使用案例 2. 搭配攝影機與顯示器的即時推論
此案例示範如何搭配所連接的 MIPI CSI 攝影機與 MIPI DSI 顯示器使用 tcnnapp，以執行即時 AI 推論並將結果視覺化呈現。此應用程式會串流來自攝影機的即時視訊輸入，於 NPU 上使用預設的量化模型（YOLOv5s 與 MobileNetv2）執行即時推論，並將結果顯示於螢幕上。  
裝置連接方式如下：
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Available%20Applications/Figure%202.%20Device%20Connection.png" width="600"></p>
<p align="center"><strong>圖 2.2 AI-G 上的攝影機與顯示器連接 </strong></p><br/>
 
連接裝置後，請輸入下列指令：
```
$ tcnnapp -i camera -o display
```
此指令會以 CSI 攝影機作為輸入來源，開始執行即時推論。擷取到的視訊影格會送入 NPU，進行物件偵測與分類作業。
推論結果（例如邊界框、類別標籤與信心分數）會直接繪製於輸出影格上。
這些加註後的影格會即時顯示於 5 吋 DSI 顯示器上，讓您立即獲得視覺回饋。
 
除了視覺輸出之外，系統也會記錄 CPU 使用率、NPU 使用率與記憶體狀態等關鍵效能指標，您可透過序列主控台或遠端介面進行監控。

### 使用案例 3. 搭配攝影機與 RTPM 的即時推論
此案例示範如何搭配所連接的 MIPI CSI 攝影機作為輸入，並以即時效能監控（RTPM）作為輸出方式來使用 tcnnapp。此應用程式會串流來自攝影機的即時視訊輸入，於 NPU 上使用預設的量化模型（YOLOv5s 與 MobileNetv2）執行即時推論，並將結果透過 RTPM 傳送至 PC，以進行視覺化呈現與效能監控。  
RTPM 工具組是一套以 Python 開發的圖形介面工具，可在 PC 環境中監控 AI-G 的輸出。它讓您得以觀察推論結果，以及 CPU、NPU 與記憶體使用率等系統效能指標。  
 
**註**：如需 RTPM 的詳細資訊，請參閱 Software 章節中的 RTPM.md。
 
裝置連接方式如下：
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Available%20Applications/Figure%204.%20Camera%20and%20RTPM%20Communication%20via%20AI-G.png"width="900"></p>
<p align="center"><strong>圖 2.4 透過 AI-G 進行攝影機與 RTPM 的通訊 </strong></p><br/>

```
$ tcnnapp -i camera -o rtpm
```
 
此指令會以 CSI 攝影機作為輸入來源，開始執行即時推論。推論結果（例如偵測到的物件與分類標籤）會傳送至主機 PC，並透過 RTPM 介面進行視覺化呈現。  
除了推論輸出之外，RTPM 也會即時顯示 CPU 使用率、NPU 負載與記憶體使用率等系統效能指標。

### 使用案例 4. 以 RTPM 作為輸入與輸出的推論
此案例示範如何使用主機 PC 透過 RTPM 串流傳來的輸入影像執行推論，並將推論結果經由同一個 RTPM 介面回傳至 PC 顯示。輸入資料可以是影像或視訊。  
請參閱 Software 章節中的 RTPM.md 文件以執行 RTPM。接著，請輸入下列指令：
```
$ tcnnapp -i rtpm -o rtpm
```
此指令會以 RTPM 同時作為輸入與輸出來執行 tcnnapp。資料會由主機 PC 透過 RTPM 傳送，經 AI-G 開發板上的 NPU 處理後，推論結果會回傳至 PC，並透過 RTPM 介面顯示。

## 2.2 tcnncameraapp
---
tcnncameraapp 是一個範例應用程式，可讓您測試並預覽 AI-G 平台所支援的相機模組。它以 Video4Linux2（V4L2）框架建置，能透過所連接的 MIPI CSI 介面與 DSI 顯示器進行即時相機預覽。  
此應用程式主要用於驗證攝影機功能、測試顯示輸出，以及對影像訊號品質進行除錯。視相機模組型號而定，它也支援同時監看多部攝影機。  
tcnncameraapp 所提供的選項如下表所示。
 
| 名稱              | 選項    | 範圍      | 預設值      | 範例           | 說明                                  |
| ------------------| --------| ----------| ------------| ---------------| --------------------------------------|
| 使用說明資訊      | -?      |     -     |             | -?             | 顯示使用說明資訊                      |
| 輸入路徑          | -p      |     -     | /dev/video0 | -p /dev/video0 | 指定輸入路徑                          |
| 輸出路徑          | -P      |     -     | /dev/overlay| -P /dev/overlay| 指定輸出路徑                          |
| 輸入寬度          | -w      | 最高 2560 | 1920        | -w 2560        | 指定輸入的寬度                        |
| 輸入高度          | -h      | 最高 1440 | 1080        | -h 1080        | 指定輸入的高度                        |
| 輸出寬度          | -W      | 最高 1920 | 1920        | -W 1920        | 指定輸出的寬度                        |
| 輸出高度          | -H      | 最高  720 | 720         | -H 720         | 指定輸出的高度                        |
| 輸出位置 X        | -X      | 最高 1920 | 0           | -X 960         | 指定輸出的 X 座標                     |
| 輸出位置 Y        | -Y      | 最高  720 | 0           | -Y 360         | 指定輸出的 Y 座標                     |
<p align="center"><strong>表 2.1 攝影機測試應用程式選項</strong></p><br/>

## 2.3 tcnputestapp
---
tcnputestapp 是一個範例應用程式，用於驗證 AI-G 平台上類神經處理單元（NPU）的基本功能。它利用 tcndnpulib 函式庫，以預先編譯的類神經網路模型直接測試 NPU 的執行。此應用程式主要用於 NPU 的內部驗證、除錯與效能測試，過程中不需使用攝影機或顯示器。  
tcnputestapp 所提供的選項如下表所示。
 
| 名稱           | 選項   | 範圍      | 預設值      | 範例                     | 說明                                  |
| ---------------| -------| ----------| ------------| -------------------------| --------------------------------------|
| 使用說明資訊   | -?     |     -     |      -      | -?                       | 顯示使用說明資訊                      |
| NPU 編號       | -d     |    0, 1   |      0      | -d 0 / -d 1 / -d 0 1     | 指定網路所使用的 NPU 索引             |
| 網路路徑       | -n     |     -     | /usr/share/yolov5s_quantized| -n /usr/share/mobilenetv2_10_quantized/   | 指定要測試的類神經網路。若選擇兩個 NPU，兩者將使用相同的類神經網路路徑|
| 測試次數       | -t     | -         | 1           | -t 100                   | 指定類神經網路的測試次數|
