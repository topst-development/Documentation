# 2. AI-G 的開機模式
---
AI-G 支援下列開機模式： 
- USB 開機模式 (FWDN)  
- eMMC 開機模式 (GPIO_SD Group)

AI-G 開發板預設固定為 eMMC 開機模式。若 eMMC 裝置中沒有開機映像，開機模式會自動切換為 FWDN 開機模式。 

<br/><br/><br/>

## 2.1 USB 開機模式 (FWDN)
--- 
圖 2.1 顯示開機模式開關與 RESET 開關。USB 開機模式用於韌體更新。若要進入 FWDN 模式，必須同時使用開機模式開關與 RESET 開關。上傳映像時建議使用此方法。

<p align="center"><strong>圖 2.1 用於進入 FWDN 開機模式的開機模式開關與 RESET 開關 </strong></p><br/>

下列步驟說明進入 USB 開機模式的開關操作方式。 
1. 供電後，RESET 開關上方的 LED 會亮起。 
2. 請按住開機模式開關。按下開機模式開關時，您會看到開關上方的紅色 LED 亮起。請持續按住開關以維持 LED 亮起。 
3. RESET 開關的 LED 預設為綠色。若您按下 RESET 開關一次，綠色 LED 會先熄滅，然後再次亮起。 
4. 請放開開機模式開關。
