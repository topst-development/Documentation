---

# 2. 設定主機環境（Windows）
---
本章說明如何設定主機 PC 環境，並分別提供在 Windows PC 與 Ubuntu PC 上進行設定的指南。
<br><br/><br/>

## 2.1 Windows 環境
--- 
本文件說明如何設定 Windows Sub-system for Linux (WSL)，以在 Windows PC 上使用 Linux。
由於 AI-G Linux SDK 以 Yocto Project 為基礎，AI-G SDK 的 Linux 版本亦遵循 Yocto Project。
您可以安裝其他版本的 Linux，但本文件是以 Ubuntu 22.04 為基礎說明 AI-G Linux SDK。
若主機 OS 為 Ubuntu，請直接前往第 2.2 節。
</br><br/>

### 2.1.1 安裝 WSL2 Ubuntu（僅限 Windows 環境）

1. 以「**以系統管理員身分執行**」方式執行 Windows PowerShell
2. 啟用 WSL2 系統。
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. 啟用虛擬機器功能。
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. 將 WSL 的預設版本設定為 2 (WSL2)。
    ```
    wsl --set-default-version 2
    ```
5. 在 Microsoft Store 中搜尋 Ubuntu 22.04.3 LTS 並下載。

    * 若您需要下載 Linux 核心更新套件，請於[此處](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)下載最新的套件。

6. 安裝 Ubuntu 期間，您可以自行選擇任意使用者名稱。

<br/><br/>


### 2.1.2 透過 WSL2 存取 Ubuntu
請開啟 Windows 命令提示字元並輸入以下命令以存取 Ubuntu。存取 Ubuntu 時，預設會從 /mnt/c/Users/[user name] 目錄啟動。
```
wsl  // access ubuntu 
ls   // check contents in your directory
```
請參閱圖 2.1 確認結果（可能因使用者而異）。

### 2.1.3 設定語言環境

在 WSL 上執行 Ubuntu 後，您應設定語言環境以確保正確的語言與地區設定。建議使用 en_US.UTF-8。請執行以下命令以使用 en_US.UTF-8。 

```
sudo locale-gen en_US.UTF-8 && sudo update-locale LANG=en_US.UTF-8 
```

設定語言環境後，您可以使用以下命令檢查語言環境類型。 

```
echo 'LANG=en_US.UTF-8' | sudo tee -a /etc/default/locale && \  

echo 'LC_ALL=en_US.UTF-8' | sudo tee -a /etc/default/locale 
```
<br/><br/>

### 2.1.4 安裝 SSH 與 Samba 

進入 Ubuntu 後，您可以使用 SSH 與 Samba 等額外的工具程式，以取得更便利的開發環境。SSH 與 Samba 可讓您在遠端電腦上執行命令，並將檔案複製到其他電腦。
 - 以下步驟需要主機 PC 連接至網路。請使用以下命令檢查您的網路狀態：
  ```
  $ sudo apt-get update
  $ sudo apt-get install -y net-tools
  $ ifconfig 
  ```

若已安裝 SSH 與 Samba，或您不打算使用它們，可以略過本章。

請使用以下命令安裝 net-tools、SSH 與 Samba。

```
$ sudo apt-get update 
$ sudo apt install -y net-tools openssh-server samba
```


下載 SSH 與 Samba 後，您應依據您的環境設定各個程式。
<br/><br/>

### 2.1.5 安裝工具程式 

請一次安裝這些工具程式。若要使用 Yocto Project，主機 PC（個人電腦或開發伺服器）上必須安裝以下工具程式。

請使用以下命令安裝工具程式。

```
$ sudo apt-get install -y gawk wget git diffstat unzip texinfo gcc-multilib build-essential chrpath

$ sudo apt-get install -y socat cpio python3 python3-pip python3-pexpect xz-utils debianutils

$ sudo apt-get install -y iputils-ping python3-git python3-jinja2 libegl1-mesa-dev libsdl1.2-dev pylint

$ sudo apt-get install -y xterm zstd ncftp curl git-lfs vim zip lz4
```
<br/><br/>


### 2.1.6 安裝 Repo（選用）

您可以使用 ***Repo*** 下載 AI-G SDK。  
若要安裝 ***Repo***，請參閱以下網站：https://source.android.com/source/downloading.html。  
若已安裝 ***Repo***，您無須重新安裝即可使用。  
安裝 ***Repo*** 前，請確認已正確設定 Python 3.6 或更高版本。

請使用以下命令安裝 ***Repo***。
```
$ sudo apt-get install repo
```

若您看到錯誤訊息 '/usr/bin/env 'python' no such file or directory'，請使用以下命令讓檔案 'python' 指向 'python3'。

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
```
若發生 ***Repo*** 錯誤，請使用以下命令下載最新版本，並直接放入 /usr/bin/ 目錄。

```
$ mkdir -p ~/bin

$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo > ~/bin/repo

$ chmod a+x ~/bin/repo

$ sudo mv ~/bin/repo /usr/bin/repo
```
請前往**第 3 章：映像檔建置指南**。

# 3. 映像檔建置指南
---
本節以主機 PC 上安裝的 Ubuntu OS 為基礎提供指引（無論是 WSL 或本機安裝的 Ubuntu）。要上傳至 AI-G 的映像檔是使用 Yocto Project 建置，因此此流程必須在 Ubuntu 環境中進行。
<br/><br/><br/>

## 3.1 SDK 建置準備
---
AI-G SDK 以 Yocto Project 4.0 Kirkstone 為基礎。因此，若要使用 AI-G SDK，必須在主機 PC 上設定 Yocto Project 環境。若要下載 SDK、source-mirror 與工具，您必須安裝工具程式。為使映像檔建置順利進行，您的 PC 必須具備**至少 60 GB 的可用儲存空間**與**至少 16 GB 的記憶體**。

<br/><br/><br/>

## 3.2 Yocto Project
---
Yocto Project 是專注於嵌入式 Linux 開發的開放原始碼專案。 
它結合了 Open Embedded 專案的一部分 Poky 與 bitbake 作為建置系統，以製作 Linux 映像檔。 
透過 Yocto Project，您可以同時建置 bootloader、核心與 rootfs。 

<br/><br/><br/>

## 3.5 建置前準備
---
以下章節說明如何設定 Yocto Project 以建置 AI-G 映像檔。
<br/><br/>

### 3.5.1 在 .gitconfig 中設定使用者電子郵件與使用者名稱
若要從 TOPST 官方 git 下載 AI-G，請設定您的電子郵件與名稱。
1. 請輸入以下指令。
```
vi ~/.gitconfig
```
2. 請輸入以下資訊。
```
[user]
    email = User email
    name = User name
```
<br/><br/>

### 3.5.2 從 Git 取得 AI-G
1. 建立名為 **topst-sdk** 的新目錄，並將目前目錄切換至 **topst-sdk**。
```
$ mkdir topst-sdk
$ cd topst-sdk
```
2. 請執行以下指令以初始化儲存庫。

```
$ repo init -u https://github.com/topst-development/manifests.git -b release/1.3.0 -m linux_yp4.0_topst.xml

```

# 4. 韌體下載工具
---
本章說明如何將 ***FWDN*** 下載至 AI-G，並登入 Linux 主控台。  
***FWDN V8*** 是可在 Windows 10 或 11 64 位元與 Linux 環境中下載韌體的 PC 工具。本章說明在 Windows 與 Linux 環境中下載的情況。
<br/><br/><br/>

## 4.1 韌體下載流程
---
***FWDN*** 的下載流程如下：

1. 將開機模式切換開關設定為 USB 開機模式（FWDN 模式）。
2. 開啟 Windows 命令提示字元或 Linux 主控台，並測試 ***FWDN V8***。
3. 將 ***FWDN V8*** 連接至開發板。
4. 下載 fai 檔案。

<br/><br/><br/>

## 4.2 USB 開機模式（FWDN 模式） 
---
您可以使用 ***FWDN*** 將建置好的映像檔傳輸至 AI-G。AI-G 透過 Ethernet 與 UART 提供 ***FWDN***。 

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/Linux%20SDK/3.%20connect%20host%20pc%20to%20topst%20ai-g.png" ></p>
<p align="center"><strong>圖 4.1 主機 PC 與 AI-G 之間的 FWDN 連接</strong></p><br/>

若要使用 ***FWDN V8***，請依下列方式將 AI-G 開發板連接至主機 PC： 

1. 請確認主機 PC 已安裝 VTC 驅動程式。若尚未安裝 VTC 驅動程式，請依第 4.2.1 章所述進行安裝。  

2. 請準備一條 USB Type-C 傳輸線與一條 Ethernet 傳輸線。 

3. 若要進入 USB 開機模式，請將 USB Type-C 傳輸線連接至 AI-G 開發板上的 USB Type-C FWDN 連接埠與主機 PC。 

4. 請將 Ethernet 傳輸線（RJ45）連接至 AI-G 開發板上的 Ethernet 連接埠與主機 PC。 

5. 請在按住 FWDN 開關的同時，將電源線連接至 AI-G 開發板。 

<br/><br/><br/>

### 4.2.1 如何安裝 VCP 驅動程式

請以系統管理員身分執行，在主機 PC 上安裝 Vendor Telechips Certification (VTC) 驅動程式（可於 [VCP driver](https://drive.google.com/file/d/1muQnY8kuKxDsy3p3FUiQqcG34Zjk-mnR/view?usp=sharing) 取得）。當您如上所述在 FWDN 模式下連接 USB 時，Telechips VTC USB 驅動程式會如圖 4.2 所示完成設定。

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/Linux%20SDK/4.%20VTC.png" width="550"></p>
<p align="center"><strong>圖 4.2 確認 COM 連接埠</strong></p><br/>

<br/><br/>

### 4.2.2 設定 Ethernet

主機 PC 網路設定 

- 控制台 → 網路和網際網路 → 網路和共用中心 -> 變更介面卡設定 -> Ethernet 內容 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/Linux%20SDK/5.%20network_setting.png"></p>

## 4.3 如何執行 FWDN
---
在執行 ***FWDN*** 之前，您必須先將建置後產生的映像檔與 ***FWDN*** 工具從 Ubuntu (WSL2) 傳輸至 Windows 環境。 
若您使用 Ubuntu 主機，可略過以下步驟，直接前往第 4.3.2 章。

1. 解壓縮 "output_aig.fwdn.zip"
```
$ cd ~/topst-sdk
$ mkdir images
$ mv ./output_aig.fwdn.zip ./images 
$ cd images
$ unzip output_aig.fwdn.zip
```

2. 將 "images" 資料夾複製到 Windows C 磁碟機。 
```
$ cd ..
$ cp -r ./images /mnt/c/ 
```
以下步驟請依主機 PC 的作業系統參閱第 4.3.1 章或第 4.3.2 章。
<br/><br/>

3. 請執行 Windows PowerShell 並前往 “C:\images”。  
```
$ cd C:\images 
```

## 4.4. 使用 UART 連接 AI-G 開發板
--- 
請執行以下步驟，並透過 UART 連線確認韌體下載已成功完成。  

1. 請在 Windows 環境中安裝序列埠驅動程式（例如 CP210x Windows Driver）與 PL2303_prolific 驅動程式。
2. 請安裝終端機模擬器，例如 Tera Term 或 PuTTY。 
3. 請連接主機 PC 與 AI-G 開發板上的 UART 腳位。請使用 USB to TTL 傳輸線。 
4. 請將黑色線連接至 GND 腳位。 
5. 請將白色線（RXD）連接至 UART 腳位中的 TX 腳位，並將綠色線（TXD）連接至 UART 腳位中的 RX 腳位。
6. 請執行終端機模擬器應用程式。
7. 請開啟 PC 上的裝置管理員，確認 UART 所使用的連接埠編號。
8. 請將裝置管理員中確認的連接埠編號輸入終端機模擬器的 **Serial line** 欄位。將 **Speed** (bps) 設定為 115200，並將 **Flow control 設定為 None。**
9. 請連接電源線。接著 AI-G 會以預設的 eMMC 開機模式開機。
