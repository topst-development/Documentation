# 2. 開始使用
---
請依照下列步驟，在 AI-G 開發板上執行 Telechips Model Zoo 所提供的類神經網路模型。
<br/><br/><br/>

## 2.1 複製儲存庫
---
```
$ git clone https://github.com/telechips-ai/TCC750x-Model-Zoo.git

$ cd TCC750x-Model-Zoo
```
<br/><br/><br/>

## 2.2 將所需模型複製到 AI-G
---
請將整個模型資料夾（yolov5m）複製到 AI-G。
您可以直接沿用原資料夾名稱，或如下列範例所示，將其重新命名為 yolov5m_quantized，以符合先前釋出的類神經網路資料夾所使用的格式。
每個資料夾都包含必要的輸出檔案（.so、.bin 等）。

```
$ scp -r [network_output_folder] root@192.168.0.100:/path/to/target/
```
請將 **network_output_folder** 替換為實際的資料夾（例如 yolov5m/）。

您可以選擇 yolov5 模型。
```
$ cd Object_Detection/YOLO/yolov5/
$ ls 
README.md  yolov5l  yolov5m  yolov5n  yolov5s  yolov5x
```
接著執行：
```
$ scp -r yolov5m/ root@192.168.0.100:/home/root/
```
<br/><br/><br/>

## 2.3 使用 tcnputestapp 或 tcnnapp 執行模型：
---
接著請在目標開發板（AI-G）上執行下列指令：
```
$ tcnputestapp -d 0 1 -n [network_output_folder_path]
```
或 
```
$ tcnnapp -n [network_output_folder_path]
```
