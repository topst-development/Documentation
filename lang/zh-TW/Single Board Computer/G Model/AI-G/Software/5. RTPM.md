# 1. 簡介
---
即時效能監控（RTPM）工具組是一套以 Python 開發的圖形化應用程式，用於即時監控並視覺化呈現 AI-G 的效能指標。透過在 AI-G 開發板與主機 PC 之間建立連線，RTPM 可協助傳輸並分析關鍵效能資料，包括 CPU、NPU、記憶體使用率以及推論時間。
 
RTPM 以兩種不同的模式運作：
 
**Injection 模式（注入模式）**：在此模式下，主機 PC 會將影像資料傳送至 AI-G 進行處理。AI-G 使用其 NPU 執行推論，並將結果回傳至 PC 進行視覺化呈現。
 
**Projection 模式（投射模式）**：在此模式下，AI-G 透過所連接的相機模組擷取影像，於內部完成處理後，再將推論結果傳送至主機 PC 上的 RTPM。
 
本工具組特別適合欲評估並最佳化 AI-G 平台上 AI 應用程式效能的開發者與工程師使用。它能即時呈現系統行為的觀察資訊，協助有效率地進行除錯與效能調校。
 
如需詳細的設定步驟與使用指引，請參閱本文件後續章節。

## 2.1 效能監控
--- 
即時效能監控工具組（RTPM）是一套以 Python 開發的圖形介面工具，
可在 PC 環境中監控 AI-G 的輸出，
並讓您檢視 CPU、NPU 與記憶體的效能資料。
 
 
 
**表 2.1 RTPM 的效能資料清單：**
 
|   No   |  效能資料            |                說明                    |
|--------|----------------------|----------------------------------------|
| 1      | 推論時間             | 各模型的推論時間（ms）                 |
| 2      | NPU 使用率           | 各模型的 NPU 使用率                    |
| 3      | FPS                  | 依據 NPU 運作所得的 FPS 資訊           |
| 4      | CPU                  | CPU 使用率（500 ms 週期）              |
| 5      | 記憶體               | 記憶體使用率（500 ms 週期）            |

## 2.4 RTPM 應用程式啟動指南
---
本節提供在主機 PC 上設定即時效能監控（RTPM）應用程式的逐步說明。
內容包含工具安裝、工作區設定，以及如何執行 RTPM 介面以監控 AI-G 上的 NPU 效能與推論結果。

### 2.4.1 安裝 RTPM 所需工具
 
- 請準備主機 PC 環境。
 
1. 安裝 Visual Studio Code。
   * 請於 Microsoft Store 搜尋「Visual Studio Code」並進行安裝。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/5.%20Install%20Visual%20Studio%20Code.png"></p>

   2. 請點選左側邊欄的 Extensions 圖示，或按下 
   *Ctrl + Shift + X*，以開啟 Extensions 檢視。
   3. 於 Extensions 搜尋列輸入 Python。
   4. 找到由 Microsoft 提供的 Python 擴充功能，然後點選 Install。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/6.%20Install%20Python3.10.png"width="800"></p>

2.  選擇您要進行推論的影像資料夾。
 
    該影像資料夾中不應包含子資料夾。
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/14.%20Select%20the%20image%20folder.png"></p>

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/15.%20Image%20folder%20selected%20at%20rtpm.png"></p>
