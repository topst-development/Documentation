## 3.1 Converter
---
Converter 會讀取神經網路檔案，並將其轉換為 ”bin”
檔案，這是 AI-G NPU SW Toolkit 所使用的網路檔案格式。
它也會執行網路推論，並收集
activation 資料的統計值，這些統計值稍後會用於網路量化。

<strong>1.  Darknet</strong>
```
$ python ./EnlightSDK/converter.py \
  ./input_networks/yolov4.cfg \
  --weight ./input_networks/yolov4.weights \
  --type obj \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/yolov4.enlight \
  --enable-track \
  --mean 0 0 0 \
  --std 1 1 1 \
  --num-class 90
```

<strong>3.  ONNX</strong>

若您的 ONNX 模型包含不支援的運算子（例如 NonMaxSuppression），則需要使用此方法。

以下流程會使用 tc-nn-toolkit 命令列介面進行三個步驟的轉換。


首先，我們將 ONNX 模型轉換為 .enlight 格式。

```
$ python ./EnlightSDK/converter.py \
  ./input_networks/mb2-ssd-lite.onnx \
  --type obj \
  --add-detection-post-process ./input_networks/mb2-ssd-lite.anchor \
  --logistic softmax \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/mb2-ssd-lite.enlight \
  --enable-track \
  --mean 0.498 0.498 0.498 \
  --std 0.502 0.502 0.502 \
  --num-class 20 \
  --variance 0.1 0.2
```

接著，使用 --force-output 以中間層作為輸出來擷取模型，以移除不支援的運算子。

```
python ./EnlightSDK/converter.py \
            ./input_networks/mb2-ssd-lite.onnx \
            --type unknown \
            --output ./output_networks/mb2-ssd-lite_wo_box_decode_score.enlight \
            --dataset-root my_dataset_path \
            --force-output Concat_0___Concat Concat_1___Concat_1
```

最後，對擷取出的模型套用 anchor box、logistic activation 與類別設定等後處理選項，以產生最終的 .enlight 模型。

```
$ python ./EnlightSDK/converter.py \
  ./output_networks/mb2-ssd-lite_wo_box_decode_score.enlight \
  --type obj \
  --add-detection-post-process ./input_networks/mb2-ssd-lite.anchor \
  --logistic softmax \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/mb2-ssd-lite.enlight \
  --enable-track \
  --mean 0.498 0.498 0.498 \
  --std 0.502 0.502 0.502 \
  --num-class 20 \
  --variance 0.1 0.2
```

```
$ python ./EnlightSDK/quantizer.py \

  --output ./output_networks/mb2-ssd-lite_quantized.enlight
```

## 3.3 Compiler
---
Compiler 會將量化後的神經網路編譯為 NPU 程式碼與
網路參數，以在 AI-G NPU 硬體上處理神經網路。

**1.  Darknet**
```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/yolov4_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

**2.  TensorFlow Lite**
```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

**3.  ONNX**
```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/mb2-ssd-lite_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5

產生的檔案會儲存於 “output_code/\<network_name\>”
目錄中的 requirements.txt 檔案內。

Compiler 輸出檔案：
- npu_cmd.bin：Telechips NPU 的推論程式碼
- quantized_network.bin：網路權重與偏差參數
- network.h：後處理所需的緩衝區大小與網路參數
- post_process.c：後處理程式碼
- 其他檔案：除錯資訊（僅供內部使用）

在神經網路應用程式中，“npu_cmd.bin” 與 “quantized_network.bin”
會使用 Telechips NPU API 與 Linux 裝置驅動程式載入 DMA 緩衝區。
“network.h” 與 “post_process.c” 會如「網路物件建置」所述，建置為網路物件
檔案 (.so)。

## 3.4 網路物件建置
---
本章說明如何使用編譯完成的神經網路檔案建置
網路物件檔案。“build_network” 目錄包含
用於建置網路模型共用程式庫檔案 (.so) 的編譯環境，
此檔案會在 AI-G 中使用。

### 3.4.2 建置物件
請將編譯器輸出目錄複製到 “build_network” 目錄。  
在執行 make 指令之前，您必須先刪除 build_network 資料夾中既有的 post_process.c 與 network.h 檔案。  
接著，請從編譯完成的 <network_name>_quantized 目錄，為 network.h 與 post_process.c 檔案在 build_network 資料夾中建立符號連結。

```
$ cd build_network
$ cp ../output_code/<network_name>_quantized/ ./ -ar
$ rm -rf network.h post_process.c
$ ln -s ./<network_name>_quantized/network.h
$ ln -s ./<network_name>_quantized/post_process.c
$ make
$ cp ./net.so ./<network_name>_quantized/
$ ls -l <network_name>_quantized/
compile_debug.log
net.so
network.h
network_buf.txt
network_group_info.csv

      ㆍ
      ㆍ

# 5. NPU 相容運算子
---
本章介紹 NPU 所支援的運算子。以下清單列出與此平台相容的主要運算。
<br/><br/><br/>

## 5.1 AI-G NPU 支援的層類型
---
AI-G NPU 支援以下層類型。

**表 5.1 支援的層類型與規格：**

|        層類型       |                        規格                        |
|-------------------------|-------------------------------------------------------------|
| Convolution             | Kernel size：1x1 至 7x7<br/>Stride：1 至 4<br/>Padding：0 至 3 <br/>Dilation：1 至 4 |
| ConvTranspose           | Kernel size：2x2 至 3x3<br/>Stride：2<br/>Padding：0 至 1  |
| Depth-wise Convolution  | Kernel size：1x1 至 5x5<br/>Stride：1 至 2<br/>Padding：0 至 2|
| Activation Function     | Bypass<br/>ReLU<br/>ReLU6<br/>Leaky Relu <br/> Sigmoid <br/> Tanh <br/> Mish <br/> Swish <br/> Clip <br/> HardSwish <br/> HardSigmoid| 
| Max Pool 2D             | Kernel size：2x2 至 13x13<br/>Stride：1 至 2<br/>Padding：0 至 6| 
| Average Pool 2D         | Kernel 大小：2x2 至 19x19<br/>Stride：1 至 2<br/>Padding：0 至 6| 
| Global Average Pool     | 支援                                                        | 
| Element-wise Operation  | 加法：Scalar + Tensor, Vector + Tensor, Tensor + Tensor <br/>  乘法：Scalar * Tensor, Vector * Tensor, Tensor * Tensor                    |  
| Batch Normalization     | 支援                                                        |  
| Concatenation           | 僅限逐通道                                                  | 
| Slice                   | 支援                                                        |
| Split                   | 支援                                                        |

<br/><br/><br/>

## 5.2 PyTorch 運算子 (ONNX)
---
即使 AI-G NPU 不支援該運算子，只要該運算位於類神經網路的最後一層，仍可由 Host CPU 執行。

**註**：Single Shot MultiBox Detector (SSD) 網路的 Softmax 層是由 CPU 在後處理程式碼中處理。


|         運算子          |               專用 HW                  |    向量處理器          |
|-------------------------|----------------------------------------|------------------------|
| Conv                    | Kernel：1x1 至 7x7<br/>Padding：0 至 3<br/>Stride：1 至 4<br/>Dilation：1 至 4  | 
| Conv Transpose          |  Kernel：2x2 至 3x3<br/>Padding：0 至 1<br/>Stride：2<br/>Output_padding：0 至 1  |                                              |  
| Dw-conv                 | Kernel：1x1 至 5x5<br/>Padding：0 至 2<br/>Stride：1 至 2<br/>Dilation：1  |
| Activation              | Relu<br/> LeakyRelu<br/> Sigmoid<br/> Tanh<br/> Mish<br/> Clip (僅限 min = 0)<br/> HardSwish<br/> HardSigmoid |
| MaxPool                 | Kernel：僅 2x2 <br/> Stride：僅 2<br/> | Kernel：2x2 至 13x13<br/>Padding：0 至 6<br/>Stride：1 至 2   |
| AveragePool             | Kernel：2x2 至 19x19<br/>Padding：0 至 6<br/>Stride：1 至 2 |
| GlobalAveragePool       | O                                                           |
| Add                     | Scalar + Tensor <br/> Tensor + Tensor <br/> | Vector + Tensor |
| Sub                     | O (轉換為 Add 運算子)                                         |
| Mul                     | Scalar * Tensor <br/> Tensor * Tensor<br/> | Tensor * Tensor |                                                   |
| Div                     | O (僅限常數除數)                                            |
| Resize                  | 最近鄰內插：2x, 4x, 8x (=2^n) <br/>雙線性內插：2x, 4x, (僅限 align_core = false) |
| Upsample                | Stride：僅 2                                                |
| Batchnorm               | O                                                           |
| Pad                     | Padding：0 至 3 (僅限零填補)                                |
| Concat                  | 方向：僅限逐通道                                            |
| Slice                   | O                                                           |
| Split                   | O                                                           |
| Squeeze                 | O                                                           |
| Unsqueeze               | O                                                           |
| MatMul                  | 其中一個 tensor 必須為常數。                                |
| Gemm                    | O                                                           |
| Flatten                 | O                                                           |
| ReduceMean              | axes：僅限 [h,w]                                            |
| ReduceSum               | axes：僅限 [h,w]                                            |
| Constant                | O                                                           |
| ConstantOfShape         | O                                                           |
