# 1. 소개
---
본 문서는 AI-G SDK에 포함된 샘플 애플리케이션 및 테스트 애플리케이션의 사용 방법을 안내합니다. 이러한 애플리케이션은 사용자가 AI-G의 온보드 NPU를 이용한 AI 추론 기능을 이해하고 평가할 수 있도록 설계되었습니다.  
본 문서는 다음 정보를 포함합니다:
- 샘플 애플리케이션
  - tcnnapp
  - tcnncameraapp
  - tcnputestapp

# 2. 샘플 애플리케이션
---
이 절에서는 AI-G SDK에서 제공하는 세 가지 샘플/테스트 애플리케이션을 설명합니다. 각 애플리케이션은 사용자가 AI-G의 AI 기능을 평가하고 활용할 수 있도록 설계되었습니다. 이 애플리케이션들은 NPU 추론 테스트 및 실시간 카메라 입력과 같은 다양한 시나리오를 다룹니다.
<br/><br/><br/>
 
## 2.1 tcnnapp
---
tcnnapp은 AI-G 플랫폼의 NPU를 사용하여 이미지 기반 추론을 수행하는 방법을 보여 주는 샘플 AI 애플리케이션입니다. 다양한 입력/출력 모드를 지원하며 YOLOv5s 및 MobileNetv2와 같은 사전 학습된 모델을 사용한 객체 검출을 시연합니다.
<br/><br/>
 
### 사용 사례 1. 파일 대 파일 기본 추론
이 사례는 로컬 이미지 파일에 대해 추론을 실행하고 그 결과를 출력 파일로 저장하는 방법을 보여 줍니다. 이는 카메라나 디스플레이 하드웨어를 사용하지 않고 기본적인 기능 테스트와 모델 검증을 수행할 때 유용합니다.  
추론을 수행하려면 다음 명령을 입력하십시오:
```
$ tcnnapp -i file -p test.png -o file -P result.png
```
 
이 명령은 입력 이미지 파일(test.png)을 사용하여 tcnnapp을 실행하고 추론 결과를 출력 파일(result.png)로 저장합니다. 모델을 지정하지 않으면 애플리케이션은 기본 양자화 모델인 YOLOv5s와 MobileNetv2를 자동으로 사용합니다.

### 사용 사례 2. 카메라와 디스플레이를 이용한 실시간 추론
이 사례는 MIPI CSI 카메라와 MIPI DSI 디스플레이를 연결한 상태에서 tcnnapp을 사용하여 실시간 AI 추론을 수행하고 그 결과를 시각화하는 방법을 보여 줍니다. 애플리케이션은 카메라에서 실시간 비디오 입력을 스트리밍하고, NPU에서 기본 양자화 모델(YOLOv5s 및 MobileNetv2)을 사용하여 실시간 추론을 수행하며, 그 결과를 화면에 표시합니다.  
장치 연결은 다음과 같습니다:
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Available%20Applications/Figure%202.%20Device%20Connection.png" width="600"></p>
<p align="center"><strong>그림 2.2 AI-G의 카메라 및 디스플레이 연결 </strong></p><br/>
 
장치를 연결한 후 다음 명령을 입력하십시오:
```
$ tcnnapp -i camera -o display
```
이 명령은 CSI 카메라를 입력으로 사용하여 실시간 추론을 시작합니다. 캡처된 비디오 프레임은 객체 검출 및 분류 작업을 위해 NPU로 전달됩니다.
바운딩 박스, 클래스 레이블, 신뢰도 점수와 같은 추론 결과는 출력 프레임 위에 직접 렌더링됩니다.
이렇게 주석이 표시된 프레임은 5인치 DSI 디스플레이에 실시간으로 표시되어 즉각적인 시각적 피드백을 제공합니다.
 
시각적 출력 외에도 시스템은 CPU 사용량, NPU 사용률, 메모리 상태와 같은 주요 성능 지표를 기록하며, 이는 시리얼 콘솔 또는 원격 인터페이스를 통해 모니터링할 수 있습니다.

### 사용 사례 3. 카메라와 RTPM을 이용한 실시간 추론
이 사례는 MIPI CSI 카메라를 입력으로 연결하고 Real-time Performance Monitor(RTPM)를 출력 방식으로 사용하여 tcnnapp을 활용하는 방법을 보여 줍니다. 이 애플리케이션은 카메라에서 실시간 비디오 입력을 스트리밍하고, NPU에서 기본 양자화 모델(YOLOv5s 및 MobileNetv2)을 사용하여 실시간 추론을 수행한 후, 시각화 및 성능 모니터링을 위해 그 결과를 RTPM을 통해 PC로 전송합니다.  
RTPM 툴킷은 PC 환경에서 AI-G의 출력을 모니터링하기 위해 Python으로 개발된 GUI 기반 도구입니다. 이를 통해 추론 결과뿐만 아니라 CPU, NPU, 메모리 사용량과 같은 시스템 성능 지표도 확인할 수 있습니다.  
 
**참고**: RTPM에 대한 자세한 내용은 Software 섹션의 RTPM.md를 참조하십시오.
 
장치 연결은 다음과 같습니다:
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Available%20Applications/Figure%204.%20Camera%20and%20RTPM%20Communication%20via%20AI-G.png"width="900"></p>
<p align="center"><strong>그림 2.4 AI-G를 통한 카메라와 RTPM 통신 </strong></p><br/>
 
카메라를 연결한 후 다음 명령을 입력하십시오:
```
$ tcnnapp -i camera -o rtpm
```
 
이 명령은 CSI 카메라를 입력으로 사용하여 실시간 추론을 시작합니다. 검출된 객체와 분류 레이블과 같은 추론 결과는 호스트 PC로 전송되어 RTPM 인터페이스를 통해 시각화됩니다.  
추론 출력 외에도 RTPM은 CPU 사용량, NPU 부하, 메모리 사용량을 포함한 시스템 성능 지표를 실시간으로 표시합니다.

### 사용 사례 4. RTPM 입력 및 출력을 이용한 추론
이 사례는 호스트 PC에서 RTPM을 통해 스트리밍된 입력 이미지를 사용하여 추론을 실행하고, 그 추론 결과를 동일한 RTPM 인터페이스를 통해 PC로 다시 전송하여 표시하는 방법을 보여 줍니다. 입력 데이터는 이미지 또는 비디오일 수 있습니다.  
RTPM을 실행하려면 Software 섹션의 RTPM.md 문서를 참조하십시오. 그런 다음 아래 명령을 입력하십시오:
```
$ tcnnapp -i rtpm -o rtpm
```
이 명령은 RTPM을 입력과 출력 모두로 사용하여 tcnnapp을 실행합니다. 데이터는 호스트 PC에서 RTPM을 통해 전송되어 AI-G 보드의 NPU에서 처리되며, 추론 결과는 PC로 다시 전송되어 RTPM 인터페이스를 통해 표시됩니다.

## 2.2 tcnncameraapp
---
tcnncameraapp은 AI-G 플랫폼에서 지원되는 카메라 모듈을 테스트하고 미리 볼 수 있는 샘플 애플리케이션입니다. Video4Linux2(V4L2) 프레임워크를 기반으로 하며, 연결된 MIPI CSI 인터페이스와 DSI 디스플레이를 통해 실시간 카메라 미리 보기를 제공합니다.  
이 애플리케이션은 주로 카메라 기능 검증, 디스플레이 출력 테스트, 이미지 신호 품질 디버깅에 사용됩니다. 또한 카메라 모듈 종류에 따라 여러 대의 카메라를 동시에 모니터링하는 기능도 지원합니다.  
tcnncameraapp에서 제공하는 옵션은 다음 표와 같습니다.
 
| 이름              | 옵션    | 범위      | 기본값      | 예시           | 설명                                  |
| ------------------| --------| ----------| ------------| ---------------| --------------------------------------|
| 사용법 정보       | -?      |     -     |             | -?             | 사용법 정보를 표시합니다              |
| 입력 경로         | -p      |     -     | /dev/video0 | -p /dev/video0 | 입력 경로를 지정합니다                |
| 출력 경로         | -P      |     -     | /dev/overlay| -P /dev/overlay| 출력 경로를 지정합니다                |
| 입력 너비         | -w      | 최대 2560 | 1920        | -w 2560        | 입력의 너비를 지정합니다              |
| 입력 높이         | -h      | 최대 1440 | 1080        | -h 1080        | 입력의 높이를 지정합니다              |
| 출력 너비         | -W      | 최대 1920 | 1920        | -W 1920        | 출력의 너비를 지정합니다              |
| 출력 높이         | -H      | 최대  720 | 720         | -H 720         | 출력의 높이를 지정합니다              |

<p align="center"><strong>표 2.1 카메라 테스트 애플리케이션 옵션</strong></p><br/>
 
**참고**: 출력 너비와 X 위치의 합은 1920을 초과할 수 없으며, 출력 높이와 Y 위치의 합은 720을 초과할 수 없습니다.

## 2.3 tcnputestapp
---
tcnputestapp은 AI-G 플랫폼의 NPU(Neural Processing Unit) 기본 기능을 검증하는 샘플 애플리케이션입니다. tcndnpulib 라이브러리를 사용하여 사전 컴파일된 신경망 모델로 NPU 실행을 직접 테스트합니다. 이 애플리케이션은 주로 카메라나 디스플레이 없이 NPU의 내부 검증, 디버깅, 성능 테스트를 수행하기 위한 용도입니다.  
tcnputestapp에서 제공하는 옵션은 다음 표와 같습니다.
 
| 이름           | 옵션   | 범위      | 기본값      | 예시                     | 설명                                  |
| ---------------| -------| ----------| ------------| -------------------------| --------------------------------------|
| 사용법 정보    | -?     |     -     |      -      | -?                       | 사용법 정보를 표시합니다              |
| NPU 번호       | -d     |    0, 1   |      0      | -d 0 / -d 1 / -d 0 1     | 네트워크의 NPU 인덱스를 지정합니다    |
| 네트워크 경로  | -n     |     -     | /usr/share/yolov5s_quantized| -n /usr/share/mobilenetv2_10_quantized/   | 테스트할 신경망을 지정합니다. NPU 두 개를 선택한 경우 동일한 신경망 경로를 사용합니다|
| 테스트 횟수    | -t     | -         | 1           | -t 100                   | 신경망 테스트 횟수를 지정합니다|
<p align="center"><strong>표 2.2 NPU 테스트 애플리케이션 옵션</strong></p><br/>
