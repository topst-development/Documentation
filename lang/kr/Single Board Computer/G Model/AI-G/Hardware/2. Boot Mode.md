# 2. AI-G의 부팅 모드
---
AI-G는 다음의 부팅 모드를 지원합니다: 
- USB Boot Mode (FWDN)  
- eMMC Boot Mode (GPIO_SD Group)

AI-G 보드는 기본적으로 eMMC Boot Mode로 고정되어 있습니다. eMMC 디바이스에 부팅 이미지가 없는 경우, 부팅 모드는 자동으로 FWDN Boot Mode로 전환됩니다. 

<br/><br/><br/>

## 2.1 USB Boot Mode (FWDN)
--- 
그림 2.1은 Boot Mode 스위치와 RESET 스위치를 나타냅니다. USB Boot Mode는 펌웨어 업데이트에 사용됩니다. FWDN 모드로 진입하려면 Boot mode 스위치와 RESET 스위치가 모두 필요합니다. 이미지를 업로드할 때에는 이 방법을 사용하는 것을 권장합니다.

<p align="center"><strong>그림 2.1 FWDN Boot Mode 진입을 위한 Boot Mode 스위치와 RESET 스위치 </strong></p><br/>

다음 단계는 USB Boot Mode로 진입하기 위한 스위치 조작 방법을 설명합니다. 
1. 전원이 공급되면 RESET 스위치 위쪽의 LED가 켜집니다. 
2. Boot Mode 스위치를 길게 누릅니다. Boot Mode 스위치를 누르면 스위치 위쪽의 빨간색 LED가 켜지는 것을 확인할 수 있습니다. LED가 계속 켜져 있도록 스위치를 계속 누르고 있으십시오. 
3. RESET 스위치의 LED는 기본적으로 녹색입니다. RESET 스위치를 한 번 누르면 녹색 LED가 꺼졌다가 다시 켜집니다. 
4. Boot Mode 스위치에서 손을 뗍니다.
