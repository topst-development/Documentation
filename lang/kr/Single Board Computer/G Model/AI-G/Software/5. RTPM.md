# 1. 소개
---
RTPM(Real-Time Performance Monitor) 툴킷은 AI-G의 성능 지표를 실시간으로 모니터링하고 시각화하기 위해 설계된 Python 기반 그래픽 애플리케이션입니다. AI-G 보드와 호스트 PC 간의 연결을 구성함으로써, RTPM은 CPU, NPU, 메모리 사용률 및 추론 시간을 포함한 주요 성능 데이터의 전송과 분석을 지원합니다.
 
RTPM은 두 가지 모드로 동작합니다:
 
**Injection Mode**: 이 모드에서는 호스트 PC가 처리를 위해 이미지 데이터를 AI-G로 전송합니다. AI-G는 NPU를 사용하여 추론을 수행하고 그 결과를 시각화를 위해 PC로 반환합니다.
 
**Projection Mode**: 이 모드에서는 AI-G가 연결된 카메라를 통해 이미지를 획득하여 내부에서 처리한 후, 추론 결과를 호스트 PC의 RTPM으로 전송합니다.
 
본 툴킷은 AI-G 플랫폼에서 AI 애플리케이션의 성능을 평가하고 최적화하려는 개발자와 엔지니어에게 특히 유용합니다. 시스템 동작에 대한 실시간 정보를 제공하여 효율적인 디버깅과 성능 튜닝을 가능하게 합니다.
 
자세한 설정 방법과 사용 지침은 본 문서의 이후 섹션을 참조하십시오.

## 2.1 성능 모니터링
--- 
RTPM(Real-Time Performance Monitoring Toolkit)은 Python을 사용하여 개발된
GUI 기반 도구로, PC 환경에서 AI-G의 출력을 모니터링하고
CPU, NPU, 메모리 성능 데이터를 확인할 수 있도록 합니다.
 
 
 
**표 2.1 RTPM의 성능 데이터 목록:**
 
|   번호   |  성능 데이터    |                설명             |
|--------|----------------------|----------------------------------------|
| 1      | Inference Time       | 각 모델의 추론 시간 (ms)     |
| 2      | NPU Utilization      | 각 모델의 NPU 사용률         |
| 3      | FPS                  | NPU 동작 기준 FPS 정보 |
| 4      | CPU                  | CPU 사용률 (500 ms 주기)         |
| 5      | Memory               | 메모리 사용률 (500 ms 주기)      |

## 2.4 RTPM 애플리케이션 실행 가이드
---
본 섹션에서는 호스트 PC에 RTPM(Real-Time Performance Monitor) 애플리케이션을 설정하는 단계별 절차를 제공합니다.
도구 설치, 워크스페이스 구성, 그리고 AI-G의 NPU 성능과 추론 결과를 모니터링하기 위한 RTPM 인터페이스 실행 방법을 포함합니다.
 
<br/><br/>
 
### 2.4.1 RTPM용 도구 설치
 
- 호스트 PC 환경을 준비합니다.
 
1. Visual Studio Code를 설치합니다.
   * Microsoft Store에서 “Visual Studio Code”를 검색하여 설치합니다.
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/5.%20Install%20Visual%20Studio%20Code.png"></p>
<p align="center"><strong>그림 2.5 Visual Studio Code 설치</strong></p><br/>
 
2. Python 3.10을 설치합니다.
   1. Visual Studio Code를 실행합니다.
   2. 왼쪽 사이드바의 Extensions 아이콘을 클릭하거나 다음 키를 눌러 Extensions 뷰를 엽니다. 
   *Ctrl + Shift + X*.
   3. Extensions 검색창에 Python을 입력합니다.
   4. Microsoft에서 제공하는 Python 확장을 찾아 Install을 클릭합니다.
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/6.%20Install%20Python3.10.png"width="800"></p>
