# 1. 소개
---
Neural 
Processing Unit (NPU)은 HW 신경망 가속기이며, TCC750x의 NPU는 객체 검출, 이미지 분류, 얼굴 검출과 같은 비전 애플리케이션용 신경망의 추론에 최적화되어 있습니다.  
이 문서는 NPU Toolkit 사용 방법을 설명합니다.
<br/><br/><br/>

## 3.1 Converter
---
Converter는 신경망 파일을 읽어 들여 ”bin”
파일로 변환합니다. 이는 AI-G NPU SW Toolkit에서 사용되는 네트워크 파일 형식입니다.
또한 네트워크 추론을 수행하고
활성화 데이터의 통계를 수집하며, 이 통계는 이후 네트워크 양자화에 사용됩니다.

<strong>1.  Darknet</strong>
```
$ python ./EnlightSDK/converter.py \
  ./input_networks/yolov4.cfg \
  --weight ./input_networks/yolov4.weights \
  --type obj \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/yolov4.enlight \
  --enable-track \
  --mean 0 0 0 \
  --std 1 1 1 \
  --num-class 90
```

<strong>3.  ONNX</strong>

이 방법은 ONNX 모델에 지원되지 않는 연산자(예: NonMaxSuppression)가 포함되어 있는 경우에 필요합니다.

다음 과정은 tc-nn-toolkit 명령줄 인터페이스를 사용한 3단계 변환으로 구성됩니다.


먼저 ONNX 모델을 .enlight 형식으로 변환합니다.

```
$ python ./EnlightSDK/converter.py \
  ./input_networks/mb2-ssd-lite.onnx \
  --type obj \
  --add-detection-post-process ./input_networks/mb2-ssd-lite.anchor \
  --logistic softmax \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/mb2-ssd-lite.enlight \
  --enable-track \
  --mean 0.498 0.498 0.498 \
  --std 0.502 0.502 0.502 \
  --num-class 20 \
  --variance 0.1 0.2
```

그런 다음 --force-output을 사용하여 중간 레이어를 출력으로 하는 모델을 추출하고 지원되지 않는 연산자를 제거합니다.

```
python ./EnlightSDK/converter.py \
            ./input_networks/mb2-ssd-lite.onnx \
            --type unknown \
            --output ./output_networks/mb2-ssd-lite_wo_box_decode_score.enlight \
            --dataset-root my_dataset_path \
            --force-output Concat_0___Concat Concat_1___Concat_1
```

마지막으로 추출된 모델에 앵커 박스, 로지스틱 활성화, 클래스 설정 등의 후처리 옵션을 적용하여 최종 .enlight 모델을 생성합니다.

```
$ python ./EnlightSDK/converter.py \
  ./output_networks/mb2-ssd-lite_wo_box_decode_score.enlight \
  --type obj \
  --add-detection-post-process ./input_networks/mb2-ssd-lite.anchor \
  --logistic softmax \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/mb2-ssd-lite.enlight \
  --enable-track \
  --mean 0.498 0.498 0.498 \
  --std 0.502 0.502 0.502 \
  --num-class 20 \
  --variance 0.1 0.2
```

## 3.2 Quantizer

정수 기반의 (양자화된) 네트워크로 변환합니다.

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/yolov4.enlight \
  --output ./output_networks/yolov4_quantized.enlight
```

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1.enlight \
  --output ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight
```

**3. ONNX**
```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/mb2-ssd-lite.enlight \
  --output ./output_networks/mb2-ssd-lite_quantized.enlight
```

생성된 파일은 “output_code/\<network_name\>”에 저장됩니다.
디렉터리의 requirements.txt 파일에 나열되어 있습니다.

Compiler 출력 파일:
- npu_cmd.bin: Telechips NPU 추론 코드를 위한 추론 코드
- quantized_network.bin: 네트워크 가중치 및 바이어스 파라미터
- network.h: 후처리를 위한 버퍼 크기 및 네트워크 파라미터
- post_process.c: 후처리 코드
- 기타 파일: 디버깅 정보 (내부용)

신경망 애플리케이션에서 “npu_cmd.bin”과 “quantized_network.bin”은
Telechips NPU API와 Linux 디바이스 드라이버를 사용하여 DMA 버퍼에
로드됩니다. “network.h”와 “post_process.c”는 네트워크 오브젝트 빌드에 나와 있는 것처럼
네트워크 오브젝트 파일 (.so)로 빌드됩니다.
<br/><br/><br/>

## 5.1 AI-G NPU 지원 레이어 유형

|        레이어 유형       |                        사양                        |
|-------------------------|-------------------------------------------------------------|
| Convolution             | 커널 크기: 1x1 ~ 7x7<br/>스트라이드: 1 ~ 4<br/>패딩: 0 ~ 3 <br/>딜레이션: 1 ~ 4 |

| Element-wise Operation  | 덧셈: Scalar + Tensor, Vector + Tensor, Tensor + Tensor <br/>  곱셈: Scalar * Tensor, Vector * Tensor, Tensor * Tensor                    |  
| Batch Normalization     | 지원                                                   |
