---

# 2. 시작하기
---
Telechips Model Zoo에서 제공하는 신경망 모델을 AI-G 보드에서 실행하려면 다음 단계를 따르십시오.
<br/><br/><br/>

## 2.1 저장소 복제
---
```
$ git clone https://github.com/telechips-ai/TCC750x-Model-Zoo.git

$ cd TCC750x-Model-Zoo
```
<br/><br/><br/>

## 2.2 원하는 모델을 AI-G로 복사
---
모델 폴더(yolov5m) 전체를 AI-G로 복사합니다.
폴더를 그대로 복사하거나, 다음 예시와 같이 이전에 배포된 신경망 폴더에서 사용된 형식에 맞추어 yolov5m_quantized로 이름을 변경할 수 있습니다.
각 폴더에는 필요한 출력 파일(.so, .bin 등)이 포함되어 있습니다.

```
$ scp -r [network_output_folder] root@192.168.0.100:/path/to/target/
```
**network_output_folder**를 실제 폴더(예: yolov5m/)로 바꾸십시오.

yolov5 모델을 선택할 수 있습니다.
```
$ cd Object_Detection/YOLO/yolov5/
$ ls 
README.md  yolov5l  yolov5m  yolov5n  yolov5s  yolov5x
```
그런 다음 실행합니다:
```
$ scp -r yolov5m/ root@192.168.0.100:/home/root/
```
<br/><br/><br/>

## 2.3 tcnputestapp 또는 tcnnapp을 사용하여 모델 실행:
---
그런 다음 타깃 보드(AI-G)에서 다음 명령을 실행합니다:
```
$ tcnputestapp -d 0 1 -n [network_output_folder_path]
```
또는 
```
$ tcnnapp -n [network_output_folder_path]
```
