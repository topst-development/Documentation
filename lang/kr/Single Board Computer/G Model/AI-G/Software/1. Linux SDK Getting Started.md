## 2.1 Windows 환경
--- 
이 문서에서는 Windows PC에서 Linux를 사용하기 위해 Windows Sub-system for Linux (WSL)를 설정하는 방법을 설명합니다.
AI-G Linux SDK는 Yocto Project를 기반으로 하므로, AI-G SDK의 Linux 버전은 Yocto Project를 따릅니다.
다른 버전의 Linux를 설치할 수도 있지만, 이 문서에서는 Ubuntu 22.04를 기준으로 AI-G Linux SDK를 설명합니다.
호스트 OS가 Ubuntu인 경우 2.2절로 이동하십시오.
</br><br/>

### 2.1.1 WSL2 Ubuntu 설치 (Windows 환경 전용)

1. Windows PowerShell을 "**관리자 권한으로 실행**"으로 실행합니다.
2. WSL2 시스템을 활성화합니다.
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. 가상 머신 기능을 활성화합니다.
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. WSL의 기본 버전을 2 (WSL2)로 설정합니다.
    ```
    wsl --set-default-version 2
    ```
5. Microsoft Store에서 Ubuntu 22.04.3 LTS를 검색하여 다운로드합니다.

    * Linux 커널 업데이트 패키지를 다운로드해야 하는 경우 [여기](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)에서 최신 패키지를 다운로드하십시오.

6. Ubuntu 설치 중 사용자 이름은 원하는 대로 지정할 수 있습니다.

<br/><br/>


### 2.1.2 WSL2를 통한 Ubuntu 접속
Windows 명령 프롬프트를 열고 다음 명령을 입력하여 Ubuntu에 접속합니다. Ubuntu에 접속하면 기본적으로 /mnt/c/Users/[user name] 디렉터리에서 시작됩니다.
```
wsl  // access ubuntu 
ls   // check contents in your directory
```

### 2.1.3 로케일 설정

WSL에서 Ubuntu를 실행한 후에는 언어 및 지역 설정이 올바르게 적용되도록 로케일을 설정해야 합니다. en_US.UTF-8을 사용하는 것을 권장합니다. en_US.UTF-8을 사용하려면 다음 명령을 실행하십시오. 

```
sudo locale-gen en_US.UTF-8 && sudo update-locale LANG=en_US.UTF-8 
```

로케일을 설정한 후에는 다음 명령을 사용하여 로케일 종류를 확인할 수 있습니다. 

```
echo 'LANG=en_US.UTF-8' | sudo tee -a /etc/default/locale && \  

echo 'LC_ALL=en_US.UTF-8' | sudo tee -a /etc/default/locale 
```
<br/><br/>

### 2.1.4 SSH 및 Samba 설치 

Ubuntu에 접속한 후에는 보다 편리한 개발 환경을 위해 SSH, Samba와 같은 추가 유틸리티를 사용할 수 있습니다. SSH와 Samba를 사용하면 원격 컴퓨터에서 명령을 실행하고 다른 컴퓨터로 파일을 복사할 수 있습니다.
 - 다음 단계를 진행하려면 호스트 PC가 네트워크에 연결되어 있어야 합니다. 다음 명령을 사용하여 네트워크 상태를 확인하십시오:
  ```
  $ sudo apt-get update
  $ sudo apt-get install -y net-tools
  $ ifconfig 
  ```

SSH와 Samba가 이미 설치되어 있거나 사용하지 않을 경우에는 이 장을 건너뛸 수 있습니다.

다음 명령을 사용하여 net-tools, SSH, Samba를 설치하십시오.

```
$ sudo apt-get update 
$ sudo apt install -y net-tools openssh-server samba
```


SSH와 Samba를 다운로드한 후에는 각 프로그램을 사용자 환경에 맞게 설정해야 합니다.
<br/><br/>

### 2.1.5 유틸리티 설치 

유틸리티를 한 번에 설치합니다. Yocto Project를 사용하려면 호스트 PC(개인용 컴퓨터 또는 개발 서버)에 다음 유틸리티가 설치되어 있어야 합니다.

다음 명령을 사용하여 유틸리티를 설치하십시오.

```
$ sudo apt-get install -y gawk wget git diffstat unzip texinfo gcc-multilib build-essential chrpath

$ sudo apt-get install -y socat cpio python3 python3-pip python3-pexpect xz-utils debianutils

$ sudo apt-get install -y iputils-ping python3-git python3-jinja2 libegl1-mesa-dev libsdl1.2-dev pylint

$ sudo apt-get install -y xterm zstd ncftp curl git-lfs vim zip lz4
```
<br/><br/>


### 2.1.6 Repo 설치 (선택 사항)

***Repo***를 사용하여 AI-G SDK를 다운로드할 수 있습니다.  
***Repo***를 설치하려면 다음 웹사이트를 참조하십시오: https://source.android.com/source/downloading.html.  
***Repo***가 이미 설치되어 있는 경우 다시 설치하지 않고 사용할 수 있습니다.  
***Repo***를 설치하기 전에 Python 3.6 이상 버전이 올바르게 설정되어 있는지 확인하십시오.

다음 명령을 사용하여 ***Repo***를 설치하십시오.
```
$ sudo apt-get install repo
```

'/usr/bin/env 'python' no such file or directory' 오류 메시지가 표시되는 경우, 다음 명령을 사용하여 'python' 파일이 'python3'을 가리키도록 하십시오.

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
```
***Repo*** 오류가 발생하는 경우, 다음 명령을 사용하여 최신 버전을 다운로드한 후 /usr/bin/ 폴더에 직접 넣으십시오.

```
$ mkdir -p ~/bin

$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo > ~/bin/repo

$ chmod a+x ~/bin/repo

$ sudo mv ~/bin/repo /usr/bin/repo
```
**3장: 이미지 빌드 가이드**로 이동하십시오.

### 2.2.6 Telechips USB 디바이스용 Udev 규칙 (선택 사항)

$ echo "SUBSYSTEM==\"usb\", ATTR{idVendor}==\"140e\", MODE=\"0666\", OWNER=\"${USER}\"" | sudo tee /etc/udev/rules.d/99-topst.rules
$ sudo udevadm control --reload-rules && sudo udevadm trigger
```

# 3. 이미지 빌드 가이드
---
이 절에서는 호스트 PC에 설치된 Ubuntu OS를 기준으로 설명합니다(WSL인지 로컬 Ubuntu 설치인지는 관계없습니다). AI-G에 업로드할 이미지는 Yocto Project를 사용하여 빌드하므로, 이 과정은 반드시 Ubuntu 환경에서 진행해야 합니다.
<br/><br/><br/>

## 3.1 SDK 빌드 준비
---
AI-G SDK는 Yocto Project 4.0 Kirkstone을 기반으로 합니다. 따라서 AI-G SDK를 사용하려면 호스트 PC에 Yocto Project 환경이 설정되어 있어야 합니다. SDK, source-mirror, tools를 다운로드하려면 유틸리티를 설치해야 합니다. 이미지를 원활하게 빌드하려면 PC에 **최소 60 GB의 여유 저장 공간**과 **최소 16 GB의 RAM**이 있어야 합니다.

<br/><br/><br/>

## 3.2 Yocto Project
---
Yocto Project는 임베디드 Linux 개발에 중점을 둔 오픈 소스 프로젝트입니다. 
Yocto Project는 Open Embedded 프로젝트의 일부인 Poky와 빌드 시스템인 bitbake를 함께 사용하여 Linux 이미지를 생성합니다. 
Yocto Project를 사용하면 부트로더, 커널, rootfs를 동시에 빌드할 수 있습니다. 

<br/><br/><br/>

## 3.5 빌드 준비
---
다음 장에서는 AI-G 이미지를 빌드하기 위해 Yocto Project를 구성하는 방법을 설명합니다.
<br/><br/>

### 3.5.1 .gitconfig에 사용자 이메일 및 사용자 이름 설정
공식 TOPST git에서 AI-G를 다운로드하려면 이메일과 이름을 설정하십시오.
1. 다음 명령을 입력합니다.
```
vi ~/.gitconfig
```
2. 다음 정보를 입력합니다.
```
[user]
    email = User email
    name = User name
```
<br/><br/>

### 3.5.2 Git에서 AI-G 가져오기
1. **topst-sdk**라는 새 디렉터리를 생성하고 현재 디렉터리를 **topst-sdk**로 변경합니다.
```
$ mkdir topst-sdk
$ cd topst-sdk
```
2. 다음 명령을 실행하여 저장소를 초기화합니다.

```
$ repo init -u https://github.com/topst-development/manifests.git -b release/1.3.0 -m linux_yp4.0_topst.xml

```

명령을 실행하면 다음과 같은 출력이 표시됩니다.

```

Downloading Repo source from https://gerrit.googlesource.com/git-repo

# 4. 펌웨어 다운로더
---
이 장에서는 AI-G에 ***FWDN***을 다운로드하고 Linux 콘솔에 로그인하는 방법을 설명합니다.  
***FWDN V8***은 Windows 10 또는 11 64비트 및 Linux 환경에서 펌웨어를 다운로드하기 위한 PC 툴입니다. 이 장에서는 Windows 및 Linux 환경에서 다운로드하는 경우를 설명합니다.
<br/><br/><br/>

## 4.1 펌웨어 다운로드 순서
---
***FWDN***의 다운로드 순서는 다음과 같습니다:

1. 부팅 모드 스위치를 USB 부팅 모드(FWDN 모드)로 설정합니다.
2. Windows 프롬프트 또는 Linux 콘솔을 열고 ***FWDN V8***을 테스트합니다.
3. ***FWDN V8***을 보드에 연결합니다.
4. fai 파일을 다운로드합니다.

<br/><br/><br/>

## 4.2 USB 부팅 모드(FWDN 모드) 
---
***FWDN***을 사용하여 빌드된 이미지를 AI-G로 전송할 수 있습니다. AI-G는 Ethernet과 UART를 사용하여 ***FWDN***을 제공합니다. 

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/Linux%20SDK/3.%20connect%20host%20pc%20to%20topst%20ai-g.png" ></p>
<p align="center"><strong>그림 4.1 FWDN을 위한 호스트 PC와 AI-G 간 연결</strong></p><br/>

***FWDN V8***을 사용하려면 다음과 같이 AI-G 보드를 호스트 PC에 연결하십시오: 

1. 호스트 PC에 VTC 드라이버가 설치되어 있는지 확인합니다. VTC 드라이버가 설치되어 있지 않으면 4.2.1장과 같이 설치하십시오.  

2. USB Type-C 케이블 1개와 Ethernet 케이블 1개를 준비합니다. 

3. USB 부팅 모드로 진입하려면 USB Type-C 케이블을 AI-G 보드의 USB Type-C FWDN 포트와 호스트 PC에 연결합니다. 

4. Ethernet 케이블(RJ45)을 AI-G 보드의 Ethernet 포트와 호스트 PC에 연결합니다. 

5. FWDN 스위치를 누른 상태에서 전원 케이블을 AI-G 보드에 연결합니다. 

<br/><br/><br/>

### 4.2.1 VCP 드라이버 설치 방법

호스트 PC에서 관리자 권한으로 실행하여 Vendor Telechips Certification (VTC) 드라이버([VCP 드라이버](https://drive.google.com/file/d/1muQnY8kuKxDsy3p3FUiQqcG34Zjk-mnR/view?usp=sharing)에서 확인 가능)를 설치하십시오. 위와 같이 FWDN 모드에서 USB를 연결하면 그림 4.2와 같이 Telechips VTC USB 드라이버가 설정됩니다.

$ unzip output_aig.fwdn.zip

## 4.4. UART를 통한 AI-G 보드 연결
--- 
다음 단계를 수행하고 UART 연결을 사용하여 펌웨어 다운로드가 성공적으로 완료되었는지 확인하십시오.  

1. Windows 환경에서 시리얼 포트 드라이버(예: CP210x Windows Driver)와 PL2303_prolific 드라이버를 설치합니다.
2. Tera Term 또는 PuTTY와 같은 터미널 에뮬레이터를 설치합니다. 
3. 호스트 PC와 AI-G 보드의 UART 핀을 연결합니다. USB to TTL 케이블을 사용하십시오. 
4. 검은색 케이블을 GND 핀에 연결합니다. 
5. 흰색 케이블(RXD)을 UART 핀의 TX 핀에 연결하고, 녹색 케이블(TXD)을 UART 핀의 RX 핀에 연결합니다.
6. 터미널 에뮬레이터 애플리케이션을 실행합니다.
7. PC에서 장치 관리자를 열고 UART에 사용 중인 포트 번호를 확인합니다.
8. 장치 관리자에서 확인한 포트 번호를 터미널 에뮬레이터의 **Serial line** 필드에 입력합니다. **Speed**(bps)를 115200으로 설정하고 **Flow control to None.**으로 설정합니다.
9. 전원 케이블을 연결합니다. 그러면 AI-G가 기본 eMMC 부팅 모드로 부팅됩니다.
