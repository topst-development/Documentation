# 4. 펌웨어 다운로드

<br/>

## 4.1 펌웨어 다운로드를 위해 TOPST AI를 컴퓨터에 연결

Firmware Downloader(**FWDN**)는 컴퓨터에서 UART 통신을 통해 TOPST AI에
ROM 이미지를 기록합니다.

TOPST AI에는 Boot Mode 버튼이 하나 있으며, Boot Mode 버튼을 통해 다음과
같은 두 가지 부팅 모드를 지원합니다:

- UART Boot Mode는 컴퓨터의 **FWDN** 프로그램을 사용하여 ROM 이미지를
  기록할 때 사용됩니다.

- eMMC Boot Mode는 eMMC 디바이스에 저장된 ROM 이미지를 사용하여 TOPST
  AI를 부팅할 때 사용됩니다.

**참고**: USB Type-C 포트는 firmware downloader(**FWDN**)에 사용됩니다.

**FWDN**을 사용하려면 다음과 같이 TOPST AI를 컴퓨터에 연결하십시오:

1.  USB Type-C 케이블 1개와 Ethernet 케이블을 준비합니다.
2.  USB Type-C 케이블을 사용하여 TOPST AI의 USB Type-C 리셉터클을
    컴퓨터에 연결합니다.
3.  Ethernet 케이블을 사용하여 TOPST AI의 Ethernet 커넥터(RJ45)를
    컴퓨터에 연결합니다.
4.  아래 두 가지 방법 중 하나를 사용하여 TOPST AI의 부팅 모드를
    변경합니다.
     1. 방법 1
         * TOPST AI에 아직 전원이 공급되지 않은 경우, FWDN 버튼을 누른 상태에서 TOPST AI에 5V 전원을 연결합니다.
         * FWDN Boot mode 버튼에서 손을 뗍니다.

     2. 방법 2
         * TOPST AI에 이미 전원이 공급된 경우, System Reset 버튼과 FWDN Boot mode 버튼을 누릅니다.
         * FWDN Boot mode 버튼에서 손을 뗍니다.

5.  **FWDN** 문서에 따라 ROM 이미지를 다운로드합니다.

그림 4.1은 TOPST AI에서 Reset 버튼, FWDN 버튼, Ethernet 포트 및 USB
Type-C 포트의 위치를 나타냅니다.
