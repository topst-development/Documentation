# 1. FWDN 가이드

이 장에서는 TOPST AI에 펌웨어 다운로더(FWDN)를 다운로드하는 방법을
설명합니다.

TOPST AI는 이더넷과 UART를 사용하여 FWDN 기능을 제공합니다. FWDN
모드에서 BL0(Chipboot ROM)은 UART를 사용하여 호스트로부터 다음 단계의
펌웨어(BL1)를 로드합니다. (BL1이 초기화를 수행합니다.) DRAM을 초기화하고
다시 UART를 사용하여 FWDN 이더넷을 지원하는 FWDN F/W를 DRAM에 로드합니다.
FWDN F/W는 TCP/IP 또는 UDP로 호스트와 연결하여 FWDN 기능(스토리지에
데이터 쓰기, 스토리지에서 데이터 읽기 등)을 수행합니다.

## 1.1 펌웨어 다운로드 순서

FWDN의 다운로드 순서는 다음과 같습니다:

1.  FWDN 모드로 진입합니다(TOPST-AI/Hardware/Overview/4.Firmware Download 참조).
2.  USB C-to-A 케이블을 USB C 타입 FWDN 포트에 연결합니다.
3.  이더넷 케이블을 이더넷 포트에 연결합니다.
4.  TOPST AI 이미지를 다운로드합니다.

<br/><br/>

## 1.2 FWDN 모드 진입 

FWDN KEY(FWDN Mode Convert)를 누른 상태에서 전원을 연결하면 FWDN 모드로
진입합니다. 또는 전원이 연결되어 있는 경우, FWDN KEY
(FWDN Mode Convert)를 누른 후 RESET KEY(System Reset)를 눌러 FWDN
모드로 진입합니다.
