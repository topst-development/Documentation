# 2. 부팅 가이드

이 장에서는 TOPST AI를 부팅하고 각 코어에 로그인하는 방법을
설명합니다.

<br/><br/>

## 2.1 부팅 순서

부팅 순서는 다음과 같습니다:

1.  MIPI 인터페이스 패널을 연결합니다.
2.  MIPI 인터페이스 카메라 모듈을 연결합니다.
3.  USB C to A 케이블을 디버그 포트에 연결합니다.
4.  5V 전원을 연결합니다.

## 2.2 UART를 이용한 TOPST AI 연결

USB 디버깅을 수행하고 Linux 환경을 개발하려면 아래 그림에 표시된 보드의 TOPST AI 디버그 포트를 사용하여 코어(CA53)에 접근할 수 있습니다.
호스트 PC에 UART Bridge VCP 드라이버를
(https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads 에서 확인 가능)
설치하십시오.
그 후 UART를 TOPST 디버깅 보드에 연결하면 CP210x USB to UART 드라이버가 다음과 같이 설정됩니다.

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20Boot.image2.png?raw=true"
style="width:4.11111in;height:4.02083in"</p>
<p align="center"><strong>그림 2.2 Windows 환경에서의 USB 연결</strong></p>

호스트 PC의 터미널 에뮬레이터를 사용하여 UART 포트를 연결하십시오.
아래는 코어에 접속하여 부팅된 로그 화면입니다.

<br/>

**예시**

- 터미널 에뮬레이터: PuTTY 또는 mobaXterm
- 속도: 115200 bps
- 데이터 비트: 8
- 패리티: None
- 정지 비트: 1
- 흐름 제어: None
