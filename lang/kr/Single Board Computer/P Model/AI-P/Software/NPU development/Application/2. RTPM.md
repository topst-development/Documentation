# 2. 실시간 성능 모니터링 툴킷

TOPST AI Board에서 취득한 이미지, NPU, CPU, MEM 성능은 Vision Protocol을
통해 PC로 전달할 수 있으며, 그 결과는 PC의 RTPM 툴킷에서 확인할 수
있습니다.

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image1.png?raw=true"></p>

<p align="center"><strong>그림 2.1 호스트 PC와 TOPST AI Board 간 연결</strong></p>

- **RTPM 다운로드** : <[RTPM](https://drive.google.com/file/d/1x3gaMhw53YloNul8m75R5fCPqzNl0RI9/view?usp=sharing)>
- 다운로드가 차단되어 있으므로 커뮤니티로 문의하시기 바랍니다.

<br/><br/>

## 2.1 성능 모니터링

Real-Time Performance Toolkit(RTPM)은 Python으로 개발된 GUI 기반 도구로서,
PC 환경에서 TOPST AI의 출력을 모니터링하고 CPU, NPU, Memory 성능 데이터를
확인할 수 있도록 합니다.

<br/>

**표 2.1 RTPM의 성능 데이터 목록:**

|  번호  |     성능 데이터      |                  설명                  |
|--------|----------------------|----------------------------------------|
| 1      | 추론 시간            | 각 모델별 추론 시간(ms)                |
| 2      | NPU                  | 각 모델별 NPU 사용률                   |
| 3      | FPS                  | NPU 동작 기준 FPS 정보                 |
| 4      | CPU                  | CPU 사용률(500ms 주기)                 |
| 5      | Memory               | Memory 사용률(500ms 주기)              |

## 2.2 Injection 모드

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image3.png?raw=true"></p>
<p align="center"><strong>그림 2.3 Injection 모드</strong></p>

Injection 모드는 TOPST AI 보드가 RTPM으로부터 이미지를 수신한 후 TOPST AI
Board에서 NPU 추론을 수행하고 그 결과를 다시 RTPM으로 전송하는
시나리오입니다.

<br/><br/>

## 2.3 Projection 모드

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image4.png?raw=true"></p>
<p align="center"><strong>그림 2.4 Projection 모드</strong></p>

Projection 모드는 보드가 카메라를 통해 이미지를 수신하고 최종 결과(박스가 합성된 이미지)를 RTPM으로 전송하는 시나리오입니다.

<br/><br/>

### 2.4.3 Projection 모드 실행

1.  input mode로 Camera (EVB)를 선택합니다.

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image19.png?raw=true"></p>
<p align="center"><strong>그림 2.19 input mode로 Camera(EVB) 선택</strong></p>

2.  start 버튼을 누릅니다.

3.  TOPST AI 보드에서 tcnnapp projection 모드를 실행합니다.

	```
	# tcnnapp -i camera -o rtpm
	```
 - **참고**: "-i camera" 옵션으로 명령을 실행하면 입력 경로가 기본값인 /dev/video0으로 설정됩니다. 연결된 카메라가 /dev/ 아래에서 어떤 video 디바이스로 인식되는지 확인하고, /dev/video0이 아닌 경우 "-p /dev/video*" 옵션으로 진행하시기 바랍니다.
