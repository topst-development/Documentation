# 1. 샘플 애플리케이션

이 장은 NPU 샘플 애플리케이션에 대한 가이드 문서입니다.

TOPST AI SDK는 NPU 기능을 검증하기 위한 샘플 애플리케이션인
‘tc-nn-app’을 제공합니다.

이 NPU 샘플 애플리케이션은 카메라, 이미지 파일, PC 스트림을 입력으로
사용하여 NPU 이미지 처리 결과를 LCD, 파일, PC 스트림으로
출력합니다.

<br/><br/>

## 1.1 개요

NPU 샘플 애플리케이션은 Neural Process Unit (NPU) 연산만 수행할 수
있습니다.
