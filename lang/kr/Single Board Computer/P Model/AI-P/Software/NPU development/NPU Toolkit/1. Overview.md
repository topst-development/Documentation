# 1. TOPST AI NPU Tool Kit

TOPST AI의 NPU는 HW 신경망 가속기입니다. 객체 검출, 이미지 분류, 얼굴
검출과 같은 비전 애플리케이션 신경망의 추론에 최적화되어
있습니다.

“TOPST-AI-Common-SW-NPU-Toolkit Guide” 문서는 NPU Toolkit의 사용
방법을 설명합니다.

<br/><br/>

## 1.1 개요

<p align="center"><strong>그림 1.1 TOPST AI SW Tool Kit 개요</strong></p>

- Converter
  * 네트워크 파일을 내부 네트워크 형식(.bin)으로 변환합니다
  * ONNX(PyTorch), TF-Lite, CFG(Darknet)를 지원합니다

<!-- -->

- Quantizer
  * 양자화된 네트워크를 생성합니다: float에서 int8로

<!-- -->

- Compiler
  * 양자화된 네트워크를 입력으로 사용하여 NPU Machine Code를 생성합니다
