# 1. GPIO 예제

GPIO(general-purpose input/output)는 집적 회로 또는 전기 회로 기판 상의
디지털 신호 핀으로, 입력 또는 출력을 포함한 동작을 사용자가
실행 시점에 제어할 수 있도록
해 줍니다.
GPIO는 특정 용도로 미리 정의되어 있지 않으며 기본적으로
사용되지 않습니다.
GPIO는 어셈블리 수준의 회로 네트워크 설계자(집적 회로 GPIO의 경우 회로
기판 설계자, 기판 수준 GPIO의 경우 시스템 통합자, S/I)에 의해 구현되며,
그 용도와 동작은 사용 시점에
정의됩니다.

GPIO가 수행하는 기능은 시스템에 따라 달라질 수 있으며, 일반적으로 제공되는 기능은 다음과 같습니다.

- 입출력 기능 (high=1, low=0)
- IRQ 신호 감지: Power management 모드의 suspend 상태에 있는 시스템을
  깨우는 데에도 사용할 수 있습니다.
  - Spinlock이 걸려 있는 상태에서도 접근할 수 있습니다

위의 기능을 통해 쓰기 방지 기능 사용, LED 제어, 트랜시버 설정
  활성화, 하드웨어 워치독 기능 또는 스위치 센싱을 수행할 수
  있습니다.

다음은 보드의 입력과 출력을 테스트하는 예제입니다. Raspberry Pi 핀맵을
  참고하여 핀 번호를 제어함으로써 입력과 출력을 테스트할 수
  있습니다.

<br/>

**예시**

```
$ echo "90" > /sys/class/gpio/export
$ echo "out" > /sys/class/gpio/gpio90/direction
$ echo 1 > /sys/class/gpio/gpio90/value
$ echo 0 > /sys/class/gpio/gpio90/value
```
