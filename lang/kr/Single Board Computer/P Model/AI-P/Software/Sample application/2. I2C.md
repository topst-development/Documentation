# 2. I2C 예제

inter-integrated circuit(I2C)는 흔히 "i-to-c"로 읽지만, 공식적인 발음은 "i-square-c"입니다.

I2C 통신은 데이터를 송수신하는 하나의 SDA 라인과 송수신 타이밍을
동기화하는 하나의 클럭 라인 SCL로 구성됩니다. 하나의 마스터와 하나
이상의 슬레이브로 구성되며, 최대 127개의 슬레이브를 연결할 수
있습니다.

- I2C 통신은 두 개의 라인을 사용하는 통신 방식입니다
- 하나의 마스터에 여러 슬레이브 장치를 연결하는 방식의 장점과 단점
  - 클럭 신호를 사용하는 동기식 통신 방식이므로 시간 제약이 없다는 장점
  - 슬레이브 선택을 위해 항상 주소 데이터가 첨부되므로 긴 데이터에는 적합하지 않다는 단점

2.  아래 그림은 i2c_example_app이 동작하도록 브레드보드를 배선하는
    방법을 보여줍니다.

    - 사용된 센서 모듈은 PCF8591입니다. PCF8591은 8 bit 아날로그-디지털 또는 8 bit 디지털-아날로그 컨버터 모듈이며, 각 핀이 최대 256까지의 아날로그 값을 읽을 수 있음을 의미합니다.

3.  i2c_example_app을 실행하면 밝기 값을 가져옵니다.

    ```
     root@telechips-tcc7500-main:~# ./i2c_example_app
     Target is 144.
    ```

4.  모듈을 손으로 가리고 실행하면 값이 증가합니다.

    ```
    root@telechips-tcc7500-main:~# ./i2c_example_app
    Target is 228.
    ```
