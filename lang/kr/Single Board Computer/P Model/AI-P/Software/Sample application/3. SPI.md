# 3. SPI 예제

Serial Peripheral Interface(SPI)는 I2C, CAN, UART와 같은 직렬 통신(serial
communication) 방식 중 하나입니다. 마이크로컨트롤러, 시프트
레지스터, SD 카드와 같은 소형 주변 장치 간에 데이터를
전송하기 위한 기능입니다. 간단히 말해, 장치와 장치, 즉 칩(IC)과
칩 사이에서 데이터를 주고받는 통신 방식 중 하나입니다. SPI 통신은
일대다 통신을 지원하는 동기식 통신 방식으로, 다중 통신 시
여러 개의 라인이 필요하다는 단점이 있습니다. 그리고 송신과
수신을 동시에 수행할 수 있습니다. 배선이 간단하여 간단한
센서나 메모리와 같은 칩 간의 통신에 자주
사용됩니다.

<br/><br/>
