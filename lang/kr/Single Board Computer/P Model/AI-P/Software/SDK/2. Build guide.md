# 2. 빌드 가이드

<br/><br/>

## 2.1 TOPST AI SDK

TOPST AI SDK는 Yocto Project 4.0 kirkstone을 기반으로 합니다.
따라서 TOPST AI SDK를 사용하려면 호스트 PC에 Yocto Project 환경을 구성해야 합니다.
SDK, source-mirror 및 tools를 다운로드하려면 유틸리티를 설치해야 합니다.

메타데이터를 기반으로 upstream에서 소스를 다운로드하여 빌드를 수행할 수 있습니다.
빌드가 완료되면 패키지, 이미지 및 SDK가 결과물로 제공됩니다.
그림 2.1은 Yocto Project의 태스크 프로세스를 나타냅니다.
