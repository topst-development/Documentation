# 3. 펌웨어 다운로드

이 장에서는 TOPST AI(오픈 플랫폼 보드)에 FWDN을 다운로드하고 Linux
콘솔에 로그인하는 방법을 설명합니다.

<br/><br/>

## 3.1 펌웨어 다운로드 순서

FWDN의 다운로드 순서는 다음과 같습니다:

1.  부트 모드 스위치를 fwdn 부팅 모드로 설정합니다.
2.  Windows 명령 프롬프트를 열고 FWDN ND를 테스트합니다.
3.  FWDN ND를 보드에 연결합니다.
4.  fai 파일을 다운로드합니다.

<br/><br/>

## 3.2 Fwdn 부팅으로 TOPST AI와 호스트 PC 연결

FWDN을 사용하여 빌드된 이미지를 TCC750x로 전송할 수 있습니다.
TCC750x는 이더넷과 UART를 사용하여 FWDN 기능을 제공합니다.

### 3.2.1 호스트 PC 환경 설정

FWDN의 자세한 구성 설정은 'TOPST AI-Software-Quick guide-1.Firmware Download'
문서의 3. FWDN 장을 참조하십시오.

### 3.3.3 부트 모드 변경

부트 모드 스위치를 누른 상태에서 전원을 공급하면 FWDN 부팅 프로세스가
시작됩니다. 부트 모드 스위치를 누르지 않고 전원을 공급하면 일반 부팅
프로세스가 시작됩니다.
리셋 스위치를 누르면 시스템이 리셋됩니다. 펌웨어를 다운로드하려면
부트 모드 스위치와 리셋 스위치를 동시에 눌러 FWDN 부팅 모드로
진입하십시오.

### 3.3.4 Windows에서의 FWDN

1.  이미지 빌드 후 생성된 fwdn 폴더를 바탕화면에 복사하고, 해당 폴더
    안에 아래 파일을 저장합니다.
    FWDN을 사용하려면 아래 링크에서 펌웨어 툴을 다운로드할 수 있습니다:

    - <[FWDN Tool](https://topst-downloads.s3.ap-northeast-2.amazonaws.com/Yocto/pre/topst.ai.pre.20240425001.windows.zip)>
  
    SD_Data.fai 이미지를 topst.ai.pre.20240425001.windows에 복사합니다.
    SD_Data.fai는 **"{build_dir}/build/tcc7500-main/tmp/deploy/fwdn/"**에 있습니다.


2.  **fwdn_batch.bat**을 실행하고 **포트 번호**를 입력합니다.

    <p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/Firmware%20Download.image5.png?raw=true"
    style="width:4.22917in;height:3.62292in"</p>

    <p align="center"><strong> 그림 3.4 FWDN 포트 번호 입력</strong></p>
