# 1. 환경 설정 

<br/><br/>


## 1.1 Ubuntu 설치

TOPST AI Linux SDK는 Yocto Project를 기반으로 하므로, TOPST AI SDK의 Linux 버전은 Yocto 프로젝트를 따릅니다.

다른 버전의 Linux를 설치할 수도 있으나, 본 문서에서는 Ubuntu 22.04를 기준으로 TOPST AI Linux SDK를 설명합니다.

Linux 배포판 버전:

- Ubuntu 22.04 (LTS)

<br/><br/>

## 1.2 WSL2 Ubuntu 설치 

1. "관리자 권한으로 실행"으로 Windows PowerShell을 실행합니다.
2. WSL2 시스템을 활성화합니다.
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. 가상 머신 기능을 활성화합니다.
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. WSL 2를 기본 버전으로 설정합니다.
    ```
    wsl --set-default-version 2
    ```
5. Microsoft Store에서 Ubuntu 22.04.3 LTS를 검색하여 다운로드합니다.

    * Linux 커널 업데이트 패키지를 다운로드해야 하는 경우, [여기](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual)에서 최신 패키지를 다운로드하십시오.

## 1.3 Linux 환경 설정

<br/>

### 1.3.1 SSH 및 Samba 설치 

Linux 환경에서의 작업은 느리지만, SSH와 Samba를 사용하면 훨씬 더
편리한 환경에서 작업할 수 있습니다. SSH와

Samba를 사용하면 원격 컴퓨터에서 명령을 실행하고 다른 컴퓨터로 파일을
복사할 수 있습니다.

SSH와 Samba가 이미 설치되어 있거나 사용하지 않을 경우, 이 장은
건너뛰어도 됩니다.

```
 $ sudo apt-get install -y net-tools openssh-server samba 
```

SSH와 Samba를 다운로드한 후에는 각 프로그램을 사용자 환경에 맞게
설정해야 합니다.

<br/>

### 1.3.2 Yocto Project용 유틸리티 설치 

유틸리티를 한 번에 설치합니다. Yocto Project를 사용하려면 다음
유틸리티가 Host PC(개인용 컴퓨터 또는

개발 서버)에 설치되어 있어야 합니다.

```
$ sudo apt-get install -y gawk wget git-core diffstat unzip texinfo gcc-multilib
$ sudo apt-get install -y build-essential chrpath socat cpio python3 python3-pip python3-pexpect
$ sudo apt-get install -y xz-utils debianutils iputils-ping python3-git python3-jinja2 libegl1-mesa libsdl1.2-dev pylint xterm

```

<br/>

### 1.3.3 Repo 설치

Repo를 통해 TOPST AI SDK를 다운로드할 수 있습니다.

repo를 설치하려면 다음 웹사이트를 참조하십시오:
<https://source.android.com/source/downloading.html>

repo가 이미 설치되어 있는 경우, 재설치 없이 사용할 수 있습니다.

repo를 설치하기 전에 설치된 Python 버전(3.6 이상)이 올바르게 설정되어 있어야 합니다.

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
$ sudo apt-get install repo
```

<br/>

repo 오류가 발생하는 경우, 최신 버전을 다운로드하여 /usr/bin/ 폴더에 직접 넣으십시오.

```
$ mkdir -p ~/bin
$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo &gt;~/bin/repo
$ chmod a+x ~/bin/repo
$ sudo mv ~/bin/repo /usr/bin/repo
```
