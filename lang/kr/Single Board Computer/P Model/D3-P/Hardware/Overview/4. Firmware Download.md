# 4. 펌웨어 다운로드를 위해 TOPST D3를 호스트 PC에 연결



Firmware Downloader(**FWDN**)는 호스트 PC에서 USB 통신을 통해 TOPST D3에 ROM 이미지를 기록합니다.  

TOPST D3에는 하나의 Boot Mode 버튼이 있으며, Boot Mode 버튼을 통해 다음과 같은 두 가지 부팅 모드를 지원합니다:
- USB Boot Mode는 호스트 PC의 **FWDN** 프로그램을 사용하여 ROM 이미지를 기록할 때 사용합니다.
- eMMC Boot Mode는 eMMC 장치에 저장된 ROM 이미지를 사용하여 TOPST D3를 부팅할 때 사용합니다.

**참고**: USB 2.0 D/H 포트는 펌웨어 다운로더(**FWDN**)에 사용됩니다.  

**FWDN**을 사용하려면 다음과 같이 TOPST D3를 호스트 PC에 연결하십시오:
1. 호스트 PC에 VTC 드라이버가 설치되어 있는지 확인하십시오. VTC 드라이버가 설치되어 있지 않은 경우, topst.ai에서 제공하는 **FWDN** 가이드라인에 따라 설치하십시오.
2. USB Type-A 케이블 1개를 준비하십시오.
3. USB Type-A 케이블을 사용하여 TOPST D3의 USB 2.0 D/H를 호스트 PC에 연결하십시오.
4. 아래 두 가지 방법 중 하나를 사용하여 TOPST D3의 부팅 모드를 변경하십시오.<br/>
   1. 방법 1
       * TOPST D3에 아직 전원이 공급되지 않은 경우, FWDN 버튼을 누른 상태에서 TOPST D3에 5V 전원을 연결하십시오.
       * FWDN Boot mode 버튼을 놓으십시오.<br/>
   2. 방법 2
       * TOPST D3에 이미 전원이 공급된 경우, Reset 버튼과 FWDN Boot mode 버튼을 누르십시오.
       * FWDN Boot mode 버튼을 놓으십시오.
5. **FWDN** 가이드에 따라 ROM 이미지를 다운로드하십시오.

그림 4.1은 TOPST D3의 Reset 버튼, FWDN 버튼 및 USB 2.0 D/H의 외관을 보여줍니다.
