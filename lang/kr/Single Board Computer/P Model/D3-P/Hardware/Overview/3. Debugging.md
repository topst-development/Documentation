## 3.3 UART/JTAG 서브보드  

UART/JTAG 서브보드는 시리얼 포트 및 JTAG용 디버깅 보드입니다. USB Type-C 케이블을 사용하여 UART/JTAG 서브보드를 호스트 PC에 연결하면 시리얼 로그를 확인할 수 있습니다.   

그림 3.3은 UART/JTAG 서브보드의 개요를 보여줍니다.  
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/95f161ce-8e9c-470c-842e-fd33b257304d"></p>
<p align="center"><strong>그림 3.3 UART/JTAG 서브보드 (상면도)</strong></p>

표 3.1은 UART/JTAG 서브보드의 커넥터를 설명합니다.  

**표 3.1 UART/JTAG 서브보드 설명:**  

| 항목 | 설명                                           |
|:----:|------------------------------------------------|
| u10  | TOPST D3 연결용 FFC 커넥터                     |
| u20  | 디버거 연결용 Male Pin Header                  |
| u30  | MCU 디버깅용 Debug 포트 (USB Type-C)           |
| u40  | A53 Core 디버깅용 Debug 포트 (USB Type-C)      |
| u50  | A72 Core 디버깅용 Debug 포트 (USB Type-C)      |  

<br/><br/>

## 3.4 UART/JTAG 서브보드를 TOPST D3에 연결  

이 장에서는 TOPST D3와 UART/JTAG 서브보드를 연결하는 방법을 설명합니다.  

다음과 같이 Flexible Flat Cable(FFC)을 사용하여 UART/JTAG 서브보드를 TOPST D3에 연결합니다.
1. FFC 1개와 USB Type-C 케이블 1개를 준비합니다.
2. UART/JTAG 서브보드의 Debug I/F 커넥터와 TOPST D3의 Debug I/F 커넥터에 FFC를 연결합니다. <br/>
    * FFC의 파란색 선이 위를 향하도록 연결하는 것이 중요합니다.
3. USB Type-C 케이블을 사용하여 UART/JTAG 서브보드를 호스트 PC에 연결합니다. <br/>
    * 대상 코어에 따라 적절한 UART 포트를 선택하려면 표 3.1을 참조하십시오. 예를 들어 A72 UART는 메인 코어(Cortex-A72 Quad)의 UART 포트에 연결할 수 있습니다.
4. 호스트 PC의 터미널 애플리케이션을 통해 시리얼 로그 메시지를 확인합니다.

그림 3.4는 UART/JTAG 서브보드의 Debug와 연결된 TOPST D3의 Debug 위치를 보여줍니다.

## 3.5 JTAG 디버거를 TOPST D3에 연결  

이 장에서는 JTAG 디버거를 TOPST D3에 연결하는 방법을 설명합니다.  

다음과 같이 JTAG 디버거를 TOPST D3에 연결합니다.
1. JTAG 디버거 1개를 준비합니다.
2. 위의 "UART/JTAG 서브보드를 TOPST D3에 연결" 장을 참조하여 UART/JTAG 서브보드를 TOPST D3에 연결합니다.
3. UART/JTAG 서브보드의 JTAG Header에 JTAG 디버거를 연결합니다.
