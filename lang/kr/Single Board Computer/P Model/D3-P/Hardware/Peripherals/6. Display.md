# 6. DisplayPort 커넥터

TOPST D3에는 최대 4Kp60 해상도의 DP 1.4를 지원하는 DisplayPort가 1개 있습니다.  


그림 6.1은 TOPST-D3에서 DisplayPort를 사용하여 디스플레이를 활성화하는 방법을 나타냅니다. HDMI만 지원하는 다른 디스플레이 장치에 연결하려면 DP to HDMI 변환 케이블을 사용할 수 있습니다.
