# 2. 소프트웨어 아키텍처

그림 2.1은 TCC8050의 소프트웨어 아키텍처를 나타냅니다. 3개의 코어는 다음과 같은 기능으로 구성되며, 각 코어는 IPC를 통해 정보를 교환합니다.

TCC8050은 CA72(메인 코어)를 사용하여 멀티미디어 기능을 제공하고, CA53(서브 코어)은 동작 중 메인 코어의 즉각적인 처리(예: 후방 카메라)를 제공합니다. CR5는 실시간 OS를 제공하여 차량과 통신하는 데 사용되는 기능을 제공합니다.
