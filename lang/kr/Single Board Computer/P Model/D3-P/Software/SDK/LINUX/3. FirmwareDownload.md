# 3. 펌웨어 다운로드

이 장에서는 TOPST D3(개방형 플랫폼 보드)에 ***FWDN***을 다운로드하고 Linux 콘솔에 로그인하는 방법을 설명합니다.  
***FWDN V8***은 Windows 10 64비트 및 Linux 환경에서 펌웨어를 다운로드하기 위한 PC 도구입니다. 이 장에서는 Windows 및 Linux 환경에서 다운로드하는 경우를 설명합니다.

<br/><br/>

## 3.1 펌웨어 다운로드 순서

***FWDN***의 다운로드 순서는 다음과 같습니다:

1. 부팅 모드 스위치를 USB 부팅 모드로 설정합니다.
2. Windows 프롬프트 또는 Linux 콘솔을 열고 ***FWDN V8***을 테스트합니다.
3. ***FWDN V8***을 보드에 연결합니다.
4. fai 파일을 다운로드합니다.

<br/><br/>

## 3.2 USB 부팅으로 TOPST D3와 호스트 PC 연결

**SW2**를 누른 상태에서 전원을 공급하면 USB 부팅 프로세스가 시작됩니다. **SW2**를 누르지 않고 전원을 공급하면 일반 부팅 프로세스가 시작됩니다.

**SW1**을 누르면 시스템이 리셋됩니다. 펌웨어를 다운로드하려면 **SW1**과 **SW2**를 동시에 눌러 USB 모드로 부팅하십시오.

## 3.3 FWDN 다운로드 준비

1. "output.fwdn.zip" 압축 해제 
    ```
    $ mkdir images
    $ mv ./output.fwdn.zip ./images
    $ cd images
    $ unzip output.fwdn.zip
    ```
2. "images" 폴더를 Windows C 드라이브로 복사합니다.
    ```
    $ cd ..
    $ cp -r /images /mnt/c/
    ```

## 3.5 Linux 환경에서의 FWDN

Linux 환경에서는 "./fwdn.sh" 명령으로 TOPST 이미지를 다운로드할 수 있습니다.

```
$ ./fwdn.sh
```

## 3.6 UART를 이용한 TOPST 연결

1. UART 연결을 사용하여 펌웨어 다운로드가 정상적으로 완료되었는지 확인합니다.
2. Windows 환경에서 시리얼 포트 드라이버(CP210x Windows Driver)를 설치합니다.([다운로드 링크](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads))
3. 부팅 모드를 일반(eMMC)으로 변경하고 재부팅합니다. C to C 케이블이 아닌 USB Type-C to USB 2.0 또는 3.0 케이블을 사용하십시오.
