# 2. 빌드 가이드

<br/><br/>

## 2.1 TOPST D3 Linux SDK 빌드 준비

TOPST D3 Linux SDK는 Yocto Project 3.1 Dunfell을 기반으로 합니다. 따라서 TOPST D3 Linux SDK를 사용하려면 호스트 PC에 Yocto Project 환경을 설정해야 합니다. SDK, source-mirror 및 tools를 다운로드하려면 유틸리티를 설치해야 합니다.  

<br/><br/>

## 2.2 Yocto Project  

Yocto Project는 임베디드 Linux 개발에 중점을 둔 오픈 소스 프로젝트입니다.  
Linux 이미지를 만들기 위해 Poky인 Open Embedded 프로젝트와 ***bitbake***를 빌드 시스템으로 조합하여 사용합니다.  
Yocto Project를 사용하면 부트로더, 커널 및 rootfs를 동시에 빌드할 수 있습니다.  

<br/><br/>
