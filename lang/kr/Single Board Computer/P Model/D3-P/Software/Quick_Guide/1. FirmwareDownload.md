# 1. FWDN 가이드

이 장에서는 TOPST D3에 Firmware Downloader(***FWDN***)를 다운로드하고 Linux 콘솔에 로그인하는 방법을 설명합니다.

<br><br>

## 1.1   펌웨어 다운로드 순서

***FWDN***의 다운로드 순서는 다음과 같습니다:

1. FWDN 모드로 진입합니다.
2. USB A-to-A 케이블을 USB 2.0 FWDN 포트에 연결합니다.
3. TOPST 이미지를 다운로드합니다.

<br><br>

## 1.2   FWDN 모드 진입

**SW2**(FWDN Mode Convert) 버튼을 누른 상태에서 전원을 연결하여 ***FWDN*** 모드로 진입하십시오. 또는 전원이 연결되어 있는 경우 **SW2** 버튼(FWDN Mode Convert)을 누른 상태에서 **SW1** 버튼(System Reset)을 눌러 ***FWDN*** 모드로 진입할 수 있습니다.

### 1.2.1 Windows 환경에서의 USB 연결

호스트 PC에서 Vendor Telechips Certification(VTC) 드라이버([telechips driver](https://drive.google.com/file/d/1muQnY8kuKxDsy3p3FUiQqcG34Zjk-mnR/view?usp=sharing)에서 확인 가능)를 관리자 권한으로 실행하여 설치하십시오. 위와 같이 FWDN 모드에서 USB를 연결하면 Telechips VTC USB 드라이버가 그림 1.2와 같이 설정됩니다.

## 1.3 CLI 도구를 이용한 Windows 환경에서의 FWDN 실행
  
FWDN을 사용하려면 아래 링크에서 펌웨어 도구를 다운로드하십시오:

- <[FWDN Tool](https://drive.google.com/file/d/1UzArkpt-Aw67YhAMtlSfkELEHYBMBqT7/view?usp=sharing)>

다음과 같이 사용하여 아래의 각 TOPST 이미지를 다운로드할 수 있습니다.

- 스크립트 위치: topst.d3.pre.20240425001\fwdn.bat


```
.\fwdn.bat
```
다음 그림에서는 .\fwdn.bat 명령을 사용하여 전체 TOPST 이미지를 다운로드합니다.
SW1(Reset) 버튼을 눌러 TOPST D3를 재부팅하면 Ubuntu 런처가 실행됩니다.
