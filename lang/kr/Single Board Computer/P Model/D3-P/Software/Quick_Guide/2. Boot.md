#  2. 부팅 가이드

이 장에서는 TOPST D3를 부팅하고 각 코어에 로그인하는 방법을 설명합니다.

<br><br>

## 2.1 부팅 순서

***FWDN***의 다운로드 순서는 다음과 같습니다:

1. DP 모니터를 위한 DP 케이블을 연결합니다.
2. 디버깅 보드와 TOPST D3를 연결합니다.
3. 콘솔에 로그인하고 각 코어에 대한 디버깅을 수행하기 위해 각 TOPST USB 케이블을 디버깅 보드에 연결합니다.
4. 5V 전원을 연결합니다.

<br><br>
