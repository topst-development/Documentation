# 4. 툴체인

툴체인은 개발 과정에서 매우 중요한 구성 요소이며, 특히 TOPST-VCP 보드와 같은 특수 하드웨어를 다룰 때 더욱 중요합니다. 툴체인은 대상 플랫폼에 맞게 코드를 컴파일, 링크, 디버깅할 수 있는 도구 모음을 제공합니다.

<br/><br/>

## 4.1 툴체인 개요

툴체인은 일반적으로 컴파일러, 링커, 어셈블러, 디버거 등의 도구로 구성됩니다. 이러한 구성 요소는 서로 연동하여 소스 코드를 대상 하드웨어에서 실행할 수 있는 실행 프로그램으로 변환합니다. 하드웨어 아키텍처와 플랫폼이 다양하므로 대상 보드에 맞는 툴체인을 선택하고 구성하는 것이 필수적입니다

<br/><br/>

## 4.2 보드에 맞는 툴체인 선택

ARM Cortex-R5 아키텍처를 기반으로 하는 TOPST-VCP 보드에는 gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi 툴체인을 권장합니다.

이 툴체인은 ARM 아키텍처에 최적화되어 있으며, 보드에 탑재된 TCC7045 칩과의 호환성을 보장합니다.

<br/><br/>

## 4.3 툴체인 설치 및 설정

다음 단계에 따라 툴체인을 다운로드하고 압축을 해제한 후 설정합니다.

1. **툴체인 다운로드** : wget 명령을 사용하여 Linaro 웹사이트에서 툴체인을 다운로드합니다 :

    ```
    $ wget https://releases.linaro.org/components/toolchain/binaries/7.2-2017.11/arm-eabi/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```

2. **툴체인 압축 해제** : 다운로드가 완료되면 .tar.xz 파일의 내용을 추출합니다.

    ```
    $ tar -xvf gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```

    <img src="https://github.com/topst-development/Documentation/assets/161264431/cd69488b-5f20-4b5e-95dd-6b1a9f37e38c">

3. **툴체인을 /opt로 이동** : /opt 디렉터리는 Linux에서 선택적 소프트웨어를 위한 표준 위치입니다. 추출한 툴체인을 이 디렉터리로 이동합니다.

    ```
    $ sudo mv gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi /opt/
    ```

## 4.4 툴체인 설치 확인

툴체인이 올바르게 설치되었는지 확인하려면 다음을 수행합니다.

1. **툴체인 디렉터리로 이동** :

    ```
    $ cd /opt/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi
    ```

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/466c6ed7-4105-4cbd-9652-401bb18c7e56">
</p>
<p align="center"><strong>그림 4.4 툴체인 디렉터리로 이동</strong></p>

2. **설치된 GCC 컴파일러 버전 확인** :
    
    ```
    $ ./bin/arm-eabi-gcc --version
    ```
