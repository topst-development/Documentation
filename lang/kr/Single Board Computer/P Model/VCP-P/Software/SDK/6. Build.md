#  6. 소스 코드 빌드

소스 코드를 성공적으로 받았다면, 다음의 중요한 단계는 소스 코드를 빌드하여 TOPST-VCP 보드에서 최적으로 동작하도록 만드는 것입니다.

<br/><br/>

## 6.1 Makefile과 빌드 시스템의 이해

Makefile은 많은 빌드 시스템의 근간이 되는 요소입니다. Makefile에는 make 유틸리티에게 프로그램을 컴파일하고 링크하는 방법을 알려주는 규칙과 지시자가 포함되어 있습니다. Makefile을 활용하면 개발자는 빌드 과정을 자동화하여 일관성과 효율성을 확보할 수 있습니다.

<br/><br/>

## 6.2 빌드 프로세스 시작

소스 코드 빌드를 시작하려면 다음 단계를 수행하십시오 :

1. **다음 명령을 사용하여 빌드 디렉터리로 이동하십시오 :**

    ```
    $ cd build/tcc70xx/gcc/
    ```

2. **다음 명령을 사용하여 make 명령을 실행하십시오 :**

    ```
    $ make
    ```

이 명령은 현재 디렉터리의 Makefile을 읽고 빌드 프로세스를 실행합니다.

3. **빌드 결과 확인** : 빌드 프로세스가 완료되면 터미널에서 다음 출력 파일들을 확인할 수 있습니다
    - output/tcc70xx_pflash_boot.rom
    - output/tcc70xx_pflash_boot_2M_ECC.rom
    - output/tcc70xx_pflash_boot_3M_ECC.rom
    - output/tcc70xx_pflash_boot_4M_ECC.rom

    이 파일들은 이후 개발 단계에서 매우 중요하므로 반드시 존재하는지 확인하십시오.
