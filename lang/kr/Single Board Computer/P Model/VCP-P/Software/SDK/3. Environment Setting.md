# 3. 환경 설정

TOPST-VCP 보드를 위한 개발을 성공적으로 수행하려면 잘 구성된 개발 환경이 필요합니다. 이 장에서는 필수 도구, 유틸리티 및 소프트웨어 패키지를 모두 갖춘 Ubuntu 22.04 시스템을 구축하는 데 필요한 단계를 안내합니다.

<br/><br/>

## 3.1 필수 도구 및 유틸리티 설치

TOPST-VCP 보드의 세부 사항을 다루기에 앞서, 몇 가지 기본 유틸리티와 도구를 설치해 두는 것이 매우 중요합니다. 이러한 도구는 이후의 다른 소프트웨어와 설정이 구축되는 기반이 됩니다.

1. **터미널** : Ubuntu 22.04에는 터미널이 기본으로 포함되어 있습니다. 이후 단계의 상당수가 터미널 명령을 필요로 하므로 사용법을 익혀 두십시오.
2. **텍스트 편집기**: Ubuntu에는 기본 텍스트 편집기가 포함되어 있으나, 선호에 따라 “nano”, “vim”과 같은 보다 강력한 편집기나 “gedit”, “VSCode”와 같은 그래픽 편집기의 설치를 고려할 수 있습니다.
3. **SSH 도구** : 개발 과정에서 다른 시스템이나 장치, 특히 TOPST- VCP 보드에 원격으로 접속하는 작업은 필수적일 수 있습니다. 다양한 SSH 도구가 이를 지원합니다:
4. **Putty** : SSH를 비롯한 여러 프로토콜을 지원하는 널리 사용되는 무료 오픈소스 터미널 에뮬레이터입니다. 가볍고 사용하기 쉽습니다.
5. **Tera Term** : 기능이 더욱 풍부한 오픈소스 터미널 에뮬레이터로, SSH를 포함한 다양한 통신 프로토콜을 폭넓게 지원합니다.

구체적인 필요와 선호에 따라 SSH 접속을 위해 이러한 도구 중 하나 이상을 선택할 수 있습니다.  

**참고로 본 가이드 문서에서는 putty를 사용합니다.**

## 3.2 apt를 사용한 소프트웨어 설치

“apt” 패키지 관리자는 Ubuntu의 강력한 도구로, 소프트웨어 패키지를 손쉽게 설치, 업데이트 및 관리할 수 있게 해 줍니다.

<br/>

### 3.2.1 패키지 목록 업데이트

새로운 소프트웨어를 설치하기 전에 사용 가능한 패키지 목록을 업데이트하는 것이 좋습니다. 이를 통해 최신 버전과 의존성을 확보할 수 있습니다.

```
$ sudo apt update
$ sudo apt upgrade
```

이 명령은 저장소에서 사용 가능한 최신 패키지 목록을 가져옵니다.

### 3.2.2 일반 개발 도구 설치

대부분의 개발 작업, 특히 TOPST-VCP 보드를 위한 작업에는 몇 가지 일반적인 도구가 필수적입니다.

다음 명령을 사용하여 이러한 도구를 설치하십시오 :

```
$ sudo apt install build-essential git
```

이 명령은 buide-essential 패키지와 git을 모두 설치합니다.
