# 2. 사전 준비 사항

TOPST-VCP 보드의 설정 및 개발 과정을 본격적으로 시작하기 전에 고려해야 할 몇 가지 사전 준비 사항이 있습니다. 본 장에서는 원활한 개발 경험을 보장하기 위해 권장 Linux 배포판, 하드웨어 요구 사항 및 필수 기초 지식을 안내합니다.

<br/><br/>

## 2.1 Linux 배포판 권장 사항

본 가이드에서는 개발 환경을 **Ubuntu 22.04** 에 구성할 것을 권장합니다. 이 버전의 Ubuntu는 안정적인 플랫폼과 폭넓은 커뮤니티 지원을 제공하여 TOPST-VCP 보드 및 관련 툴체인과의 호환성과 사용 편의성을 보장합니다.

다운로드 및 설치:

- Ubuntu 공식 웹사이트를 방문하여 Ubuntu 22.04 LTS(Long Term Support) 배포판을 다운로드합니다.
- 제공된 설치 지침에 따라 개발용 호스트 PC에 Ubuntu 22.04를 설치합니다.

## 2.2 하드웨어 요구 사항

TOPST-VCP 보드와 연결하여 개발 작업을 수행하려면 다음 하드웨어 구성 요소가 필수적입니다 :

- TOPST-VCP 보드: 하드웨어 작업에 적합한 작업 공간에 보드를 준비해 두십시오.
- USB-C 케이블: 개발용 호스트 PC와 TOPST-VCP 보드 간의 연결에 사용됩니다. 개발 과정 전반에 걸쳐 안정적인 연결을 유지할 수 있도록 품질이 좋은 케이블을 사용하십시오.

필요한 하드웨어를 준비한 후, USB-C 케이블을 사용하여 TOPST-VCP 보드를 개발용 호스트 PC에 연결합니다. 개발 중 발생할 수 있는 문제를 방지하기 위해 연결이 견고한지 확인하십시오.

<br/><br/>

## 2.3 사전 지식 요구 사항

시작하기 전에 다음 개념을 숙지하는 것이 필수적입니다:

- Ubuntu 기초: Ubuntu 22.04 환경에서 탐색하고 작업하는 방법에 대한 기본적인 이해.
- TOPST-VCP의 부팅 모드: TOPST-VCP 보드는 다양한 부팅 모드를 제공하므로 개발자는 특정 프로젝트에 가장 적합한 모드를 선택할 수 있습니다.

부팅 모드를 선택하는 방법에 대한 자세한 지침은 보드와 함께 제공됩니다. 제공된 문서를 참조하여 개발 목적에 맞는 적절한 모드를 선택하십시오
