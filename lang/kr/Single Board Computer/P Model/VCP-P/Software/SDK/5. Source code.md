#  5. 소스 코드 가져오기

소스 코드는 모든 개발 프로젝트의 근간을 이룹니다. 소스 코드에는 특정 플랫폼용 소프트웨어를 빌드하고 실행하는 데 필요한 모든 파일, 설정 및 지침이 포함되어 있습니다. TOPST-VCP 보드의 경우, 호환성과 최적의 성능을 보장하기 위해 올바른 소스 코드를 가져오는 것이 매우 중요합니다.

이 장에서는 널리 사용되는 버전 관리 시스템인 git을 사용하여 소스 코드를 가져오는 과정을 안내합니다.

<br/><br/>

## 5.1 TOPST-VCP 소스 코드 클론

TOPST-VCP 보드의 소스 코드를 가져오려면 git clone 명령을 사용합니다. 이 명령은 원격 저장소의 사본을 로컬 시스템에 생성하여 코드를 직접 다룰 수 있게 해줍니다.

TOPST-VCP 소스 코드를 클론하려면 다음 단계를 따르십시오:

1. **터미널 열기** : Ubuntu 22.04 시스템에서 터미널 애플리케이션을 실행합니다.
2. **원하는 디렉터리로 이동** : 소스 코드를 저장할 적절한 위치를 시스템에서 선택합니다. 예를 들어 사용자 홈 디렉터리에 저장하려면 다음 명령을 사용합니다

    ```
    $ cd ~
    ```

<p align="center"><strong>그림 5.1 원하는 디렉터리로 이동</strong></p>


3. **저장소 클론** : 다음 명령을 사용하여 제공된 git 주소에서 TOPST-VCP 소스 코드를 클론합니다

    ```
    $ git clone https://gitlab.com/topst.ai/topst-vcp.git
    ```

    <img src="https://github.com/topst-development/Documentation/assets/161264431/db75cc26-4056-4742-a818-37108feb3a59">
</p>
<p align="center"><strong>그림 5.2 저장소 클론</strong></p>

4. **클론한 디렉터리로 이동** : 클론 과정이 완료되면 다음 명령을 사용하여 소스 코드가 들어 있는 디렉터리로 이동합니다

    ```
    $ cd topst-vcp
    ```

이제 시스템에 TOPST-VCP 소스 코드의 로컬 사본이 준비되었으며, 빌드 및 개발을 진행할 수 있습니다.

<br/><br/>

## 5.2 소스 코드 구조 익히기

클론한 후에는 소스 코드의 디렉터리 구조와 내용을 익혀 두는 것이 좋습니다. 이를 통해 특정 파일이 어디에 있는지, 코드베이스가 어떻게 구성되어 있는지 더 잘 이해할 수 있습니다.

- ls와 같은 명령을 사용하여 디렉터리의 내용을 나열합니다.
- 주요 디렉터리와 파일을 살펴보고 그 목적과 기능을 파악합니다.

```
$ ls -al
```
