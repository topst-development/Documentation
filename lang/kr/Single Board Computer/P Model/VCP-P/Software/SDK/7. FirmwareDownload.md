# 7. TOPST VCP 하드웨어로 다운로드

빌드된 소프트웨어를 TOPST-VCP 보드로 전송하는 것은 개발 과정에서 매우 중요한 단계입니다. 이 장에서는 Linux 기반 개발 환경을 사용하여 VCP 하드웨어에 소프트웨어를 다운로드하는 방법에 대한 포괄적인 가이드를 제공합니다.

<br/><br/>

## 7.1 하드웨어 준비

다운로드 과정을 시작하기 전에 TOPST-VCP 보드가 안정적인 위치에 있고 방해 요소가 없는지 확인하십시오. 모든 스위치와 커넥터에 쉽게 접근할 수 있는지 확인하고 3.3v 전원 케이블이 올바르게 연결되어 있어야 합니다.

<br/><br/>

## 7.2 개발 호스트 PC에 하드웨어 연결

1. **USB C 케이블 연결:** USB C 케이블을 사용하여 TOPST-VCP 보드를 개발 호스트 PC에 연결합니다.
2. **연결 확인**: Linux 시스템에서 다음 명령을 실행합니다

    ```
    $ sudo dmesg | grep tty
    ```

## 7.3 빌드된 소프트웨어 전송

1. **보드를 다운로드 모드로 설정 :** TOPST-VCP 보드에서 FWDN 스위치를 FWDN 위치로 전환합니다. PORN 버튼을 눌러 리셋합니다. 이제 보드는 FWDN 다운로드 모드입니다.

2. **다운로드 명령 실행** : FWDN 도구를 사용하여 4MB 플래시용 소프트웨어를 보드에 다운로드합니다

    ```
    $ sudo ../../../tools/fwdn_vcp/fwdn --fwdn ../../../tools/fwdn_vcp/vcp_fwdn.rom -w output\tcc70xx_pflash_boot_4M_ECC.rom
    ```

## 7.4 보드의 소프트웨어 검증

소프트웨어가 보드에 다운로드되면 올바르게 동작하는지 검증하는 것이 중요합니다:

1. **minicom 설치**  
    ```
    $ sudo apt install minicom
    ```

2.  **시리얼 연결 열기** : 다음 명령을 사용하여 시리얼 연결을 시작합니다

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

## 7.5 일반적인 문제 해결

세심하게 준비하더라도 다운로드 과정에서 간혹 문제가 발생할 수 있습니다. 다음은 몇 가지 일반적인 문제에 대한 해결 방법입니다:

**문제:** fwdn 도구가 ttyUSB0 장치에 접근할 권한이 없다고 보고합니다.

**해결 방법** : 이 문제는 사용자 계정에 시리얼 장치에 접근하는 데 필요한 권한이 없을 때 발생합니다. 사용자 계정을 dialout 그룹에 추가하여 이러한 권한을 부여할 수 있습니다.

1. **사용자 그룹 권한 수정** : 다음 명령을 실행합니다

    ```
    $ sudo usermod -aG dialout $USER
    ```
<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/a7552057-86de-4c49-876d-d50435bd16e4">
</p>
<p align="center"><strong>그림 7.8 사용자 그룹 권한 수정</strong></p>


2. **로그아웃 후 다시 로그인** : 그룹 변경 사항이 적용되려면 현재 세션에서 로그아웃한 후 다시 로그인해야 합니다. 그 후 ttyUSB0 장치에 다시 접근해 보십시오

발생하는 문제의 대부분은 해결 방법이나 우회 방법이 있다는 점을 기억하십시오. 오류 메시지를 이해하고 의심스러운 경우 문서나 온라인 커뮤니티를 참조하는 것이 필수적입니다.

**문제** : minicom을 사용할 때 TOPST-VCP 보드와 통신이 제대로 되지 않거나 비정상적으로 동작합니다.

**해결 방법** :이 문제는 minicom의 기본 흐름 제어가 하드웨어로 설정되어 있기 때문에 발생할 수 있습니다. TOPST-VCP 보드와 원활하게 통신하려면 흐름 제어를 "none"으로 설정해야 합니다.


1. **minicom 실행 :**

    다음을 입력하기만 하면 minicom 도구를 시작할 수 있습니다 :

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

</p>
<p align="center"><strong>그림 7.9 minicom 실행</strong></p>

2. **설정 화면 접근 :** minicom에서 Ctrl-A를 누른 다음 “o”를 눌러 설정 화면에 접근합니다.

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/79fa7579-374f-4714-9490-3a1d3fe40a70">

<p align="center"><strong>그림 7.10 설정 화면 접근</strong></p>

3. **시리얼 포트 설정으로 이동** : 옵션 목록에서 "Serial port setup"을 선택합니다
4. **흐름 제어 수정 :** 시리얼 포트 설정에서 “ F”를 눌러 하드웨어 흐름 제어를 "No"로 전환합니다.

5. **종료 및 저장** : 완료되면 설정을 종료하고 구성을 저장합니다. 이제 minicom이 TOPST-VCP 보드와 올바르게 통신할 것입니다.
