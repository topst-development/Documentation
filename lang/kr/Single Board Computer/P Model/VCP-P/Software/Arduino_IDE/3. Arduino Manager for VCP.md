# 3. TOPST VCP Arduino 보드 매니저

이 저장소는 TOPST VCP용 Arduino 보드 매니저를 제공합니다. 이 보드 매니저를 사용하면 Arduino IDE에 TOPST VCP 보드 지원을 손쉽게 추가할 수 있으며, 익숙한 도구를 사용하여 프로그램을 작성하고 업로드할 수 있습니다.

<br/><br/>

## 3.1 주요 기능

- TOPST VCP용 보드 정의를 간편하게 설치할 수 있습니다.
- Arduino IDE와 호환됩니다.
- 모든 주요 TOPST VCP 보드 모델을 지원합니다.

<br/><br/>

## 3.2 설치

Arduino IDE에 TOPST VCP 보드 매니저를 설치하려면 다음 단계를 따르십시오:

1. Arduino IDE를 **관리자 권한으로 실행**하여 엽니다.
2. `File > Preferences`로 이동합니다.
3. "Additional Board Manager URLs" 필드에 다음 URL을 추가합니다:
   ```
   https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
   ```
   이 필드에 이미 다른 URL이 있는 경우 쉼표로 구분하십시오.

4. "OK"를 클릭하여 설정을 저장합니다.
5. `Tools > Board > Boards Manager...`로 이동합니다.
6. Boards Manager에서 "TOPST VCP"를 검색합니다.
7. TOPST VCP 항목 옆의 "Install"을 클릭합니다.

<br/><br/>

## 3.3 사용 방법

설치 후 Arduino IDE의 `Tools > Board` 메뉴에서 TOPST VCP 보드를 선택할 수 있습니다. 사용 중인 하드웨어에 해당하는 보드를 선택한 다음, 평소와 같이 스케치를 작성하고 업로드하십시오.
