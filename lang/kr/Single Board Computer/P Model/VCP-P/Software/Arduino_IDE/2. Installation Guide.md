# 2. TOPST VCP Arduino Core 설치 가이드

본 가이드는 Arduino 통합 개발 환경(IDE)에서 사용할 TOPST VCP Arduino core를 다운로드하고 설치하는 데 도움이 됩니다.

<br/><br/>

## 2.1 설치 가이드

### Step 1: Arduino IDE 다운로드

먼저 Arduino 보드를 프로그래밍하기 위한 플랫폼 역할을 하는 Arduino IDE가 필요합니다.

- 공식 Arduino 웹사이트를 방문하십시오: [Arduino Software](https://www.arduino.cc/en/software)
- 사용 중인 운영 체제(Windows, macOS, Linux)에 적합한 버전을 선택하십시오.
- 설치 프로그램을 다운로드하여 실행하십시오.

<br/>

### Step 2: Arduino IDE 설치

Arduino IDE를 설치하려면 사용 중인 운영 체제에 따라 다음 단계를 수행하십시오:

#### Windows:
1. 다운로드한 `.exe` 파일을 실행합니다.
2. 설치 안내에 따라 진행합니다. 필요한 드라이버를 모두 설치해야 합니다.

#### macOS:
1. `.dmg` 파일을 엽니다.
2. Arduino 애플리케이션을 Applications 폴더로 드래그합니다.

#### Linux:
1. `.tar.xz` 파일의 압축을 해제합니다.
2. 압축을 해제한 디렉터리에서 터미널을 엽니다.
3. `./install.sh`를 실행하여 설치합니다.

<br/>

### Step 3: TOPST VCP 보드 추가

TOPST VCP 보드를 프로그래밍하려면 Board Manager를 통해 해당 core를 Arduino IDE에 추가해야 합니다.

1. Arduino IDE를 엽니다.
2. **File > Preferences**로 이동합니다.
3. "Additional Board Manager URLs" 필드에 TOPST VCP core용으로 다음 URL을 추가합니다:

    ```
    https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
    ```

    (참고: 위 URL을 TOPST VCP core에 대해 실제로 제공되는 URL로 바꾸십시오.)
4. "OK"를 클릭하여 변경 사항을 저장합니다.
5. **Tools > Board > Boards Manager**로 이동합니다.
6. Boards Manager에서 "TOPST VCP"를 검색합니다.
7. TOPST VCP 항목이 나타나면 "Install"을 클릭합니다.

<br/>

### Step 4: TOPST VCP 보드 선택

설치 후에는 TOPST VCP 보드를 선택해야 합니다:

1. **Tools > Board**로 이동합니다.
2. 아래로 스크롤하여 "TOPST VCP"를 찾아 선택합니다.

<br/>

### Step 5: 설치 확인

간단한 스케치를 업로드하여 설정이 올바르게 동작하는지 테스트합니다:

1. TOPST VCP 보드를 USB로 PC에 연결합니다.
2. **Tools > Port**에서 적절한 포트를 선택합니다.
3. **File > Examples > 01.Basics > Blink**를 엽니다.
4. **Upload** 버튼을 눌러 스케치를 보드로 전송합니다.
5. 온보드 LED가 깜박이기 시작하면 보드가 올바르게 설정된 것입니다.

<br/><br/>

## 2.2 문제 해결

설정 중 문제가 발생하는 경우 [Arduino 문제 해결 가이드](https://www.arduino.cc/en/Guide/Troubleshooting)를 참조하십시오.
