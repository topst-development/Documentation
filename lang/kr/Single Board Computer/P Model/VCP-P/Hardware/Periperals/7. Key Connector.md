# 7. 키 커넥터 (J10D1)


J10D1은 외부 키 기능을 연결하기 위한 표준 20핀/2 mm 커넥터입니다.  
다른 스위치 기능을 사용하려면 키 서브 보드를 먼저 개발해야 합니다.
