# 3. 부팅 모드 (SW2)


TOPST VCP는 부트 모드(BM)를 사용하는 부팅 설정용 핀 1개를 제공하며 2가지 모드를 지원합니다:  
UART 부팅 모드와 노멀 모드입니다.

슬라이드 스위치(SW2)는 TOPST VCP의 부팅 모드를 선택하는 데 사용됩니다.

## 3.1 UART 부팅 모드
이 모드는 주로 펌웨어 다운로드(**FWDN**) 모드를 위한 것입니다.
이 모드에서는 UART 포트를 사용하여 사용자 정의 영역에 프로그램을 다운로드할 수 있습니다.


표 3.2는 UART 부팅 모드를 위한 슬라이드 스위치 설정을 설명합니다.  

 **표 3.2 부팅 모드용 UART 설정:**
