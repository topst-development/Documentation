# 5. 디버깅 및 FWDN용 커넥터 (JC1)  


TOPST VCP에서 JC1은 UART를 통한 디버깅 또는 FWDN에 사용됩니다.  
이는 표준 USB Type-C 커넥터입니다.  

그림 5.1은 JC1의 위치를 나타냅니다.  
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/8b19656c-59d5-4389-87f3-4939bf501587"></p>  
<p align="center"><strong>그림 5.1 USB Type-C 커넥터</strong></p>  

JC1을 통해 FWDN을 수행하거나 TCC7045의 디버깅 메시지를 확인할 수 있습니다.  
TOPST VCP에서는 JC1용으로 USB to UART 브리지 컨트롤러가 설계되어 있으며, USB Type-C 케이블을 사용하여 JC1을 PC에 직접 연결할 수 있습니다.
