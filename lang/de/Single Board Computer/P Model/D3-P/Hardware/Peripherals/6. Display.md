# 6. DisplayPort-Anschluss

Das TOPST D3 verfügt über einen DisplayPort, der DP 1.4 mit einer Auflösung von bis zu 4Kp60 unterstützt.  


Abbildung 6.1 zeigt, wie das Display über DisplayPort am TOPST-D3 aktiviert wird. Wenn Sie andere Displaygeräte anschließen möchten, die nur HDMI unterstützen, können Sie DP-auf-HDMI-Adapterkabel verwenden.
