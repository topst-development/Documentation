# 3. Kameraschnittstelle


Das TOPST D3 verfügt über eine MIPI-CSI-Kamera mit 2 Lanes, die mit dem Raspberry Pi Kameragerät kompatibel ist, sowie über einen MIPI-CSI-Kameraanschluss mit 4 Lanes für eine 4-Kanal-Kameraanwendung wie ein Surround View Monitoring (SVM) System (optionale Unterstützung).  

<br/><br/>
