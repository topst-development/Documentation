## 3.3 UART/JTAG-Sub-Board  

Das UART/JTAG-Sub-Board ist ein Debugging-Board für den seriellen Anschluss und JTAG. Sie können das serielle Log prüfen, indem Sie das UART/JTAG-Sub-Board über ein USB-Type-C-Kabel mit Ihrem Host-PC verbinden.   

Abbildung 3.3 zeigt die Übersicht über das UART/JTAG-Sub-Board.  
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/95f161ce-8e9c-470c-842e-fd33b257304d"></p>
<p align="center"><strong>Abbildung 3.3 UART/JTAG-Sub-Board (Ansicht von oben)</strong></p>

Tabelle 3.1 beschreibt die Anschlüsse des UART/JTAG-Sub-Boards.  

**Tabelle 3.1 Beschreibung des UART/JTAG-Sub-Boards:**  

| Pos. | Beschreibung                                   |
|:----:|------------------------------------------------|
| u10  | FFC-Anschluss zum Verbinden des TOPST D3       |
| u20  | Stiftleiste zum Anschließen des Debuggers      |
| u30  | Debug-Anschluss (USB Type-C) für MCU-Debugging |
| u40  | Debug-Anschluss (USB Type-C) für A53-Core-Debugging |
| u50  | Debug-Anschluss (USB Type-C) für A72-Core-Debugging |  

<br/><br/>

## 3.4 UART/JTAG-Sub-Board mit dem TOPST D3 verbinden  

In diesem Kapitel wird beschrieben, wie Sie den TOPST D3 und das UART/JTAG-Sub-Board verbinden.  

Verbinden Sie das UART/JTAG-Sub-Board wie folgt über ein Flexible Flat Cable (FFC) mit dem TOPST D3:
1. Halten Sie ein FFC und ein USB-Type-C-Kabel bereit.
2. Verbinden Sie das FFC mit dem Debug-I/F-Anschluss auf dem UART/JTAG-Sub-Board und dem Debug-I/F-Anschluss auf dem TOPST D3. <br/>
    * Es ist wichtig, dass die blaue Linie des FFC beim Anschließen nach oben zeigt.
3. Verbinden Sie das UART/JTAG-Sub-Board über ein USB-Type-C-Kabel mit Ihrem Host-PC. <br/>
    * Siehe Tabelle 3.1, um den passenden UART-Anschluss entsprechend dem Ziel-Core auszuwählen. Zum Beispiel kann A72 UART mit dem UART-Anschluss des Haupt-Cores (Cortex-A72 Quad) verbunden werden.
4. Prüfen Sie die serielle Log-Meldung über die Terminal-Anwendung auf Ihrem Host-PC.

## 3.5 JTAG-Debugger mit dem TOPST D3 verbinden  

In diesem Kapitel wird beschrieben, wie Sie einen JTAG-Debugger mit dem TOPST D3 verbinden.  

Verbinden Sie den JTAG-Debugger wie folgt mit dem TOPST D3:
1. Halten Sie einen JTAG-Debugger bereit.
2. Verbinden Sie gemäß dem obigen Kapitel „UART/JTAG-Sub-Board mit dem TOPST D3 verbinden“ das UART/JTAG-Sub-Board mit dem TOPST D3.
3. Verbinden Sie den JTAG-Debugger mit dem JTAG-Header auf dem UART/JTAG-Sub-Board.
