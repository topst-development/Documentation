# 4. TOPST D3 für den Firmware-Download mit dem Host-PC verbinden



Der Firmware Downloader(**FWDN**) schreibt über die USB-Kommunikation auf dem Host-PC ein ROM-Image auf das TOPST D3.  

Das TOPST D3 verfügt über eine Boot-Mode-Taste und unterstützt über diese Taste die beiden folgenden Boot-Modi:
- Der USB Boot Mode dient dazu, mit dem Programm **FWDN** auf Ihrem Host-PC ein ROM-Image zu schreiben.
- Der eMMC Boot Mode dient dazu, das TOPST D3 mit einem ROM-Image zu booten, das im eMMC-Gerät gespeichert ist.

**Hinweis**: Der USB 2.0 D/H Anschluss wird für den Firmware Downloader (**FWDN**) verwendet.  

Um **FWDN** zu verwenden, verbinden Sie das TOPST D3 wie folgt mit dem Host-PC:
1. Prüfen Sie, ob der VTC-Treiber auf dem Host-PC installiert ist. Falls der VTC-Treiber nicht installiert ist, installieren Sie ihn gemäß der **FWDN**-Anleitung, die Sie auf topst.ai finden.
2. Halten Sie ein USB-Typ-A-Kabel bereit.
3. Verbinden Sie USB 2.0 D/H am TOPST D3 über das USB-Typ-A-Kabel mit dem Host-PC.
4. Verwenden Sie eine der beiden folgenden Methoden, um den Boot-Modus des TOPST D3 zu ändern.<br/>
   1. Methode 1
       * Falls das TOPST D3 noch nicht mit Strom versorgt wird, drücken Sie die FWDN-Taste und schließen Sie die 5V-Stromversorgung an das TOPST D3 an.
       * Lassen Sie die FWDN-Boot-Mode-Taste los.<br/>
   2. Methode 2
       * Falls das TOPST D3 bereits mit Strom versorgt wird, drücken Sie die Reset-Taste und die FWDN-Boot-Mode-Taste.
       * Lassen Sie die FWDN-Boot-Mode-Taste los.
5. Laden Sie Ihr ROM-Image gemäß der **FWDN**-Anleitung herunter.
