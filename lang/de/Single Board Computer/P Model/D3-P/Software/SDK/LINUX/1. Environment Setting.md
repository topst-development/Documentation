#  1. Host-Umgebung einrichten

<br><br>

## 1.1 Ubuntu-Installation

Da das TOPST D3 Linux SDK auf dem Yocto Project basiert, richtet sich die Linux-Version des TOPST D3 SDK nach dem Yocto Project.

Sie können auch eine andere Linux-Version installieren, in diesem Dokument wird das TOPST D3 Linux SDK jedoch auf Basis von Ubuntu 22.04 beschrieben.

Version der Linux-Distribution:

- Ubuntu 22.04 (LTS)

<br/><br/>

## 1.2 WSL2 Ubuntu installieren 

1. Führen Sie Windows PowerShell mit „**Als Administrator ausführen**“ aus
2. Aktivieren Sie das WSL2-System.
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. Aktivieren Sie die Funktion für virtuelle Maschinen.
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. Legen Sie WSL 2 als Standardversion fest.
    ```
    wsl --set-default-version 2
    ```
5. Suchen Sie im Microsoft Store nach Ubuntu 22.04.3 LTS und laden Sie es herunter.

    * Wenn Sie das Linux-Kernel-Updatepaket herunterladen müssen, laden Sie das neueste Paket [hier](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual) herunter.

## 1.3 Linux-Umgebung einrichten

<br>

### 1.3.1 SSH und Samba installieren

Nachdem eine virtuelle Maschine installiert wurde, können Sie zusätzliche Dienstprogramme wie SSH und Samba für eine komfortablere Entwicklungsumgebung verwenden. SSH und Samba ermöglichen es Ihnen, Befehle auf entfernten Computern auszuführen und Dateien auf andere Computer zu kopieren.

Wenn SSH und Samba bereits installiert sind oder Sie sie nicht verwenden, können Sie dieses Kapitel überspringen.

Verwenden Sie den folgenden Befehl, um net-tools, SSH und Samba zu installieren.

```
$ sudo apt install -y net-tools openssh-server samba
```


Nach dem Herunterladen von SSH und Samba sollten Sie jedes Programm an Ihre Umgebung anpassen.

<br>

### 1.3.2 Dienstprogramme

Installieren Sie die Dienstprogramme auf einmal. Um das Yocto Project zu verwenden, müssen die folgenden Dienstprogramme auf dem Host-PC (einzelner Computer oder Entwicklungsserver) installiert sein.

Verwenden Sie den folgenden Befehl, um die Dienstprogramme zu installieren.

```
$ sudo apt-get install -y gawk wget git diffstat unzip texinfo gcc-multilib build-essential chrpath

$ sudo apt-get install -y socat cpio python3 python3-pip python3-pexpect xz-utils debianutils

$ sudo apt-get install -y iputils-ping python3-git python3-jinja2 libegl1-mesa libsdl1.2-dev pylint

$ sudo apt-get install -y xterm zstd ncftp curl git-lfs vim zip
```

<br>

### 1.3.3 Repo installieren

Wenn Repo bereits installiert ist, können Sie es ohne Neuinstallation verwenden.  
Vor der Installation von Repo muss die installierte Python-Version (3.6 oder höher) korrekt eingerichtet sein.

Verwenden Sie den folgenden Befehl, um repo zu installieren.
```
$ sudo apt-get install repo
```

Wenn die Fehlermeldung '/usr/bin/env 'python' no such file or directory' angezeigt wird, verwenden Sie den folgenden Befehl, damit die Datei 'python' auf 'python3' verweist.

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
```
Wenn ein Repo-Fehler auftritt, verwenden Sie den folgenden Befehl, um die neueste Version herunterzuladen und sie direkt in den Ordner /usr/bin/ zu legen.

```
$ mkdir -p ~/bin

$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo > ~/bin/repo

$ chmod a+x ~/bin/repo

$ sudo mv ~/bin/repo /usr/bin/repo
```

### 1.3.4 Udev-Regeln für Telechips-USB-Gerät
Nachdem Sie den folgenden Befehl ausgeführt haben, müssen Sie beim Herunterladen von FWDN unter Linux den Befehl 'sudo' nicht mehr verwenden.
```
$ echo "SUBSYSTEM==\"usb\", ATTR{idVendor}==\"140e\", MODE=\"0666\", OWNER=\"${USER}\"" | sudo tee /etc/udev/rules.d/99-topst.rules
$ sudo udevadm control --reload-rules && sudo udevadm trigger
```
