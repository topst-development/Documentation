# 3. Firmware-Download

In diesem Kapitel wird beschrieben, wie Sie ***FWDN*** auf das TOPST D3 (Open-Platform-Board) herunterladen und sich an der Linux-Konsole anmelden.  
Das ***FWDN V8*** ist ein PC-Werkzeug zum Herunterladen von Firmware in Windows 10 64-Bit- und Linux-Umgebungen. In diesem Kapitel wird der Fall des Herunterladens in Windows- und Linux-Umgebungen beschrieben.

<br/><br/>

## 3.1 Ablauf des Firmware-Downloads

Der Download-Ablauf von ***FWDN*** ist wie folgt:

1. Stellen Sie den Boot-Modus-Schalter auf den USB-Boot-Modus.
2. Öffnen Sie die Windows-Eingabeaufforderung oder die Linux-Konsole und testen Sie ***FWDN V8***.
3. Verbinden Sie ***FWDN V8*** mit dem Board.
4. Laden Sie die fai-Datei herunter.

<br/><br/>

## 3.2 TOPST D3 und Host-PC über USB-Boot verbinden

Wenn Sie **SW2** drücken und die Stromversorgung einschalten, wird der USB-Boot-Vorgang gestartet. Wenn Sie die Stromversorgung einschalten, ohne **SW2** zu drücken, wird der normale Boot-Vorgang gestartet.

Durch Drücken von **SW1** wird das System zurückgesetzt. Wenn Sie eine Firmware herunterladen möchten, drücken Sie **SW1** und **SW2** gleichzeitig, um in den USB-Modus zu booten.

## 3.3 Vorbereitung für den FWDN-Download

1. Entpacken Sie "output.fwdn.zip" 
    ```
    $ mkdir images
    $ mv ./output.fwdn.zip ./images
    $ cd images
    $ unzip output.fwdn.zip
    ```
2. Kopieren Sie den Ordner "images" auf das Windows-Laufwerk C.
    ```
    $ cd ..
    $ cp -r /images /mnt/c/
    ```

## 3.5 FWDN in der Linux-Umgebung

In einer Linux-Umgebung können Sie das TOPST-Image mit dem Befehl "./fwdn.sh" herunterladen.

```
$ ./fwdn.sh
```

<br/><br/>

## 3.6 TOPST-Verbindung über UART

1. Verwenden Sie die UART-Verbindung, um zu überprüfen, ob der Firmware-Download erfolgreich abgeschlossen wurde.
2. Installieren Sie den Treiber für den seriellen Anschluss (CP210x Windows Driver) in der Windows-Umgebung.([Download-Link](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads))
3. Ändern Sie den Boot-Modus auf normal (eMMC) und starten Sie neu. Verwenden Sie ein Kabel von USB Type-C auf USB 2.0 oder 3.0, kein C-auf-C-Kabel.
