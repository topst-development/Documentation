# 2. Build-Anleitung

<br/><br/>

## 2.1 Vorbereitung des Builds des TOPST D3 Linux SDK

TOPST D3 Linux SDK basiert auf Yocto Project 3.1 Dunfell. Daher muss auf dem Host-PC die Umgebung des Yocto Project eingerichtet werden, um TOPST D3 Linux SDK zu verwenden. Um SDK, source-mirror und Tools herunterzuladen, müssen Sie Hilfsprogramme installieren.  

<br/><br/>

## 2.2 Yocto Project  

Das Yocto Project ist ein Open-Source-Projekt, das sich auf die Entwicklung von Embedded Linux konzentriert.  
Es verwendet eine Kombination aus dem Open Embedded Project, also Poky, und ***bitbake*** als Build-System, um Linux-Images zu erstellen.  
Mit dem Yocto Project können Sie Bootloader, Kernel und rootfs gleichzeitig bauen.  

<br/><br/>

```
$ ./easy-setup.sh
```

Wenn Sie Accept auswählen, können Sie mit dem folgenden Befehl bauen.
```

	source yocto/poky/oe-init-build-env build-main
	bitbake topst

[!] Will you use subcore? (yes/no) no
```
```
$ source yocto/poky/oe-init-build-env build-main

    core-image-minimal
    core-image-sato
    meta-toolchain
    meta-ide-support

    topst-minimal
    topst-multimedia    (minimal + GStreamer)
    topst               (minimal + GStreamer + Qt)

```
Wenn Sie beim Bauen die folgende Meldung und den Fehler **"patchelf-uninative: /lib/x86_64-linux-gnu/libstdc++.so.6: version `GLIBCXX_3.4.29' not found (required by patchelf-uninative)"** sehen, gehen Sie bitte wie folgt vor und bauen Sie erneut.

```
sudo add-apt-repository ppa:ubuntu-toolchain-r/test
sudo apt update
sudo apt install g++-11
```
