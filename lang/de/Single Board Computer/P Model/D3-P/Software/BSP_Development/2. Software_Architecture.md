# 2. Softwarearchitektur

Abbildung 2.1 zeigt die Softwarearchitektur des TCC8050. Die drei Kerne umfassen die folgenden Funktionen, wobei jeder von ihnen Informationen über den IPC austauscht.

Der TCC8050 nutzt den CA72 (Hauptkern), um Multimediafunktionen bereitzustellen, und der CA53 (Nebenkern) sorgt während des Betriebs für die unmittelbare Verarbeitung des Hauptkerns (zum Beispiel Rückfahrkamera). Der CR5 stellt ein Echtzeitbetriebssystem bereit, das die Funktionen für die Kommunikation mit einem Fahrzeug liefert.
