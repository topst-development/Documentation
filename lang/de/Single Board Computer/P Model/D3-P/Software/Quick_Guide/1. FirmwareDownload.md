# 1. FWDN-Anleitung

In diesem Kapitel wird beschrieben, wie Sie den Firmware Downloader (***FWDN***) auf das TOPST D3 herunterladen und sich an der Linux-Konsole anmelden.

<br><br>

## 1.1   Ablauf des Firmware-Downloads

Der Download-Ablauf von ***FWDN*** ist wie folgt:

1. Wechseln Sie in den FWDN-Modus.
2. Schließen Sie das USB-A-zu-A-Kabel an den USB 2.0 FWDN-Anschluss an.
3. Laden Sie das TOPST-Image herunter.

<br><br>

## 1.2   In den FWDN-Modus wechseln

Drücken Sie die Taste **SW2** (FWDN Mode Convert) und schließen Sie die Stromversorgung an, um in den ***FWDN***-Modus zu wechseln. Wenn die Stromversorgung bereits angeschlossen ist, drücken Sie alternativ die Taste **SW2** (FWDN Mode Convert) und anschließend die Taste **SW1** (System Reset), um in den ***FWDN***-Modus zu wechseln.

## 1.3 FWDN in der Windows-Umgebung mit dem CLI-Tool ausführen
  
Um FWDN zu verwenden, laden Sie das Firmware-Tool über den folgenden Link herunter:

- <[FWDN-Tool](https://drive.google.com/file/d/1UzArkpt-Aw67YhAMtlSfkELEHYBMBqT7/view?usp=sharing)>

Sie können jedes der folgenden TOPST-Images wie folgt herunterladen.

- Skriptspeicherort: topst.d3.pre.20240425001\fwdn.bat


```
.\fwdn.bat
```
In der folgenden Abbildung wird das gesamte TOPST-Image mit dem Befehl .\fwdn.bat heruntergeladen.
Wenn das TOPST D3 durch Drücken der Taste SW1 (Reset) neu gestartet wird, wird der Ubuntu-Launcher ausgeführt.
