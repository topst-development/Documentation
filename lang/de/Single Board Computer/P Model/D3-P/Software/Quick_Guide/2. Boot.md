#  2. Boot-Anleitung

In diesem Kapitel wird beschrieben, wie Sie das TOPST D3 booten und sich für jeden Core anmelden.

<br><br>

## 2.1 Boot-Reihenfolge

Die Download-Reihenfolge von ***FWDN*** ist wie folgt:

1. Schließen Sie das DP-Kabel für den DP-Monitor an.
2. Verbinden Sie das Debugging-Board und das TOPST D3.
3. Schließen Sie jedes TOPST USB-Kabel an das Debugging-Board an, um sich an der Konsole anzumelden und für jeden Core das Debugging durchzuführen.
4. Schließen Sie die 5V-Stromversorgung an.

<br><br>

## 2.2 TOPST-Verbindung über UART

Um USB-Debugging durchzuführen und die Linux-Umgebung zu entwickeln, können Sie über das unten gezeigte TOPST Debugging-Board auf den jeweiligen Core (CA72/CA53/MCU) zugreifen.
