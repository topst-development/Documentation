# 4. Display-Schnittstelle

Das TOPST AI verfügt über einen MIPI-DSI-Anschluss mit 2 Lanes, der für das TOPST LCD vorgesehen ist.
(kompatibel mit dem Raspberry Pi LCD).

<br/><br/>
