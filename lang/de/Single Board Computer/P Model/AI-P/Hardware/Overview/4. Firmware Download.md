# 4. Firmware-Download

<br/>

## 4.1 TOPST AI für den Firmware-Download mit dem Computer verbinden

Der Firmware Downloader (**FWDN**) schreibt ein ROM-Image über die
UART-Kommunikation auf dem Computer in das TOPST AI.

Das TOPST AI verfügt über eine Boot-Mode-Taste und unterstützt über die
Boot-Mode-Taste die folgenden zwei Boot-Modi:

- Der UART Boot Mode wird verwendet, um mit dem Programm **FWDN**
  auf Ihrem Computer ein ROM-Image zu schreiben.

- Der eMMC Boot Mode wird verwendet, um das TOPST AI mit einem ROM-Image zu starten, das
  im eMMC-Gerät gespeichert ist.

**Hinweis**: Der USB-Type-C-Anschluss wird für den Firmware Downloader (**FWDN**) verwendet.

Um **FWDN** zu verwenden, schließen Sie das TOPST AI wie folgt an Ihren Computer an:

1.  Halten Sie ein USB-Type-C-Kabel und ein Ethernet-Kabel bereit
2.  Verbinden Sie die USB-Type-C-Buchse am TOPST AI mit Ihrem Computer,
    indem Sie das USB-Type-C-Kabel verwenden.
3.  Verbinden Sie den Ethernet-Anschluss(RJ45) am TOPST AI mit Ihrem Computer,
    indem Sie das Ethernet-Kabel verwenden.
4.  Verwenden Sie eine der beiden folgenden Methoden, um den Boot-Modus des
    TOPST AI zu ändern.
     1. Methode 1
         * Wenn das TOPST AI noch nicht mit Strom versorgt wird, drücken Sie die FWDN-Taste und schließen Sie die 5V-Stromversorgung an das TOPST AI an.
         * Lassen Sie die FWDN-Boot-Mode-Taste los.

     2. Methode 2
         * Wenn das TOPST AI bereits mit Strom versorgt wird, drücken Sie die System-Reset-Taste und die FWDN-Boot-Mode-Taste.
         * Lassen Sie die FWDN-Boot-Mode-Taste los.

5.  Laden Sie Ihr ROM-Image gemäß dem **FWDN**-Dokument herunter.
