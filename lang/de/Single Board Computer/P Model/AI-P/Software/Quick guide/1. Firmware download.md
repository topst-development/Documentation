# 1. FWDN-Anleitung

In diesem Kapitel wird beschrieben, wie Sie den Firmware Downloader (FWDN) auf
das TOPST AI herunterladen.

TOPST AI stellt die FWDN-Funktion über Ethernet und UART bereit. Im FWDN-
Modus lädt BL0(Chipboot ROM) die Firmware der nächsten Stufe(BL1) vom Host
über UART.(BL1 initialisiert). DRAM und lädt die FWDN-F/W, die FWDN über
Ethernet unterstützt, erneut über UART in den DRAM . Die FWDN-F/W verbindet den Host
über TCP/IP oder UDP und führt FWDN-Funktionen aus (etwa das Schreiben von Daten in den
Speicher, das Lesen von Daten aus dem Speicher usw.).

## 1.1 Ablauf des Firmware-Downloads

Der Download-Ablauf von FWDN ist wie folgt:

1.  Wechseln Sie in den FWDN-Modus (siehe TOPST-AI/Hardware/Overview/4.Firmware Download).
2.  Schließen Sie das USB-C-auf-A-Kabel an den USB-C-FWDN-Anschluss an.
3.  Schließen Sie das Ethernet-Kabel an den Ethernet-Anschluss an.
4.  Laden Sie das TOPST AI Image herunter.

<br/><br/>

## 1.2 In den FWDN-Modus wechseln 

Drücken Sie die FWDN KEY (FWDN Mode Convert) und schließen Sie die Stromversorgung an, um in den
FWDN-Modus zu gelangen. Ist die Stromversorgung bereits angeschlossen, drücken Sie alternativ die FWDN KEY
(FWDN Mode Convert) und die RESET KEY(System Reset), um in den
FWDN-Modus zu gelangen.
