# 2. BOOT-ANLEITUNG

In diesem Kapitel wird beschrieben, wie Sie das TOPST AI booten und sich für
jeden Core anmelden.

<br/><br/>

## 2.1 Boot-Reihenfolge

Die Boot-Reihenfolge ist wie folgt:

1.  Schließen Sie das Panel mit MIPI-Schnittstelle an.
2.  Schließen Sie das Kameramodul mit MIPI-Schnittstelle an.
3.  Schließen Sie das USB-C-auf-A-Kabel an den Debug-Anschluss an.
4.  Schließen Sie die 5V-Stromversorgung an.

## 2.2 TOPST AI-Verbindung über UART

Um USB-Debugging durchzuführen und die Linux-Umgebung zu entwickeln, können Sie über den unten gezeigten TOPST AI Debug-Anschluss auf dem Board auf den Core (CA53) zugreifen.
Installieren Sie den UART-Bridge-VCP-Treiber (zu finden unter
https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads)
auf dem Host-PC.
Anschließend wird der CP210x USB-to-UART-Treiber wie folgt eingerichtet, wenn Sie den UART mit dem TOPST Debugging-Board verbinden.

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20Boot.image2.png?raw=true"
style="width:4.11111in;height:4.02083in"</p>
<p align="center"><strong>Abbildung 2.2 USB-Verbindung in der Windows-Umgebung</strong></p>

Verbinden Sie den UART-Anschluss über den Terminal-Emulator auf dem Host-PC.
Unten sehen Sie den Log-Bildschirm, der durch die Verbindung mit dem Core gebootet wurde.

<br/>

**Beispiel**

- Terminal-Emulator: PuTTY oder mobaXterm
- Geschwindigkeit: 115200 bps
- Datenbits: 8
- Parität: None
- Stoppbits: 1
- Flusssteuerung: None
