# 3. Firmware-Download

In diesem Kapitel wird beschrieben, wie Sie FWDN auf das TOPST AI (Open-
Platform-Board) herunterladen und sich an der Linux-Konsole anmelden.

<br/><br/>

## 3.1 Ablauf des Firmware-Downloads

Der Download-Ablauf von FWDN ist wie folgt:

1.  Stellen Sie den Boot-Modus-Schalter auf den fwdn-Boot-Modus.
2.  Öffnen Sie die Windows-Eingabeaufforderung und testen Sie FWDN ND.
3.  Verbinden Sie FWDN ND mit dem Board.
4.  Laden Sie die fai-Datei herunter.

<br/><br/>

### 3.3.3 Boot-Modus ändern

Wenn Sie den Boot-Modus-Schalter drücken und die Stromversorgung anlegen, wird der
FWDN-Boot-Vorgang gestartet. Wenn Sie die Stromversorgung ohne Drücken des Boot-Modus-Schalters anlegen,
wird der normale Boot-Vorgang gestartet.
Durch Drücken des Reset-Schalters wird das System zurückgesetzt. Wenn Sie eine
Firmware herunterladen möchten, drücken Sie den Boot-Modus-Schalter und den Reset-Schalter
gleichzeitig, um in den FWDN-Boot-Modus zu gelangen.

### 3.3.4 FWDN unter Windows

1.  Kopieren Sie nach dem Erstellen des Images den erzeugten Ordner fwdn auf den
    Desktop und speichern Sie die unten genannte Datei in diesem Ordner.
    Um FWDN zu verwenden, können Sie das Firmware-Tool über den folgenden Link herunterladen:

    - <[FWDN Tool](https://topst-downloads.s3.ap-northeast-2.amazonaws.com/Yocto/pre/topst.ai.pre.20240425001.windows.zip)>
  
    Kopieren Sie das Image SD_Data.fai nach topst.ai.pre.20240425001.windows.
    SD_Data.fai befindet sich in **"{build_dir}/build/tcc7500-main/tmp/deploy/fwdn/"**.


2.  Führen Sie **fwdn_batch.bat** aus und geben Sie die **Portnummer** ein.

    <p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/Firmware%20Download.image5.png?raw=true"
    style="width:4.22917in;height:3.62292in"</p>

    <p align="center"><strong> Abbildung 3.4 Eingabe der Portnummer für FWDN</strong></p>
