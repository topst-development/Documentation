# 1. Einrichtung der Umgebung 

<br/><br/>


## 1.1 Ubuntu-Installation

Da das TOPST AI Linux SDK auf dem Yocto Project basiert, richtet sich die Linux-Version des TOPST AI SDK nach dem Yocto Project.

Sie können auch eine andere Linux-Version installieren, in diesem Dokument wird das TOPST AI Linux SDK jedoch auf Basis von Ubuntu 22.04 beschrieben.

Version der Linux-Distribution:

- Ubuntu 22.04 (LTS)

<br/><br/>

## 1.2 WSL2 Ubuntu installieren 

1. Führen Sie Windows PowerShell mit „Als Administrator ausführen“ aus
2. Aktivieren Sie das WSL2-System.
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. Aktivieren Sie die Funktion für virtuelle Maschinen.
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. Legen Sie WSL 2 als Standardversion fest
    ```
    wsl --set-default-version 2
    ```
5. Suchen Sie im Microsoft Store nach Ubuntu 22.04.3 LTS und laden Sie es herunter.

    * Wenn Sie das Linux-Kernel-Updatepaket herunterladen müssen, laden Sie das neueste Paket [hier](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual) herunter.

## 1.3 Einrichten der Linux-Umgebung

<br/>

### 1.3.1 SSH und Samba installieren 

Das Arbeiten in einer Linux-Umgebung ist langsam, aber Sie können SSH und Samba verwenden, um
in einer wesentlich komfortableren Umgebung zu arbeiten. SSH und

Samba ermöglichen es Ihnen, Befehle auf entfernten Computern auszuführen und Dateien
auf andere Computer zu kopieren.

Wenn SSH und Samba bereits installiert sind oder Sie sie nicht verwenden, können Sie
dieses Kapitel überspringen.

```
 $ sudo apt-get install -y net-tools openssh-server samba 
```

Nach dem Herunterladen von SSH und Samba sollten Sie jedes Programm an Ihre
Umgebung anpassen.

<br/>

### 1.3.2 Dienstprogramme für das Yocto Project installieren 

Installieren Sie die Dienstprogramme auf einmal. Für die Verwendung des Yocto Project müssen die folgenden
Dienstprogramme auf dem Host-PC (einzelner Computer oder

Entwicklungsserver) installiert sein.

```
$ sudo apt-get install -y gawk wget git-core diffstat unzip texinfo gcc-multilib
$ sudo apt-get install -y build-essential chrpath socat cpio python3 python3-pip python3-pexpect
$ sudo apt-get install -y xz-utils debianutils iputils-ping python3-git python3-jinja2 libegl1-mesa libsdl1.2-dev pylint xterm

```

<br/>

### 1.3.3 Repo installieren

Sie können das TOPST AI SDK über Repo herunterladen.

Informationen zur Installation von repo finden Sie auf der folgenden Website:
<https://source.android.com/source/downloading.html>

Wenn repo bereits installiert ist, können Sie es ohne Neuinstallation verwenden.

Vor der Installation von repo sollte die installierte Python-Version (3.6 oder höher) richtig eingestellt sein.

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
$ sudo apt-get install repo
```

<br/>

Wenn ein repo-Fehler auftritt, laden Sie die neueste Version herunter und legen Sie sie direkt in den Ordner /usr/bin/ ab.

```
$ mkdir -p ~/bin
$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo &gt;~/bin/repo
$ chmod a+x ~/bin/repo
$ sudo mv ~/bin/repo /usr/bin/repo
```
