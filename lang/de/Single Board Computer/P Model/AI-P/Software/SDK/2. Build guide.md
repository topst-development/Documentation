# 2. Build-Anleitung

<br/><br/>

## 2.1 TOPST AI SDK

TOPST AI SDK basiert auf Yocto Project 4.0 kirkstone. 
Daher muss die Yocto-Project-Umgebung auf dem Host-PC eingerichtet werden, um TOPST AI SDK zu verwenden. 
Um SDK, source-mirror und tools herunterzuladen, müssen Sie Dienstprogramme installieren.

Sie können den Quellcode anhand der Metadaten aus dem Upstream herunterladen und den Build durchführen.
Nach Abschluss des Builds werden Package, Image und SDK als Ergebnisse bereitgestellt.
Abbildung 2.1 zeigt den Task-Prozess des Yocto Project.
