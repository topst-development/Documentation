# 1. Beispielanwendung

Dieses Kapitel ist ein Leitfaden für die NPU-Beispielanwendung.

Das TOPST AI SDK stellt eine Beispielanwendung mit dem Namen ‘tc-nn-app’
zur Überprüfung der NPU-Funktionalität bereit.

Diese NPU-Beispielanwendung verwendet Kamera, Bilddateien und PC-Stream als
Eingaben und gibt die Ergebnisse der NPU-Bildverarbeitung an LCD, Datei und
PC-Stream aus.

<br/><br/>

## 1.1 Übersicht

Die NPU-Beispielanwendung kann ausschließlich Operationen der Neural Process
Unit (NPU) ausführen.
