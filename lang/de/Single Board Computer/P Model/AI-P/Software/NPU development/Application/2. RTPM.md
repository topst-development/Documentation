# 2. Real-Time Performance Monitoring Toolkit

Bilder sowie NPU-, CPU- und MEM-Leistungsdaten, die vom TOPST AI Board erfasst
werden, können über das Vision Protocol an den PC übertragen werden, und die
Ergebnisse können im RTPM-Toolkit auf dem PC eingesehen werden.

## 2.1 Leistungsüberwachung

Das Real-Time Performance Toolkit (RTPM) ist ein GUI-basiertes, in Python
entwickeltes Werkzeug, das die Ausgabe des TOPST AI in einer PC-Umgebung
überwacht und Ihnen die Prüfung von CPU-, NPU- und Speicherleistungsdaten ermöglicht.

<br/>

**Tabelle 2.1 Listen der Leistungsdaten von RTPM:**

|   Nr.  |    Leistungsdaten    |              Beschreibung              |
|--------|----------------------|----------------------------------------|
| 1      | Inferenzzeit         | Inferenzzeit für jedes Modell (ms)     |
| 2      | NPU                  | NPU-Auslastung je Modell               |
| 3      | FPS                  | Fps-Informationen zum NPU-Betrieb      |
| 4      | CPU                  | CPU-Auslastung (500ms-Zyklus)          |
| 5      | Speicher             | Speicherauslastung (500ms-Zyklus)      |

## 2.2 Injection-Modus

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image3.png?raw=true"></p>
<p align="center"><strong>Abbildung 2.3 Injection-Modus</strong></p>

Der Injection-Modus ist ein Szenario, in dem das TOPST AI Board ein Bild
vom RTPM empfängt, anschließend die NPU-Inferenz auf dem TOPST AI Board
ausführt und das Ergebnis an das RTPM zurücksendet.

<br/><br/>

## 2.3 Projection-Modus

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image4.png?raw=true"></p>
<p align="center"><strong>Abbildung 2.4 Projection-Modus</strong></p>

Der Projection-Modus ist ein Szenario, in dem das Board ein Bild über die Kamera empfängt und das Endergebnis (das zusammengesetzte Bild des Rahmens) an das RTPM sendet.

<br/><br/>

## 2.4 Anleitung zum Start der RTPM-Anwendung

<br/>

### 2.4.1 Anleitung zur Einrichtung der RTPM-Anwendung

<br/>

### 2.4.1.1 Werkzeuge für RTPM installieren

- Bereiten Sie die Umgebung auf dem Host-PC vor.

  1.  Installieren Sie Visual Studio Code.
       * Suchen Sie im Microsoft Store nach „Visual Studio Code“ und installieren Sie es.

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image5.png?raw=true"></p>
<p align="center"><strong>Abbildung 2.5 Visual Studio Code installieren</strong></p>

  2.  Installieren Sie Python3.10
        * Suchen Sie im Microsoft Store nach „Python3.10“ und installieren Sie es.

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image6.png?raw=true"></p>
<p align="center"><strong>Abbildung 2.6 Python3.10 installieren</strong></p>

<br/>

### 2.4.1.2 RTPM-Anwendung öffnen

1.  Kopieren Sie den Ordner rtpm (\<TOPST AI SDK\>\rtpm) aus dem SDK-Verzeichnis
    auf den Host-PC (Windows-PC).

2.  Öffnen Sie Visual Studio Code.

    1.  Drücken Sie die Tastenkombination „Ctrl+Shift+P“.

    2.  Geben Sie den folgenden Befehl ein.
         * Python: Select Interpreter
           
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image7.png?raw=true">

### 2.4.3 Projection-Modus ausführen

1.  Wählen Sie Camera (EVB) als Eingabemodus aus.

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Single%20Board%20Computer/P%20Model/AI-P/Software/media/2.%20RTPM.image19.png?raw=true"></p>
<p align="center"><strong>Abbildung 2.19 Camera(EVB) als Eingabemodus auswählen</strong></p>

2.  Drücken Sie die Start-Schaltfläche.

3.  Führen Sie tcnnapp im Projection-Modus auf dem TOPST AI Board aus.

	```
	# tcnnapp -i camera -o rtpm
	```
 - **HINWEIS**: Wenn der Befehl mit der Option "-i camera" ausgeführt wird, wird der Eingabepfad auf den Standardwert /dev/video0 gesetzt. Prüfen Sie bitte, als welches Videogerät die angeschlossene Kamera unter /dev/ erkannt wird, und verwenden Sie die Option "-p /dev/video*", falls es nicht /dev/video0 ist.

<br/>
