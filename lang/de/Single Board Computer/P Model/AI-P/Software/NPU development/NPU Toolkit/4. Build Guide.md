## 4.1 Converter

Der Converter liest die Datei des neuronalen Netzes und konvertiert sie in eine
„bin"-Datei, also das Netzdateiformat, das im TOPST AI NPU SW Toolkit verwendet wird.
Außerdem führt er Netzinferenzen durch und sammelt Statistiken der
Aktivierungsdaten, die später für die Quantisierung des Netzes verwendet werden.

<br/>

<strong>1.  Darknet</strong>

```
$ python ./EnlightSDK/converter.py \
  ./input_networks/yolov4.cfg \
  --weight ./input_networks/yolov4.weights \
  --type obj \
  --dataset Custom \
  --dataset-root my_dataset_path \
  --output ./output_networks/yolov4.enlight \
  --enable-track \
  --mean 0 0 0 \
  --std 1 1 1 \
  --num-class 90
```

## 4.2 Quantizer

Der Quantizer konvertiert das ursprüngliche Netzmodell, das auf Gleitkomma-
operationen basiert, in ein ganzzahlbasiertes (quantisiertes) Netz.

<br/>

**1.  Darknet**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/yolov4.enlight \
  --output ./output_networks/yolov4_quantized.enlight
```

<br/>

**2.  TensorFlow Lite**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1.enlight \
  --output ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight
```

<br/>

**3.  ONNX**

```
$ python ./EnlightSDK/quantizer.py \
  ./output_networks/mb2-ssd-lite.enlight \
  --output ./output_networks/mb2-ssd-lite_quantized.enlight
```

## 4.3 Compiler

Der Compiler kompiliert ein quantisiertes neuronales Netz in NPU-Code und
Netzparameter für die Verarbeitung neuronaler Netze auf der TOPST NPU HW.

<br/>

**1.  Darknet**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/yolov4_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

**2.  TensorFlow Lite**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/lite-model_ssd_mobilenet_v1_100_320_fp32_nms_1_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

**3.  ONNX**

```
$ python ./EnlightSDK/compiler.py \
  ./output_networks/mb2-ssd-lite_quantized.enlight \
  --th-iou 0.5 \
  --th-conf 0.5
```

<br/>

Die erzeugten Dateien werden im Verzeichnis „output_code/\<network_name\>"
gespeichert.

Compiler-Ausgabedatei:

- npu_cmd.bin: TELECHIPS NPU-Inferenzcode
- quantized_network.bin: Netzgewichts- und Bias-Parameter
- network.h: Puffergröße und Netzparameter für die Nachverarbeitung
- post_process.c: Code für die Nachverarbeitung
- Weitere Dateien: Debugging-Informationen (nur intern)

In Anwendungen für neuronale Netze werden „npu_cmd.bin" und „quantized_network.bin"
mithilfe der TELECHIPS NPU-APIs und des Linux-Gerätetreibers in DMA-Puffer
geladen. „network.h" und „post_process.c" werden als Netzobjektdatei
(.so) erstellt, wie unter Network Object Build gezeigt.
