# 2. I2C-Beispiel

Der Inter-Integrated Circuit (I2C) wird gemeinhin als "i-to-c" gelesen, die formale Aussprache lautet jedoch "i-square-c".

Die I2C-Kommunikation besteht aus einer Leitung SDA zum Senden und
Empfangen von Daten sowie einer Taktleitung SCL zur Synchronisierung des Sende- und
Empfangstimings. Sie besteht aus einem Master und einem oder mehreren Slaves, und
es können bis zu 127 Slaves angeschlossen werden.

- Die I2C-Kommunikation ist ein Kommunikationsverfahren, das zwei Leitungen verwendet
- Stärken und Schwächen beim Anschluss mehrerer Slave-Geräte an einen einzelnen Master
  - Zeitlicher Vorteil, da es sich um ein synchrones Kommunikationsverfahren handelt, das Taktsignale verwendet
  - Der Nachteil, dass es für lange Daten ungeeignet ist, weil zur Slave-Auswahl stets Adressdaten angehängt werden

3.  Wenn Sie die i2c_example_app ausführen, ruft sie den Helligkeitswert ab.

    ```
     root@telechips-tcc7500-main:~# ./i2c_example_app

    ```

    ```
    Target is 228.
    ```
