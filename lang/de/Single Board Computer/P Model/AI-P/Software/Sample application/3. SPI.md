# 3. SPI-Beispiel

Serial Peripheral Interface (SPI) ist eine serielle Kommunikationsmethode
(serielle Kommunikation) wie I2C, CAN und UART. Eine Funktion zum
Übertragen von Daten zwischen kleinen Peripheriegeräten wie Mikrocontrollern,
Schieberegistern und SD-Karten. Vereinfacht gesagt ist es eine der
Kommunikationsmethoden zum Austausch von Daten zwischen Geräten und Geräten, also zwischen
Chips (ICs) und Chips. Die SPI-Kommunikation ist eine synchrone Kommunikationsmethode,
die eine Eins-zu-viele-Kommunikation unterstützt und den Nachteil hat, dass
für mehrere Kommunikationsverbindungen mehrere Leitungen erforderlich sind. Außerdem können Sie gleichzeitig senden
und empfangen. Sie ist einfach zu verdrahten und wird daher häufig für die
Kommunikation zwischen Chips wie einfachen Sensoren und Speicher verwendet.
