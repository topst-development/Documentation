# 1. GPIO-Beispiel

GPIO(general-purpose input/output) ist ein digitaler Signalpin auf einem
integrierten Schaltkreis oder einer elektrischen Leiterplatte, der es ermöglicht, den
Betrieb einschließlich Eingabe oder Ausgabe zur Laufzeit durch den Benutzer
zu steuern.
GPIO ist nicht für einen bestimmten Zweck vordefiniert und wird nicht
standardmäßig verwendet.
GPIO wird von einem Schaltungsnetzdesigner auf Baugruppenebene implementiert
(Leiterplattendesigner für GPIO integrierter Schaltkreise, Systemintegrator
für GPIO auf Substratebene, S/I), dessen Zweck und Verhalten bei der
Verwendung definiert werden.

Die Funktionen, die GPIO ausführt, können je nach System variieren; die im Allgemeinen bereitgestellten Funktionen sind die folgenden.

- Ein-/Ausgabefunktion (high=1, low=0)
- Erkennung von IRQ-Signalen: Dies kann auch verwendet werden, um das System im
  Suspend-Zustand im Power-Management-Modus aufzuwecken.
  - Zugriff ist auch dann möglich, wenn der Spinlock blockiert ist

Die oben genannten Funktionen ermöglichen es Ihnen, den Schreibschutz zu nutzen,
  LEDs zu steuern, Transceiver-Einstellungen zu aktivieren, Hardware-Watchdog-Funktionen
  oder Schaltererkennung zu verwenden.

Im Folgenden finden Sie ein Beispiel zum Testen der Ein- und Ausgabe des
  Boards. Sie können die Ein- und Ausgabe testen, indem Sie die Pin-Nummer
  anhand der Raspberry Pi Pinbelegung steuern.

<br/>

**Beispiel**

```
$ echo "90" > /sys/class/gpio/export
$ echo "out" > /sys/class/gpio/gpio90/direction
$ echo 1 > /sys/class/gpio/gpio90/value
$ echo 0 > /sys/class/gpio/gpio90/value
```
