# 1. Einführung

<br/><br/>

## 1.1 Zweck der Anleitung  

Diese Anleitung bietet einen umfassenden Überblick über die Einrichtung einer Softwareentwicklungsumgebung für das TOPST-VCP Board auf einem Linux-System. Wenn Sie die in diesem Dokument beschriebenen Schritte befolgen, verfügen Sie als Entwickler über die notwendigen Werkzeuge, Konfigurationen und Kenntnisse, um effektiv mit dem TOPST-VCP Board und der zugehörigen Toolchain zu arbeiten.

<br/><br/>

## 1.2 Übersicht über das TOPST VCP Board  

Das TOPST-VCP Board ist ein leistungsstarkes und vielseitiges Entwicklungsboard, das auf eine Vielzahl von Anwendungen zugeschnitten ist. Im Herzen des Boards liegt der TCC7045 Chip, der auf der ARM Cortex-R5 Architektur aufbaut. Diese Kombination sorgt für ein ausgewogenes Verhältnis von Effizienz und Leistung und macht das Board zur ersten Wahl für Entwickler, die die Leistungsfähigkeit ARM-basierter Anwendungen nutzen möchten.

## 1.3 Übersicht über die Toolchain  

Für eine effektive Entwicklung auf dem TOPST-VCP Board ist es entscheidend, die richtige Toolchain einzusetzen. Diese Anleitung empfiehlt ausdrücklich die Verwendung von gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi für die Cross-Kompilierung. Diese Toolchain ist nicht nur mit der ARM Cortex-R5 Architektur kompatibel, sondern bietet auch eine Reihe von Werkzeugen, die für den TCC7045 Chip optimiert sind.
