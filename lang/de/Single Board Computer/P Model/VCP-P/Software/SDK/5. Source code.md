#  5. Quellcode beziehen

Der Quellcode bildet das Rückgrat jedes Entwicklungsprojekts. Er enthält alle notwendigen Dateien, Konfigurationen und Anweisungen, die zum Erstellen und Ausführen von Software für eine bestimmte Plattform erforderlich sind. Im Kontext des TOPST-VCP Boards ist der Bezug des richtigen Quellcodes entscheidend, um Kompatibilität und optimale Leistung sicherzustellen.

In diesem Kapitel wird beschrieben, wie Sie den Quellcode mit git, einem weit verbreiteten Versionsverwaltungssystem, beziehen.

<br/><br/>

## 5.1 Den TOPST-VCP Quellcode klonen

Um den Quellcode für das TOPST-VCP Board zu beziehen, verwenden Sie den Befehl git clone. Dieser Befehl erstellt eine Kopie des entfernten Repositorys auf Ihrem lokalen Rechner, sodass Sie direkt mit dem Code arbeiten können.

Führen Sie die folgenden Schritte aus, um den TOPST-VCP Quellcode zu klonen:

1. **Terminal öffnen** : Starten Sie die Terminal-Anwendung auf Ihrem Ubuntu 22.04 System.
2. **Zum gewünschten Verzeichnis wechseln** : Wählen Sie auf Ihrem System einen geeigneten Speicherort, an dem Sie den Quellcode ablegen möchten. Wenn Sie ihn beispielsweise im Home-Verzeichnis des Benutzers speichern möchten, verwenden Sie den Befehl

    ```
    $ cd ~
    ```

3. **Repository klonen** : Verwenden Sie den folgenden Befehl, um den TOPST-VCP Quellcode von der angegebenen git-Adresse zu klonen

    ```
    $ git clone https://gitlab.com/topst.ai/topst-vcp.git
    ```

4. **Zum geklonten Verzeichnis wechseln** : Sobald der Klonvorgang abgeschlossen ist, verwenden Sie den folgenden Befehl, um in das Verzeichnis mit dem Quellcode zu wechseln

    ```
    $ cd topst-vcp
    ```

<br/><br/>

## 5.2 Sich mit der Quellcode-Struktur vertraut machen

Nach dem Klonen ist es hilfreich, sich mit der Verzeichnisstruktur und dem Inhalt des Quellcodes vertraut zu machen. So erhalten Sie ein besseres Verständnis dafür, wo bestimmte Dateien liegen und wie die Codebasis organisiert ist.

- Verwenden Sie Befehle wie ls, um den Inhalt von Verzeichnissen aufzulisten.
- Erkunden Sie wichtige Verzeichnisse und Dateien, um deren Zweck und Funktionsweise zu verstehen.

```
$ ls -al
```
