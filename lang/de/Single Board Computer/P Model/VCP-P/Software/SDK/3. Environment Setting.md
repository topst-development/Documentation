# 3. Einrichtung der Umgebung

Für eine erfolgreiche Entwicklung für das TOPST-VCP Board ist eine gut strukturierte Entwicklungsumgebung erforderlich. In diesem Kapitel werden die notwendigen Schritte beschrieben, um Ihr Ubuntu 22.04 System mit allen wesentlichen Werkzeugen, Dienstprogrammen und Softwarepaketen einzurichten.

<br/><br/>

## 3.1 Wesentliche Werkzeuge und Dienstprogramme installieren

Bevor Sie sich mit den Besonderheiten des TOPST-VCP Boards befassen, ist es wichtig, einige grundlegende Dienstprogramme und Werkzeuge installiert zu haben. Diese Werkzeuge bilden die Grundlage, auf der weitere Software und Konfigurationen aufbauen.

1. **Terminal** : Ubuntu 22.04 wird mit einem integrierten Terminal geliefert. Machen Sie sich mit dessen Verwendung vertraut, da viele der folgenden Schritte Terminal-Befehle erfordern.
2. **Texteditor**: Ubuntu wird zwar mit einem einfachen Texteditor geliefert, Sie sollten jedoch je nach Vorliebe die Installation leistungsfähigerer Editoren wie „nano“, „vim“ oder grafischer Editoren wie „gedit“ oder „VSCode“ in Betracht ziehen.
3. **SSH-Werkzeuge** : Der Fernzugriff auf andere Systeme oder Geräte, insbesondere auf das TOPST- VCP Board, kann während der Entwicklung entscheidend sein. Verschiedene SSH-Werkzeuge können dies erleichtern:
4. **Putty** : Ein beliebter, kostenloser und quelloffener Terminal-Emulator, der unter anderem SSH unterstützt. Er ist ressourcenschonend und einfach zu bedienen.
5. **Tera Term** : Ein quelloffener Terminal-Emulator, der über mehr Funktionen verfügt und umfangreiche Unterstützung für verschiedene Kommunikationsprotokolle einschließlich SSH bietet.

Je nach Ihren konkreten Anforderungen und Vorlieben können Sie eines oder mehrere dieser Werkzeuge für den SSH-Zugriff auswählen.  

**Zu Ihrer Information: In diesem Handbuch wird putty verwendet.**

<br/><br/>

## 3.2 Software mit apt installieren

Der Paketmanager „apt“ ist ein leistungsfähiges Werkzeug in Ubuntu, mit dem Sie Softwarepakete einfach installieren, aktualisieren und verwalten können.

<br/>

### 3.2.1 Die Paketliste aktualisieren

Bevor Sie neue Software installieren, ist es empfehlenswert, die Liste der verfügbaren Pakete zu aktualisieren. So stellen Sie sicher, dass Sie die neuesten Versionen und Abhängigkeiten erhalten.

```
$ sudo apt update
$ sudo apt upgrade
```

Dieser Befehl ruft die neueste Liste der verfügbaren Pakete aus den Repositorys ab.

### 3.2.2 Gängige Entwicklungswerkzeuge installieren

Für die meisten Entwicklungsaufgaben, insbesondere für das TOPST-VCP Board, sind einige gängige Werkzeuge unerlässlich.

Installieren Sie diese Werkzeuge mit dem folgenden Befehl :

```
$ sudo apt install build-essential git
```

Dieser Befehl installiert sowohl das Paket buide-essential als auch git.
