# 4. Toolchain

Eine Toolchain ist eine entscheidende Komponente im Entwicklungsprozess, insbesondere bei der Arbeit mit spezialisierter Hardware wie dem TOPST-VCP Board. Sie stellt eine Sammlung von Werkzeugen bereit, mit denen Entwickler ihren Code für die Zielplattform kompilieren, linken und debuggen können.

<br/><br/>

## 4.1 Übersicht über Toolchains

Eine Toolchain besteht typischerweise aus einem Compiler, einem Linker, einem Assembler und einem Debugger sowie weiteren Werkzeugen. Diese Komponenten arbeiten zusammen, um Quellcode in ausführbare Programme umzuwandeln, die auf der Zielhardware laufen können. Angesichts der Vielfalt an Hardware-Architekturen und Plattformen ist es unerlässlich, die richtige, auf das Ziel-Board zugeschnittene Toolchain auszuwählen und zu konfigurieren

<br/><br/>

## 4.2 Auswahl der Toolchain für das Board

Für das TOPST-VCP Board, das auf der ARM Cortex-R5 Architektur basiert, wird die Toolchain gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi empfohlen.

Diese Toolchain ist für die ARM-Architektur optimiert und stellt die Kompatibilität mit dem TCC7045 Chip auf dem Board sicher.

<br/><br/>

## 4.3 Toolchain installieren und einrichten

Führen Sie die folgenden Schritte aus, um die Toolchain herunterzuladen, zu entpacken und einzurichten:

1. **Toolchain herunterladen** : Verwenden Sie den Befehl wget, um die Toolchain von der Linaro-Website herunterzuladen :

    ```
    $ wget https://releases.linaro.org/components/toolchain/binaries/7.2-2017.11/arm-eabi/gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```

<p align="center"><strong>Abbildung 4.1 Herunterladen der Toolchain läuft</strong></p>

2. **Toolchain entpacken** : Sobald der Download abgeschlossen ist, entpacken Sie den Inhalt der .tar.xz-Datei.

    ```
    $ tar -xvf gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi.tar.xz
    ```


<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/cd69488b-5f20-4b5e-95dd-6b1a9f37e38c">

<p align="center"><strong>Abbildung 4.2 Toolchain entpacken</strong></p>

3. **Toolchain nach /opt verschieben** : Das Verzeichnis /opt ist ein Standardort für optionale Software unter Linux. Verschieben Sie die entpackte Toolchain in dieses Verzeichnis.

    ```
    $ sudo mv gcc-linaro-7.2.1-2017.11-x86_64_arm-eabi /opt/
    ```

