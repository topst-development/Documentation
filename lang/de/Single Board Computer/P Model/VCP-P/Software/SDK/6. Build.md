#  6. Erstellen des Quellcodes

Nachdem der Quellcode erfolgreich bezogen wurde, besteht der nächste entscheidende Schritt darin, ihn zu bauen und so sicherzustellen, dass er optimal auf dem TOPST-VCP-Board läuft.

<br/><br/>

## 6.1 Makefiles und Build-Systeme verstehen

Ein Makefile ist ein Grundpfeiler vieler Build-Systeme. Es enthält Regeln und Direktiven, die dem Werkzeug make mitteilen, wie ein Programm kompiliert und gelinkt wird. Durch die Verwendung von Makefiles können Entwickler den Build-Prozess automatisieren und dadurch Konsistenz und Effizienz sicherstellen.

<br/><br/>

## 6.2 Starten des Build-Prozesses

Führen Sie die folgenden Schritte aus, um mit dem Erstellen des Quellcodes zu beginnen :

1. **Verwenden Sie den folgenden Befehl, um zum Build-Verzeichnis zu navigieren :**

    ```
    $ cd build/tcc70xx/gcc/
    ```

2. **Verwenden Sie den folgenden Befehl, um den Befehl make auszuführen :**

    ```
    $ make
    ```

Dieser Befehl liest das Makefile im aktuellen Verzeichnis und führt den Build-Prozess aus.

3. **Überprüfen Sie die Build-Ausgabe** : Sobald der Build-Prozess abgeschlossen ist, sollten Sie die folgenden Ausgabedateien im Terminal finden
    - output/tcc70xx_pflash_boot.rom
    - output/tcc70xx_pflash_boot_2M_ECC.rom
    - output/tcc70xx_pflash_boot_3M_ECC.rom
    - output/tcc70xx_pflash_boot_4M_ECC.rom

    Stellen Sie sicher, dass diese Dateien vorhanden sind, da sie für die nächsten Entwicklungsschritte entscheidend sind.
