# 7. Herunterladen auf die TOPST VCP-Hardware

Das Übertragen der erstellten Software auf das TOPST-VCP-Board ist ein entscheidender Schritt im Entwicklungsprozess. Dieses Kapitel bietet eine umfassende Anleitung, wie Sie die Software mithilfe einer Linux-basierten Entwicklungsumgebung auf die VCP-Hardware herunterladen.

<br/><br/>

## 7.1 Vorbereiten der Hardware

Bevor Sie den Download-Vorgang starten, stellen Sie sicher, dass sich das TOPST-VCP-Board in einer stabilen Lage befindet und keinen möglichen Störungen ausgesetzt ist. Stellen Sie sicher, dass alle Schalter und Anschlüsse leicht zugänglich sind und dass das 3.3v-Stromkabel korrekt angeschlossen ist.

<br/><br/>

## 7.2 Anschließen der Hardware an den Entwicklungs-Host-PC

1. **USB-C-Kabelverbindung:** Verwenden Sie ein USB-C-Kabel, um das TOPST-VCP-Board mit Ihrem Entwicklungs-Host-PC zu verbinden.
2. **Überprüfen der Verbindung**: Führen Sie auf Ihrem Linux-Rechner den folgenden Befehl aus

    ```
    $ sudo dmesg | grep tty
    ```

## 7.3 Übertragen der erstellten Software

1. **Board in den Download-Modus versetzen :** Schieben Sie auf dem TOPST-VCP-Board den FWDN-Schalter in die Position FWDN. Drücken Sie die PORN-Taste, um es zurückzusetzen. Das Board befindet sich nun im FWDN-Download-Modus.

</p>
<p align="center"><strong>Abbildung 7.2 Board in den Download-Modus versetzen</strong></p>

2. **Download-Befehl ausführen** : Verwenden Sie das FWDN-Werkzeug, um die Software für den 4MB-Flash auf das Board herunterzuladen

    ```
    $ sudo ../../../tools/fwdn_vcp/fwdn --fwdn ../../../tools/fwdn_vcp/vcp_fwdn.rom -w output\tcc70xx_pflash_boot_4M_ECC.rom
    ```

<p align="center"><strong>Abbildung 7.3 Download-Befehl ausführen</strong></p>

3. **Board zurücksetzen:** Nachdem der Download-Vorgang abgeschlossen ist, schieben Sie den FWDN-Schalter zurück in die Position NORMAL. Setzen Sie das Board zurück, indem Sie es entweder erneut einschalten oder die PORN-Taste drücken.

## 7.4 Überprüfen der Software auf dem Board

Sobald die Software auf das Board heruntergeladen wurde, ist es entscheidend, den korrekten Betrieb zu überprüfen:

1. **minicom installieren**  
    ```
    $ sudo apt install minicom
    ```
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/20a8f4ad-68da-472d-8b56-7a8fffad0643"></p>
<p align="center"><strong>Abbildung 7.5 Minicom installieren</strong></p>

2.  **Serielle Verbindung öffnen** : Verwenden Sie den folgenden Befehl, um eine serielle Verbindung herzustellen

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

</p>
<p align="center"><strong>Abbildung 7.6 Serielle Verbindung öffnen</strong></p>


3. **Nun sehen Sie das folgende Ergebnis im Terminal** : Wenn die Verbindung erfolgreich ist, sollten Sie mit dem Board interagieren und dessen Antworten beobachten können. Dies bestätigt, dass die Software heruntergeladen wurde und auf dem TOPST-VCP-Board korrekt arbeitet.

## 7.5 Behebung häufiger Probleme

Selbst bei sorgfältiger Vorbereitung können beim Download-Vorgang gelegentlich Probleme auftreten. Nachfolgend finden Sie Lösungen für einige häufige Probleme:

**Problem:** Das Werkzeug fwdn meldet fehlende Berechtigungen für den Zugriff auf das Gerät ttyUSB0.

**Lösung** : Dieses Problem tritt auf, wenn Ihr Benutzerkonto nicht über die erforderlichen Berechtigungen für den Zugriff auf serielle Geräte verfügt. Sie können Ihrem Benutzerkonto diese Berechtigungen erteilen, indem Sie es der Gruppe dialout hinzufügen.

1. **Berechtigungen der Benutzergruppe ändern** : Führen Sie den folgenden Befehl aus

    ```
    $ sudo usermod -aG dialout $USER
    ```
<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/a7552057-86de-4c49-876d-d50435bd16e4">
</p>
<p align="center"><strong>Abbildung 7.8 Berechtigungen der Benutzergruppe ändern</strong></p>


2. **Abmelden und wieder anmelden** : Damit die Gruppenänderung wirksam wird, müssen Sie sich von Ihrer aktuellen Sitzung abmelden und anschließend wieder anmelden. Versuchen Sie danach erneut, auf das Gerät ttyUSB0 zuzugreifen

Denken Sie daran, dass es für die meisten auftretenden Probleme Lösungen oder Umgehungen gibt. Es ist wichtig, die Fehlermeldungen zu verstehen und im Zweifelsfall die Dokumentation oder Online-Communities zu Rate zu ziehen.

**Problem** : Bei der Verwendung von minicom kommt keine ordnungsgemäße Kommunikation zustande oder das TOPST-VCP-Board verhält sich unregelmäßig.

**Lösung** :Das Problem kann auftreten, weil die Flusssteuerung in minicom standardmäßig auf Hardware eingestellt ist. Für eine reibungslose Kommunikation mit dem TOPST-VCP-Board müssen Sie die Flusssteuerung auf "none" setzen.


1. **minicom starten :**

    Starten Sie das Werkzeug minicom, indem Sie einfach Folgendes eingeben :

    ```
    $ minicom -D /dev/ttyUSB0 -b 115200 -8
    ```

    <img src="https://github.com/topst-development/Documentation/assets/161264431/7f8fd60c-eb59-474e-99f2-a5ab9cc6abc8">
</p>
<p align="center"><strong>Abbildung 7.9 minicom starten</strong></p>

2. **Setup-Bildschirm aufrufen :** Drücken Sie in minicom Ctrl-A gefolgt von “o”, um den Setup-Bildschirm aufzurufen.

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/79fa7579-374f-4714-9490-3a1d3fe40a70">
</p>
<p align="center"><strong>Abbildung 7.10 Setup-Bildschirm aufrufen</strong></p>

3. **Zu Serial Port Setup navigieren** : Wählen Sie in der Liste der Optionen "Serial port setup"
4. **Flusssteuerung ändern :** Drücken Sie im Serial Port Setup “ F”, um die Hardware-Flusssteuerung auf "No" umzuschalten.

<p align="center">
    <img src="https://github.com/topst-development/Documentation/assets/161264431/9c4ac77c-1e19-4bee-a0f3-f3ad6f3b3791">
</p>
<p align="center"><strong>Abbildung 7.11 Flusssteuerung ändern</strong></p>

5. **Beenden und speichern** : Wenn Sie fertig sind, beenden Sie das Setup und speichern Sie die Konfiguration. Nun sollte minicom ordnungsgemäß mit dem TOPST-VCP-Board kommunizieren.
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/e9c61695-1637-470c-b91f-34ddeff4a923"></p>
<p align="center"><strong>Abbildung 7.12 Beenden und speichern</strong></p>

**Hinweis**: Wenn Sie ein anderes serielles Kommunikationswerkzeug als minicom verwenden,stellen Sie ebenso sicher, dass Sie dessen Flusssteuerung für den korrekten Betrieb auf "none" setzen.
