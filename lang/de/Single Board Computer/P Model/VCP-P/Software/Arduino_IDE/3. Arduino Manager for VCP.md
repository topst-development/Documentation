# 3. TOPST VCP Arduino Board Manager

Dieses Repository enthält den Arduino Board Manager für TOPST VCP. Mit diesem Board Manager können Benutzer die Unterstützung für TOPST VCP Boards einfach zur Arduino IDE hinzufügen und Programme mit den vertrauten Werkzeugen schreiben und hochladen.

<br/><br/>

## 3.1 Funktionen

- Einfache Installation der Board-Definitionen für TOPST VCP.
- Kompatibel mit der Arduino IDE.
- Unterstützt alle wichtigen TOPST VCP Board-Modelle.

<br/><br/>

## 3.2 Installation

Gehen Sie wie folgt vor, um den TOPST VCP Board Manager in der Arduino IDE zu installieren:

1. Öffnen Sie die Arduino IDE **mit Administratorrechten**.
2. Gehen Sie zu `File > Preferences`.
3. Fügen Sie im Feld "Additional Board Manager URLs" die folgende URL hinzu:
   ```
   https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
   ```
   Wenn dieses Feld bereits andere URLs enthält, trennen Sie diese durch Kommas.

4. Klicken Sie auf "OK", um die Einstellungen zu speichern.
5. Gehen Sie zu `Tools > Board > Boards Manager...`.
6. Suchen Sie im Boards Manager nach "TOPST VCP".
7. Klicken Sie neben dem Eintrag für TOPST VCP auf "Install".

<br/><br/>

## 3.3 Verwendung

Nach der Installation können Sie Ihr TOPST VCP Board im Menü `Tools > Board` der Arduino IDE auswählen. Wählen Sie das Board aus, das Ihrer Hardware entspricht, und schreiben und laden Sie Ihre Sketches anschließend wie gewohnt hoch.
