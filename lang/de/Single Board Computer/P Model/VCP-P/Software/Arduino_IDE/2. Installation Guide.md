# 2. Installationsanleitung für den TOPST VCP Arduino Core

Diese Anleitung hilft Ihnen beim Herunterladen und Installieren des TOPST VCP Arduino Core zur Verwendung mit der Arduino Integrated Development Environment (IDE).

<br/><br/>

## 2.1 Installationsanleitung

### Schritt 1: Arduino IDE herunterladen

Zunächst benötigen Sie die Arduino IDE, die als Plattform zum Programmieren Ihrer Arduino-Boards dient.

- Besuchen Sie die offizielle Arduino-Website: [Arduino Software](https://www.arduino.cc/en/software)
- Wählen Sie die für Ihr Betriebssystem geeignete Version aus (Windows, macOS, Linux).
- Laden Sie das Installationsprogramm herunter und führen Sie es aus.

<br/>

### Schritt 2: Arduino IDE installieren

Führen Sie je nach Betriebssystem die folgenden Schritte aus, um die Arduino IDE zu installieren:

#### Windows:
1. Führen Sie die heruntergeladene `.exe`-Datei aus.
2. Folgen Sie den Anweisungen des Installationsprogramms. Stellen Sie sicher, dass Sie alle erforderlichen Treiber installieren.

#### macOS:
1. Öffnen Sie die `.dmg`-Datei.
2. Ziehen Sie die Arduino-Anwendung in Ihren Ordner „Applications“.

#### Linux:
1. Entpacken Sie die `.tar.xz`-Datei.
2. Öffnen Sie ein Terminal im entpackten Verzeichnis.
3. Führen Sie `./install.sh` aus, um die Installation zu starten.

<br/>

### Schritt 3: Das TOPST VCP Board hinzufügen

Um das TOPST VCP Board zu programmieren, müssen Sie dessen Core über den Board Manager zur Arduino IDE hinzufügen.

1. Öffnen Sie die Arduino IDE.
2. Navigieren Sie zu **Datei > Einstellungen**.
3. Fügen Sie im Feld „Additional Board Manager URLs“ die folgende URL für den TOPST VCP Core hinzu:

    ```
    https://raw.githubusercontent.com/topst-vcp/topst-vcp-board-manager/main/package_topst_vcp_index.json
    ```

    (Hinweis: Ersetzen Sie die obige URL durch die tatsächlich für den TOPST VCP Core bereitgestellte URL.)
4. Klicken Sie auf „OK“, um Ihre Änderungen zu speichern.
5. Gehen Sie zu **Werkzeuge > Board > Boards Manager**.
6. Suchen Sie im Boards Manager nach „TOPST VCP“.
7. Klicken Sie auf „Install“, wenn der Eintrag TOPST VCP erscheint.

<br/>

### Schritt 4: Das TOPST VCP Board auswählen

Nach der Installation müssen Sie das TOPST VCP Board auswählen:

1. Gehen Sie zu **Werkzeuge > Board**.
2. Scrollen Sie nach unten zu „TOPST VCP“ und wählen Sie es aus.

<br/>

### Schritt 5: Installation überprüfen

Testen Sie, ob Ihre Einrichtung funktioniert, indem Sie einen einfachen Sketch hochladen:

1. Schließen Sie das TOPST VCP Board über USB an Ihren PC an.
2. Wählen Sie unter **Werkzeuge > Port** den passenden Anschluss aus.
3. Öffnen Sie **Datei > Beispiele > 01.Basics > Blink**.
4. Drücken Sie die Schaltfläche **Hochladen**, um den Sketch auf das Board zu übertragen.
5. Wenn die Onboard-LED zu blinken beginnt, ist das Board korrekt eingerichtet.

<br/><br/>

## 2.2 Fehlerbehebung

Wenn während der Einrichtung Probleme auftreten, finden Sie weitere Informationen im [Arduino Troubleshooting Guide](https://www.arduino.cc/en/Guide/Troubleshooting).


Weitere Informationen und erweiterte Funktionen finden Sie in der TOPST VCP Dokumentation oder unter [Arduino Help Center](https://support.arduino.cc/hc/en-us).
