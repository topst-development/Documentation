# 7. Tastenanschluss (J10D1)


J10D1 ist ein standardmäßiger 20-poliger Anschluss mit 2 mm Raster zum Anschließen einer externen Tastenfunktion.  
Wenn Sie andere Schalterfunktionen verwenden möchten, muss zunächst eine Tasten-Zusatzplatine entwickelt werden.
