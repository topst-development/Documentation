# 5. Anschluss (JC1) für Debugging und FWDN  


Auf dem TOPST VCP wird JC1 für Debugging oder FWDN über UART verwendet.  
Dies ist ein standardmäßiger USB-Typ-C-Anschluss.  

Abbildung 5.1 zeigt die Position von JC1.  
<p align="center"><img src="https://github.com/topst-development/Documentation/assets/161264431/8b19656c-59d5-4389-87f3-4939bf501587"></p>  
<p align="center"><strong>Abbildung 5.1 USB-Typ-C-Anschluss</strong></p>  

Über JC1 können Sie FWDN durchführen oder die Debugging-Meldungen des TCC7045 prüfen.  
Auf dem TOPST VCP ist für JC1 ein USB-zu-UART-Bridge-Controller vorgesehen, und Sie können JC1 mit dem USB-Typ-C-Kabel direkt an den PC anschließen.
