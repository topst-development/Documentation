# 3. Boot-Modus (SW2)


Das TOPST VCP verfügt über einen Pin für die Boot-Konfiguration über den Boot-Modus (BM) und unterstützt 2 Modi:  
UART-Boot-Modus und Normalmodus.

Der Schiebeschalter (SW2) dient zur Auswahl der Boot-Modi des TOPST VCP.

## 3.1 UART-Boot-Modus
Dieser Modus ist hauptsächlich für den Firmware-Download-Modus (**FWDN**) vorgesehen.
In diesem Modus können Sie über den UART-Anschluss ein Programm in einen benutzerdefinierten Bereich herunterladen.


Tabelle 3.2 beschreibt die Einstellung des Schiebeschalters für den UART-Boot-Modus.
