# 2. Boot-Modi im AI-G
---
AI-G unterstützt die folgenden Boot-Modi: 
- USB Boot Mode (FWDN)  
- eMMC Boot Mode (GPIO_SD Group)

Das AI-G Board ist standardmäßig auf den eMMC Boot Mode festgelegt. Wenn sich kein Boot-Image im eMMC-Gerät befindet, wird der Boot-Modus automatisch auf den FWDN Boot Mode umgeschaltet. 

<br/><br/><br/>

## 2.1 USB Boot Mode (FWDN)
--- 
Abbildung 2.1 zeigt den Boot-Mode-Schalter und den RESET-Schalter. Der USB Boot Mode wird für Firmware-Updates verwendet. Um in den FWDN-Modus zu gelangen, werden sowohl der Boot-Mode-Schalter als auch der RESET-Schalter benötigt. Es wird empfohlen, diese Methode beim Hochladen des Image zu verwenden.

<p align="center"><strong>Abbildung 2.1 Boot-Mode-Schalter und RESET-Schalter zum Aufrufen des FWDN Boot Mode </strong></p><br/>

Die folgenden Schritte beschreiben die Bedienung der Schalter zum Aufrufen des USB Boot Mode. 
1. Wenn die Stromversorgung anliegt, leuchtet die LED über dem RESET-Schalter auf. 
2. Halten Sie den Boot-Mode-Schalter gedrückt. Wenn Sie den Boot-Mode-Schalter drücken, sehen Sie, wie die rote LED über dem Boot-Mode-Schalter aufleuchtet. Halten Sie den Schalter weiterhin gedrückt, damit die LED leuchtet. 
3. Die LED des RESET-Schalters ist standardmäßig grün. Wenn Sie den RESET-Schalter einmal drücken, erlischt die grüne LED und leuchtet dann wieder auf. 
4. Lassen Sie den Boot-Mode-Schalter los.
