# 1. Einführung
---
Dieses Dokument stellt eine Sammlung neuronaler Netze bereit, die für AI-G optimiert sind. Das in Kapitel 2.1 vorgestellte Repository enthält verschiedene Modelle für Aufgaben wie Klassifizierung und Objekterkennung. Dieses Repository wird in einem sofort ausführbaren Format für Evaluierungsboards bereitgestellt und enthält Benchmark-Ergebnisse, die die Leistung und Effizienz von AI-G belegen.
<br/><br/><br/>

# 2. Erste Schritte
---
Führen Sie die folgenden Schritte aus, um ein vom Telechips Model Zoo bereitgestelltes neuronales Netz auf dem AI-G-Board auszuführen.
<br/><br/><br/>

## 2.1 Repository klonen
---
```
$ git clone https://github.com/telechips-ai/TCC750x-Model-Zoo.git

$ cd TCC750x-Model-Zoo
```
<br/><br/><br/>

## 2.2 Gewünschtes Modell auf das AI-G kopieren
---
Kopieren Sie den gesamten Modellordner (yolov5m) auf das AI-G.
Sie können den Ordner entweder unverändert kopieren oder ihn in yolov5m_quantized umbenennen, damit er dem Format der zuvor veröffentlichten Ordner für neuronale Netze entspricht, wie im folgenden Beispiel gezeigt.
Jeder Ordner enthält die erforderlichen Ausgabedateien (.so, .bin usw.).

```
$ scp -r [network_output_folder] root@192.168.0.100:/path/to/target/
```
Ersetzen Sie **network_output_folder** durch den tatsächlichen Ordner (z. B. yolov5m/).

Sie können das yolov5-Modell auswählen.
```
$ cd Object_Detection/YOLO/yolov5/
$ ls 
README.md  yolov5l  yolov5m  yolov5n  yolov5s  yolov5x
```
Führen Sie dann Folgendes aus:
```
$ scp -r yolov5m/ root@192.168.0.100:/home/root/
```
<br/><br/><br/>

## 2.3 Modell mit tcnputestapp oder tcnnapp ausführen:
---
Führen Sie anschließend den folgenden Befehl auf dem Zielboard (AI-G) aus:
```
$ tcnputestapp -d 0 1 -n [network_output_folder_path]
```
oder 
```
$ tcnnapp -n [network_output_folder_path]
```
