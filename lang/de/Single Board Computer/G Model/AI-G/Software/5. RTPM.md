# 1. Einführung
---
Das RTPM-Toolkit (Real-Time Performance Monitor) ist eine Python-basierte grafische Anwendung, die dazu dient, die Leistungsdaten des AI-G in Echtzeit zu überwachen und zu visualisieren. Durch die Herstellung einer Verbindung zwischen dem AI-G-Board und einem Host-PC ermöglicht RTPM die Übertragung und Analyse wichtiger Leistungsdaten, darunter CPU-, NPU- und Speicherauslastung sowie Inferenzzeiten.
 
RTPM arbeitet in zwei unterschiedlichen Modi:
 
**Injection Mode**: In diesem Modus sendet der Host-PC die Bilddaten zur Verarbeitung an das AI-G. Das AI-G führt die Inferenz mit seiner NPU durch und gibt die Ergebnisse zur Visualisierung an den PC zurück.
 
**Projection Mode**: In diesem Modus erfasst das AI-G Bilder über die angeschlossene Kamera, verarbeitet sie intern und überträgt die Inferenzergebnisse an das RTPM auf dem Host-PC.
 
Dieses Toolkit ist besonders nützlich für Entwickler und Ingenieure, die die Leistung von KI-Anwendungen auf der AI-G-Plattform bewerten und optimieren möchten. Es bietet Einblicke in das Systemverhalten in Echtzeit und ermöglicht effizientes Debugging und Performance-Tuning.
 
Ausführliche Anweisungen zur Einrichtung und Hinweise zur Verwendung finden Sie in den nachfolgenden Abschnitten dieses Dokuments.

## 2.1 Leistungsüberwachung
--- 
Das Real-Time Performance Monitoring Toolkit (RTPM) ist ein GUI-basiertes Werkzeug, das
mit Python entwickelt wurde, die Ausgabe des AI-G in einer PC-Umgebung überwacht
und Ihnen das Prüfen von CPU-, NPU- und Speicherleistungsdaten ermöglicht.
 
 
 
**Tabelle 2.1 Liste der Leistungsdaten von RTPM:**
 
|   No   |  Leistungsdaten      |                Beschreibung            |
|--------|----------------------|----------------------------------------|
| 1      | Inferenzzeit         | Inferenzzeit für jedes Modell (ms)     |
| 2      | NPU-Auslastung       | NPU-Auslastung für jedes Modell        |
| 3      | FPS                  | FPS-Daten basierend auf NPU-Betrieb    |
| 4      | CPU                  | CPU-Auslastung (Zyklus 500 ms)         |
| 5      | Speicher             | Speicherauslastung (Zyklus 500 ms)     |

## 2.4 Anleitung zum Starten der RTPM-Anwendung
---
Dieser Abschnitt enthält eine Schritt-für-Schritt-Anleitung zur Einrichtung der Anwendung Real-Time Performance Monitor (RTPM) auf einem Host-PC.
Er umfasst die Installation der Werkzeuge, die Konfiguration des Workspace und die Ausführung der RTPM-Oberfläche zur Überwachung der NPU-Leistung und der Inferenzergebnisse auf dem AI-G.
 
<br/><br/>
 
### 2.4.1 Werkzeuge für RTPM installieren
 
- Bereiten Sie die Host-PC-Umgebung vor.
 
1. Installieren Sie Visual Studio Code.
   * Suchen Sie im Microsoft Store nach „Visual Studio Code“ und installieren Sie es.
 
<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/NPU%20development/RTPM/5.%20Install%20Visual%20Studio%20Code.png"></p>

   *Ctrl + Shift + X* drücken.
   3. Geben Sie in der Suchleiste der Extensions-Ansicht Python ein.
   4. Suchen Sie die von Microsoft bereitgestellte Python-Erweiterung und klicken Sie auf Install.
