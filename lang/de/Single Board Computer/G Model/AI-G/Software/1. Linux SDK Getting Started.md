# 1. Einführung
---
Dieses Dokument enthält Richtlinien für das Erstellen des AI-G SDK, einschließlich der Einrichtung der Host-Umgebung, des Erstellens des SDK, der Verwendung des Firmware-Downloaders und der Verbindung des AI-G mit einem PC.

Dieses Dokument enthält Informationen zu den folgenden Themen: 
- Einrichten der Host-Umgebung  
- Anleitung zum Erstellen des Image  
- Anleitung zum Firmware-Download 
- Verbinden des AI-G-Boards mit einem PC

<br/><br/><br/><br/>

# 2. Einrichten der Host-Umgebung (Windows)
---
In diesem Kapitel wird beschrieben, wie die Umgebung des Host-PCs eingerichtet wird, mit separaten Anleitungen für die Einrichtung auf einem Windows-PC und einem Ubuntu-PC.
<br><br/><br/>

## 2.1 Windows-Umgebung
--- 
Dieses Dokument beschreibt, wie Sie das Windows Sub-system for Linux (WSL) einrichten, um Linux auf einem Windows-PC zu verwenden.
Da das AI-G Linux SDK auf dem Yocto Project basiert, richtet sich die Linux-Version des AI-G SDK nach dem Yocto Project.
Sie können eine andere Linux-Version installieren, in diesem Dokument wird das AI-G Linux SDK jedoch auf Basis von Ubuntu 22.04 beschrieben.
Wenn das Host-Betriebssystem Ubuntu ist, fahren Sie mit Abschnitt 2.2 fort.
</br><br/>

### 2.1.1 WSL2 Ubuntu installieren (nur Windows-Umgebung)

1. Führen Sie Windows PowerShell mit „**Als Administrator ausführen**“ aus
2. Aktivieren Sie das WSL2-System.
    ```
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```
3. Aktivieren Sie die Funktion für virtuelle Maschinen.
    ```
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
4. Legen Sie WSL standardmäßig auf Version 2 (WSL2) fest.
    ```
    wsl --set-default-version 2
    ```
5. Suchen Sie im Microsoft Store nach Ubuntu 22.04.3 LTS und laden Sie es herunter.

    * Wenn Sie das Linux-Kernel-Updatepaket herunterladen müssen, laden Sie das neueste Paket [hier](https://learn.microsoft.com/ko-kr/windows/wsl/install-manual) herunter.

6. Sie können während der Ubuntu-Installation einen beliebigen Benutzernamen wählen.

<br/><br/>


### 2.1.2 Zugriff auf Ubuntu über WSL2
Öffnen Sie die Windows-Eingabeaufforderung und geben Sie den folgenden Befehl ein, um auf Ubuntu zuzugreifen. Wenn Sie auf Ubuntu zugreifen, startet es standardmäßig im Verzeichnis /mnt/c/Users/[user name].
```
wsl  // access ubuntu 
ls   // check contents in your directory
```

### 2.1.3 Locale festlegen

Nachdem Sie Ubuntu unter WSL gestartet haben, sollten Sie die Locale festlegen, um korrekte Sprach- und Regionaleinstellungen sicherzustellen. Es wird empfohlen, en_US.UTF-8 zu verwenden. Führen Sie die folgenden Befehle aus, um en_US.UTF-8 zu verwenden. 

```
sudo locale-gen en_US.UTF-8 && sudo update-locale LANG=en_US.UTF-8 
```

Nachdem Sie die Locale festgelegt haben, können Sie den Locale-Typ mit den folgenden Befehlen prüfen. 

```
echo 'LANG=en_US.UTF-8' | sudo tee -a /etc/default/locale && \  

echo 'LC_ALL=en_US.UTF-8' | sudo tee -a /etc/default/locale 
```
<br/><br/>

### 2.1.4 SSH und Samba installieren 

Nachdem Sie Ubuntu gestartet haben, können Sie zusätzliche Dienstprogramme wie SSH und Samba für eine komfortablere Entwicklungsumgebung verwenden. SSH und Samba ermöglichen es Ihnen, Befehle auf entfernten Computern auszuführen und Dateien auf andere Computer zu kopieren.
 - Für die folgenden Schritte muss der Host-PC mit dem Netzwerk verbunden sein. Prüfen Sie Ihren Netzwerkzustand mit den folgenden Befehlen:
  ```
  $ sudo apt-get update
  $ sudo apt-get install -y net-tools
  $ ifconfig 
  ```

Wenn SSH und Samba bereits installiert sind oder Sie sie nicht verwenden möchten, können Sie dieses Kapitel überspringen.

Verwenden Sie den folgenden Befehl, um net-tools, SSH und Samba zu installieren.

```
$ sudo apt-get update 
$ sudo apt install -y net-tools openssh-server samba
```


Nachdem Sie SSH und Samba heruntergeladen haben, sollten Sie jedes Programm an Ihre Umgebung anpassen.
<br/><br/>

### 2.1.5 Dienstprogramme installieren 

Installieren Sie die Dienstprogramme auf einmal. Um das Yocto Project zu verwenden, müssen die folgenden Dienstprogramme auf dem Host-PC (Personal Computer oder Entwicklungsserver) installiert sein.

Verwenden Sie den folgenden Befehl, um die Dienstprogramme zu installieren.

```
$ sudo apt-get install -y gawk wget git diffstat unzip texinfo gcc-multilib build-essential chrpath

$ sudo apt-get install -y socat cpio python3 python3-pip python3-pexpect xz-utils debianutils

$ sudo apt-get install -y iputils-ping python3-git python3-jinja2 libegl1-mesa-dev libsdl1.2-dev pylint

$ sudo apt-get install -y xterm zstd ncftp curl git-lfs vim zip lz4
```
<br/><br/>


### 2.1.6 Repo installieren (optional)

Sie können das AI-G SDK mit ***Repo*** herunterladen.  
Weitere Informationen zur Installation von ***Repo*** finden Sie auf der folgenden Website: https://source.android.com/source/downloading.html.  
Wenn ***Repo*** bereits installiert ist, können Sie es ohne Neuinstallation verwenden.  
Bevor Sie ***Repo*** installieren, stellen Sie sicher, dass Python Version 3.6 oder höher korrekt eingerichtet ist.

Verwenden Sie den folgenden Befehl, um ***Repo*** zu installieren.
```
$ sudo apt-get install repo
```

Wenn die Fehlermeldung '/usr/bin/env 'python' no such file or directory' angezeigt wird, verwenden Sie den folgenden Befehl, mit dem die Datei 'python' auf 'python3' verweist.

```
$ sudo ln -sf /usr/bin/python3 /usr/bin/python
```
Wenn ein ***Repo***-Fehler auftritt, verwenden Sie den folgenden Befehl, um die neueste Version herunterzuladen und sie direkt in den Ordner /usr/bin/ zu legen.

```
$ mkdir -p ~/bin

$ curl http://commondatastorage.googleapis.com/git-repo-downloads/repo > ~/bin/repo

$ chmod a+x ~/bin/repo

$ sudo mv ~/bin/repo /usr/bin/repo
```
Fahren Sie mit **Kapitel 3: Anleitung zum Erstellen des Image** fort.

# 3. Anleitung zum Erstellen des Image
---
Dieser Abschnitt bietet eine Anleitung auf Basis des auf dem Host-PC installierten Ubuntu-Betriebssystems (unabhängig davon, ob es sich um WSL oder eine lokale Ubuntu-Installation handelt). Das auf den AI-G zu übertragende Image wird mit dem Yocto Project erstellt, daher muss der Vorgang in der Ubuntu-Umgebung durchgeführt werden.
<br/><br/><br/>

## 3.1 Vorbereitung des SDK-Builds
---
Das AI-G SDK basiert auf Yocto Project 4.0 Kirkstone. Daher muss die Yocto-Project-Umgebung auf dem Host-PC eingerichtet werden, um das AI-G SDK zu verwenden. Um SDK, source-mirror und Tools herunterzuladen, müssen Sie Dienstprogramme installieren. Damit das Image reibungslos erstellt werden kann, muss Ihr PC über **mindestens 60 GB verfügbaren Speicherplatz** und **mindestens 16 GB RAM** verfügen.

<br/><br/><br/>

## 3.2 Yocto Project
---
Das Yocto Project ist ein Open-Source-Projekt, das sich auf die Entwicklung von eingebettetem Linux konzentriert. 
Es verwendet eine Kombination aus Poky, das Teil des Open-Embedded-Projekts ist, und bitbake als Build-System, um Linux-Images zu erstellen. 
Mit dem Yocto Project können Sie Bootloader, Kernel und rootfs gleichzeitig erstellen. 

<br/><br/><br/>

## 3.3 Task-Prozess des Yocto Project
---
Abbildung 3.1 zeigt den Task-Prozess des Yocto Project. Sie können den Quellcode auf Basis von Metadaten aus Upstream-Repositories herunterladen und ihn anschließend erstellen. Nach Abschluss des Builds werden Package, Image und SDK als Ergebnisse bereitgestellt.

## 3.5 Vorbereitung des Builds

<br/><br/>

### 3.5.1 Benutzer-E-Mail und Benutzernamen in .gitconfig festlegen
Um AI-G aus dem offiziellen TOPST-git herunterzuladen, konfigurieren Sie Ihre E-Mail-Adresse und Ihren Namen.
1. Geben Sie den folgenden Befehl ein.
```
vi ~/.gitconfig
```
2. Geben Sie die folgenden Informationen ein.
```
[user]
    email = User email
    name = User name
```
<br/><br/>

### 3.5.2 AI-G aus Git beziehen
1. Erstellen Sie ein neues Verzeichnis mit dem Namen **topst-sdk** und wechseln Sie in das Verzeichnis **topst-sdk**.
```
$ mkdir topst-sdk
$ cd topst-sdk
```
2. Führen Sie den folgenden Befehl aus, um das Repository zu initialisieren.

```
$ repo init -u https://github.com/topst-development/manifests.git -b release/1.3.0 -m linux_yp4.0_topst.xml
```

# 4. Firmware-Downloader
---
In diesem Kapitel wird beschrieben, wie Sie ***FWDN*** auf das AI-G herunterladen und sich an der Linux-Konsole anmelden.  
***FWDN V8*** ist ein PC-Werkzeug zum Herunterladen von Firmware in 64-Bit-Umgebungen von Windows 10 oder 11 sowie unter Linux. In diesem Kapitel wird das Herunterladen in Windows- und Linux-Umgebungen beschrieben.
<br/><br/><br/>

## 4.1 Ablauf des Firmware-Downloads
---
Der Ablauf des Herunterladens mit ***FWDN*** ist wie folgt:

1. Stellen Sie den Boot-Modus-Schalter auf den USB-Boot-Modus (FWDN-Modus).
2. Öffnen Sie die Windows-Eingabeaufforderung oder die Linux-Konsole und testen Sie ***FWDN V8***.
3. Verbinden Sie ***FWDN V8*** mit dem Board.
4. Laden Sie die fai-Datei herunter.

<br/><br/><br/>

## 4.2 USB-Boot-Modus (FWDN-Modus) 
---
Sie können das erstellte Image mit ***FWDN*** auf das AI-G übertragen. AI-G stellt ***FWDN*** über Ethernet und UART bereit. 

<p align="center"><img src="https://raw.githubusercontent.com/topst-development/Documentation/refs/heads/main/Assets/TOPST%20AI-G/Software/Linux%20SDK/3.%20connect%20host%20pc%20to%20topst%20ai-g.png" ></p>
<p align="center"><strong>Abbildung 4.1 Verbindung zwischen Host-PC und AI-G für FWDN</strong></p><br/>

Um ***FWDN V8*** zu verwenden, schließen Sie das AI-G-Board wie folgt an den Host-PC an: 

1. Prüfen Sie, ob der VTC-Treiber auf dem Host-PC installiert ist. Falls der VTC-Treiber nicht installiert ist, installieren Sie ihn wie in Kapitel 4.2.1 beschrieben.  

2. Halten Sie ein USB-Type-C-Kabel und ein Ethernet-Kabel bereit. 

3. Um in den USB-Boot-Modus zu gelangen, verbinden Sie das USB-Type-C-Kabel mit dem USB-Type-C-FWDN-Anschluss am AI-G-Board und mit dem Host-PC. 

4. Verbinden Sie das Ethernet-Kabel (RJ45) mit dem Ethernet-Anschluss am AI-G-Board und mit dem Host-PC. 

5. Schließen Sie das Netzkabel an das AI-G-Board an, während Sie den FWDN-Schalter gedrückt halten. 

<br/><br/><br/>

### 4.2.1 Installation des VCP-Treibers

Installieren Sie den Vendor Telechips Certification (VTC)-Treiber (zu finden unter [VCP-Treiber](https://drive.google.com/file/d/1muQnY8kuKxDsy3p3FUiQqcG34Zjk-mnR/view?usp=sharing)) auf dem Host-PC, indem Sie ihn als Administrator ausführen. Wenn Sie das USB-Kabel wie oben gezeigt im FWDN-Modus anschließen, wird der Telechips VTC USB-Treiber wie in Abbildung 4.2 gezeigt eingerichtet.

## 4.3 Ausführen von FWDN
---
Bevor Sie ***FWDN*** ausführen, müssen Sie zunächst das Image und das ***FWDN***-Werkzeug, die Sie nach dem Build erstellt haben, von Ubuntu (WSL2) in die Windows-Umgebung übertragen. 
Wenn Sie einen Ubuntu-Host verwenden, können Sie die folgenden Schritte überspringen und zu Kapitel 4.3.2 wechseln.

1. Entpacken Sie "output_aig.fwdn.zip"
```
$ cd ~/topst-sdk
$ mkdir images
$ mv ./output_aig.fwdn.zip ./images 
$ cd images
$ unzip output_aig.fwdn.zip
```

2. Kopieren Sie den Ordner "images" auf das Windows-Laufwerk C. 
```
$ cd ..
$ cp -r ./images /mnt/c/ 
```
Weitere Informationen zu den folgenden Schritten finden Sie je nach Betriebssystem Ihres Host-PCs in Kapitel 4.3.1 oder Kapitel 4.3.2.
<br/><br/>

3. Führen Sie Windows PowerShell aus und wechseln Sie zu “C:\images”.  
```
$ cd C:\images 
```
4. Geben Sie den Befehl **.\fwdn_nd.bat** ein, um den Firmware-Download zu starten. Die Datei “fwdn_nd.bat” ist eine ausführbare Datei, die Firmware automatisch mithilfe von ***FWDN V8*** herunterlädt.

### 4.3.2 FWDN in der Linux-Umgebung ausführen 

In einer Linux-Umgebung können Sie das AI-G-Image herunterladen, indem Sie den folgenden Befehl eingeben. 

```
./fwdn.sh 
```

## 4.4. Verbindung des AI-G-Boards über UART
--- 
Führen Sie die folgenden Schritte aus und überprüfen Sie über die UART-Verbindung, ob der Firmware-Download erfolgreich abgeschlossen wurde.  

1. Installieren Sie den Treiber für die serielle Schnittstelle (zum Beispiel CP210x Windows Driver) und den PL2303_prolific-Treiber in der Windows-Umgebung.
2. Installieren Sie einen Terminal-Emulator wie Tera Term oder PuTTY. 
3. Verbinden Sie den Host-PC mit dem UART-Pin am AI-G-Board. Verwenden Sie ein USB-zu-TTL-Kabel. 
4. Schließen Sie das schwarze Kabel an den GND-Pin an. 
5. Schließen Sie das weiße Kabel (RXD) an den TX-Pin der UART-Pins an und das grüne Kabel (TXD) an den RX-Pin der UART-Pins.
6. Starten Sie die Terminal-Emulator-Anwendung.
7. Öffnen Sie den Geräte-Manager auf Ihrem PC und prüfen Sie die Portnummer, die für UART verwendet wird.
8. Geben Sie die im Geräte-Manager ermittelte Portnummer in das Feld **Serial line** im Terminal-Emulator ein. Setzen Sie **Speed** (bps) auf 115200 und **Flow control to None.**
9. Schließen Sie das Netzkabel an. Anschließend startet das AI-G im standardmäßigen eMMC-Boot-Modus.
