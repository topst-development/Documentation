# Endbenutzer-Lizenzvereinbarung (EULA)

Dieses SDK wird zur uneingeschränkten Nutzung, Änderung und Verbreitung bereitgestellt, soweit nicht durch geltende Gesetze und die nachstehenden Bedingungen eingeschränkt. Wenn Sie diesen Bedingungen nicht zustimmen, nutzen Sie das SDK nicht.
